<Exercise
  id="practice-02-math-5"
  kind="build"
  level={3}
  name="丸いテーブル"
  stdin={`120
60`}
  tests={[
    { kind: 'stdout', stdin: `120\n60\n` },
    { kind: 'stdout', stdin: `0\n50\n` },
    { kind: 'stdout', stdin: `100\n100\n` },
    { kind: 'stdout', stdin: `150\n45\n` },
  ]}
  hints={['先に円周の長さを求めて、丸める前の値を変数に入れます。', '座れる人数は、円周に1人の幅が何回入るかです。小数を整数に切り捨てる書き方は、第2章1節にあります。']}
  syntax={['input', 'operators', 'round-math', 'print']}
>
丸いテーブルのまわりに、人が並んで座ります。テーブルの直径と、1人が座るのに要る幅から、円周の長さと、座れる人数を求めてください。

座れる人数は、円周の長さを1人の幅で割り、端数を切り捨てた数です。人数は、丸める前の円周の長さから求めます。

<Input>
- 1行目: テーブルの直径（cm、整数）
- 2行目: 1人が座るのに要る幅（cm、1以上の整数）
</Input>

<Output>
小数第1位までに丸めた円周の長さと、座れる人数を、この順に2行で表示します。人数は整数で、`6` のように小数点を付けずに表示します。
</Output>
</Exercise>
