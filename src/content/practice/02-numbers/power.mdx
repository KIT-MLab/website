<Exercise
  id="practice-02-power-5"
  kind="build"
  level={3}
  name="複利の貯金"
  stdin={`10000
5
3`}
  tests={[
    { kind: 'stdout', stdin: `10000\n5\n3\n` },
    { kind: 'stdout', stdin: `0\n3\n10\n` },
    { kind: 'stdout', stdin: `5000\n0\n7\n` },
    { kind: 'stdout', stdin: `1000\n10\n0\n` },
  ]}
  hints={['年利が5なら、1年で金額が1.05倍になります。2年なら、それをもう1回掛けます。', '同じ数を年数の回だけ掛けるのは、べき乗で書けます。丸めるのは最後です。']}
  syntax={['input', 'operators', 'round-math', 'print']}
>
お金を預けると、1年ごとに、そのときの金額の年利（%）ぶんだけ増えます。預けた金額・年利・年数から、預けたあとの金額を求めてください。途中の年の金額は丸めず、最後の金額だけを小数第2位までに丸めます。

<Input>
- 1行目: 預けた金額（円、整数）
- 2行目: 年利（%、整数）
- 3行目: 年数（整数）
</Input>

<Output>
預けたあとの金額を、数だけ1行で表示します。
</Output>
</Exercise>
