<Exercise
  id="practice-05-def-3"
  kind="build"
  level={2}
  name="電車の運賃表"

<Input>
- 1行目: 乗車の回数（1以上の整数）
- 2行目から: 乗車1回につき1行、乗る距離（km、1以上の整数）
</Input>

<Output>
乗車1回につき1行、距離と運賃を表示します。距離の数の後ろに `km` を、運賃の数の後ろに `円` を付けます。形は出力例のとおりです。
</Output>
</Exercise>

  syntax={['input', 'function', 'for', 'operators', 'print']}
>
植物を育てて、毎週の高さを測ります。測り始めの高さと毎週の高さから、週ごとの伸びを表示するプログラムを書いてください。

1週ぶんの表示は、関数 `show_growth(week, before, after)` にします。`week` は週の番号、`before` は前の週の高さ、`after` はその週の高さです。

- 1行目: 測り始めの高さ（cm、整数）
- 2行目: 測った週の数（1以上の整数）
- 3行目から: 1週につき1行、その週の高さ（cm、整数。前の週の高さと同じか、それより高い）
</Input>

<Output>
1週につき1行、週の番号と、その週の伸びを表示します。週の番号は1から数え、最初の週の伸びは、測り始めの高さからの伸びです。形は出力例のとおりです。
</Output>
</Exercise>
