<Exercise
  id="practice-04-for-5"
  kind="build"
  level={3}
  name="スタンプカード"
  stdin={`12`}
  tests={[
    { kind: 'stdout', stdin: `12\n` },
    { kind: 'stdout', stdin: `4\n` },
    { kind: 'stdout', stdin: `0\n` },
    { kind: 'stdout', stdin: `20\n` },
    { kind: 'stdout', stdin: `5\n` },
  ]}
  hints={['5回目と10回目のように、両方の条件に当てはまる回があります。どちらを先に確かめるかは、第3章3節の `elif` の順番で決まります。']}
  syntax={['input', 'for', 'if', 'operators', 'print', 'string']}
>
カフェのスタンプカードは、来店のたびにスタンプが1つ押されます。5回目、15回目のように、5の倍数の回にはボーナスがもらえます。

10回目、20回目のように、10の倍数の回には、ボーナスではなく割引券がもらえます。1回目から決めた回数まで、来店のたびに、その回の結果を表示してください。

<Input>
- 1行目: 来店する回数（0以上の整数）
</Input>

<Output>
1回目から、来店する回数までを、1行に1回ずつ表示します。ふつうの回は `1回目`、5の倍数の回は `5回目 ボーナス`、10の倍数の回は `10回目 割引券` の形です。回数が0のときは、何も表示しません。
</Output>
</Exercise>
