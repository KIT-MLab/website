<Exercise
  id="practice-04-total-1"
  kind="build"
  level={1}
  name="売店の売上合計"
  stdin={`4
3200
0
4150
2800`}
  forbid={['sum(']}
  tests={[
    { kind: 'stdout', stdin: `4\n3200\n0\n4150\n2800\n` },
    { kind: 'stdout', stdin: `0\n` },
    { kind: 'stdout', stdin: `1\n999\n` },
    { kind: 'stdout', stdin: `3\n500\n500\n500\n` },
  ]}
  hints={['合計を入れる変数を、繰り返しの前に決めておく書き方は、第4章1節の2つ目のコードを見てください。']}
  syntax={['input', 'for', 'variable', 'operators', 'print']}
>
学校の売店で、毎日の売上を記録しています。何日ぶんかの売上を、すべて足した合計を求めてください。`sum()` という関数を知っている人も、ここでは使わず、繰り返しで求めてください。

<Input>
- 1行目: 記録した日数（0以上の整数）
- 2行目から: 1日の売上（円、0以上の整数）。日数ぶんの行があります
</Input>

<Output>
売上の合計を、数だけで1行に表示します。日数が0のときは、0です。
</Output>
</Exercise>

</Output>
