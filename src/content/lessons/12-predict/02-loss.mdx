{/* 困る例 */}

AさんとBさんの直線のどちらが良いかは、予測の並びを見比べても決めにくいので、1つの数で決めたいです。ただ、差の2乗の和（第7章2節）は人数が増えるほど大きくなるので、平均にします。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

hours = np.array([2.0, 3.0, 5.0, 6.0, 8.0])
scores = np.array([45, 52, 65, 70, 82])

def predict(hours, a, b):
    return a * hours + b

def mse(pred, actual):
    return np.mean((pred - actual) ** 2)

pred1 = predict(hours, 6, 30)
pred2 = predict(hours, 8, 20)
print(mse(pred1, scores))
print(mse(pred2, scores))`}
  out={`16.4
35.6`}
/>

{/* 説明 */}

最初のコードの9〜10行目の `mse` は、予測 `pred` と実際の点数 `actual` の差を2乗し、平均をとる関数です。予測のずれの大きさを1つの数にしたものを損失と呼び、その測り方の1つが、この差の2乗の平均、つまり平均二乗誤差です。

人数で割って平均するので、人数が違っても1人あたりの大きさで比べられます。Aさんの直線で、先頭の4人と5人全員を比べて確かめます。

<Run
  code={`import numpy as np

hours = np.array([2.0, 3.0, 5.0, 6.0, 8.0])
scores = np.array([45, 52, 65, 70, 82])

squares = (6 * hours + 30 - scores) ** 2
print(np.sum(squares[:4]))
print(np.mean(squares[:4]))
print(np.sum(squares))
print(np.mean(squares))`}
  out={`66.0
16.5
82.0
16.4`}
/>

差の2乗の和は `66.0` から `82.0` に増えますが、平均は `16.5` と `16.4` で、ほとんど変わりません。

最初のコードの14〜15行目で、Aさんの直線の損失は`16.4`、Bさんの直線の損失は`35.6`です。損失が小さいAさんの直線のほうが、良い予測だと言えます。
