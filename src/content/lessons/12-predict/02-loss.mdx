{/* 困る例 */}

AさんとBさんの直線のどちらが良いかは、見た目では決められません。差の2乗の和（第7章1節）は人数が増えるほど大きくなるので、人数の違う集まりどうしでは比べられません。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

hours = np.array([2.0, 3.0, 5.0, 6.0, 8.0])
scores = np.array([45, 52, 65, 70, 82])

def predict(hours, a, b):
    return a * hours + b

def mse(pred, actual):
    return np.mean((pred - actual) ** 2)

pred1 = predict(hours, 6, 30)
pred2 = predict(hours, 8, 20)
print(mse(pred1, scores))
print(mse(pred2, scores))`}
  out={`16.4
35.6`}
/>

{/* 説明 */}

9〜10行目の `mse` は、予測 `pred` と実際の `actual` の差を2乗し、平均をとる関数です。この値を損失と呼びます。

差を2乗してから平均するので、人数がいくつでも1人あたりの大きさで比べられます。この損失を平均二乗誤差と呼びます。

Aさんの直線で、データの先頭の5人と先頭の10人を比べます。差の2乗の和は `82.0` から `133.0` に増えますが、平均は `16.4` と `13.3` で、同じ1人あたりの大きさとして比べられます。

14〜15行目で、Aさんの直線の損失は`16.4`、Bさんの直線の損失は`35.6`です。損失が小さいAさんの直線のほうが、良い予測だと言えます。
