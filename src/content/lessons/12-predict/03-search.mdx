第12章2節では、Aさんの直線の損失が `16.4` で、Bさんの直線の `35.6` より小さいことを確かめました。この節では、④の学習として、損失がいちばん小さくなる `a` と `b` を、候補を全部試して選びます。Aさんの直線より損失の小さい直線はあるでしょうか。

{/* 困る例 */}

損失が小さい `a` を見つけたいのですが、どんな `a` を試せばよいか分かりません。`b` も一緒に探すとなると、組み合わせはさらに増えます。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

hours = np.array([2.0, 3.0, 5.0, 6.0, 8.0])
scores = np.array([45, 52, 65, 70, 82])

def loss(a, b):
    pred = a * hours + b
    return np.mean((pred - scores) ** 2)

a_candidates = np.linspace(4, 8, 9)
b_candidates = np.linspace(20, 40, 11)

best_a = a_candidates[0]
best_b = b_candidates[0]
best_loss = loss(best_a, best_b)
for a in a_candidates:
    for b in b_candidates:
        current = loss(a, b)
        if current < best_loss:
            best_loss = current
            best_a = a
            best_b = b

print(best_a)
print(best_b)
print(round(best_loss, 2))`}
  out={`6.0
34.0
0.4`}
/>

{/* 説明 */}

6〜8行目の `loss` は、前の節の `predict` と `mse` を、`a` と `b` だけで呼べるようにまとめたものです。10行目の `np.linspace(4, 8, 9)` は、4から8まで等間隔に並んだ9個の値（4.0, 4.5, …, 8.0）で、これが `a` の候補です。11行目は同じ書き方で、20から40までの11個（20.0, 22.0, …, 40.0）を `b` の候補にしています。候補の範囲は、データを見て見当を付けて決めます。範囲の端が選ばれたら、範囲を広げて試し直します。

13〜15行目は、第4章2節で最大の値を探したときと同じく、最初の候補の組とその損失を、いまのところいちばん良い組として覚えておきます。

16〜18行目は、第4章1節で見た2重のfor文です。小さい例で、回る順番をもう一度確かめます。

<Run
  code={`for a in [1, 2, 3]:
    for b in [10, 20]:
        print(a, b)`}
  out={`1 10
1 20
2 10
2 20
3 10
3 20`}
/>

`a` が `1` のあいだに、`b` は `10`、`20` の順に変わります。次に `a` が `2` になり、また `b` が `10` から回ります。全部で 3 × 2 = 6 回です。この節の最初のコードでは、`a` の候補9個のそれぞれに `b` の候補11個を試すので、9 × 11 = 99 組の損失を計算します。

最初のコードの19〜22行目で、それまでより小さい損失が出るたびに、その `a`, `b`, 損失を覚え直します。24〜26行目では、最後に残った組を表示します。`a` は `6.0`、`b` は `34.0` で、損失は `0.4` です。Aさんの直線の `16.4` より、ずっと小さくなりました。

選ばれるのは、決めた候補の中で損失がいちばん小さい組です。候補の間隔を細かくすると、たいていはより良い組が見つかりますが、間隔の取り方が変わって、それまで候補に入っていた良い値（たとえば `b` の `34`）が候補から外れると、損失が大きくなることもあります。また、いちばん良い組が範囲の外にあれば、間隔をいくら細かくしても届きません。
