全体図3 では、機械学習が5つの段階で進むことを見ました。この節は③の、モデル（式の形）を決めるところで、全体図2 の式「点数 ＝ a × 勉強時間 ＋ b」を Python の関数として書きます。`a` と `b` を取りかえながら、何人ぶんもの点数を一度に予測するには、どう書けばよいでしょうか。

{/* 困る例 */}

「点数 ＝ a × 勉強時間 ＋ b」で5人の点数を予測するのに、Aさんは `a = 6`、`b = 30` を選び、Bさんは `a = 8`、`b = 20` を選びました。この式はグラフにすると直線になるので、ここからはAさんの直線、Bさんの直線と呼びます。5人の勉強時間を配列 `hours` にして `6 * hours + 30` と書けば、Aさんの予測は出せます。けれども、数を式に直接書くと、`a` と `b` を変えるたびに式を書き直すことになります。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

hours = np.array([2.0, 3.0, 5.0, 6.0, 8.0])

def predict(hours, a, b):
    return a * hours + b

print(predict(hours, 6, 30))
print(predict(hours, 8, 20))`}
  out={`[42. 48. 60. 66. 78.]
[36. 44. 60. 68. 84.]`}
/>

{/* 説明 */}

3行目の `hours` は、予測に使う入力です。この値を特徴量と呼びます。

5〜6行目の `predict` は、`a` と `b` を使って `a * hours + b` を返す関数です。5行目の引数 `hours` は、3行目の `hours` と同じ名前ですが、関数の中では、呼び出すときに渡した値が使われます。`a * hours + b` のような、入力から予測を出す式をモデル（model）と呼びます。ここでのモデルは直線です。`a` と `b` は、モデルの中でデータに合わせて決める数で、パラメータ（parameter）と呼びます。

全体図2 で表を使って見たモデルとパラメータを、ここでは関数 `predict` として書いています。

8〜9行目は、同じ `hours` に異なる `a`, `b` を渡し、AさんとBさんの直線をそれぞれ計算しています。関数が返す値を予測と呼びます。

予測は、まだ点数の分からない新しい人にも使います。新しい人にどれだけ当たるかは、第15章で測ります。
