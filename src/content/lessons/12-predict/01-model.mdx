{/* 困る例 */}

Aさんは勉強時間から点数を予想する直線を `a = 6`、`b = 30` として引きました。Bさんは `a = 8`、`b = 20` として引きました。どちらの直線で予想すればよいか決めたくても、「予想」がまだコードになっていません。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

hours = np.array([2.0, 3.0, 5.0, 6.0, 8.0])

def predict(hours, a, b):
    return a * hours + b

print(predict(hours, 6, 30))
print(predict(hours, 8, 20))`}
  out={`[42. 48. 60. 66. 78.]
[36. 44. 60. 68. 84.]`}
/>

{/* 説明 */}

3行目の `hours` は、予測に使う入力です。この値を特徴と呼びます。

5〜6行目の `predict` は、`a` と `b` を使って `a * hours + b` を返す関数です。この式の形をモデル（model）と呼び、ここでは直線です。`a` と `b` は、モデルの中でデータに合わせて決める数で、パラメータ（parameter）と呼びます。

8〜9行目は、同じ `hours` に異なる `a`, `b` を渡し、AさんとBさんの直線をそれぞれ計算しています。関数が返す値を予測と呼びます。

予測は、まだ点数の分からない新しい人にも使います。どれだけ当たるかは第15章で測ります。
