{/* 困る例 */}

気温を「暑い」「ちょうどいい」「寒い」の3段階に分けたいとします。ifとelseだけでは2つにしか分けられず、3段階目を表せません。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`temperature = 32
if temperature >= 30:
    print("暑い")
elif temperature >= 15:
    print("ちょうどいい")
else:
    print("寒い")`}
  out={`暑い`}
/>

{/* 説明 */}

2行目と4行目の `if`・`elif` は、条件を上から順に確かめます。最初に成り立った条件の、インデントした部分だけが実行されます。

1つ目の `if temperature >= 30` が成り立てば `暑い` が表示され、残りの条件は確かめられません。成り立たなければ、次の `elif temperature >= 15` に進みます。

条件を並べる順は大切です。`temperature >= 15` を先に書くと、`32` でも最初の条件が成り立ち、`ちょうどいい` と表示されます。そのため、高い方から順に書きます。

`elif` はいくつでも重ねられます。最後に置いた `else` は、どの条件にも当てはまらなかったときの処理です。

境界の値がどちらに入るかは、比べる記号で決まります。`temperature` がちょうど `30` のときは最初のifが成り立ち、`暑い` になります。
