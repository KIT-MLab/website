{/* 困る例 */}

気温を「暑い」「ちょうどいい」「寒い」の3段階に分けたいとします。ifとelseだけでは2つにしか分けられず、3段階目を表せません。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`temperature = 32
if temperature >= 30:
    print("暑い")
elif temperature >= 15:
    print("ちょうどいい")
else:
    print("寒い")`}
  out={`暑い`}
/>

{/* 説明 */}

2行目と4行目の `if`・`elif` は、条件を上から順に確かめます。最初に成り立った条件のブロックだけが実行されます。

1つ目の `if temperature >= 30` が成り立てば `暑い` が表示され、残りの条件は確かめられません。成り立たなければ、次の `elif temperature >= 15` に進みます。

`elif` はいくつでも重ねられます。最後に置いた `else` は、どの条件にも当てはまらなかったときの処理です。

境界の値がどちらに入るかは、比べる記号で決まります。`temperature` がちょうど `30` のときは最初のifが成り立ち、`暑い` になります。

{/* よくある間違い */}

<Mistake
  id="elif-typo"
  code={`score = 85
if score >= 90:
    print("優")
elseif score >= 80:
    print("良")
else:
    print("可")`}
  error={`SyntaxError: invalid syntax`}
>
`elseif` という綴りはありません。`elif` と書いてください。
</Mistake>

<Mistake
  id="elif-after-else"
  code={`score = 85
if score >= 90:
    print("優")
else:
    print("可")
elif score >= 80:
    print("良")`}
  error={`SyntaxError: 'elif' block follows an 'else' block`}
>
`elif` は `else` より前に置きます。並びを `if` → `elif` → `else` の順に直してください。
</Mistake>
