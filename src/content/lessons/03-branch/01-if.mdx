{/* 困る例 */}

点数が60点以上なら「合格です」と出したいとします。これまでの書き方では、点数がいくつでも同じ行が実行され、点数によって出す言葉を変えられません。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`score = 75
if score >= 60:
    print("合格です")
print("判定を終えました")`}
  out={`合格です
判定を終えました`}
/>

{/* 説明 */}

2行目の `if score >= 60:` はif文（if statement）です。`if` の後ろに条件を書き、行の最後に `:` を置きます。

条件が成り立つとき、下の行が実行されます。条件が成り立たなければ、インデントされた行は実行されません。

3行目の `print("合格です")` は行の頭に空白があります。この空白をインデント（字下げ）と呼び、if文の中身であることを示します。

`score >= 60` は、`score` が `60` 以上かどうかを表す条件です。比べる記号には次のものがあります。

| 記号 | 読み方 | 例 | 結果 |
|---|---|---|---|
| `>` | より大きい | `7 > 5` | 成り立つ |
| `<` | より小さい | `7 < 5` | 成り立たない |
| `>=` | 以上 | `5 >= 5` | 成り立つ |
| `<=` | 以下 | `5 <= 3` | 成り立たない |
| `==` | 等しい | `5 == 5` | 成り立つ |
| `!=` | 等しくない | `5 != 5` | 成り立たない |

`==` は等しいかどうかを比べる記号で、変数に値を入れる `=` とは別のものです。

4行目の `print("判定を終えました")` にはインデントがなく、if文の外にあります。条件が成り立つかどうかにかかわらず、この行は必ず実行されます。

条件だけを `print(7 > 5)` のように表示すると、成り立つときは `True`、成り立たないときは `False` と出ます。

<Level0 title="インデントの入力方法">
行の頭に空白を入れるときは、`Tab` キーを押すか、半角空白を4つ続けて入力します。コロンで終わる行の次の行では、多くのエディタが自動でインデントを入れてくれます。
</Level0>
