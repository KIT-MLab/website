{/* 困る例 */}

点数が60点以上なら「合格です」と出したいとします。これまでの書き方では、点数に関わらず同じ行が実行され、結果によって出す言葉を変えられません。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`score = 75
if score >= 60:
    print("合格です")
print("判定を終えました")`}
  out={`合格です
判定を終えました`}
/>

{/* 説明 */}

2行目の `if score >= 60:` はif文（if statement）です。`if` の後ろに条件を書き、行の最後に `:` を置きます。

条件が成り立つとき、下の行が実行されます。3行目の `print("合格です")` は行の頭に空白があります。この空白を字下げ（インデント）と呼び、if文の中身であることを示します。

`score >= 60` は、`score` が `60` 以上かどうかを表す条件です。`>=` は以上、`<=` は以下を表します。条件が成り立たなければ、字下げされた行は実行されません。

4行目の `print("判定を終えました")` には字下げがなく、if文の外にあります。条件の成り立つ・成り立たないに関わらず、この行は必ず実行されます。

<Level0 title="字下げの入力方法">
行の頭に空白を入れるときは、`Tab` キーを押すか、半角空白を4つ続けて入力します。コロンで終わる行の次の行は、多くのエディタが自動で頭をそろえます。
</Level0>

{/* よくある間違い */}

<Mistake
  id="if-missing-colon"
  code={`score = 75
if score >= 60
    print("合格です")`}
  error={`SyntaxError: expected ':'`}
>
if文の条件の後ろに `:` がありません。行の最後にコロンを付けてください。
</Mistake>

<Mistake
  id="if-missing-indent"
  code={`score = 75
if score >= 60:
print("合格です")`}
  error={`IndentationError: expected an indented block after 'if' statement on line 2`}
>
if文の中身の行に字下げがありません。`if` の次の行の頭に半角空白を入れてください。
</Mistake>

<Mistake
  id="if-arrow"
  code={`score = 75
if score => 60:
    print("合格です")`}
  error={`SyntaxError: invalid syntax`}
>
`=>` という書き方はありません。「以上」を表すには `>=` と書きます。
</Mistake>
