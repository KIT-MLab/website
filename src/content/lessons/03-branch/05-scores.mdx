{/* 困る例 */}

第2章で作った点数表は、平均と基準点を表示するところまでです。基準点を上回っているかどうかは、自分の目で見比べる必要があります。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`japanese = 65
mathematics = 82
english = 70
threshold = 60
average = (japanese + mathematics + english) / 3
if average >= threshold:
    print(f"平均{round(average, 1)}点 合格")
else:
    print(f"平均{round(average, 1)}点 不合格")`}
  out={`平均72.3点 合格`}
/>

{/* 説明 */}

1〜5行目は前の章までに作った点数表です。変数（第1章）に点数を残し、平均を計算しています。

6行目の `if average >= threshold:` はif文（第3章）です。平均が基準点以上かどうかを判定します。

判定に使うのは、5行目で計算した `average` の値です。

7〜9行目は、判定の結果に応じてf文字列（第1章）で表示を変えます。丸めた平均（`round`、第2章）に「合格」か「不合格」を続けます。

基準点を変数にしているので、`threshold` の値を変えれば合格ラインを変えられます。`average` の値そのものは、ifの中でもelseの中でも変わりません。

{/* よくある間違い */}

<Mistake
  id="scores-if-forgot-int"
  code={`japanese = int(input())
mathematics = input()
english = int(input())
threshold = 60
average = (japanese + mathematics + english) / 3
if average >= threshold:
    print(f"平均{round(average, 1)}点 合格")
else:
    print(f"平均{round(average, 1)}点 不合格")`}
  stdin={`80
70
90`}
  error={`TypeError: unsupported operand type(s) for +: 'int' and 'str'`}
>
`mathematics` の `int()` を付け忘れています。3つとも整数に変えてから計算してください。
</Mistake>

<Mistake
  id="scores-threshold-name"
  code={`japanese = 80
mathematics = 70
english = 90
average = (japanese + mathematics + english) / 3
threshold = 60
if average >= thresholds:
    print(f"平均{round(average, 1)}点 合格")
else:
    print(f"平均{round(average, 1)}点 不合格")`}
  error={`NameError: name 'thresholds' is not defined`}
>
`threshold` と `thresholds` は別の名前です。定義した名前とそろえてください。
</Mistake>
