{/* 困る例 */}

点数が60以上80未満のときだけ「合格ラインです」と表示したいとします。条件は「60以上」と「80未満」の2つありますが、ここまでのif文に書いた条件は、いつも1つだけでした。

{/* やってみる */}

2つの条件を1つのif文で確かめるには、`and` を使います。次のコードの ▶ を押してください。

<Run
  code={`score = 72
if score >= 60 and score < 80:
    print("合格ラインです")
else:
    print("合格ラインではありません")`}
  out={`合格ラインです`}
/>

{/* 説明 */}

2行目の `score >= 60 and score < 80` は、`score >= 60` と `score < 80` を `and` でつないだ条件です。`and` でつなぐと、左右の条件がどちらも成り立つときだけ、全体が成り立ちます。`score` が `72` のときは両方成り立つので、`合格ラインです` と表示されます。`score` が `55` だったら、`score < 80` は成り立っても `score >= 60` が成り立たないので、`else` のほうになります。

`and` の左右には、それぞれ条件を丸ごと書きます。「60以上80未満」という日本語につられて、`score >= 60 and < 80` のように `and` の右の `score` を省くと、エラーになります。

左右のどちらか一方でも成り立てばよいときは、`or` を使います。次のコードは、点数が0より小さいか、100より大きければ範囲外とします。

<Run
  code={`score = 120
if score < 0 or score > 100:
    print("範囲外です")
else:
    print("範囲内です")`}
  out={`範囲外です`}
/>

`score` が `120` なので、`score < 0` は成り立ちませんが、`score > 100` が成り立ちます。`or` は片方だけで足りるので、全体が成り立ち、`範囲外です` と表示されます。

`not` は、後ろの条件が成り立つかどうかを逆にします。

<Run
  code={`score = 45
if not (score >= 60):
    print("不合格です")
else:
    print("合格です")`}
  out={`不合格です`}
/>

`not` の後ろのかっこの中は、先に確かめます。`score >= 60` は `45` では成り立たないので、`not` で逆になって全体が成り立ち、`不合格です` と表示されます。

出席が10回以上で、そのうえテストが60点以上かレポートが80点以上なら合格、とするときは、次のように書きます。

<Run
  code={`attendance = 8
score = 75
report = 90
if attendance >= 10 and (score >= 60 or report >= 80):
    print("合格です")
else:
    print("不合格です")`}
  out={`不合格です`}
/>

`and` と `or` を混ぜるときは、先にまとめたいほうを `()` で囲みます。かっこを外して `attendance >= 10 and score >= 60 or report >= 80` と書くと、第2章4節の `*` と `+` と同じで、`and` が先にまとまります。すると `report >= 80` だけで全体が成り立つので、出席が足りなくても `合格です` と表示されます。

| 書き方 | 成り立つとき |
|---|---|
| `条件A and 条件B` | 条件Aと条件Bがどちらも成り立つとき |
| `条件A or 条件B` | 条件Aと条件Bの少なくとも一方が成り立つとき |
| `not (条件)` | かっこの中の条件が成り立たないとき |
