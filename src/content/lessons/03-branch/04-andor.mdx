{/* 困る例 */}

点数が60以上80未満のときだけ「合格ラインです」と出したいとします。2つの条件を同時に満たすかどうかを、1つのifでまだ書けません。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`score = 55
if score >= 60 and score < 80:
    print("合格ラインです")
else:
    print("合格ラインではありません")`}
  out={`合格ラインではありません`}
/>

{/* 説明 */}

2行目の `score >= 60 and score < 80` はandを使った条件です。`and` の両側が両方成り立つときだけ、全体が成り立ちます。

`or` は、両側のどちらか一方でも成り立てば全体が成り立ちます。`score < 0 or score > 100` は、0未満か100より大きいかのどちらかで成り立ちます。

`not` は、条件の成り立つ・成り立たないを反転させます。`not (score >= 60)` は `score >= 60` が成り立たないときに成り立ちます。

`and` は `or` より先に評価されます。複数を組み合わせるときは、`()` で区切ると意図が伝わりやすくなります。

{/* よくある間違い */}

<Mistake
  id="andor-double-amp"
  code={`score = 70
if score >= 60 && score < 80:
    print("合格ラインです")`}
  error={`SyntaxError: invalid syntax`}
>
`&&` という書き方はありません。両方が成り立つ条件には `and` を使います。
</Mistake>

<Mistake
  id="andor-missing-colon"
  code={`score = 70
if score >= 60 and score < 80
    print("合格ラインです")`}
  error={`SyntaxError: expected ':'`}
>
条件が長くなっても、行の最後に `:` が要ります。コロンが抜けていないか確かめてください。
</Mistake>
