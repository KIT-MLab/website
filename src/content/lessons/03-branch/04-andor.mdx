{/* 困る例 */}

点数が60以上80未満のときだけ「合格ラインです」と出したいとします。2つの条件を同時に満たすかどうかを、1つのifでまだ書けません。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`score = 55
if score >= 60 and score < 80:
    print("合格ラインです")
else:
    print("合格ラインではありません")`}
  out={`合格ラインではありません`}
/>

{/* 説明 */}

2行目の `score >= 60 and score < 80` は `and` を使った条件です。`and`・`or`・`not` は次のように使い分けます。

| 演算子 | 成り立つ条件 | 例 |
|---|---|---|
| `and` | 両側が両方成り立つとき | `score >= 60 and score < 80` |
| `or` | 両側のどちらか一方でも成り立つとき | `score < 0 or score > 100` |
| `not` | 条件が成り立たないとき | `not (score >= 60)` |

`not` は条件の結果を反転させます。それ自体で新しい条件を作るわけではありません。

「やってみる」の例では `score` が `55` です。`score >= 60` が成り立たないため、`and` でつないだ全体も成り立ちません。

`and` は `or` より先に評価されます。複数を組み合わせるときは、`()` で区切ると意図が伝わりやすくなります。

{/* よくある間違い */}

<Mistake
  id="andor-double-amp"
  code={`score = 70
if score >= 60 && score < 80:
    print("合格ラインです")`}
  error={`SyntaxError: invalid syntax`}
>
`&&` という書き方はありません。両方が成り立つ条件には `and` を使います。
</Mistake>

<Mistake
  id="andor-missing-colon"
  code={`score = 70
if score >= 60 and score < 80
    print("合格ラインです")`}
  error={`SyntaxError: expected ':'`}
>
条件が長くなっても、行の最後に `:` が要ります。コロンが抜けていないか確かめてください。
</Mistake>
