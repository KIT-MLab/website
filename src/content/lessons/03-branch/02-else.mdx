{/* 困る例 */}

点数が60点未満のとき「不合格です」と出したいとします。ifだけでは、条件が成り立たないときに実行する行を指定できません。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`score = 45
if score >= 60:
    print("合格です")
else:
    print("不合格です")`}
  out={`不合格です`}
/>

{/* 説明 */}

4行目の `else:` の次の行から、ifの条件が成り立たなかったときの処理を、インデントして書きます。

`else` には条件を書きません。ifの条件が成り立つかどうかで、2つの処理のどちらか一方だけが実行されます。

5行目の `print("不合格です")` はelseの中身で、3行目の `print("合格です")` と同じ深さのインデントを付けます。`if` と `else` は対で使い、`else` だけを単独では書けません。

このコードでは `score` が `45` なのでifの条件は成り立たず、elseの中身が実行されて `不合格です` が表示されます。

2で割った余り（第2章）が `0` かどうかを条件にすると、偶数か奇数かで分けられます。

<Run
  code={`number = 7
if number % 2 == 0:
    print("偶数です")
else:
    print("奇数です")`}
  out={`奇数です`}
/>

`number % 2` は `number` を2で割った余りで、`number % 2 == 0` は「2で割り切れる」という条件です。`7` を2で割った余りは `1` なので条件は成り立たず、elseの `奇数です` が表示されます。
