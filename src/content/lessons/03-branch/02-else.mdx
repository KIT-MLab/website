{/* 困る例 */}

点数が60点未満のとき「不合格です」と出したいとします。ifだけでは、条件が成り立たないときに実行する行を指定できません。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`score = 45
if score >= 60:
    print("合格です")
else:
    print("不合格です")`}
  out={`不合格です`}
/>

{/* 説明 */}

3行目の `else:` はelseです。ifの条件が成り立たなかったときの処理を、直後のまとまりに書きます。

`else` には条件を書きません。ifの条件が成り立つかどうかで、2つの処理のどちらか一方だけが実行されます。

4行目の `print("不合格です")` はelseの中身で、3行目のifと同じ深さの字下げを付けます。`if` と `else` は対で使い、`else` だけを単独では書けません。

このコードでは `score` が `45` なのでifの条件は成り立たず、elseの中身が実行されて `不合格です` が表示されます。ifとelseは片方しか動かないので、`合格です` と `不合格です` が同時に表示されることはありません。

{/* よくある間違い */}

<Mistake
  id="else-zenkaku-colon"
  code={`score = 45
if score >= 60：
    print("合格です")
else:
    print("不合格です")`}
  error={`SyntaxError: invalid character '：' (U+FF1A)`}
>
コロンが全角になっています。`:` は半角で入力してください。日本語入力がオンだと全角になります。
</Mistake>

<Mistake
  id="else-eq-mixup"
  code={`score = 45
if score = 60:
    print("ちょうど60点です")
else:
    print("60点ではありません")`}
  error={`SyntaxError: invalid syntax. Maybe you meant '==' or ':=' instead of '='?`}
>
比べるときは `==` を使います。`=` は変数に値を入れる記号で、比べる記号ではありません。
</Mistake>
