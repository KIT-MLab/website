{/* 困る例 */}

名前と点数を1行にまとめて、`名前:佐藤 点数:80` と表示したいとします。`print("名前:", "佐藤", "点数:", 80)` とコンマで並べると、`名前: 佐藤 点数: 80` のように `:` のあとに空白が入ってしまいます。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`name = "佐藤"
score = 80
print(f"名前:{name} 点数:{score}")`}
  out={`名前:佐藤 点数:80`}
/>

{/* 説明 */}

文字列の前に `f` を付けたものをf文字列（f-string）と呼びます。`{name}` のように `{}` の中に変数を書くと、その値に置き換わります。

3行目の `{name}` には `"佐藤"` が、`{score}` には `80` が入ります。数も `{}` の中に書けば、そのまま文字の並びとして出ます。

`{}` の中には、変数だけでなく計算の式も書けます。`{100 - score}` のように書くと、計算した結果に置き換わります。

文字列どうしは `+` で1つにつなげられます。`"赤" + "青"` は `"赤青"` になり、間に空白は入りません。

文字列と数は値の種類（型）が違うので、`"点数は" + 80` のように `+` でそのままつなぐと、エラーで止まります。先に `str()` で数を文字列に変えます。

`"点数は" + str(80)` は `"点数は80"` になります。f文字列を使えば、この `str()` を書かずに済みます。

<Run
  code={`print("合計" + str(5) + "円")`}
  out={`合計5円`}
/>
