{/* 困る例 */}

入力欄の数に1を足して表示するプログラムを作るとします。`x = input()` のあとに `print(x + 1)` と書くと、Python はエラーで止まります。第1章3節で見たとおり、`x` に入っているのは文字列で、文字列に数は足せないためです。

{/* やってみる */}

入力欄に `5` と書いてある状態で ▶ を押してください。

<Run
  code={`x = int(input())
print(x + 1)`}
  stdin={`5`}
  out={`6`}
/>

{/* 説明 */}

計算の前に、文字列を整数に変える関数 `int()` を通します。整数（integer）は小数点を持たない数で、`3` や `-7` と書きます。`int("5")` は数の `5` になります。

1行目の `int(input())` のように、関数の中に別の関数を書くと、内側から順に実行されます。整数に変えた `5` が `x` に入るので、2行目の `x + 1` は `6` になります。

<Figure
  caption="値のうつりかわり"
  code="int(input())"
  marks={[
    { part: 'input()', note: '入力欄の1行を読み取る', value: '"5"（文字列）' },
    { part: 'int(input())', note: '整数に変える', value: '5（整数）' },
  ]}
/>
