{/* 困る例 */}

国語・数学・英語の点数から合計と平均を出したいとします。点数を受け取り、名前で覚えておき、結果を文章で示せないと、確認するたびにコードを書き換えることになります。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`japanese = 80
mathematics = 70
total = japanese + mathematics
print(f"合計{total}点")`}
  out={`合計150点`}
/>

{/* 説明 */}

1行目と2行目は変数（第3節）です。点数に名前を付けて残しています。3行目は `+` で合計を計算し、`total` という変数に入れています。

4行目はf文字列（第4節）です。`{total}` の場所に計算した値が入り、1行の文章になります。入力欄から点数を受け取るときは `input()` と `int()`（第2節）を使います。

教科が増えても、変数を増やして `+` でつなげば合計が出せます。平均は合計を教科の数で割れば求まります。

教科の数がもっと増えると、変数を増やすたびにコードも長くなります。値をまとめて扱うリストは、第4章で扱います。リストを使うと、教科の数が変わっても同じ書き方で処理できます。

{/* よくある間違い */}

<Mistake id="forgot-int" code={`japanese = int(input())
mathematics = input()
english = int(input())
print(japanese + mathematics + english)`} stdin={`80
70
90`} error={`TypeError: unsupported operand type(s) for +: 'int' and 'str'`}>
`mathematics` だけ `int()` を付け忘れています。`input()` の結果は文字列なので、計算する前に必ず整数に変えてください。エラー文の `int` と `str` は、`japanese` が整数、`mathematics` が文字列のままであることを示しています。
</Mistake>

<Mistake id="total-mismatch" code={`japanese = 80
mathematics = 70
english = 90
total = japanese + mathematics + english
print(f"合計{totals}点")`} error={`NameError: name 'totals' is not defined`}>
`total` と `totals` は別の名前です。`totals` は定義されていないため、`NameError` になります。合計を表す変数名をそろえてください。
</Mistake>
