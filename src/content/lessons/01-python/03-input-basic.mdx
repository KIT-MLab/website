{/* 困る例 */}

名前を受け取って、あいさつを表示するプログラムを作るとします。`name = "佐藤"` と書くと、出る名前はいつも佐藤です。別の人の名前で試すたびに、コードを書き直すことになります。

{/* やってみる */}

入力欄に `佐藤` と `京都` の2行が書いてある状態で、▶ を押してください。

<Run
  code={`name = input()
city = input()
print("こんにちは", name)
print("出身は", city)`}
  stdin={`佐藤
京都`}
  out={`こんにちは 佐藤
出身は 京都`}
/>

{/* 説明 */}

`input()` は、入力欄の1行を読み取る関数です。1行目の `name = input()` は、読み取った値を変数 `name` に入れます（第1章2節）。コードを書き換えずに、実行するたびに入力欄で名前を変えられます。

`input()` は、呼ぶたびに入力欄の次の行を上から順に読みます。

読み取った値は文字列（第1章1節）です。入力欄に `5` と書いても、数ではなく文字の `5` として受け取ります。数として計算に使う方法は、次の節で扱います。

入力欄に読む行が残っていないのに `input()` を呼ぶと、実行が止まります。画面には「入力欄が空です。入力欄に値を書いてから実行してください」と出ます。

上の例で入力欄の2行目を消して ▶ を押すと、2行目の `city = input()` で止まります。`print` の行までは進まないので、このメッセージだけが出ます。

読み取った値を1回しか使わないときは、変数に入れずに `print("こんにちは", input())` とも書けます。かっこの中の `input()` が先に実行され、読み取った値が引数になります。

`input("あなたの年齢は？")` のようにかっこに文字列を書くと、読み取る前にその文字列を表示します。

<Run
  code={`age = input("あなたの年齢は？")
print(age, "歳です")`}
  stdin={`19`}
  out={`あなたの年齢は？19 歳です`}
/>

質問の文だけが `print` と同じ画面に表示され、答えは自分で打ち込みます。このサイトでは答えを入力欄から読み、画面では質問のすぐ後ろに、打ち込んだように薄い色で出して改行します。この薄い `19` は表示のためのもので、次の行の `19 歳です` が、プログラムの `print` が出した結果です。

課題では、問題文に書いていない質問の文を `input()` に入れないでください。質問の文も出力に入るので、正しい出力と合わなくなります。

<Level0 title="入力欄の場所">
入力欄はコード欄のすぐ下にあります。1行書いたら改行し、次の行を書いてください。書き終えてから ▶ を押します。
</Level0>
