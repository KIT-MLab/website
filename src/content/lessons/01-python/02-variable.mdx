{/* 困る例 */}

100円の品物について、値段・送料50円を足した額・20円引きの額を3行で表示するとします。`100` を3か所に書いた場合、値段が90円に変わると3か所とも書き直すことになります。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`price = 100
print(price + 50)
print(price - 20)`}
  out={`150
80`}
/>

{/* 説明 */}

1行目の `price = 100` は、`price` という名前に `100` を結び付けています。これを変数（variable）と呼びます。`=` の左に名前、右に値を書きます。

`=` の右には、`price + 50` のような式も書けます。先に右を計算し、その結果が左の名前に結び付きます。

`=` は数学の等号とは違います。右の値を左の名前に結び付ける記号で、`price` と `100` が等しいという意味ではありません。

2行目と3行目の `price` を書いた場所には、結び付けた `100` が入って計算されます。同じ値を2か所以上で使うとき、変数を使えば1か所を直すだけで済みます。

<Compare
  badTitle="数をそのまま書く"
  badCode={`print(100)
print(100 + 50)
print(100 - 20)`}
  badNote="値段が90円になったら、3か所を書き直す"
  goodTitle="変数に入れる"
  goodCode={`price = 100
print(price)
print(price + 50)
print(price - 20)`}
  goodNote="1行目だけ直せばよい"
/>

`price = 150` のように書き直すと、値は新しいものに置き換わります。前の `100` という値は残らず、以後の `price` は `150` として扱われます。

名前は自分で決められますが、途中に空白を入れることはできません。
