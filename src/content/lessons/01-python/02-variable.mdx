{/* 困る例 */}

100円の品物について、値段と、送料50円を足した額と、20円引きの額を、3行で表示するとします。`100` を3か所に書いた場合、値段が90円に変わると3か所とも書き直すことになります。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`price = 100
print(price)
print(price + 50)
print(price - 20)`}
  out={`100
150
80`}
/>

{/* 説明 */}

1行目の `price = 100` は、`price` という名前に `100` を結び付けています。これを変数（variable）と呼びます。`=` の左に名前、右に値を書きます。

`=` は数学の等号とは違います。右の値を左の名前に結び付ける記号で、`price` と `100` が等しいという意味ではありません。

2行目から4行目の `price` を書いた場所には、結び付けた `100` が入って計算されます。

<Compare
  badTitle="数をそのまま書く"
  badCode={`print(100)
print(100 + 50)
print(100 - 20)`}
  badNote="値段が90円になったら、3か所を書き直す"
  goodTitle="変数に入れる"
  goodCode={`price = 100
print(price)
print(price + 50)
print(price - 20)`}
  goodNote="1行目だけ直せばよい"
/>

あとの行で `price = 150` と書くと、`price` の値は置き換わります。前の `100` は残らず、以後の `price` は `150` です。

`=` の右には式も書けます。先に右を計算するので、`price = price + 10` は、いまの `price` に10を足した値を `price` に入れ直します。

<Run
  code={`price = 100
price = price + 10
print(price)`}
  out={`110`}
/>

名前と値をコンマで並べて `a, b = 3, 5` と書くと、`a` に `3`、`b` に `5` を一度に入れられます。

名前は自分で決められますが、次の決まりがあります。

| 名前 | 使えるか | わけ |
|---|---|---|
| `price_2` | 使える | 英字・数字・`_` だけ |
| `2price` | 使えない | 数字で始まる |
| `total price` | 使えない | 途中に空白がある |
| `total-price` | 使えない | `-` は引き算の記号になる |
| `if` | 使えない | Python が決まった意味で使う語 |

大文字と小文字は区別され、`Price` と `price` は別の変数です。`print` のような関数の名前は、変数に使うとその関数が使えなくなるので避けます。

名前は、小文字の英単語を `_` でつなぐ形（`total_price`）がよく使われます。日本語の名前も動きますが、ふつうは使いません。
