{/* 困る例 */}

名前と点数を1行にまとめて表示したいとします。`"点数は" + 80` のように文字列と数を `+` でつなぐと、Pythonはエラーで止まり、報告の文が作れません。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`name = "佐藤"
score = 80
print(f"名前:{name} 点数:{score}")`}
  out={`名前:佐藤 点数:80`}
/>

{/* 説明 */}

文字列の前に `f` を付けたものをf文字列（f-string）と呼びます。`{name}` のように `{}` の中に変数を書くと、その値が文字列の中に展開されます。

1行目の `{name}` には `"佐藤"` が、`{score}` には `80` が入ります。数値も `{}` の中に書けば、そのまま文字の並びとして出ます。

`{}` の中には、変数だけでなく計算の式も書けます。`{100 - score}` のように書くと、計算した結果がそのまま文字列に展開されます。

`+` で数値を文字列とつなぐときは、先に `str()` で文字列に変えます。`"点数は" + str(80)` は `"点数は80"` になります。f文字列を使えば、この `str()` を書かずに済みます。

{/* よくある間違い */}

<Mistake id="str-plus-int-literal" code={`print("点数は" + 80)`} error={`TypeError: can only concatenate str (not "int") to str`}>
文字列と数値は `+` で直接つなげません。`str(80)` のように文字列に変えるか、f文字列を使ってください。
</Mistake>

<Mistake id="fstring-missing-brace" code={`name = "佐藤"
print(f"名前:{name")`} error={`SyntaxError: f-string: expecting '}'`}>
`{` に対応する `}` が抜けています。f文字列の `{}` は開いたら必ず閉じてください。
</Mistake>
