{/* 困る例 */}

全角の記号や1文字違いの綴りは、見た目がそっくりです。目で追うだけでは気づけず、動かしてはじめてエラーになって出ます。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`apple = 3
orange = 5
print(f"くだものは{apple + orange}個です")`}
  out={`くだものは8個です`}
/>

{/* 説明 */}

SyntaxErrorは、Pythonが実行を始める前に、文の形を読み取れないときに出ます。コロンの不足やかっこの閉じ忘れ、全角の記号がおもな原因です。この行より先へは、1行も実行されません。

NameErrorは、文の形は正しいのに、実行の途中で使った名前が見つからないときに出ます。`apple` を `aple` と綴り間違えると起こります。組み込みの `print` を `pirnt` と書いても、同じNameErrorになります。

コロンの不足、かっこの閉じ忘れ、全角の記号、字下げの誤りは、どれもSyntaxErrorの仲間です。直すたびに、次のSyntaxErrorが出ることもあります。

どちらの種類でも、いちばん下の行の名前と行番号を読めば、場所が分かります。

{/* よくある間違い */}

<Mistake
  id="syntax-name-typo"
  code={`apple = 3
orange = 5
print(f"くだものは{aple + orange}個です")`}
  error={`NameError: name 'aple' is not defined`}
>
`aple` という名前が見つかりません。1行目で付けた名前は `apple` なので、綴りをそろえてください。
</Mistake>

<Mistake
  id="syntax-zenkaku-paren"
  code={`apple = 3
orange = 5
print(f"くだものは{apple + orange}個です"）`}
  error={`SyntaxError: invalid character '）' (U+FF09)`}
>
行の最後の `）` が全角です。`print` の閉じかっこは半角の `)` で書いてください。
</Mistake>

<Mistake
  id="syntax-indent"
  code={`for score in [40, 55, 50]:
print(score)`}
  error={`IndentationError: expected an indented block after 'for' statement on line 1`}
>
for文の中身の行に字下げがありません。`for` の次の行の頭に半角空白を入れてください。
</Mistake>
