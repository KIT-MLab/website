{/* 困る例 */}

全角の記号や1文字違いの綴りは、見た目がそっくりです。目で追うだけでは気づけず、動かしてはじめてエラーとして表示されます。

{/* やってみる */}

次の2つのコードは、どちらも止まります。▶ を押して、いちばん下の行を見てください。

<Run
  code={`apple = 3
orange = 5
print(f"くだものは{apple + orange}個です"）`}
  error={`SyntaxError: invalid character '）' (U+FF09)`}
/>

<Run
  code={`apple = 3
orange = 5
print(f"くだものは{aple + orange}個です")`}
  error={`NameError: name 'aple' is not defined`}
/>

{/* 説明 */}

SyntaxErrorは、Pythonが実行を始める前に、文の形を読み取れないときに出ます。コロンの不足やかっこの閉じ忘れ、全角の記号がおもな原因です。SyntaxErrorが出るプログラムは、1行も実行されません。

1つ目の例では、3行目の最後の `）` が全角なので、`invalid character`（使えない文字）と出ました。

NameErrorは、文の形は正しいのに、実行の途中で使った名前が見つからないときに出ます。2つ目の例のように、`apple` を `aple` と綴り間違えると起こります。`print` を `pirnt` と書き間違えても、同じNameErrorになります。

インデントの誤りもSyntaxErrorの仲間で、画面には `IndentationError` という名前で出ます。1つ直すと、そのあとの行にある別のSyntaxErrorが出ることもあります。

どちらの種類でも、いちばん下の行でエラーの名前を、その少し上の行で行番号を読めば、直す場所の見当がつきます。
