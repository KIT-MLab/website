{/* 困る例 */}

`input()` で読み取った値を、そのまま数として計算しようとするとエラーが出ます。エラーの文を見ただけでは、何がいけないのか分かりません。

{/* やってみる */}

次の2つのコードは、どちらも入力欄の値を数として使おうとして止まります。▶ を押してください。

<Run
  code={`total = 0
score = input()
total = total + score
print(total)`}
  stdin={`70`}
  error={`TypeError: unsupported operand type(s) for +: 'int' and 'str'`}
/>

<Run
  code={`age = int(input())
print(f"来年は{age + 1}歳です")`}
  stdin={`10歳`}
  error={`ValueError: invalid literal for int() with base 10: '10歳'`}
/>

{/* 説明 */}

TypeErrorは、型が合わない操作をしようとしたときに出ます。文字列と整数をそのまま `+` でつなごうとすると起こります。`int()` で数に変える前の値を計算に使うと、よく出ます。

1つ目の例は、`+` の左が整数（`int`）、右が文字列（`str`）なので足せない、と言っています。

ValueErrorは、`int()` に渡した文字列が数として読み取れないときに出ます。`int()` には文字列を渡すので型は合っています。ただ、中身が数字でない文字だと数に変換できません。

2つ目の例は、`'10歳'` を `int()` で数に変えられなかった、と言っています。

見分け方は、型そのものが違うか、型は合っているが値がおかしいかです。文字列のまま計算すればTypeError、数字でない文字列を `int()` に渡せばValueErrorです。

ほかにも、実行の途中で止まるエラーがあります。`numbers[3]` のように、リストに無い位置のインデックスを指定すると `IndexError` が出ます。`5 / 0` のように0で割ると、`ZeroDivisionError` が出ます。止まるコードと、そのとき最後に出るエラーの行を、「この節の書き方」の表にまとめてあります。
