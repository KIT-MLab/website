{/* 困る例 */}

`input()` で読み取った値を、そのまま数として計算しようとするとエラーが出ます。文字だけを見ても、何がいけないのか分かりません。

{/* やってみる */}

入力欄に `10` と書いてある状態で ▶ を押してください。

<Run
  code={`age = int(input())
print(f"来年は{age + 1}歳です")`}
  stdin={`10`}
  out={`来年は11歳です`}
/>

{/* 説明 */}

TypeErrorは、型が合わない操作をしようとしたときに出ます。文字列と整数をそのまま `+` でつなごうとすると起こります。`int()` で数に変える前の値を計算に使うと、よく出ます。

ValueErrorは、`int()` に渡した文字列が数として読み取れないときに出ます。型は文字列のままで正しいのに、中身が数字でない文字だと変換できません。

見分け方は、型そのものが違うか、型は合っているが値がおかしいかです。文字列のまま計算すればTypeError、数字でない文字列をint()に渡せばValueErrorです。

どちらも、いちばん下の行に型の名前と詳しい値が書かれています。

{/* よくある間違い */}

<Mistake
  id="type-input-str"
  code={`age = input()
print(f"来年は{age + 1}歳です")`}
  stdin={`10`}
  error={`TypeError: can only concatenate str (not "int") to str`}
>
`age` が文字列のままです。`int(input())` のように整数へ変えてから、足し算に使ってください。
</Mistake>

<Mistake
  id="type-int-nonnumeric"
  code={`age = int(input())
print(f"来年は{age + 1}歳です")`}
  stdin={`じゅう`}
  error={`ValueError: invalid literal for int() with base 10: 'じゅう'`}
>
`int()` に渡した `じゅう` は数字ではありません。入力欄には半角の数字を書いてください。
</Mistake>
