{/* 困る例 */}

プログラムが最後まで動いて、エラーも出ないのに、答えが違うことがあります。行番号という手がかりが無く、どこを見ればいいのか分かりません。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`scores = [40, 65, 82]
count = 0
for value in scores:
    if value >= 60:
        count = count + 1
print(count)`}
  out={`2`}
/>

{/* 説明 */}

エラーが出ないときは、値を目で追うしかありません。確かめたい行の近くに `print(値)` をもう1行足すと、その時点で何が入っているかが分かります。

条件の向きが逆、繰り返しの中で添字を固定したまま、`return` を書き忘れて `None` が返る、はよくある形です。これらを手がかりに、出力を1つずつ期待する値と見比べてください。

たとえば `value >= 60` を `value <= 60` と書いても、動きはします。数え方だけが変わるので、実行結果と自分が期待する値を並べて見比べてください。

確かめ終えたら、途中で足したprintは消してから提出してください。
