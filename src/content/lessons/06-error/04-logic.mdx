{/* 困る例 */}

プログラムが最後まで動いて、エラーも出ないのに、答えが違うことがあります。行番号という手がかりが無く、どこを見ればいいのか分かりません。

{/* やってみる */}

次のコードは、25度以上の日が何日あるかを数えるつもりで書いたものです。▶ を押してください。

<Run
  code={`temps = [22, 27, 25, 19]
count = 0
for temp in temps:
    if temp > 25:
        count = count + 1
    print(temp, count)
print(count)`}
  out={`22 0
27 1
25 1
19 1
1`}
/>

{/* 説明 */}

エラーが出ないときは、途中の値を自分で確かめます。確かめたい行の近くに `print(値)` をもう1行足すと、その時点で何が入っているかが分かります。

この例の6行目 `print(temp, count)` が、確かめるために足した行です。数えたいのは `27` と `25` の2日ですが、`25` の行で `count` が増えていません。4行目の `temp > 25` が25ちょうどを外しているので、`temp >= 25` に直すと `2` になります。

よくある間違いは4つあります。条件の `>` と `>=` を取り違えること、`<` と `>` の向きを取り違えること、`scores[0]` のように同じ位置を取り出し続けること、`return` の書き忘れです。

確かめ終えたら、途中で足したprintは消してから提出してください。
