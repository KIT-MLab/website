{/* 困る例 */}

商品の税込み価格を計算する関数を作るとします。税率はほとんどの場合10%ですが、呼び出すたびに `0.1` を書くことになります。ときどき違う税率も使うので、関数の中に固定することもできません。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`def price_with_tax(amount, rate=0.1):
    return amount * (1 + rate)

print(price_with_tax(1000))
print(price_with_tax(1000, 0.2))`}
  out={`1100.0
1200.0`}
/>

{/* 説明 */}

1行目の `rate=0.1` の部分が既定値（default value）です。呼び出すときに `rate` を渡さなければ、この値が使われます。

4行目は `rate` を渡していないので、既定値の `0.1` が使われます。結果は `1100.0` です。5行目のように渡せば、その値が既定値の代わりに使われます。

`amount` には既定値がありません。呼び出すたびに必ず渡す必要があります。既定値のある引数は、既定値のない引数より後ろに書きます。

よく使う値を既定値にしておくと、呼び出す側は短く書けます。違う値を使いたいときだけ渡せばよいので、同じ関数を使い回せます。

{/* よくある間違い */}

<Mistake
  id="args-default-order"
  code={`def price_with_tax(rate=0.1, amount):
    return amount * (1 + rate)`}
  error={`SyntaxError: parameter without a default follows parameter with a default`}
>
既定値のない引数を、既定値のある引数より後ろに書いています。`amount` を先に、`rate=0.1` をあとに書いてください。
</Mistake>

{/* 課題 */}

関数 `judge(score, border)` を書いてください。`score` は点数、`border` は合格の基準点です。`score` が `border` 以上なら `"合格"`、そうでなければ `"不合格"` を返します。

`border` の既定値を `60` にしてください。
</Exercise>
