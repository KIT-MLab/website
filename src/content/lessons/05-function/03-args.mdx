{/* 困る例 */}

商品の税込み価格を計算する関数を作るとします。税率はほとんどの場合10%なのに、呼び出すたびに `0.1` を書くことになります。ときどき違う税率も使うので、関数の中に固定することもできません。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`def price_with_tax(amount, rate=0.1):
    return amount * (1 + rate)

print(price_with_tax(1000))
print(price_with_tax(1000, 0.2))`}
  out={`1100.0
1200.0`}
/>

{/* 説明 */}

1行目の `rate=0.1` の部分がデフォルト値です。呼び出すときに `rate` を渡さなければ、この値が使われます。

4行目は `rate` を渡していないので、デフォルト値の `0.1` が使われます。結果は `1100.0` です。5行目のように渡せば、その値がデフォルト値の代わりに使われます。

`amount` にはデフォルト値がありません。呼び出すたびに必ず渡す必要があります。デフォルト値のある引数は、デフォルト値のない引数より後ろに書きます。
