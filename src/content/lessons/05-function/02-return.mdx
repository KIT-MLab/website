{/* 困る例 */}

前の節の `show_average` は、平均を表示します。表示した数をそのあとの計算に使おうとしても、変数に取り出す方法がありません。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`def average(a, b):
    return (a + b) / 2

result = average(80, 90)
print(result + 10)`}
  out={`95.0`}
/>

{/* 説明 */}

1行目の `def average(a, b):` は関数の定義です。2行目の `return (a + b) / 2` がこの節の新しい書き方です。

`return` は、計算した値を呼び出した場所に持ち帰ります。ここで関数の実行は終わり、それより後の行には進みません。

4行目の `result = average(80, 90)` で、返ってきた値を `result` という変数に入れています。5行目のように、受け取った値をそのあとの計算に使えます。

`return` を書いていない関数を呼ぶと、返ってくる値は `None`（何も無いことを表す値）です。前の節の `show_average` を `result = show_average(80, 90)` と呼ぶと、画面には平均が表示されます。ただし、`result` に入るのは `None` です。

`return` の後ろにコンマで値を並べると、複数の値を一度に返せます。たとえば、`a` を `b` で割った商と余りを返す関数 `divide` は、`return a // b, a % b` と書きます。関数全体のコードは、「この節の書き方」の表にあります。

呼び出す側は、第1章2節の `a, b = 3, 5` と同じ形で、`q, r = divide(7, 2)` のように、コンマで並べた変数で受け取ります。すると、`q` に `3`、`r` に `1` が入ります。
