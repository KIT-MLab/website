{/* 困る例 */}

前の節の `price_with_tax(amount, rate=0.1)` は、`amount` が先、`rate` があとという決まりでした。`price_with_tax(500, 0.2)` と書くつもりで `price_with_tax(0.2, 500)` と順番を逆にしても、エラーは出ません。ところが、金額は `600.0` ではなく `100.2` になります。

{/* やってみる */}

次のコードの ▶ を押してください。前の節の関数に、送料の `shipping` を足したものです。

<Run
  code={`def price_with_tax(amount, rate=0.1, shipping=0):
    return amount * (1 + rate) + shipping

print(price_with_tax(rate=0.2, amount=1000))
print(price_with_tax(1000, shipping=500))`}
  out={`1200.0
1600.0`}
/>

{/* 説明 */}

前の節の `rate=0.1` は、関数を定義するときに書くデフォルト値でした。4行目の `rate=0.2` は、呼び出すときに書く名前と値です。同じ `=` ですが、書く場所が違います。

4行目は `rate` を先に書いていますが、結果は `1200.0` です。名前で渡し先が決まるので、**書く順番は関係なくなります。** `price_with_tax(0.2, 500)` のように、引数の順番を取り違える間違いが起きません。

5行目は `rate` を書かず、`shipping` だけ名前で渡しています。**途中の引数を飛ばせます。** 名前を書かなければ、`shipping` に渡すために `rate` の値も書くことになります。

名前を書いて渡す引数を、キーワード引数（keyword argument）と呼びます。名前のない引数と混ぜてもかまいませんが、**名前を書いた引数より後ろに、名前のない引数は書けません。**
