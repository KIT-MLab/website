{/* 困る例 */}

前の節の `price_with_tax(amount, rate)` は、`amount` が先、`rate` があとの約束でした。呼び出すときに `price_with_tax(0.2, 1000)` と順番を逆にしても、エラーは出ません。それでも `200.2` という、意図しない金額になります。

{/* やってみる */}

次のコードの ▶ を押してください。前の節の関数に、送料の `shipping` を足したものです。

<Run
  code={`def price_with_tax(amount, rate=0.1, shipping=0):
    return amount * (1 + rate) + shipping

print(price_with_tax(rate=0.2, amount=1000))
print(price_with_tax(1000, shipping=500))`}
  out={`1200.0
1600.0`}
/>

{/* 説明 */}

5.3節の `rate=0.1` は、関数を定義するときに書く既定値でした。4行目の `rate=0.2` は、呼び出すときに書く名前と値です。同じ `=` ですが、書く場所が違います。

4行目は `rate` を先に書いていますが、結果は `1200.0` です。名前で渡し先が決まるので、**書く順番は関係なくなります。** 前の節の「順番を間違える」が起きません。

5行目は `rate` を書かず、`shipping` だけ名前で渡しています。**途中の引数を飛ばせます。** 名前を書かなければ、`shipping` に渡すために `rate` の値も書くことになります。

名前を書いて渡す引数を、キーワード引数（keyword argument）と呼びます。名前のない引数と混ぜてもかまいませんが、**名前を書いた引数より後ろに、名前のない引数は書けません。**

{/* よくある間違い */}

<Mistake
  id="keyword-after-positional"
  code={`def price_with_tax(amount, rate=0.1, shipping=0):
    return amount * (1 + rate) + shipping

print(price_with_tax(rate=0.2, 1000))`}
  error={`SyntaxError: positional argument follows keyword argument`}
>
名前を書いた `rate=0.2` のあとに、名前のない `1000` を書いています。名前のない引数は、名前を書いた引数より前に置いてください。
</Mistake>
