{/* 困る例 */}

2教科の平均を3か所に計算式で書いたとします。`(80 + 90) / 2` のように書けば動きますが、計算のしかたを変えたくなると、3か所とも直すことになります。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`def show_average(a, b):
    print(f"平均{(a + b) / 2}")

show_average(80, 90)
show_average(50, 70)`}
  out={`平均85.0
平均60.0`}
/>

{/* 説明 */}

1行目の `def show_average(a, b):` は関数の定義です。`def` の後ろに関数の名前、`()` の中に引数の名前を書きます。ここでは `a` と `b` の2つです。

2行目の `print(f"平均{(a + b) / 2}")` が関数の中身です。インデントした行は、関数を呼び出すたびに実行されます。

4行目の `show_average(80, 90)` で呼び出すと、`a` に `80`、`b` に `90` が入り、2行目が実行されます。5行目は同じ関数を、別の値で呼び出しています。

同じ計算を書く行は、この2行だけで足ります。呼び出す場所がいくつ増えても、直すのは関数の中身1か所です。

{/* よくある間違い */}

<Mistake
  id="def-missing-colon"
  code={`def show_average(a, b)
    print((a + b) / 2)`}
  error={`SyntaxError: expected ':'`}
>
`def` の行の最後に `:` がありません。関数を定義する行の最後には、必ずコロンを書いてください。
</Mistake>

<Mistake
  id="def-missing-indent"
  code={`def show_average(a, b):
print((a + b) / 2)`}
  error={`IndentationError: expected an indented block after function definition on line 1`}
>
関数の中身の行にインデントがありません。`def` の次の行の頭に半角空白を入れてください。
</Mistake>
