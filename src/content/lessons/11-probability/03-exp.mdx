{/* 困る例 */}

点数が1, -1, 2のとき、11.2節と同じく合計で割ると、-1の項が負の数のまま残り、分布になりません。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

print(round(np.exp(1), 3))

scores = np.array([1, -1, 2])
positive = np.exp(scores)
print(np.round(positive, 2))
print(np.round(positive / np.sum(positive), 3))`}
  out={`2.718
[2.72 0.37 7.39]
[0.259 0.035 0.705]`}
/>

{/* 説明 */}

3行目の `np.exp(1)` は $e$ の値です。$e$ はネイピア数(Napier's constant)と呼ばれる約2.718の数で、小数第3位まで丸めています。

6行目の `np.exp(scores)` は、`scores` の各成分を $e$ の何乗かに変えます。この関数を指数関数(exponential function)と呼びます。どんな数を入れても正の数になり、大きい数を入れるほど値も大きくなります。

8行目で、正になった値を合計で割ると分布になります。この計算の形には、第4部で名前が付きます。

{/* よくある間違い */}

<Mistake
  id="exp-math-array"
  code={`import numpy as np
import math

scores = np.array([1, -1, 2])
print(math.exp(scores))`}
  error={`TypeError: only 0-dimensional arrays can be converted to Python scalars`}
>
`math.exp` は数を1つずつ受け取る関数で、配列をまとめて渡せません。配列には `np.exp` を使ってください。
</Mistake>
