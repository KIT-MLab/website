{/* 困る例 */}

過去30日の天気の記録があります。「雨の日が多かった」とは言えても、次に雨になりやすいかを数で比べられません。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`records = ["晴れ", "晴れ", "雨", "曇り", "雨", "晴れ", "雨", "晴れ", "雨", "曇り"]

count = 0
for day in records:
    if day == "雨":
        count = count + 1

print(count / len(records))`}
  out={`0.4`}
/>

{/* 説明 */}

4〜6行目は、`records` を1つずつ調べ、`"雨"` と等しい要素の数を `count` に数えています。8行目で、その数を記録の総数で割っています。この割合を相対度数と呼び、確率とみなします。

`count` は0以上 `len(records)` 以下なので、割った値は必ず0以上1以下になります。確率がこの範囲に収まることは、この先の節でも使う性質です。
