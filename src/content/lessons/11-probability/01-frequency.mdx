{/* 困る例 */}

過去10日の天気の記録があります。「雨の日が多かった」とは言えても、雨になりやすさを数で表せません。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`records = ["晴れ", "晴れ", "雨", "曇り", "雨", "晴れ", "雨", "晴れ", "雨", "曇り"]

count = 0
for day in records:
    if day == "雨":
        count = count + 1

print(count / len(records))`}
  out={`0.4`}
/>

{/* 説明 */}

4〜6行目は、`records` を1つずつ調べ、`"雨"` と等しい要素がいくつあるかを `count` に数えています。8行目で、その数を記録の総数で割っています。この割合を相対度数と呼び、この先も同じくらいの割合で雨になると考えて、雨の確率とみなします。

`count` は0以上 `len(records)` 以下なので、割った値は必ず0以上1以下になります。
