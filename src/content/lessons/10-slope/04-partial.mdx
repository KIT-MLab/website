{/* 困る例 */}

直線 `y = a*x + b` で点数を予測しています。7.1節のずれ(差の2乗の和)を小さくしたいのですが、`a` と `b` のどちらを動かせばよいか分かりません。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

hours = np.array([2, 3, 5, 6, 8])
scores = np.array([45, 52, 65, 70, 82])

def loss(a, b):
    pred = a * hours + b
    return np.sum((pred - scores) ** 2)

a = 7
b = 30
h = 0.0001
slope_a = (loss(a + h, b) - loss(a, b)) / h
slope_b = (loss(a, b + h) - loss(a, b)) / h
print(round(slope_a, 1))
print(round(slope_b, 1))`}
  out={`78.0
8.0`}
/>

{/* 説明 */}

6〜8行目の `loss` は、7.1節と同じ「予測と実際の差の2乗の和」を、`a` と `b` の関数として書いたものです。ずれは `a` と `b` の2つで決まります。

13行目の `slope_a` は、`b` を固定したまま `a` だけを `h` だけ増やし、ずれの変化を `h` で割っています。`a` の向きだけを見た傾きです。14行目の `slope_b` は、逆に `a` を固定して `b` の向きを見ています。

このように、動かす変数を1つだけ選んで求める傾きを偏微分と呼びます。動かさなかった変数は、そのときだけ定数として扱います。
