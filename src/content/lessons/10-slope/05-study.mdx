{/* 困る例 */}

前の節で、直線 `y = a*x + b` のずれを減らす、`a` の向きと `b` の向きの傾きを数値で出せるようになりました。ですが、傾きの値だけでは、`a` と `b` をそれぞれ増やすべきか減らすべきかが分かりません。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

hours = np.array([2, 3, 5, 6, 8])
scores = np.array([45, 52, 65, 70, 82])

def loss(a, b):
    pred = a * hours + b
    return np.sum((pred - scores) ** 2)

a = 7
b = 30
h = 0.0001
current = loss(a, b)
slope_a = (loss(a + h, b) - current) / h
slope_b = (loss(a, b + h) - current) / h
print(current)
print(round(slope_a, 1))
print(round(slope_b, 1))
if slope_a > 0:
    print("aを減らす")
else:
    print("aを増やす")
if slope_b > 0:
    print("bを減らす")
else:
    print("bを増やす")`}
  out={`22
78.0
8.0
aを減らす
bを減らす`}
/>

{/* 説明 */}

14〜15行目の `slope_a`・`slope_b` は、前の節と同じ偏微分です。どちらも正なので、`a` と `b` のどちらを増やしてもずれは増えます。

19〜26行目は、傾きが正なら減らす、負なら増やすと判定しています。第10章3節の「傾きの符号と動く向き」を、`a` と `b` の2つに当てはめただけです。

ここで出すのは向きまでで、`a` や `b` を実際には動かしません。1歩動かして次のずれを求め直すのは、第3部の回帰で扱います。
