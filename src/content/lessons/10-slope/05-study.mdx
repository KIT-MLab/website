{/* 困る例 */}

前の節で、`a = 7`、`b = 30` のとき、`a` の向きの傾きは78.0、`b` の向きの傾きは8.0でした。ずれを減らすには、`a` と `b` をそれぞれ増やせばよいのか減らせばよいのかを、プログラムで出したいです。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

hours = np.array([2, 3, 5, 6, 8])
scores = np.array([45, 52, 65, 70, 82])

def loss(a, b):
    pred = a * hours + b
    return np.sum((pred - scores) ** 2)

a = 7
b = 30
h = 0.0001
current = loss(a, b)
slope_a = (loss(a + h, b) - current) / h
print(current)
print(round(slope_a, 1))
if slope_a > 0:
    print("aを減らす")
else:
    print("aを増やす")`}
  out={`22
78.0
aを減らす`}
/>

{/* 説明 */}

13行目の `current` は、いまの `a`・`b` でのずれ（22）です。14行目は、前の節と同じ `a` の向きの偏微分を、`current` を使って求めています。

17〜20行目は、傾きが正なら `a` を減らし、負なら `a` を増やすと判定しています。第10章3節の、傾きの符号から動かす向きを決めるやり方を、`a` に当てはめたものです。78.0 は正なので、`a` を減らすとずれが減ります。

`b` の向きも、同じ形で判定できます。

ここで出すのは向きまでで、`a` や `b` を実際には動かしません。1歩ずつ動かしてずれを減らしていくのは、第13章で扱います。
