{/* 困る例 */}

`x**2` の `x = 3` での傾き（曲線の接線の傾き）を、2点を結ぶ直線で調べたいのですが、もう1点の選び方で値が変わってしまいます。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`def f(x):
    return x ** 2

x0 = 3
for h in [2, 0.5, 0.01]:
    print(h, round((f(x0 + h) - f(x0)) / h, 4))`}
  out={`2 8.0
0.5 6.5
0.01 6.01`}
/>

{/* 説明 */}

5〜6行目は、幅 `h` を2、0.5、0.01と狭めながら、`x0` と `x0 + h` の2点を結ぶ直線の傾きを求めています。値は8.0、6.5、6.01と、ある数に近づいていきます。

`h` を0にどんどん近づけたとき、傾きが近づいていく値を、`x = 3` での微分と呼びます。これが、曲線の `x = 3` での傾き（その点で曲線に接する直線の傾き）です。数IIで習ったとおり、`x**2` を微分すると `2x` になるので、`x = 3` では6です。

上の値も6に近づいています。ただし `h` は0にはできないので、`h = 0.01` のときの6.01のように、微分の値から少しずれます。

コンピュータの小数は有限の桁で近似されます（第2章1節）。丸めずに表示すると `6.009999999999849` のような値になることがあるので、桁数を決めて丸めます。
