{/* 困る例 */}

`x**2` の `x = 3` での傾きを、2点を結ぶ直線で調べたいのですが、もう1点の選び方で値が変わってしまいます。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`def f(x):
    return x ** 2

x0 = 3
for h in [2, 0.5, 0.01]:
    print(h, round((f(x0 + h) - f(x0)) / h, 4))`}
  out={`2 8.0
0.5 6.5
0.01 6.01`}
/>

{/* 説明 */}

5〜6行目は、幅 `h` を2、0.5、0.01と狭めながら、`x0` と `x0 + h` の2点を結ぶ直線の傾きを求めています。値は8.0、6.5、6.01と、ある数に近づいていきます。

`h` を0に近づけたときに近づいていく値を微分と呼びます。数IIで習った `x**2` の微分は `2x` なので、`x = 3` では6です。上の値も6に近づいています。

コンピュータの小数は有限の桁で近似されます。丸めずに表示すると `6.009999999999849` のような値になることがあるので、桁数を決めて丸めます。

<Secant fn="x**2" x0={3} xmin={0} xmax={5.4} ymin={0} ymax={28} caption="x = 3 での傾き" />

図の表は、上のコードと同じ計算を、`h = 2` から `0.01` まで自動でくり返した結果です。コードの出力と見比べてください。

{/* よくある間違い */}

<Mistake
  id="derivative-h-zero"
  code={`def f(x):
    return x ** 2
x0 = 3
h = 0
print((f(x0 + h) - f(x0)) / h)`}
  error={`ZeroDivisionError: division by zero`}
>
`h` を0にすると、`x0` と `x0 + h` が同じ点になり、割り算ができません。微分は `h` を0に近づけた値なので、0そのものは使いません。
</Mistake>
