{/* 困る例 */}

`y = x**2 - 4*x + 5` の値をできるだけ小さくしたいのですが、いまの `x` をどちらへ動かせばよいか分かりません。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`def f(x):
    return x ** 2 - 4 * x + 5

x0 = 0.5
h = 0.0001
slope = (f(x0 + h) - f(x0)) / h
print(round(slope, 4))

if slope > 0:
    print("左へ動かす")
else:
    print("右へ動かす")`}
  out={`-2.9999
右へ動かす`}
/>

{/* 説明 */}

6行目は、前の節と同じ式で `x0 = 0.5` での傾きを求めています。値は負なので、`x` を増やすと `f(x)` は減ります。

傾きが正なら、`x` を増やすと値も増えるので、値を減らすには左(小さい方)へ動かします。傾きが負なら逆に、右(大きい方)へ動かすと値が減ります。9〜12行目の `if` は、この向きを傾きの符号だけで決めています。
