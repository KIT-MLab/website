{/* 困る例 */}

点数を予測する式に、勉強時間の2乗や3乗も使って曲線を複雑にするほど、訓練データでの損失は下がり続けます。しかし、テストデータでは、どこかで損失が上がり始めます。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

hours  = np.array([2.0, 3.0, 5.0, 6.0, 8.0, 9.0, 6.0, 6.5, 8.5, 5.5, 7.0, 8.0, 2.5, 0.5, 3.0, 3.0, 8.0, 8.5, 0.5, 4.5, 7.5, 1.5, 7.5, 1.5, 4.5, 7.5, 3.0, 3.5, 3.0, 6.5])
scores = np.array([45, 52, 65, 70, 82, 84, 63, 70, 85, 68, 70, 80, 44, 39, 62, 52, 85, 91, 33, 66, 80, 39, 77, 39, 72, 73, 52, 50, 49, 77])

rng = np.random.default_rng(50)
idx = rng.permutation(30)
train_idx = idx[:6]
test_idx = idx[6:]

for degree in [1, 3, 5]:
    coef = np.polyfit(hours[train_idx], scores[train_idx], degree)
    pred_train = np.polyval(coef, hours[train_idx])
    pred_test = np.polyval(coef, hours[test_idx])
    train_loss = np.mean((pred_train - scores[train_idx]) ** 2)
    test_loss = np.mean((pred_test - scores[test_idx]) ** 2)
    print(round(train_loss, 1), round(test_loss, 1))`}
  out={`25.1 19.9
6.4 56.8
0.0 723.0`}
/>

{/* 説明 */}

12行目の`np.polyfit(x, y, 次数)`は、指定した次数までの曲線の係数を求める関数です。次数3なら、勉強時間の1乗・2乗・3乗を使った曲線になります。係数には、何も掛けない数（直線の`b`にあたるもの）も入るので、次数3の係数は4つです。

`np.polyfit`は、誤差の2乗の平均が最も小さくなる係数を、一度に求めます。求め方は、この教材では扱いません。

13〜14行目の`np.polyval(係数, x)`は、その係数を使って予測の値を求めます。訓練データとテストデータへの分け方は、第15章1節と同じです。違いが見えやすいように、訓練データを6人だけにしています。

出力は、次数の並びと同じ順で3行になります。次数を1、3、5と増やすと、訓練データの損失は`25.1`→`6.4`→`0.0`と下がり続けますが、テストデータの損失は`19.9`→`56.8`→`723.0`と上がります。次数1だけテストデータのほうが小さいのは、1節で見たとおり、分け方しだいで起こることです。

次数5の曲線は係数が6つあるので、訓練データの6人の点をちょうど通るように決められます。そのため、訓練データの損失が`0.0`になります。このように曲線が訓練データに合いすぎて、テストデータで外れることを、過学習と呼びます。
