{/* 困る例 */}

勉強時間から点数を予測する直線を、30人全員のデータで学習すると、その30人については損失が小さくなります。新しく来た人にどれだけ当たるかは、これでは確かめられません。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

hours  = np.array([2.0, 3.0, 5.0, 6.0, 8.0, 9.0, 6.0, 6.5, 8.5, 5.5, 7.0, 8.0, 2.5, 0.5, 3.0, 3.0, 8.0, 8.5, 0.5, 4.5, 7.5, 1.5, 7.5, 1.5, 4.5, 7.5, 3.0, 3.5, 3.0, 6.5])
scores = np.array([45, 52, 65, 70, 82, 84, 63, 70, 85, 68, 70, 80, 44, 39, 62, 52, 85, 91, 33, 66, 80, 39, 77, 39, 72, 73, 52, 50, 49, 77])

rng = np.random.default_rng(3)
idx = rng.permutation(30)
train_idx = idx[:24]
test_idx = idx[24:]

train_hours = hours[train_idx]
train_scores = scores[train_idx]
test_hours = hours[test_idx]
test_scores = scores[test_idx]

a = 0.0
b = 0.0
for i in range(1500):
    z = a * train_hours + b
    a = a - 0.02 * np.mean(2 * (z - train_scores) * train_hours)
    b = b - 0.02 * np.mean(2 * (z - train_scores))

train_loss = np.mean((a * train_hours + b - train_scores) ** 2)
test_loss = np.mean((a * test_hours + b - test_scores) ** 2)
print(round(train_loss, 1))
print(round(test_loss, 1))`}
  out={`15.4
34.1`}
/>

{/* 説明 */}

6行目の`np.random.default_rng(3)`は、種3で乱数（順番の決まっていない数）を作る準備をします（第8章4節）。種は、並びを決める番号です。

7行目の`.permutation(30)`は、0から29の整数をランダムな順に並べた配列を返します。種が同じなら、並びは毎回同じになります。

8〜9行目で、並びの先頭24個を訓練データ（学習用のデータ）、残り6個をテストデータ（テスト用のデータ）のインデックスにします。11行目の`hours[train_idx]`のように、配列をインデックスにして複数の値をまとめて取り出せます（第7章4節）。

18〜21行目は、第13章3節の勾配降下法を、`a`と`b`に分けて書いたものです。訓練データだけで`a`と`b`を決めています。

訓練データの損失は`15.4`ですが、この分け方では、テストデータの損失は`34.1`まで上がります。テストデータは6人しかいないので、損失は誰が入るかで大きく変わり、種によってはテストデータのほうが小さく出ることもあります。
