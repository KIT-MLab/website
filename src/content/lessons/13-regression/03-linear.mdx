第13章2節までは、`x` が1つだけの `(x - 3) ** 2 + 1` で、勾配降下法と学習率を試しました。この節では、④の学習として、30人のデータに直線 `a * hours + b` を勾配降下法で合わせます。先頭の5人は第12章1〜4節と同じで、そこに25人を足した30人です。`a` と `b` の2つを、どうやって一緒に動かせばよいでしょうか。

第13章1節では、動かす値が `x` の1つだけで、傾きも1つでした。直線では `a` と `b` の2つを動かすので、`a` を少し動かしたときと、`b` を少し動かしたときで、損失の増え方が違います。2つを一度に動かすための傾きの求め方は、まだ決めていません。

  code={`import numpy as np

hours = np.array([2.0, 3.0, 5.0, 6.0, 8.0, 9.0, 6.0, 6.5, 8.5, 5.5, 7.0, 8.0, 2.5, 0.5, 3.0, 3.0, 8.0, 8.5, 0.5, 4.5, 7.5, 1.5, 7.5, 1.5, 4.5, 7.5, 3.0, 3.5, 3.0, 6.5])
scores = np.array([45, 52, 65, 70, 82, 84, 63, 70, 85, 68, 70, 80, 44, 39, 62, 52, 85, 91, 33, 66, 80, 39, 77, 39, 72, 73, 52, 50, 49, 77])

def loss(w):
    pred = hours * w[0] + w[1]
    return np.mean((pred - scores) ** 2)

def grad(w):
    pred = hours * w[0] + w[1]
    return np.array([np.mean(2 * (pred - scores) * hours), np.mean(2 * (pred - scores))])

w = np.array([0.0, 0.0])
h = 0.0001
num_a = (loss(w + np.array([h, 0])) - loss(w)) / h
num_b = (loss(w + np.array([0, h])) - loss(w)) / h
print(np.round(np.array([num_a, num_b]), 1))
print(np.round(grad(w), 1))

w = w - 0.02 * grad(w)
print(np.round(w, 2))
print(round(loss(w), 1))`}

{/* 説明 */}

`w` は `[a, b]` をまとめた配列で、`w[0]` が `a`、`w[1]` が `b` です。

16行目の `num_a` は、`b` を止めて `a` だけを `h` 動かしたときの損失の増え方を `h` で割った数で、`a` についての傾きです。求め方は第13章1節の `slope` と同じで、`w` に `[h, 0]` を足すと `a` だけが `h` 動きます。17行目の `num_b` は、`[0, h]` を足して `b` だけを動かしたときの傾きです。

このように、1つだけを動かして求めた傾きを並べた `[num_a, num_b]` が、`a` と `b` の勾配です（くわしくは第10章4節）。10〜12行目の `grad` は、同じ勾配を `h` を使わずに式で求める関数です。式は結果だけ示します（導き方は、この教材のずっと後で扱います）。

18〜19行目で、`w = [0.0, 0.0]` での2つの求め方を比べると、どちらも `[-723.  -127.6]` で一致します。一致を確かめてから、この式を使います。勾配が2つとも負なので、損失を小さくするには、`a` も `b` も増やします。

21行目は、第13章1節の `x = x - 0.3 * slope` と同じ形で、`a` と `b` を一度に動かします（学習率は0.02）。22〜23行目で、動かしたあとの `w` と損失を表示しています。動かす量は 学習率 × 勾配 なので、学習率を変えると、動く量も同じ割合で変わります。`a` と `b` が 0 のときの損失は `4334.2` なので、1回で大きく下がりました。1回目は勾配が大きいので `a` は `14.46` と大きく動きますが、損失は下がっています。くり返すと `a` は 6 のあたりへ戻ってきます（1000回で `6.06`）。

全体図1 で見た回帰（数を予測すること）のうち、直線のモデルを学習して数を予測するものを、線形回帰と呼びます。ここでは、勉強時間から点数を予測する直線です。全体図2 では表の中から損失の小さい組を選びましたが、ここでは勾配降下法で少しずつ動かして学習します。

同じ計算を1000回くり返すと、`a ≈ 6.06`、`b ≈ 33.29`、損失 ≈ `19.0` になります。第12章3節と同じように、この30人で候補を全部試すと、`a` は `6.1`、`b` は `33.1`、損失は `19.03` です。勾配降下法の損失が少し小さいのは、全部試す方法が決まったきざみの値しか試せないからです。勾配降下法は、きざみに関係なく `a` と `b` を動かせます。
