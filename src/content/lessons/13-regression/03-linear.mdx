{/* 困る例 */}

第10章5節では、直線 `a * hours + b`（第12章1節）で `a = 7`、`b = 30` のとき、`a` と `b` をそれぞれ増やすか減らすかの向きまでは分かりました。ですが、`a` と `b` はまだ1回も動かしていません。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

hours = np.array([2.0, 3.0, 5.0, 6.0, 8.0, 9.0, 6.0, 6.5, 8.5, 5.5, 7.0, 8.0, 2.5, 0.5, 3.0, 3.0, 8.0, 8.5, 0.5, 4.5, 7.5, 1.5, 7.5, 1.5, 4.5, 7.5, 3.0, 3.5, 3.0, 6.5])
scores = np.array([45, 52, 65, 70, 82, 84, 63, 70, 85, 68, 70, 80, 44, 39, 62, 52, 85, 91, 33, 66, 80, 39, 77, 39, 72, 73, 52, 50, 49, 77])

def loss(w):
    pred = hours * w[0] + w[1]
    return np.mean((pred - scores) ** 2)

def grad(w):
    pred = hours * w[0] + w[1]
    return np.array([np.mean(2 * (pred - scores) * hours), np.mean(2 * (pred - scores))])

w = np.array([0.0, 0.0])
h = 0.0001
num_a = (loss(w + np.array([h, 0])) - loss(w)) / h
num_b = (loss(w + np.array([0, h])) - loss(w)) / h
print(np.round(np.array([num_a, num_b]), 1))
print(np.round(grad(w), 1))

w = w - 0.02 * grad(w)
print(np.round(w, 2))
print(round(loss(w), 1))`}
  out={`[-723.  -127.6]
[-723.  -127.6]
[14.46  2.55]
622.6`}
/>

{/* 説明 */}

`w` は `[a, b]` をまとめた配列で、`w[0]` が `a`、`w[1]` が `b` です。10〜12行目の `grad` は、`a` と `b` それぞれの勾配をまとめた配列を返します。式は結果だけ示します（導き方は、この教材のずっと後で扱います）。

16〜19行目で、`w = [0.0, 0.0]` の勾配を、第10章4節と同じ数値の偏微分（`num_a`・`num_b`）と比べます。`w` に `[h, 0]` を足すと `a` だけが `h` 動き、`[0, h]` を足すと `b` だけが動きます。

比べた結果は、どちらも `[-723.  -127.6]` で一致します。一致を確かめてから、この式を使います。

21〜23行目は、`w = [0.0, 0.0]` から、`a`・`b` を1回だけ動かし、そのときの `w` と損失を表示しています。

点数のような数を予測することを回帰と呼びます。損失が小さくなるように直線のモデルを学習し、それで数を予測することを、線形回帰と呼びます。

同じ計算を1000回くり返すと、`a ≈ 6.06`、`b ≈ 33.29`、損失 ≈ `19.0` になります。第12章5節の総当たり（`6.1`、`33.1`、損失 `19.03`）より損失が少し小さいのは、総当たりが決まった刻みの値しか試せないからです。勾配降下法は、刻みに関係なく `a` と `b` を動かせます。
