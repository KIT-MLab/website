第13章1節では、歩幅 `0.3` で勾配降下法をくり返し、`x` を `3` に近づけました。この節も④の学習の話で、1回に動かす大きさを変えると、`x` の動き方がどう変わるかを調べます。歩幅を大きくすれば、それだけ早く `3` に着くでしょうか。

{/* 困る例 */}

第13章1節の歩幅0.3を1.05に上げてみます（第13章1節のコードの `0.3` を `1.05`、`range(5)` を `range(8)` に替えて ▶ を押すと確かめられます。数は小数第2位まで丸めて書きます）。`x` は、1回目から順に `6.30` → `-0.63` → `6.99` と、3を行ったり来たりしながら離れていきます。`f(x)` の値は、1回動かしたあとの `11.89` から、8回動かしたあとの `42.35` まで増えます。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`def f(x):
    return (x - 3) ** 2 + 1

h = 0.0001
for lr in [0.05, 0.3, 1.05]:
    x = 0
    for i in range(20):
        slope = (f(x + h) - f(x)) / h
        x = x - lr * slope
    print(lr, round(x, 4), round(f(x), 4))`}
  out={`0.05 2.6352 1.1331
0.3 2.9999 1.0
1.05 -17.1822 408.3217`}
/>

{/* 説明 */}

5行目の `lr` は学習率で、第13章1節の歩幅のことです。全体図2 で見た学習は、パラメータを、損失が小さくなるように選ぶことでした。勾配降下法では、そのパラメータを少しずつ動かして選びます。学習率は、その1回に動かす大きさを決める数です。

動かす量は `lr * 勾配` なので、学習率が大きいほど1回で大きく動きます。6行目で、学習率を替えるたびに `x` を `0` に戻してから動かしています。

学習率が0.05のときは、20回動かしても `x` が3に届かず、0.3のときはほぼ届きます。1.05のときは、動かすたびに3を飛び越えて、前より遠くへ行き過ぎ、`f(x)` の値が際限なく増え続けます。このように、動かすほど `f(x)` の値が大きくなっていく状態を、発散と呼びます。
