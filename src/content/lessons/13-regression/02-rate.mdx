{/* 困る例 */}

第13章1節の学習率0.3を1.05に上げてみます。8回動かしても `x` は `6.30` → `-0.63` → `6.99` と行ったり来たりします。値は `11.89` から `42.35` まで増えてしまいました。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`def f(x):
    return (x - 3) ** 2 + 1

h = 0.0001
for lr in [0.05, 0.3, 1.05]:
    x = 0
    for i in range(20):
        slope = (f(x + h) - f(x)) / h
        x = x - lr * slope
    print(lr, round(x, 4), round(f(x), 4))`}
  out={`0.05 2.6352 1.1331
0.3 2.9999 1.0
1.05 -17.1822 408.3217`}
/>

{/* 説明 */}

5行目の `lr` は学習率で、1回に動かす量を決める数です。動かす量は `lr * 勾配`（第13章1節）なので、学習率が大きいほど1回で大きく動きます。

学習率0.05は20回動かしても3に届かず、0.3はほぼ届きます。1.05では動かすたびに3から離れる向きへ行き過ぎ、値が際限なく増え続けます。この、動かすほど値が大きくなっていく状態を発散と呼びます。
