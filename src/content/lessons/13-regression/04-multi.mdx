第13章3節では、勉強時間だけを入力にした直線を、勾配降下法で学習しました。この節では、②の入力を勉強時間と睡眠時間の2つに増やし、④の学習を同じ勾配降下法で行います。入力が増えても同じ式で書くには、どうすればよいでしょうか。

{/* 困る例 */}

点数を勉強時間だけでなく睡眠時間からも予測したいです。第13章3節のように `a` と `b` の勾配をそれぞれ書くと、入力が増えるたびに式を書き足すことになります。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

hours = np.array([2.0, 3.0, 5.0, 6.0, 8.0, 9.0, 6.0, 6.5, 8.5, 5.5, 7.0, 8.0, 2.5, 0.5, 3.0, 3.0, 8.0, 8.5, 0.5, 4.5, 7.5, 1.5, 7.5, 1.5, 4.5, 7.5, 3.0, 3.5, 3.0, 6.5])
sleep = np.array([6.5, 7.0, 6.0, 6.5, 7.0, 5.5, 8.5, 6.5, 6.5, 6.5, 7.0, 6.5, 6.5, 8.5, 8.0, 8.0, 7.5, 7.0, 6.0, 8.5, 6.5, 5.0, 8.0, 5.0, 8.0, 7.0, 5.0, 4.5, 6.5, 4.5])
scores = np.array([45, 52, 65, 70, 82, 84, 63, 70, 85, 68, 70, 80, 44, 39, 62, 52, 85, 91, 33, 66, 80, 39, 77, 39, 72, 73, 52, 50, 49, 77])
X = np.array([hours, sleep]).T

def predict(X, w, b):
    return X @ w + b

print(predict(X, np.array([6.0, 0.0]), 20)[:5])

w = np.array([0.0, 0.0])
b = 0.0
n = len(scores)
pred = predict(X, w, b)
w = w - 0.01 * (X.T @ (pred - scores) * 2 / n)
b = b - 0.01 * np.mean(2 * (pred - scores))
print(np.round(w, 2))
print(round(b, 2))`}
  out={`[32. 38. 50. 56. 68.]
[7.23 8.57]
1.28`}

{/* 説明 */}

6行目の `X` は、`hours` と `sleep` を行として並べ（第7章5節の「この節の書き方」の表）、`.T`（第8章2節）で転置して、1人ぶんが1行になる形にしています。先頭の3人ぶんは、次のとおりです。

| | 勉強時間 | 睡眠時間 |
|---|---:|---:|
| 1人目 | 2.0 | 6.5 |
| 2人目 | 3.0 | 7.0 |
| 3人目 | 5.0 | 6.0 |

9行目の `X @ w` は、`X` の1行ずつについて、`w` と同じ位置どうしを掛けて足します（行列とベクトルの積と呼ぶ計算で、くわしくは第9章3節）。結果は、1人に1つずつ、人数ぶんの数を並べた配列です。11行目では `w` が `[6.0, 0.0]`、`b` が `20` なので、1人目の予測は 2.0 × 6.0 ＋ 6.5 × 0.0 ＋ 20 ＝ 32 です。

出力の1行目の先頭の `32.` がこれです。入力がいくつあっても、`X @ w + b` の同じ式で書けます。11行目の終わりの `[:5]` は、30人の予測のうち、先頭の5人ぶんだけを取り出して表示するためのものです。

`w` は入力ごとの重みをまとめた配列です。重みは、入力それぞれに掛ける数のことです（全体図3 で、言葉ごとの重みとして出てきました）。`b` は入力に掛ける数ではなく、全員の予測に同じだけ足す数です。第13章3節では `b` も `w` に入れていましたが、ここでは入力が増えても1つのままなので、`w` とは別の変数にします。

13〜18行目は、`w = [0.0, 0.0]`、`b = 0.0` から1回だけ動かしています。17行目の `w` の勾配は、人数を `n`（15行目）として `X.T @ (予測 - 答え) * 2 / n` です（導き方は、この教材のずっと後で扱います）。`X.T @ (予測 - 答え)` を先に計算してから 2 を掛けても、先に 2 を掛けてから `@` で計算しても、結果は同じです。

`X.T` は `X` を転置したもので、1行目が30人の勉強時間、2行目が30人の睡眠時間です。そのため、この式の1つ目の値は、30人ぶんの「勉強時間 ×（予測 − 答え）」の合計を、2倍して `n` で割ったものです。これは第13章3節の `a` の勾配 `np.mean(2 * (pred - scores) * hours)` と同じで、始めの `w`・`b` では約 `-723.0` です。学習率が 0.01 なので、1回動かしたあとの `w` の1つ目は 0.01 × 723.0 ＝ `7.23` で、出力の `7.23` がこれです（第13章3節の書き換える問題の `[7.23 1.28]` の `7.23` と同じ）。

2つ目の値は、同じことを睡眠時間で計算した勾配です。18行目の `b` の勾配は、第13章3節と同じ `np.mean(2 * (予測 - 答え))` です。
