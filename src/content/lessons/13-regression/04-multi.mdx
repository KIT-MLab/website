{/* 困る例 */}

点数を勉強時間だけでなく睡眠時間からも予測したいです。第13章3節のように `a` と `b` の勾配をそれぞれ書くと、入力が増えるたびに式を書き足すことになります。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

hours = np.array([2.0, 3.0, 5.0, 6.0, 8.0, 9.0, 6.0, 6.5, 8.5, 5.5, 7.0, 8.0, 2.5, 0.5, 3.0, 3.0, 8.0, 8.5, 0.5, 4.5, 7.5, 1.5, 7.5, 1.5, 4.5, 7.5, 3.0, 3.5, 3.0, 6.5])
sleep = np.array([6.5, 7.0, 6.0, 6.5, 7.0, 5.5, 8.5, 6.5, 6.5, 6.5, 7.0, 6.5, 6.5, 8.5, 8.0, 8.0, 7.5, 7.0, 6.0, 8.5, 6.5, 5.0, 8.0, 5.0, 8.0, 7.0, 5.0, 4.5, 6.5, 4.5])
scores = np.array([45, 52, 65, 70, 82, 84, 63, 70, 85, 68, 70, 80, 44, 39, 62, 52, 85, 91, 33, 66, 80, 39, 77, 39, 72, 73, 52, 50, 49, 77])
X = np.array([hours, sleep]).T

def predict(X, w, b):
    return X @ w + b

print(predict(X, np.array([6.0, 0.0]), 20)[:5])

w = np.array([0.0, 0.0])
b = 0.0
n = len(scores)
pred = predict(X, w, b)
w = w - 0.01 * (X.T @ (pred - scores) * 2 / n)
b = b - 0.01 * np.mean(2 * (pred - scores))
print(np.round(w, 2))
print(round(b, 2))`}
  out={`[32. 38. 50. 56. 68.]
[7.23 8.57]
1.28`}
/>

{/* 説明 */}

6行目の `X` は、`hours` と `sleep` を行として並べ（第7章5節の「この節の書き方」の表）、`.T`（第8章2節）で転置して、1人ぶんが1行になる形にしています。`predict` は `X @ w + b` で予測を出し、入力がいくつあっても同じ式で書けます。11行目では、30人のうち先頭の5人ぶんだけ表示しています。

`w` は入力ごとの重みをまとめた配列です。重みは、入力それぞれに掛ける数のことです（第12章4節）。`b` は入力に掛ける数ではなく、全員の予測に同じだけ足す数です。第13章3節では `b` も `w` に入れていましたが、ここでは入力が増えても1つのままなので、`w` とは別の変数にします。

13〜18行目は、`w = [0.0, 0.0]`、`b = 0.0` から1回だけ動かしています。17行目の `w` の勾配は、人数を `n`（15行目）として `X.T @ (予測 - 答え) * 2 / n` です。第13章3節の勾配の式を、入力の数ぶんまとめて行列の積で計算する形にしています（導き方は、この教材のずっと後で扱います）。始めの `w`・`b` では、この式の1つ目の値は約 `-723.0` で、第13章3節の `a` の勾配と同じです。

18行目の `b` の勾配は、第13章3節と同じ `np.mean(2 * (予測 - 答え))` です。
