{/* 困る例 */}

第10章3節で、`(x - 3) ** 2 + 1` を `x = 0` から減らすには右へ動かせばよいと分かりました。1回だけ動かしても `x` は `1.8` で、値が最も小さくなる `x = 3` にはまだ遠いままです。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`def f(x):
    return (x - 3) ** 2 + 1

x = 0
h = 0.0001
for i in range(5):
    slope = (f(x + h) - f(x)) / h
    x = x - 0.3 * slope
    print(round(x, 4), round(f(x), 4))`}
  out={`1.8 2.4401
2.52 1.2304
2.808 1.0369
2.9232 1.0059
2.9692 1.0009`}
/>

{/* 説明 */}

6〜9行目は、いまの `x` での傾きを求め、`0.3`（歩幅）をかけて `x` から引く計算を5回くり返しています。この、傾きぶん動かす計算をくり返すことを勾配降下と呼び、ここでの傾きの値を勾配と呼びます。

`x` は `1.8` → `2.52` → `2.808` と、値が最も小さくなる `x = 3` に少しずつ近づきます。動かす量は `0.3 * 勾配` なので、勾配が0に近づくほど1回に動く量も小さくなります。
