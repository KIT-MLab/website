{/* 困る例 */}

第10章3節では、傾きの符号を見て、値を小さくするには `x` を右と左のどちらへ動かせばよいかを決めました。ですが、どれだけ動かすか、何回動かすかはまだ決めていません。この節では、`(x - 3) ** 2 + 1` を `x = 0` から小さくしていきます。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`def f(x):
    return (x - 3) ** 2 + 1

x = 0
h = 0.0001
for i in range(5):
    slope = (f(x + h) - f(x)) / h
    x = x - 0.3 * slope
    print(round(x, 4), round(f(x), 4))`}
  out={`1.8 2.4401
2.52 1.2304
2.808 1.0369
2.9232 1.0059
2.9692 1.0009`}
/>

{/* 説明 */}

6〜9行目は5回くり返す部分で、いまの `x` での傾きを求め、`0.3`（歩幅）をかけて `x` から引きます。引いたあとで、そのときの `x` と `f(x)` を表示します。傾きが負のときは、引くと `x` が増えるので、右へ動きます（第10章3節の向きと同じです）。

この、傾きに応じた量だけ動かす計算をくり返すことを勾配降下法と呼び、ここでの傾きの値を勾配と呼びます。

`x` は `1.8` → `2.52` → `2.808` と、`f(x)` が最も小さくなる `x = 3` に少しずつ近づきます。動かす量は `0.3 * 勾配` なので、勾配が0に近づくほど1回に動く量も小さくなります。
