第13章4節では、勉強時間と睡眠時間の2つを入力にして学習しました。この節では、②の入力を勉強時間と通学時間にして、④の学習を同じ方法で行います。単位の違う入力をそのまま使っても、うまく学習できるでしょうか。

{/* 困る例 */}

点数を、勉強時間（時間）と通学時間（分）から予測したいです。第13章4節と同じ方法で学習すると、学習率0.0005では発散します。発散しないところまで学習率を下げると、今度はなかなか損失が下がりません。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

hours = np.array([2.0, 3.0, 5.0, 6.0, 8.0, 9.0, 6.0, 6.5, 8.5, 5.5, 7.0, 8.0, 2.5, 0.5, 3.0, 3.0, 8.0, 8.5, 0.5, 4.5, 7.5, 1.5, 7.5, 1.5, 4.5, 7.5, 3.0, 3.5, 3.0, 6.5])
commute = np.array([20, 20, 75, 50, 60, 60, 70, 10, 50, 20, 40, 85, 55, 15, 55, 20, 70, 90, 90, 60, 80, 40, 20, 50, 45, 65, 90, 30, 80, 20])
scores = np.array([45, 52, 65, 70, 82, 84, 63, 70, 85, 68, 70, 80, 44, 39, 62, 52, 85, 91, 33, 66, 80, 39, 77, 39, 72, 73, 52, 50, 49, 77])

def train(X, lr, steps):
    w = np.array([0.0, 0.0])
    b = 0.0
    n = len(scores)
    for i in range(steps):
        pred = X @ w + b
        w = w - lr * (X.T @ (pred - scores) * 2 / n)
        b = b - lr * np.mean(2 * (pred - scores))
    return np.mean((X @ w + b - scores) ** 2)

X_raw = np.array([hours, commute]).T
print(round(train(X_raw, 0.0003, 1000), 1))

hours_z = (hours - hours.mean()) / hours.std()
commute_z = (commute - commute.mean()) / commute.std()
X_std = np.array([hours_z, commute_z]).T
print(round(train(X_std, 0.1, 1000), 2))`}

19.01`}

{/* 説明 */}

7〜15行目の `train` は、第13章4節の勾配降下法を関数にしたものです。学習したあとの損失を返します。

17〜18行目は、勉強時間と通学時間をそのまま入力にしています。学習率0.0003で1000回くり返しても、損失は `137.7` です。18行目の `0.0003` を `0.0005` に変えて ▶ を押すと、損失の代わりに `nan`（計算できなくなった値）が出ます。

通学時間は勉強時間より数が大きいので、通学時間の重みの勾配が大きくなります。学習率をその大きい勾配に合わせて小さくすると、勾配の小さいほかのパラメータ（とくに `b`）は、1回に少ししか動きません。そのため、1000回では損失が下がりきりません。

20〜23行目は、勉強時間と通学時間をそれぞれ標準化してから学習しています。標準偏差は、値が平均からどれだけ散らばっているかを表す数です（くわしくは第11章5節）。標準化は、平均を引いて標準偏差で割る計算です。こうすると、どの入力も平均が0、標準偏差が1にそろいます（第11章6節）。

| | 平均 | 標準偏差 | 1人目の値 | 1人目を標準化した値 |
|---|---:|---:|---:|---:|
| 勉強時間（時間） | 5.03 | 2.58 | 2.0 | −1.17 |
| 通学時間（分） | 51.17 | 24.92 | 20 | −1.25 |

1人目の勉強時間は (2.0 − 5.03) ÷ 2.58 で約 −1.17 です。標準化すると、勉強時間も通学時間も、30人ともだいたい −2 から 2 のあいだの数になり、単位による大きさの違いが無くなります。この入力なら、学習率0.1で、損失は `19.01` まで下がります。勉強時間だけのとき（第13章3節）の損失 `19.0` と、ほぼ同じです。通学時間を足しても損失がほとんど変わらないので、通学時間は点数の予測にほとんど効いていないことが分かります。

20行目の `hours.std()` は標準偏差を求める書き方で、`np.std(hours)` と同じ意味です。平均を求める `hours.mean()` と同じ形で書けます。

新しい人を予測するときは、その人の入力も、学習に使った30人の平均と標準偏差で標準化します。新しい人だけで平均や標準偏差を求めてはいけません。1人だけでは標準偏差が0になり、割り算ができません。
