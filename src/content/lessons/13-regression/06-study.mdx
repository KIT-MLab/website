{/* 困る例 */}

第13章5節までで、勾配降下法で学習することと、入力を標準化することを、別々に試しました。この節では、勉強時間と睡眠時間の2つから、新しい人の点数を予測するところまでを、1つのプログラムにつなげます。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

hours = np.array([2.0, 3.0, 5.0, 6.0, 8.0, 9.0, 6.0, 6.5, 8.5, 5.5, 7.0, 8.0, 2.5, 0.5, 3.0, 3.0, 8.0, 8.5, 0.5, 4.5, 7.5, 1.5, 7.5, 1.5, 4.5, 7.5, 3.0, 3.5, 3.0, 6.5])
sleep = np.array([6.5, 7.0, 6.0, 6.5, 7.0, 5.5, 8.5, 6.5, 6.5, 6.5, 7.0, 6.5, 6.5, 8.5, 8.0, 8.0, 7.5, 7.0, 6.0, 8.5, 6.5, 5.0, 8.0, 5.0, 8.0, 7.0, 5.0, 4.5, 6.5, 4.5])
scores = np.array([45, 52, 65, 70, 82, 84, 63, 70, 85, 68, 70, 80, 44, 39, 62, 52, 85, 91, 33, 66, 80, 39, 77, 39, 72, 73, 52, 50, 49, 77])

h_mean = hours.mean()
h_std = hours.std()
s_mean = sleep.mean()
s_std = sleep.std()
X = np.array([(hours - h_mean) / h_std, (sleep - s_mean) / s_std]).T

def loss(w, b):
    pred = X @ w + b
    return np.mean((pred - scores) ** 2)

def grad_w(w, b):
    pred = X @ w + b
    n = len(scores)
    return X.T @ (pred - scores) * 2 / n

def grad_b(w, b):
    pred = X @ w + b
    return np.mean(2 * (pred - scores))

w = np.array([0.0, 0.0])
b = 0.0
loss_before = loss(w, b)

for i in range(200):
    gw = grad_w(w, b)
    gb = grad_b(w, b)
    w = w - 0.1 * gw
    b = b - 0.1 * gb

new_x = np.array([(5 - h_mean) / h_std, (7 - s_mean) / s_std])
print(round(loss_before, 2))
print(round(loss(w, b), 2))
print(np.round(w, 2))
print(round(b, 2))
print(round(new_x @ w + b, 1))`}
  out={`4334.2
16.88
[15.51  1.47]
63.8
64.0`}
/>

{/* 説明 */}

7〜11行目で勉強時間と睡眠時間を標準化し（第13章5節）、1人ぶんが1行になる `X` を作ります。平均と標準偏差を変数に残しておくのは、36行目で新しい人を標準化するときにも使うためです。30〜34行目の勾配降下法は、第13章4節と同じ式です。

損失は、学習前の `4334.2` から、200回のくり返しで `16.88` に下がります。そのあとの `[15.51  1.47]` が学習した `w`、`63.8` が `b` です。36行目と41行目は、勉強時間5時間・睡眠時間7時間の人の予測で、`64.0` と出ます。
