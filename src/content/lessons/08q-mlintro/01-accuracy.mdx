**最初の問いかけ（はじめの3分。予想を数で言ってもらい、並べて書き出す）**

- 「タイタニック号の乗客891人のうち、生き残ったのは何割だと思う？」（答え: 342人、約38%）
- 「"女性なら生き残った" と予想すると、何割当たると思う？」（答え: 701人、78.7%）

**答え合わせで言うこと（最後の7分）**

- 生き残ったのは342人（38%）。だから「全員亡くなった」と言うだけで549人、61.6% 当たる
- 「女性なら生存」は78.7%。何も見ない予想（基準）の61.6%より17ポイント高い
- 演習問題3の「1等なら生存」は67.9%。基準より6ポイントしか上がらない。性別のほうが効く
- 練習問題2の「男性なら生存」は21.3%。基準よりずっと低い
- ひとことの要点: 正解率は、それだけでは良し悪しが分からない。基準と比べて初めて言える

**次につなげる問い（答えは言わない。入口2 で確かめる）**

- 「性別に等級を組み合わせたら、78.7% より上がると思う？」

**よく詰まるところ**

- 当たりの人数に、亡くなった男性468人を足し忘れる（生き残った女性233人だけだと 0.262 になる）
- 演習問題3で、等級ごとの「亡くなった人数」（乗客 − 生き残り）を出さずに、生き残った人数を足してしまう
- `input()` を `int()` に通し忘れて `TypeError` になる
- 差を丸めずに表示して、`0.06285072951739623` のような長い数になる

</Facilitate>

{/* 困る例 */}

タイタニック号の乗客のうち891人について、生き残ったかどうかの記録があります。「女性なら生き残った」と予想する規則を立てても、それがどれくらい当たるのかは、まだ数で言えません。

{/* やってみる */}

次のコードの ▶ を押してください。数は、891人の記録を性別ごとに数えたものです。

<Run
  code={`passengers = 891
survived = 342
female_survived = 233
male_died = 468

rule = (female_survived + male_died) / passengers
all_died = (passengers - survived) / passengers
print(f"女性なら生存: {round(rule, 3)}")
print(f"全員亡くなった: {round(all_died, 3)}")`}
  out={`女性なら生存: 0.787
全員亡くなった: 0.616`}
/>

{/* 説明 */}

891人を性別で分けて数えると、次のようになります。

| | 乗客 | 生き残った | 亡くなった |
|---|---|---|---|
| 女性 | 314 | 233 | 81 |
| 男性 | 577 | 109 | 468 |
| 合計 | 891 | 342 | 549 |

機械学習は、このような記録から、答えを当てる規則を作ることです。規則が出した答えを予測と呼びます。

「女性なら生存」が当たるのは、生き残った女性233人と、亡くなった男性468人です。6行目は、当たりの人数を全体の人数で割っています。この割合を正解率と呼びます。

7行目は、全員が亡くなったと予想したときの正解率です。記録を何も見ずに言っても、0.616 当たります。このいちばん単純な予想の正解率を、ベースライン（基準の正解率）と呼びます。

正解率は、基準と比べて初めて良し悪しが言えます。「女性なら生存」は基準より0.171高いので、性別を見た意味があります。
