{/* 困る例 */}

配点の重みを、理系・文系の順に2行3列の表で持っているとします。そのまま `scores @ weights` と書くと、`ValueError` で止まります。エラーの最後には `(size 2 is different from 3)` と、そろっていない2つの数が出ます。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

scores = np.array([[80, 70, 90], [60, 50, 40]])
weights = np.array([[0.3, 0.3, 0.4], [0.4, 0.2, 0.4]])
print(scores.shape, weights.shape)
print(scores @ weights.T)
print((scores @ weights.T).shape)`}
  out={`(2, 3) (2, 3)
[[81. 82.]
 [49. 50.]]
(2, 2)`}
/>

{/* 説明 */}

5行目で形を確かめると、`scores` は `(2, 3)`、`weights` も `(2, 3)` です。行列の積は、左の列の数と右の行の数がそろっていないと計算できません。ここでは左の列が3、右の行が2で、そろっていません。

6行目の `weights.T` は、第8章2節の転置です。形を `(3, 2)` に変えることで、`scores` の列の数3とそろいます。

7行目の形は `(2, 2)` です。`(2, 3) @ (3, 2)` の結果は、左の行の数と右の列の数を並べた形になります。

行と列の数を文字で書くと、`(n, k) @ (k, m) → (n, m)` です。掛ける前に、結果がこの形になると分かっていれば、エラーが出ても原因をすぐ探せます。
