{/* 困る例 */}

理系の配点(0.3・0.3・0.4)と文系の配点(0.4・0.2・0.4)の2通りで、全員分の合計を出したいとします。9.3節の計算を、配点の数だけ書くことになります。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

scores = np.array([[80, 70, 90], [60, 50, 40]])
W = np.array([[0.3, 0.4], [0.3, 0.2], [0.4, 0.4]])
result = scores @ W
print(result.shape)
print(result[0, 0])
print(scores[0] @ W[:, 0])`}
  out={`(2, 2)
81.0
81.0`}
/>

{/* 説明 */}

4行目の `W` は、3科目の重みを2通り並べた行列です。0列目が理系の配点、1列目が文系の配点になります。

5行目の `scores @ W` は行列の積です。`(2, 3)` と `(3, 2)` の積は `(2, 2)` の形になり、6行目の `shape` で確かめられます。

7行目と8行目は、どちらも `81.0` です。結果の1マスは、左の行(1人目の点数)と右の列(理系の配点)の内積になっています。

行列の積は、行列とベクトルの積を広げたものです。右側の列が増えるほど、結果の列も同じ数だけ増えます。

{/* よくある間違い */}

<Mistake
  id="matmul-row-vs-col"
  code={`import numpy as np
scores = np.array([[80, 70, 90], [60, 50, 40]])
W = np.array([[0.3, 0.4], [0.3, 0.2], [0.4, 0.4]])
print(scores[0] @ W[0])`}
  error={`ValueError: matmul: Input operand 1 has a mismatch in its core dimension 0, with gufunc signature (n?,k),(k,m?)->(n?,m?) (size 2 is different from 3)`}
>
`W[0]` は0行目(1科目分の2通りの配点)で、列ではありません。列を取り出すには `W[:, 0]` のように書きます。
</Mistake>
