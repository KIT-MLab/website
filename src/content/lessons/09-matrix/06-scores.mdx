{/* 困る例 */}

第8章の点数表の平均は、3科目を同じ重さで数えています。理系の配点0.3・0.3・0.4で重みを付けた平均でも、合否を出したいとします。for文の中で1人ずつ `scores[i, 0] * 0.3 + scores[i, 1] * 0.3 + scores[i, 2] * 0.4` と書くと、式が長くなります。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

flat = [80, 70, 90, 60, 50, 40]
scores = np.array(flat).reshape(2, 3)
weights = np.array([0.3, 0.3, 0.4])
weighted = np.round(scores @ weights, 1)
print(weighted)
print(weighted[1])`}
  out={`[81. 49.]
49.0`}
/>

{/* 説明 */}

4行目の `reshape(2, 3)` は、第8章5節と同じく、1本に並んだ値を2人分・3科目の表に直します。

5行目の `weights` は、第9章3節と同じく、配点を並べたベクトルです。6行目の `scores @ weights` で、全員分の重みを付けた合計が一度に出ます。配点の合計が1.0なので、この値がそのまま重みを付けた平均になり、この節では配点平均と呼びます。

6行目では、`np.round`（第7章7節）で全員分をまとめて小数第1位に丸めています。8行目の `weighted[1]` のように、インデックスで1人分を取り出せます。for文の中で `weighted[i]` と書けば、第8章の平均と同じように1人ずつ合否を出せます。

第8章の点数表のプログラムに、配点を使った合否を足してください。配点は理系の0.3・0.3・0.4です。3科目に配点を掛けて足した値を、配点平均と呼びます。

読み取った値は `reshape` で人数行3列の表にしてください。1人分ずつリストにまとめて読み取ることはしないでください。

配点平均は、行列とベクトルの積で全員分を一度に求めてください。`scores[i] @ weights` のように1人ずつ内積を計算することはしないでください。

平均と配点平均は、どちらも基準点 `60` 以上なら `合格`、そうでなければ `不合格` とします。基準点と配点は、それぞれ1つの変数に入れて使います。

`total_score` や `average_score` のような関数は定義しないでください。`for value in scores` のような、値を1つずつ合計する書き方もしないでください。

<Input>
- 1行目: 人数（整数）
- 2行目から: 1人ずつ3科目の点数（整数、1行に1つ。人数×3行）
</Input>

<Output>
1人ずつ、次の3行をこの順に表示します。
- その人の3科目の平均（小数第1位まで丸める）と合否
- その人の3科目の点数から、科目ごとの全員の平均を引いた差（小数第1位まで丸めた配列のまま）
- 配点平均（小数第1位まで丸める）と合否

形は出力例のとおりです。
</Output>
</Exercise>
