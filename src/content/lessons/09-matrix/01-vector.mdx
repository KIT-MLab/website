{/* 困る例 */}

2人の3科目の点数が、どれくらい近いかを1つの数で言いたいとします。科目ごとの差を見ても、3つの数のままでは、全体としてどれくらい近いかが分かりません。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

v = np.array([3, 4])
print(np.sqrt(np.sum(v ** 2)))

a = np.array([80, 70, 90])
b = np.array([60, 50, 40])
print(np.sqrt(np.sum((a - b) ** 2)))`}
  out={`5.0
57.445626465380286`}
/>

{/* 説明 */}

ベクトルは、数を1列に並べたものです。並んでいる1つ1つの数を、成分と呼びます。3行目の `v` は、成分が3と4の、2つの数からなるベクトルです。

4行目は成分を2乗して足し、平方根を取っています。`np.sum(…)` は `( )` の中の配列の値をすべて足し（`.sum()` と同じです。第7章2節の「この節の書き方」の表）、`np.sqrt(…)` は平方根を出します（`math.sqrt` と同じです）。横3・縦4の直角三角形の斜辺を三平方の定理で出すのと同じ計算で、これを `v` の長さと呼びます。

成分が3つ以上に増えても、同じ式で長さを計算できます。6〜7行目の `a` と `b` は、3科目の点数を並べたベクトルです。

8行目の `a - b` は、科目ごとの差を並べたベクトルです。その長さを、2人の点数の距離と呼びます。値が小さいほど、2人の点数は近いことになります。
