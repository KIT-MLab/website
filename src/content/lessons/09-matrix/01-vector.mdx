{/* 困る例 */}

2人の3科目の点数が、どれくらい近いかを1つの数で言いたいとします。科目ごとの差を見ても、3つの数のままでは、全体としてどれくらい近いかが分かりません。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

v = np.array([3, 4])
print(np.sqrt(np.sum(v ** 2)))

a = np.array([80, 70, 90])
b = np.array([60, 50, 40])
print(np.sqrt(np.sum((a - b) ** 2)))`}
  out={`5.0
57.445626465380286`}
/>

{/* 説明 */}

3行目の `v` は、数Cで習った2次元のベクトル `(3, 4)` と同じ並びです。4行目は成分を2乗して足し、平方根を取っています。三平方の定理と同じ計算で、`v` の長さになります。

ベクトルは、数を1列に並べたものです。成分が2つなら平面の矢印と同じですが、3つ以上に増やしても同じ式で長さを計算できます。6〜8行目の `a` と `b` は、3科目の点数を並べたベクトルです。

8行目の `a - b` は、科目ごとの差を並べたベクトルです。その長さを、2人の点数の距離と呼びます。値が小さいほど、2人の点数は近いことになります。

2乗の和を求めるとき、for文で1つずつ足しても同じ値になりますが、配列ならまとめて計算できます。成分の数が増えても、書き方を変える必要がありません。

{/* よくある間違い */}

<Mistake
  id="vector-length-mismatch"
  code={`import numpy as np
a = np.array([80, 70, 90])
b = np.array([70, 90])
print(np.sqrt(np.sum((a - b) ** 2)))`}
  error={`ValueError: operands could not be broadcast together with shapes (3,) (2,) `}
>
`a` は3つ、`b` は2つの成分です。ベクトルどうしの引き算は、成分の数がそろっていないとできません。入力した数を数え直してください。
</Mistake>
