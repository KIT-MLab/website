{/* 困る例 */}

3科目の点数に、科目ごとに0.3・0.3・0.4の重みを掛けて足したいとします。重みは、その科目をどれだけ大事に数えるかを表す倍率です。`a[0] * w[0] + a[1] * w[1] + a[2] * w[2]` と書くと、科目が増えるたびに式が長くなります。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

a = np.array([80, 70, 90])
w = np.array([0.3, 0.3, 0.4])
print(a[0] * w[0] + a[1] * w[1] + a[2] * w[2])
print(a @ w)`}
  out={`81.0
81.0`}
/>

{/* 説明 */}

5行目は、3科目の点数と重みを、同じ位置どうし掛けて足しています。

6行目の `a @ w` は、同じ計算を1つの記号で表します。これを内積と呼びます。2つのベクトルの、同じ位置の成分どうしを掛けて足した1つの数です。

内積は `np.sum(a * w)` と書いても同じ値になります。`a * w` は、第7章1節の `a - b` と同じく、同じ位置どうしを掛けた配列です。
