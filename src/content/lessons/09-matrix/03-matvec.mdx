{/* 困る例 */}

全員分の重み付きの合計を出すには、1人ずつ内積を計算して並べることになります。人数が増えるたびに、同じ計算を書き直します。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

scores = np.array([[80, 70, 90], [60, 50, 40]])
w = np.array([0.3, 0.3, 0.4])
print(scores[0] @ w)
print(scores[1] @ w)
print(scores @ w)`}
  out={`81.0
49.0
[81. 49.]`}
/>

{/* 説明 */}

3行目の `scores` は、点数を行と列の2方向に並べた行列です。1行が1人分、1列が1科目分の点数になります。

5行目と6行目は、第9章2節と同じ内積を1人ずつ計算しています。`scores[0]` は1人目の3科目、`scores[1]` は2人目の3科目です。

7行目の `scores @ w` は、全員分をまとめて計算します。`(2, 3)` の行列と `(3,)` のベクトルの積は `(2,)` の形になり、各行と `w` の内積が並びます。

for文で1人ずつ計算しても同じ値になりますが、行列とベクトルの積なら1行で書けます。人数が増えても、書き方は変わりません。

{/* よくある間違い */}

<Mistake
  id="matvec-order"
  code={`import numpy as np
scores = np.array([[80, 70, 90], [60, 50, 40]])
w = np.array([0.3, 0.3, 0.4])
print(w @ scores)`}
  error={`ValueError: matmul: Input operand 1 has a mismatch in its core dimension 0, with gufunc signature (n?,k),(k,m?)->(n?,m?) (size 2 is different from 3)`}
>
行列とベクトルの積は、左右を入れ替えると成分の数が合わなくなります。全員分をまとめて計算したいときは、行列を先、ベクトルをあとに書きます。
</Mistake>
