{/* 困る例 */}

「3の5乗」を計算したくても `3 * 3 * 3 * 3 * 3` と書くのは大変です。「10を3で割った余り」を求める書き方も、まだ知りません。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`print(3 ** 5)
print(10 % 3)
print(10 // 3)`}
  out={`243
1
3`}
/>

{/* 説明 */}

1行目の `3 ** 5` はべき乗（exponentiation）の計算です。`3` を5回掛け合わせた `243` になります。

2行目の `10 % 3` は剰余（remainder）です。10を3で割った余りの `1` を返します。`%` の記号を使います。

3行目の `10 // 3` は整数除算（floor division）です。10を3で割った商を、小数点以下を切り捨てた整数の `3` で返します。

`//` は `%` と対になっています。割った商を `//` で、余りを `%` で求めれば、割り算の結果を2つの整数に分けられます。

`**` は `*` や `/` より先に計算されます。`2 * 3 ** 2` は `2 * 9` として計算され、`18` になります。

{/* よくある間違い */}

<Mistake id="pow-needs-int" code={`n = input()
print(3 ** n)`} stdin={`5`} error={`TypeError: unsupported operand type(s) for ** or pow(): 'int' and 'str'`}>
`input()` の結果は文字列です。べき乗の計算に使う前に `int()` で整数に変えてください。
</Mistake>

<Mistake id="mod-by-zero" code={`print(10 % 0)`} error={`ZeroDivisionError: division by zero`}>
0で割ることはできません。`%` と `//` のどちらも、右側の数が0だとエラーになります。
</Mistake>
