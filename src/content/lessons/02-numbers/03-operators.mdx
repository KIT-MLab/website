{/* 困る例 */}

「3の5乗」を `3 * 3 * 3 * 3 * 3` と書くと、掛けた回数を数え間違えやすくなります。「10を3で割った余り」は、`10 / 3` では `3.3333333333333335` となり、余りの `1` が出ません。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`print(3 ** 5)
print(10 % 3)
print(10 // 3)`}
  out={`243
1
3`}
/>

{/* 説明 */}

1行目の `3 ** 5` はべき乗（exponentiation）です。2行目の `10 % 3` は余り（剰余）です。3行目の `10 // 3` は切り捨て除算（整数除算）です。

| 記号 | 読み方 | 例 | 結果 |
|---|---|---|---|
| `**` | べき乗 | `3 ** 5` | `243`（3を5回掛けた値） |
| `%` | 余り | `10 % 3` | `1`（10を3で割った余り） |
| `//` | 切り捨て除算 | `10 // 3` | `3`（10を3で割った商） |

秒数を分と秒に分けるときなど、`//` と `%` はよく組み合わせて使います。

`//` は `%` と対になっています。割った商を `//` で、余りを `%` で求めれば、割り算の結果を2つの整数に分けられます。

`//` は、答えより小さい側の整数に切り捨てます。負の数では `int()` と結果が違い、`-9 // 2` は `-5`、`int(-9 / 2)` は `-4` です。
