{/* 困る例 */}

「3の5乗」を `3 * 3 * 3 * 3 * 3` と書くと、掛けた回数を数え間違えやすくなります。「10を3で割った余り」は、`10 / 3` では `3.3333333333333335` となり、余りの `1` が出ません。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`print(3 ** 5)
print(10 % 3)
print(10 // 3)`}
  out={`243
1
3`}
/>

{/* 説明 */}

計算に使う記号を演算子（operator）と呼びます。第1章1節の `+` `-` `*` `/` のほかに、1行目の `3 ** 5` はべき乗（exponentiation）、2行目の `10 % 3` は余り、3行目の `10 // 3` は切り捨て除算です。7つの演算子は次のとおりです。

| 記号 | 意味 | 例 | 結果 |
|---|---|---|---|
| `+` | 足し算 | `2 + 3` | `5` |
| `-` | 引き算 | `7 - 2` | `5` |
| `*` | 掛け算 | `4 * 3` | `12` |
| `/` | 割り算 | `7 / 2` | `3.5` |
| `**` | べき乗 | `3 ** 5` | `243`（3を5個掛け合わせた値） |
| `%` | 余り | `10 % 3` | `1`（10を3で割った余り） |
| `//` | 切り捨て除算 | `10 // 3` | `3`（10を3で割って切り捨てた値） |

`/` の答えはいつも float です。ほかの演算子は、int どうしなら int、float が混ざれば float になります（`10 ** -3` のように、`**` の指数が負のときだけ、int どうしでも float です）。

秒数を分と秒に分けるときなど、`//` と `%` はよく組み合わせて使います。

`//` は、割り算の答えを、それ以下でいちばん大きい整数に切り捨てます。負の数では `int()` と結果が違い、`-9 // 2` は `-5`、`int(-9 / 2)` は `-4` です。
