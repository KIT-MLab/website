{/* 困る例 */}

10個のりんごを2人で分けると、答えは `5` のはずです。ところが `10 / 2` を計算すると `5.0` になります。整数のつもりで書いた式が、いつも小数の形で返ってきます。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`print(10 / 4)
print(9 / 3)`}
  out={`2.5
3.0`}
/>

{/* 説明 */}

`/` で割り算をすると、結果は必ず小数になります。1行目の `10 / 4` は `2.5` に、2行目の `9 / 3` は割り切れる式でも `3.0` になります。

値の種類を型（type）と呼びます。`3` のような整数の型は `int`、`2.5` のような小数の型は `float` です。`float` は浮動小数点数（floating-point number）の略です。

整数と小数を混ぜて計算すると、結果も自動的に float になります。たとえば `1 + 2.5` は `3.5` です。

`float()` は、文字列や整数を小数に変える関数です。`int()` が文字列を整数に変えるように、`float()` は文字列を小数に変えます。小数を含む入力を読み取るときに使います。

<Run
  code={`x = float(input())
print(x * 2)`}
  stdin={`2.5`}
  out={`5.0`}
/>

`int()` に小数を渡すと、小数点以下を取り除いて整数にします。`int(7.9)` の結果は `7` で、`8` には丸まりません。最初に見た `10 / 2` も、`int(10 / 2)` と書けば `5` になります。
