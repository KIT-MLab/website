{/* 困る例 */}

10個のりんごを2人で分けると、答えは `5` のはずです。ところが `10 / 2` を計算すると `5.0` になります。整数のつもりで書いた式が、いつも小数の形で返ってきます。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`print(10 / 4)
print(9 / 3)`}
  out={`2.5
3.0`}
/>

{/* 説明 */}

`/` で割り算をすると、結果は必ず小数になります。1行目の `10 / 4` は `2.5` に、2行目の `9 / 3` は割り切れる式でも `3.0` になります。

値の種類を型（type）と呼びます。この小数の型を `float`（浮動小数点数）と呼びます。

整数と小数を混ぜて計算すると、結果も自動的に float になります。たとえば `1 + 2.5` は `3.5` です。

`float()` は、文字列や整数を小数に変える関数です。`int()` が文字列を整数に変えるのと対になる関数で、小数を含む入力を読み取るときに使います。

`int()` に小数を渡すと、小数点以下を切り捨てて整数にします。`int(7.9)` の結果は `7` で、`8` には丸まりません。

{/* よくある間違い */}

<Mistake id="int-cant-decimal" code={`age = int(input())
print(age)`} stdin={`3.5`} error={`ValueError: invalid literal for int() with base 10: '3.5'`}>
入力に小数点が含まれると `int()` はエラーになります。小数として読み取るときは `float()` を使ってください。
</Mistake>

<Mistake id="float-bad-string" code={`weight = float(input())
print(weight)`} stdin={`abc`} error={`ValueError: could not convert string to float: 'abc'`}>
`float()` は数字として読める文字列しか変換できません。入力に数字以外の文字が混ざっていないか確認してください。
</Mistake>
