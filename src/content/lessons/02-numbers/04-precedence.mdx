{/* 困る例 */}

2と3の和に4を掛けたくて `2 + 3 * 4` と書くと、答えは `20` ではなく `14` になります。足し算を先にさせる書き方が要ります。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`print(2 + 3 * 4)
print((2 + 3) * 4)`}
  out={`14
20`}
/>

{/* 説明 */}

Python は、演算子ごとに決まった順番で計算します。この順番を優先順位（precedence）と呼びます。

1行目の `2 + 3 * 4` は、先に `3 * 4` が計算されて `12` になり、これに `2` を足して `14` になります。第2章3節の演算子も入れると、順番は次のとおりです。

| 計算する順 | 演算子 |
|---|---|
| 1 | `**` |
| 2 | `*` `/` `//` `%` |
| 3 | `+` `-` |

`2 * 3 ** 2` は `**` が先なので `2 * 9` として計算され、`18` になります。

計算する順の表の2番目や3番目のように、同じ順位の演算子が並ぶときは、左から順に計算します（`8 / 4 / 2` は `(8 / 4) / 2` と同じです）。

2行目の `(2 + 3) * 4` は `()` で囲んだ `2 + 3` が最初に計算され、`5` になってから `4` を掛けます。`()` で囲んだ中は、優先順位に関係なく最初に計算されます。

かっこは何重にも重ねられます。`(12 - (2 + 3)) * 4` は、内側の `()` から順に計算します。
