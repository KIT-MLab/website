{/* 困る例 */}

`2 + 3 * 4` を計算すると、左から順に `20` になりそうですが、Python では `14` になります。思った順番で計算させる書き方が分かりません。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`print(2 + 3 * 4)
print((2 + 3) * 4)`}
  out={`14
20`}
/>

{/* 説明 */}

Python は `*` と `/` を、`+` と `-` より先に計算します。この順番を優先順位（precedence）と呼びます。

1行目の `2 + 3 * 4` は、先に `3 * 4` が計算されて `12` になり、`2` を足した `14` になります。

2行目の `(2 + 3) * 4` は `()` で囲んだ `2 + 3` が最初に計算され、`5` になってから `4` を掛けます。`()` は優先順位を無視して、中を最初に計算させます。つまり `()` を使えば、計算の順番を自分で決められます。

かっこは何重にも重ねられます。`((2 + 3) * 4) - 1` は、内側の `()` から順に計算します。

<Figure
  caption="計算の順番"
  code="((2 + 3) * 4) - 1"
  marks={[
    { part: '(2 + 3)', note: '内側のかっこを先に計算する', value: '5' },
    { part: '((2 + 3) * 4)', note: '外側のかっこを計算する', value: '20' },
    { part: '((2 + 3) * 4) - 1', note: '残りを計算する', value: '19' },
  ]}
/>

式が複雑になったら、かっこで区切ると読みやすくなります。
