{/* 困る例 */}

`2 + 3 * 4` を計算すると、左から順に `20` になりそうですが、Python では `14` になります。思った順番で計算させる書き方が分かりません。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`print(2 + 3 * 4)
print((2 + 3) * 4)`}
  out={`14
20`}
/>

{/* 説明 */}

Python は `*` と `/` を、`+` と `-` より先に計算します。この順番を優先順位（precedence）と呼びます。

1行目の `2 + 3 * 4` は、先に `3 * 4` が計算されて `12` になり、`2` を足した `14` になります。`**` は `*` よりさらに先に計算されます。

2行目の `(2 + 3) * 4` は `()` で囲んだ `2 + 3` が最初に計算され、`5` になってから `4` を掛けます。`()` は優先順位を無視して、中を最初に計算させます。

かっこは何重にも重ねられます。`((2 + 3) * 4) - 1` のように書くと、内側の `()` から順に計算され、`19` になります。式が複雑になったら、かっこで区切ると読みやすくなります。

{/* よくある間違い */}

<Mistake id="missing-close-paren" code={`print((2 + 3) * 4`} error={`SyntaxError: '(' was never closed`}>
`(` の数だけ `)` が要ります。開いたかっこを閉じ忘れていないか、行の終わりを確認してください。
</Mistake>

<Mistake id="extra-close-paren" code={`print((2 + 3) * 4))`} error={`SyntaxError: unmatched ')'`}>
`)` が `(` より1つ多くなっています。対応するかっこの数を数え直してください。
</Mistake>
