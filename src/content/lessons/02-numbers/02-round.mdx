{/* 困る例 */}

3教科の平均を出すとき、`240 / 3` なら `80.0` です。しかし `245 / 3` は `81.66666666666667` になり、読みにくい桁数のまま表示されてしまいます。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`total = 245
average = total / 3
print(average)
print(round(average))
print(round(average, 1))`}
  out={`81.66666666666667
82
81.7`}
/>

{/* 説明 */}

`round()` は、数値を丸める関数です。3行目で `average` をそのまま表示すると、長い小数のままです。4行目の `round(average)` は、いちばん近い整数の `82` を返します。

5行目の `round(average, 1)` は、小数第1位までに丸めた `81.7` を返します。2つ目の引数の `1` が、残す小数点以下の桁数です。

`round()` は新しい値を返すだけで、元の `average` の中身は変わりません。f文字列で表示するときは、`rounded = round(average, 1)` と変数に入れてから `{rounded}` と書けます。`{round(average, 1)}` のように、`{}` の中に直接書くこともできます。

2つ目の引数を変えると、残る桁数が変わります。

| 2つ目の引数 | 結果の例 |
|---|---|
| `0` | `round(average, 0)` は `82.0` |
| `1` | `round(average, 1)` は `81.7` |
| `2` | `round(average, 2)` は `81.67` |
| 省略 | `round(average)` は `82` |

`0` を書くと小数の `82.0`、省略すると整数の `82` になり、結果の型が違います。

ちょうど真ん中の値は、偶数の側に丸まります。`round(2.5)` は `3` ではなく `2`、`round(3.5)` は `4` です。また、丸めた結果の末尾の0は表示されず、`round(2.504, 2)` は `2.5` と出ます。
