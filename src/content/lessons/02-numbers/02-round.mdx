{/* 困る例 */}

3教科の平均を出すとき、`240 / 3` なら `80.0` です。しかし `245 / 3` は `81.66666666666667` になり、読みにくい桁数のまま表示されてしまいます。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`total = 245
average = total / 3
print(average)
print(round(average, 1))`}
  out={`81.66666666666667
81.7`}
/>

{/* 説明 */}

`round(値, 桁数)` は、指定した桁数に数値を丸める関数です。3行目で `average` をそのまま表示すると、長い小数のままです。

4行目の `round(average, 1)` は、小数第1位までに丸めた `81.7` を返します。第2引数の `1` が、残す小数点以下の桁数です。

`round()` は新しい値を返すだけで、元の `average` の中身は変わりません。表示するときや、別の変数に入れるときに使います。

第2引数を変えると、残る桁数が変わります。

| 第2引数 | 結果の例 |
|---|---|
| `0` | `round(average, 0)` は `82.0` |
| `1` | `round(average, 1)` は `81.7` |
| `2` | `round(average, 2)` は `81.67` |
| 省略 | `round(average)` は `82` |

`0` を書くと小数の `82.0`、省略すると整数の `82` になり、結果の型が違います。

{/* よくある間違い */}

<Mistake id="round-digits-string" code={`average = 81.666
print(round(average, "1"))`} error={`TypeError: 'str' object cannot be interpreted as an integer`}>
第2引数の桁数は整数で書きます。`"1"` のように文字列で渡すとエラーになります。
</Mistake>

<Mistake id="round-of-string" code={`average = "81.6"
print(round(average, 1))`} error={`TypeError: type str doesn't define __round__ method`}>
`round()` は数値にしか使えません。`average` が文字列のままなら、先に `float()` で変えてください。
</Mistake>
