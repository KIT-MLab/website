{/* 困る例 */}

点数の平均や最大を出すには、for文で合計してから割ったり、大きい値を探したりすることになります。人ごと・科目ごとに出したいと、同じ形の計算を何度も書きます。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

scores = np.array([[80, 70, 90], [60, 50, 40]])
print(scores.mean())
print(scores.mean(axis=0))
print(scores.mean(axis=1))`}
  out={`65.0
[70. 60. 65.]
[80. 50.]`}
/>

{/* 説明 */}

3行目の `scores` は、前の節で作った2次元配列です。4行目の `scores.mean()` は、6つの値すべての平均です。

5行目の `axis=0` は、第5章4節で見た名前を書いて渡す引数です。人をまたいで計算し、科目ごとの平均 `[70. 60. 65.]` になります。結果の個数は科目の数と同じです。

6行目の `axis=1` は科目をまたいで計算し、人ごとの平均 `[80. 50.]` になります。結果の個数は人数と同じです。

`sum()` と `max()` も同じ形で、合計といちばん大きい値を求められます。`axis=` を付けなければ、配列全体でまとめます。

{/* よくある間違い */}

<Mistake
  id="axis-out-of-bounds"
  code={`import numpy as np
scores = np.array([[80, 70, 90], [60, 50, 40]])
print(scores.mean(axis=2))`}
  error={`AxisError: axis 2 is out of bounds for array of dimension 2`}
>
この配列には軸が `0` と `1` の2つしかありません。`axis=2` は存在しない軸です。
</Mistake>
