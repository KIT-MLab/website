{/* 困る例 */}

第6章までの点数表では、合計を出す関数がfor文で1つずつ足していて、その関数を人数ぶんのfor文の中から呼んでいました。そのため、合計を1つ出すのにもfor文が二重になります。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

table = []
for i in range(2):
    table.append([int(input()), int(input()), int(input())])
scores = np.array(table)
print(scores.sum(axis=1))
print(np.round(scores.mean(axis=1), 1))`}
  stdin={`40
55
50
65
82
70`}
  out={`[145 217]
[48.3 72.3]`}
/>

{/* 説明 */}

3〜6行目は、第7章5節の `append` の形を for文の中で2人ぶんくり返し、2次元配列 `scores` を作っています。

7行目の `scores.sum(axis=1)` は、人ごとに3科目を合計します。第5章の `total_score` を人数ぶん呼び出さなくても、一度で全員の合計が出ます。

8行目の `scores.mean(axis=1)` は人ごとの平均です。`np.round(配列, 1)` は、第2章の `round()` と同じ丸め方で、配列の値すべてを丸めます。ここでは小数第1位までです。

第5章・第6章の点数表を、配列を使って書き直してください。平均は小数第1位に丸め、基準点以上なら `合格`、そうでなければ `不合格` とします。基準点は `60` とし、変数に入れます。

`total_score` や `average_score` のような関数は定義しないでください。`total = total + value` のような、値を1つずつ足し上げる書き方もしないでください。

- 1行目: 人数（整数）
- 2行目から: 1人ずつ、3科目の点数（整数、1行に1つ）
</Input>

<Output>
1人ずつ、平均と合否を1行で表示します。形は出力例のとおりです。
</Output>
