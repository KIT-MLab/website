{/* 困る例 */}

配列の中から条件に合う値だけを取り出したいとき、for文で1つずつ確かめて、リストに入れていくことになります。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

scores = np.array([40, 90, 55, 70, 30])
print(scores >= 60)
print(scores[scores >= 60])`}
  out={`[False  True False  True False]
[90 70]`}
/>

{/* 説明 */}

4行目の `scores >= 60` は、各要素が条件を満たすかを比べ、`True` と `False` の配列で返します。

5行目の `scores[scores >= 60]` は、その配列を `[ ]` の中に書いています。`True` の位置の値だけが取り出されます。

`True` と `False` のどちらかしか持たない値をブールと呼ぶので、これをブールインデックス（条件での取り出し）と呼びます。

元の並び順は変わりません。
