{/* 困る例 */}

配列の中から条件に合う値だけを集めたいとき、for文で1つずつ確かめて、リストに集めることになります。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

scores = np.array([40, 90, 55, 70, 30])
print(scores >= 60)
print(scores[scores >= 60])
print(len(scores[scores >= 60]))`}
  out={`[False  True False  True False]
[90 70]
2`}
/>

{/* 説明 */}

4行目の `scores >= 60` は、各要素が条件を満たすかを比べ、`True` と `False` の配列で返します。

5行目の `scores[scores >= 60]` は、その配列を `[ ]` の中に書いています。`True` の位置の値だけが取り出されます。これをブールインデックス（条件での取り出し）と呼びます。

取り出す個数は、条件を満たす値の数で変わります。6行目のように `len()` を使うと、その個数を数えられます。

for文を書かずに、条件に合う値だけを取り出せます。元の並び順は変わりません。
