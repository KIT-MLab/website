{/* 困る例 */}

5人の点数から、前の3人分だけを取り出したいとします。インデックスを1つずつ書くと、`scores[0]` `scores[1]` `scores[2]` と並べることになります。取り出したい数が増えるほど、書く量も増えます。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

scores = np.array([40, 90, 55, 70, 30])
print(scores[1:3])
print(scores[:3])
print(scores[2:])`}
  out={`[90 55]
[40 90 55]
[55 70 30]`}
/>

{/* 説明 */}

4行目の `scores[1:3]` はスライス（slice）です。`[開始:終了]` の形で、インデックス1から2までを取り出します。終了のインデックス3は含まれません。

5行目の `[:3]` のように開始を省くと、先頭から取り出します。6行目の `[2:]` のように終了を省くと、最後まで取り出します。

開始や終了には、`scores[:k]` のように、数の入った変数も書けます。

リストにも同じ書き方が使えます。例は、第4章3節の「この節の書き方」の表にあります。
