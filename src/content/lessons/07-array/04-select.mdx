{/* 困る例 */}

配列の中から条件に合う値だけを集めたいとき、for文で1つずつ確かめて、リストに集めることになります。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

scores = np.array([40, 90, 55, 70, 30])
print(scores[scores >= 60])
print(scores[1:3])`}
  out={`[90 70]
[90 55]`}
/>

{/* 説明 */}

4行目の `scores >= 60` は、各要素が条件を満たすかを `True` `False` で表した配列です。`scores[scores >= 60]` は、その配列をインデックスにして `True` の位置の値だけを取り出します。これをブールインデックス（条件での取り出し）と呼びます。

5行目の `scores[1:3]` はスライス（slice）です。`[開始:終了]` の形で、インデックス1から2までの範囲を取り出します。終了のインデックス3は含まれません。

ブールインデックスは、条件を満たす値の数によって、結果の個数が変わります。スライスは、指定した範囲の個数がそのまま返ります。

どちらも、for文を書かずに一部の値だけを取り出せます。元の並び順は変わりません。

{/* よくある間違い */}

<Mistake
  id="select-truth-value"
  code={`import numpy as np
scores = np.array([40, 90, 55, 70, 30])
if scores >= 60:
    print(scores)`}
  error={`ValueError: The truth value of an array with more than one element is ambiguous. Use a.any() or a.all()`}
>
`scores >= 60` は複数の値からなる配列です。if文の条件には使えません。`scores[scores >= 60]` のようにインデックスとして使ってください。
</Mistake>
