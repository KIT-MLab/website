{/* 困る例 */}

第6章までの点数表は、合計を出すためにfor文で1つずつ足す関数を、人数ぶん呼び出していました。人数や科目が増えるほど、計算に使うfor文が増えていきます。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

scores = np.array([[40, 55, 50], [65, 82, 70]])
print(scores.sum(axis=1))
print(np.round(scores.mean(axis=1), 1))`}
  out={`[145 217]
[48.3 72.3]`}
/>

{/* 説明 */}

3行目の `scores` は、2人分の点数をまとめた2次元配列です。1行が1人分の3科目にあたります。

4行目の `scores.sum(axis=1)` は、人ごとに3科目を合計します。第6章の `total_score` を人数ぶん呼び出さずに、一度で終わります。

5行目の `scores.mean(axis=1)` は人ごとの平均です。`np.round(..., 1)` で小数第1位に丸めています。

`total_score` と `average_score`、それを人数ぶん呼び出すfor文は、もう要りません。人数が増えたときも、配列の行数が増えるのみで、計算の書き方はそのままです。

第5章・第6章の点数表を、配列を使って書き直してください。入力欄の1行目を人数として読み取り、続けて人数ぶん3教科の点数を読み取ります。

1人ずつ `平均48.3点 不合格` の形で、平均と合否を表示してください。基準点は `60` とし、変数にします。

`total_score` や `average_score` のような関数は定義しないでください。`for value in scores` のような、値を1つずつ合計する書き方もしないでください。
