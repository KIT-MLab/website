{/* 困る例 */}

3人の点数の平均と最高点を出すとします。第4章のやり方では、for文で合計を足し上げてから人数で割り、最高点はもう1つのfor文で探すことになります。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

scores = np.array([80, 70, 90])
print(scores.mean())
print(scores.sum())
print(scores.max())
print(scores.min())`}
  out={`80.0
240
90
70`}
/>

{/* 説明 */}

4行目の `scores.mean()` は、配列の値すべての平均を返します。配列の名前のあとに `.mean()` を付けて呼び出します。

5〜7行目の `sum()` `max()` `min()` も同じ形で、合計・いちばん大きい値・いちばん小さい値を返します。

平均の `80.0` は、割り算で求めるので `float` になります。合計・最大・最小は、元の値と同じ整数のままです。返ってきた値は、ふつうの数と同じように計算に使えます。

`scores.mean()` は、`np.mean(scores)` のように `np.` の関数としても書けます。この先の章では、この形をよく使います。
