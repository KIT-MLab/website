{/* 困る例 */}

2次元配列の点数表で、科目ごとの平均を出したいとします。第7章2節の `mean()` をそのまま使うと、6つの値すべての平均が1つ出ます。科目ごとに分けるには、for文で1人ずつ回して、科目ごとに足し上げることになります。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

scores = np.array([[80, 70, 90], [60, 50, 40]])
print(scores.mean())
print(scores.mean(axis=0))
print(scores.mean(axis=1))`}
  out={`65.0
[70. 60. 65.]
[80. 50.]`}
/>

{/* 説明 */}

4行目の `scores.mean()` は、2次元配列でも6つの値すべての平均になります。

5行目の `axis=0` は、第5章4節で見た名前を書いて渡す引数です。`0` は `shape` の `(2, 3)` の0番目、つまり人の数の2にあたり、この方向を軸（axis）と呼びます。

`axis=0` は、80と60、70と50、90と40を縦に（人をまたいで）計算するので、科目ごとの平均 `[70. 60. 65.]` になります。結果の個数は科目の数と同じです。

6行目の `axis=1` は、80と70と90、60と50と40を横に（科目をまたいで）計算するので、人ごとの平均 `[80. 50.]` になります。結果の個数は人数と同じです。`sum()` `max()` `min()` にも、同じように `axis=` を付けられます。

`[70. 60. 65.]` の `70.` は、`70.0` のことです。平均は割り算で求めるので `float` になります。配列の中では、小数点のあとの `0` を省いて表示します。
