{/* 困る例 */}

点数のリストの全員に10点を足したいとき、for文で1人ずつ取り出して計算することになります。人数が増えるほど、同じ形の行を書くことになります。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

scores = np.array([40, 55, 50])
print(scores + 10)`}
  out={`[50 65 60]`}
/>

{/* 説明 */}

1行目の `import numpy as np` は、numpyというモジュールを読み込みます。`np` という短い名前で使えるようにします。

3行目の `np.array([40, 55, 50])` で配列（array）を作ります。配列はリストに似ていますが、要素ごとの計算をまとめて行えます。

4行目の `scores + 10` は、3つの値それぞれに10を足します。for文を書かずに、全員分の計算が1行で終わります。

表示される `[50 65 60]` は、値の間をコンマなしで区切った形です。リストの `[50, 65, 60]` とは表示のされ方が違います。

{/* よくある間違い */}

<Mistake
  id="array-no-as-np"
  code={`import numpy
scores = np.array([40, 55, 50])
print(scores)`}
  error={`NameError: name 'np' is not defined`}
>
`import numpy` だけでは `np` という名前は使えません。`import numpy as np` と書いてください。
</Mistake>
