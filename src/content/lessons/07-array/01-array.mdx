{/* 困る例 */}

点数のリストの全員に10点を足したいとき、for文で1人ずつ取り出して計算することになります。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

scores = np.array([40, 55, 50])
print(scores + 10)

retest = np.array([60, 70, 80])
print(retest - scores)`}
  out={`[50 65 60]
[20 15 30]`}
/>

{/* 説明 */}

1行目の `import numpy as np` は、numpyというモジュールを読み込みます。`np` という短い名前で使えるようにします。

3行目の `np.array([40, 55, 50])` で配列（array）を作ります。配列はリストに似ていますが、要素ごとの計算をまとめてできます。

4行目の `scores + 10` は、3つの値それぞれに10を足します。

7行目の `retest - scores` は、再試験の点数から元の点数を、同じ位置どうしで引き算します。配列どうしも、このように計算できます。`+` `-` `*` `/` `**` のどれも、要素ごとに計算します。

計算の記号のほかに、`np.sqrt(配列)` のように、`np.` で始まる数学の関数も、配列の値ひとつずつに使えます。使える関数の一覧は、この節の最初にある「この節の書き方」の表にあります。

表示される `[50 65 60]` は、値の間をコンマではなく空白で区切った形です。リストの `[50, 65, 60]` とは表示のされ方が違います。
