{/* 困る例 */}

点数表は人と科目の2方向に値が並びます。1つの配列にそのまま並べると、どこからどこまでが1人分か分からなくなります。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

table = []
table.append([80, 70, 90])
table.append([60, 50, 40])
scores = np.array(table)
print(scores)
print(scores.shape)
print(scores[0])
print(scores[1][2])`}
  out={`[[80 70 90]
 [60 50 40]]
(2, 3)
[80 70 90]
40`}
/>

{/* 説明 */}

3〜5行目は、空のリスト `table` に、1人分の3科目のリストを1行ずつ `append` しています。リストを並べたリストができます。人数を入力から読むときは、for文の中でこの `append` を人数ぶんくり返します。

6行目の `np.array(table)` で、これが2次元配列（2D array）になります。行が人、列が科目にあたります。値が決まっているときは、`np.array([[80, 70, 90], [60, 50, 40]])` と1行でも書けます。

7行目の `print(scores)` は、1行ずつ改行して表示します。8行目の `scores.shape` は行数と列数を調べます。`(2, 3)` は2行3列という意味です。

9行目の `scores[0]` は、0番目の行をそのまま取り出します。1人分の3科目が配列で返ります。

10行目の `scores[1][2]` は、1番目の行の2番目の値です。`[行][列]` の順にインデックスを重ねます。`scores[1]` だけなら1行ぶんの配列、`[2]` まで書くとその中の1つの値になります。
