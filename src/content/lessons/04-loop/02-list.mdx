{/* 困る例 */}

点数が5人ぶんあるとします。`score1` から `score5` まで、5つの変数を作ることになります。10人になれば10個です。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`numbers = [3, 7, 2, 9, 4]
for value in numbers:
    print(value)`}
  out={`3
7
2
9
4`}
/>

{/* 説明 */}

1行目の `numbers = [3, 7, 2, 9, 4]` はリスト（list）です。複数の値を1つの名前にまとめて持てます。値は `[` `]` の中に、`,` で区切って並べます。

2行目の `for value in numbers:` は、リストの値を先頭から順に `value` に入れます。入れるたびに、インデントした行を繰り返します。1回目は `value` が `3`、2回目は `7` になります。

この繰り返しは、リストに入っている値の数だけ続きます。

次のコードは、入力欄の4行の中から一番大きい値を探します。入力欄に `6` `2` `9` `4` と4行書いてある状態で ▶ を押してください。

<Run
  code={`largest = int(input())
numbers = [int(input()), int(input()), int(input())]
for value in numbers:
    if value > largest:
        largest = value
print(largest)`}
  stdin={`6
2
9
4`}
  out={`9`}
/>

1行目で最初の1行を読み、いまのところの最大として `largest` に入れます。

2行目のように、`[` `]` の中に `int(input())` を並べて書くと、入力欄の残りの3行を整数にして、リストにまとめられます。

4〜5行目で、`value` が `largest` より大きいときだけ `largest` を入れ直します。繰り返しが終わると、`largest` には一番大きい `9` が残ります。`largest = value` は `if` の中の行なので、さらに1段インデントします。
