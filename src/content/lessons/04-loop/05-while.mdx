{/* 困る例 */}

参加者が入力した行を、`終わり` と入力されるまで受け取りたいとします。for文は繰り返す回数を先に決める書き方で、回数が決まっていない繰り返しをまだ書けません。

{/* やってみる */}

入力欄に `a` `b` `c` `終わり` と4行書いてある状態で ▶ を押してください。

<Run
  code={`count = 0
line = input()
while line != "終わり":
    count = count + 1
    line = input()
print(count)`}
  stdin={`a
b
c
終わり`}
  out={`3`}
/>

{/* 説明 */}

3行目の `while line != "終わり":` はwhile文（while statement）です。条件が成り立つ間、字下げした行を繰り返します。

2行目の `input()` で、判定に使う最初の行を先に読みます。5行目でも同じように読み直すので、繰り返すたびに新しい行と比べられます。

入力欄に `終わり` の行が来ると、3行目の条件が成り立たなくなり、繰り返しが終わります。for文と違い、繰り返す回数を先には決めません。

4行目の `count = count + 1` で、繰り返すたびに数を1つ増やします。最後の `print(count)` で、`終わり` より前に読んだ行の数を表示します。

{/* よくある間違い */}

<Mistake
  id="while-missing-quotes"
  code={`line = input()
while line != 終わり:
    line = input()`}
  stdin={`a`}
  error={`NameError: name '終わり' is not defined`}
>
`終わり` に `"` が付いていません。文字列として比べるには `"終わり"` のように引用符で囲みます。
</Mistake>

<Mistake
  id="while-forgot-int"
  code={`total = 0
line = input()
while line != "終わり":
    total = total + line
    line = input()
print(total)`}
  stdin={`3
5
終わり`}
  error={`TypeError: unsupported operand type(s) for +: 'int' and 'str'`}
>
`line` は文字列のままです。数として足すには `int(line)` のように整数へ変えてください。
</Mistake>
