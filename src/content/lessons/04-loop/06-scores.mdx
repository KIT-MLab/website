{/* 困る例 */}

第3章までの点数表は、1人ぶんの判定しかできません。人数が増えると、同じコードを人数ぶん書き写すことになります。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`threshold = 60
for i in range(2):
    scores = [int(input()), int(input()), int(input())]
    average = (scores[0] + scores[1] + scores[2]) / 3
    if average >= threshold:
        print(f"平均{round(average, 1)}点 合格")
    else:
        print(f"平均{round(average, 1)}点 不合格")`}
  stdin={`40
55
50
65
82
70`}
  out={`平均48.3点 不合格
平均72.3点 合格`}
/>

{/* 説明 */}

2行目の `for i in range(2):` で、判定を2人ぶん繰り返します。3行目の `scores = [int(input()), int(input()), int(input())]` は、1人ぶんの3教科を読み取ってリストにまとめます（第4章2節）。

第3章までは、3教科をそれぞれ別の変数に読み取っていました。繰り返しの中に書いたので、人数が増えても、書くのはこの1人ぶんのコードだけです。

5〜8行目は第3章のif文とelseをそのまま使い、平均と基準点を比べています。`average` は、1人判定するたびに新しい値に入れ替わります。
