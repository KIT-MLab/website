{/* 困る例 */}

第3章までの点数表は、1人ぶんの判定しかできません。人数が増えると、同じコードを人数ぶん書き写すことになります。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`threshold = 60
for i in range(2):
    scores = [int(input()), int(input()), int(input())]
    average = (scores[0] + scores[1] + scores[2]) / 3
    if average >= threshold:
        print(f"平均{round(average, 1)}点 合格")
    else:
        print(f"平均{round(average, 1)}点 不合格")`}
  stdin={`40
55
50
65
82
70`}
  out={`平均48.3点 不合格
平均72.3点 合格`}
/>

{/* 説明 */}

2行目の `for i in range(2):` で、判定を2人ぶん繰り返します。3行目は `scores = [int(input()), int(input()), int(input())]` です。1人ぶんの3教科を、リストにまとめて読み取ります。

第3章までは、3教科をそれぞれ別の変数に読み取っていました。リストにまとめたことで、人数が増えても同じ3行のままで対応できます。

5〜8行目は第3章のif文とelseをそのまま使い、平均と基準点を比べています。繰り返しの中の変数は、1人判定するたびに読み取り直されます。同じ変数名を、人数ぶん使い回しています。

{/* よくある間違い */}

<Mistake
  id="scores-loop-count-no-int"
  code={`count = input()
threshold = 60
for i in range(count):
    scores = [int(input()), int(input()), int(input())]
    average = (scores[0] + scores[1] + scores[2]) / 3
    print(average)`}
  stdin={`1
60
60
60`}
  error={`TypeError: 'str' object cannot be interpreted as an integer`}
>
`count` が文字列のままです。`range()` に渡すには `int(input())` で整数に変えてください。
</Mistake>

<Mistake
  id="scores-loop-threshold-name"
  code={`count = int(input())
threshold = 60
for i in range(count):
    scores = [int(input()), int(input()), int(input())]
    average = (scores[0] + scores[1] + scores[2]) / 3
    if average >= thresholds:
        print(f"平均{round(average, 1)}点 合格")
    else:
        print(f"平均{round(average, 1)}点 不合格")`}
  stdin={`1
60
60
60`}
  error={`NameError: name 'thresholds' is not defined`}
>
`threshold` と `thresholds` は別の名前です。定義した名前とそろえてください。
</Mistake>
