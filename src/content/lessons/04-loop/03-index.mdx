{/* 困る例 */}

リストの中で、1番先頭の値と3番目の値だけを比べたいとします。`for value in numbers:` はすべての値を順に取り出す書き方で、決まった位置の値だけを選べません。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`numbers = [3, 7, 2, 9, 4]
print(numbers[0])
print(numbers[2])
print(len(numbers))`}
  out={`3
2
5`}
/>

{/* 説明 */}

2行目の `numbers[0]` はインデックス（添字）を使って値を取り出しています。インデックスは `0` から数えるので、`numbers[0]` は先頭の `3` です。

3行目の `numbers[2]` は、先頭から3つ目の `2` です。`0`、`1`、`2` と数えるので、インデックスは3つ目でも `2` になります。

4行目の `len(numbers)` は、リストに入っている値の数を返す関数です。`numbers` には5つの値があるので `5` です。

`range(len(numbers))` と書けば、`0` から `len(numbers) - 1` までのインデックスを順に作れます。`for i in range(len(numbers)):` とすれば、インデックスを使って1つずつ処理できます。

{/* よくある間違い */}

<Mistake
  id="index-out-of-range"
  code={`numbers = [3, 7, 2, 9, 4]
print(numbers[5])`}
  error={`IndexError: list index out of range`}
>
インデックスは `0` から数えるので、最後の値のインデックスは `len(numbers) - 1` です。`numbers[5]` の位置には値がありません。
</Mistake>

<Mistake
  id="index-len-method"
  code={`numbers = [3, 7, 2, 9, 4]
print(numbers.len())`}
  error={`AttributeError: 'list' object has no attribute 'len'`}
>
`len` はリストの後ろに `.` を付けて呼ぶ形ではありません。`len(numbers)` のように、かっこの中にリストを渡します。
</Mistake>
