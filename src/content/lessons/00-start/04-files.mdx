{/* 困る例 */}

作ったプログラムを保存しても、あとで見つからないことがあります。同じ名前のファイルが2つあると、どちらが正しいのか分かりません。ファイルの種類も、名前を見ただけでは分からないことがあります。

{/* やってみる */}

自分のパソコンでエクスプローラーを開き、ファイルを1つ見てください。設定はまだ変えません。

いま、設定を変える前のエクスプローラーで、ファイル名の末尾はどう見えていますか。

- `.py` や `.txt` のような文字列が見える
- 何も見えない（拡張子は隠れている）
- 作った日付が見える
- ファイルの保存場所が見える
</Exercise>

{/* 説明 */}

ファイルは、保存した文章やプログラムの1つのまとまりです。フォルダは、ファイルをまとめて入れる場所です。保存する場所を決めておくと、あとで迷いません。

ファイル名の末尾には、種類を表す文字列が付きます。これを拡張子と呼び、`.py` は Python のプログラムを表します。多くのパソコンは、既定では拡張子を隠す設定になっています。

エクスプローラーの「表示」にある「ファイル名拡張子」という項目にチェックを入れると、拡張子を表示できます。

<Level0 title="拡張子を表示する設定">
エクスプローラーを開き、上部の「表示」を選びます。一覧の中から、上で説明した項目にチェックを入れると、ファイル名の末尾に `.py` や `.txt` が見えるようになります。
</Level0>

{/* よくある間違い */}

<Mistake id="start-files-dot" code={`x = 3．14
print(x)`} error={`SyntaxError: invalid character '．' (U+FF0E)`}>
全角の `．` になっています。小数点もファイルの拡張子の `.` も、半角で打ちます。日本語入力をオフにしてから打ち直してください。
</Mistake>
