{/* 困る例 */}

コードを1文字直すたびに、全部を打ち直すのは大変です。消してはいけない行を、誤って消してしまうこともあります。戻し方を知らないと、そのたびに最初から打ち直すことになります。

{/* やってみる */}

<Exercise
  id="start-03-copy-4"
  kind="type"
  tests={[{ kind: 'text', expect: `雨 のち 晴れ` }]}
  hints={[]}
  mistakes={[]}
>
次の言葉を、そのまま半角の空白で区切って打ってください。打てたら「採点する」を押します。

```text
雨 のち 晴れ
```
</Exercise>

{/* 説明 */}

`Ctrl+C` はコピー、`Ctrl+V` は貼り付けです。`Ctrl+A` は、いま見えている範囲をすべて選択します。ドラッグでも、好きな範囲を選択できます。

`Ctrl+Z` を押すと、直前の操作を1つ戻せます。書き間違えたときは、打ち直す前にまず `Ctrl+Z` を押してください。

<Level0 title="行を選択する">
行の左はしをクリックしてから下にドラッグすると、複数の行を選べます。行の途中を3回連続でクリックしても、その行を選べます。
</Level0>

{/* よくある間違い */}

<Mistake id="start-copy-space" code={`　print(1)`} error={`SyntaxError: invalid non-printable character U+3000`}>
行の先頭に全角の空白が入っています。資料からコピーすると、こうした空白が混ざることがあります。打ち直すか、余分な空白を消してください。
</Mistake>

<Mistake id="start-copy-quote" code={`print(＇A＇)`} error={`SyntaxError: invalid character '＇' (U+FF07)`}>
全角のシングルクォートになっています。文書からのコピーで、記号が置き換わることがあります。半角の `'` を直接打ち直してください。
</Mistake>
