{/* 困る例 */}

Python では `_` や `#` や `[` のような記号をよく使います。日本語入力がオンのままだと、これらは別の文字になります。キーボードの配置は人によって違うので、位置を覚えても打てるとは限りません。

{/* やってみる */}

<Exercise
  id="start-02-symbols-2"
  kind="type"
  tests={[{ kind: 'text', expect: `my_data` }]}
  hints={[]}
  mistakes={[]}
>
次の文字列を、そのまま半角で打ってください。打てたら「採点する」を押します。

```text
my_data
```
</Exercise>

{/* 説明 */}

記号の多くは、`Shift` を押しながら数字や文字のキーを打ちます。組み合わせるキーは、キーボードによって違います。この節では、実際に打って合っているかを確かめます。

記号を打つときも、日本語入力はオフにします。オンのままだと全角の記号になり、Python には読み取れません。

<Level0 title="記号が打てないとき">
キーボードによって、記号の位置は変わります。近くのキーも試しながら、下の欄で確かめてください。
</Level0>

{/* よくある間違い */}

<Mistake id="start-symbols-hash" code={`＃comment
print(1)`} error={`SyntaxError: invalid character '＃' (U+FF03)`}>
全角の `＃` になっています。半角の `#` を、日本語入力をオフにしてから打ってください。
</Mistake>

<Mistake id="start-symbols-bracket" code={`data = [1, 2, 3]
print(data［0］)`} error={`SyntaxError: invalid character '［' (U+FF3B)`}>
全角の `［` になっています。半角の `[` を、日本語入力をオフにしてから打ってください。
</Mistake>
