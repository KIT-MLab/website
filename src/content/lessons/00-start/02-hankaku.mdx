{/* 困る例 */}

全角の数字で検索しても、目当ての物が見つからないことがあります。半角のつもりで打った記号が、日本語入力のせいで全角になっていることが原因です。見た目はよく似ているので、自分では気づきにくいです。

{/* やってみる */}

次の記号を、すべて半角で打ってください。

```text
( ) : = 100 ,
```
</Exercise>

{/* 説明 */}

半角と全角は、見た目が似ていても別の文字です。全角の数字や記号は、日本語入力がオンのときに打たれます。

全角のままでは、検索でもファイル名でも、半角として扱われません。打つ前に、日本語入力をオフにしておくと安全です。

この章の問題は、全角が混ざっていると、どこが全角かを教えてくれます。位置の手がかりをもとに、打ち直してください。

<Level0 title="いまの入力方式を確かめる">
クリックは、マウスの左のボタンを1回押す操作です。

いちばん確実なのは、実際に打ってみて、出た文字を見る方法です。数字を打って、`2` のように半角で出れば半角、`２` のように全角で出れば全角です。

下の打つ欄をクリックしたあとなら、画面右下、時計の左あたりの小さな文字でも分かります。`A` なら半角、`あ` なら全角です。クリックすると切り替わります。
</Level0>
