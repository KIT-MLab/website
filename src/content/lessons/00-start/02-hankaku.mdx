{/* 困る例 */}

全角の数字で検索すると、探しているものが見つからないことがあります。半角のつもりで打った数字が、日本語入力のせいで全角になっていることが原因です。見た目はよく似ているので、自分では気づきにくいです。

{/* やってみる */}

<Exercise

  tests={[{ kind: 'text', expect: `( ) : = 100 ,` }]}
  hints={[]}
>
次の記号と数字を、すべて半角で打ってください。

```text
( ) : = 100 ,
```
</Exercise>

{/* 説明 */}

半角と全角は、見た目が似ていても別の文字です。日本語入力がオンのときに数字や記号を打つと、全角で入力されます。

全角のままでは、検索でも半角として扱われません。打つ前に、キーボードの左上にある `半角/全角` キーを押して、日本語入力をオフにしておくと安全です。日本語と記号を混ぜるときは、日本語の前ではオン、記号の前ではオフにして、`半角/全角` キーで何度でも切り替えます。

この章の問題は、全角が混ざっていると、何文字目が全角かを教えてくれます。その文字を半角で打ち直してください。

<Level0 title="いまの入力方式を確かめる">
クリックは、マウスの左のボタンを1回押す操作です。

いちばん確実なのは、実際に打ってみて、出た文字を見る方法です。数字を打って、`2` のように半角で出れば半角、`２` のように全角で出れば全角です。

下の入力欄をクリックしたあとなら、画面右下、時計の左あたりの小さな文字でも分かります。`A` なら半角、`あ` なら全角です。その小さな文字をクリックしても、切り替わります。
</Level0>
