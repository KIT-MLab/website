{/* 困る例 */}

長い文を1文字ずつ打ち直すのは、時間がかかります。消してはいけない部分を誤って消してしまうと、元に戻せるか不安になります。戻し方を知らないと、そのたびに最初から打ち直すことになります。

{/* やってみる */}

  tests={[{ kind: 'text', expect: `左 右` }]}

次の2つの言葉を、コピーと貼り付けを使って、順番を逆にして入力欄に入れてください。区切りは半角の空白1つです。

```text
右 左
```
</Exercise>

{/* 説明 */}

`Ctrl` を押したまま、もう1つのキーを押して使う操作があります。よく使う4つを表にまとめます。

| キー | すること |
|---|---|
| `Ctrl+C` | 選んだ文字をコピーする |
| `Ctrl+V` | 貼り付ける |
| `Ctrl+A` | 入力欄の中で押すと、欄の文字をすべて選ぶ |
| `Ctrl+Z` | 直前の操作を1つ戻す |

ドラッグは、マウスのボタンを押したまま動かして離す操作です。ドラッグすると、コピーしたい文字の範囲を好きなように選べます。

打ち直す前に、まず `Ctrl+Z` を押すと安心です。このあとの問題の入力欄に試しに1文字打ってから `Ctrl+Z` を押すと、その文字が消えて元に戻ります。
