{/* 説明 */}

半角と全角は、見た目が似ていても別の文字です。日本語入力がオンのときは、数字や記号も全角になります。`Ａ` や `１` のような文字です。

全角の文字は、Python の命令や記号としては読み取れません。英数字や記号を打つ前に、日本語入力をオフにしてください。

切り替えには、キーボードの専用キーや、画面の表示を使います。次の「よくある間違い」で、実際に出るエラーを見てみます。

<Level0 title="日本語入力の切り替え方">
画面の隅に、いまの入力方式を示す表示があります。クリックすると切り替わります。キーボードに切り替え専用のキーがあれば、それも使えます。
</Level0>

{/* よくある間違い */}

<Mistake id="start-hankaku-quote" code={`print(“A”)`} error={`SyntaxError: invalid character '“' (U+201C)`}>
全角のダブルクォートになっています。日本語入力をオフにしてから `"` を打ってください。
</Mistake>

<Mistake id="start-hankaku-equal" code={`x＝10
print(x)`} error={`SyntaxError: invalid character '＝' (U+FF1D)`}>
全角の `＝` になっています。半角の `=` を、日本語入力をオフにしてから打ってください。
</Mistake>
