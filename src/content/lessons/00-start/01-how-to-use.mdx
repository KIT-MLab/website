{/* 困る例 */}

このページには、読む場所のほかに、押す場所や入力する場所があります。どこを押せば練習が進むのか分からないと、迷ったまま時間だけが過ぎます。合っているかどうかも、自分では確かめられません。

{/* やってみる */}

<Exercise
  id="start-01-how-to-use-1"
  kind="type"
  tests={[{ kind: 'text', expect: `れんしゅう` }]}
  hints={[]}
  mistakes={[]}
>
この教材の課題は、こうやって解きます。下に出る欄に文字を打って、「採点する」を押してください。

```text
れんしゅう
```
</Exercise>

{/* 説明 */}

打つ問題は「採点する」を押すと、合っているかがその場で分かります。落ちても、上の欄はそのまま残ります。

選ぶ問題には採点するボタンがありません。選んでから0.5秒たつと、自動で合っているかが分かります。

課題は1問ずつ出ます。1問に通ると、その場が次の問題に入れ替わります。上には「4問中 2問目」のように、いま何問目かが出ます。

右側の欄には、この章の節の一覧があります。その下には用語集と、アカウントを作る場所があります。
