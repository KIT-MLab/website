{/* 説明 */}

ファイル名の末尾には、種類を表す短い文字の並びが付きます。これを拡張子と呼びます。多くのパソコンは、既定でこれを隠しています。

表示する設定に変えると、`.py` や `.jpg` のような文字の並びが見えるようになります。`.py` は、次の章から作るものです。`.jpg` は、写真によく使われます。

<Level0 title="拡張子を表示する設定">
エクスプローラーの上のほうにある「表示」を選びます。一覧の中から、「ファイル名拡張子」にチェックを入れてください。

チェックすると、ファイル名の後ろに `.txt` や `.jpg` のような文字の並びが見えるようになります。
</Level0>
