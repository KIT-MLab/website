{/* 困る例 */}

`_` や `{` のような記号は、ふだんの文章ではあまり使いません。いざ打とうとすると、キーボードのどこにあるか分からず、探すだけで時間がかかります。キーボードの配置は機種によって違うので、覚えた場所が別のパソコンでは違っていることがあります。

{/* やってみる */}

<Exercise

  kind="type"
  tests={[{ kind: 'text', expect: `#` }]}
  hints={[]}
>
次の記号を、半角で打ってください。

```text
#
```
</Exercise>

{/* 説明 */}

記号の多くは、`Shift` を押しながら数字や文字のキーを打つと入力できます。組み合わせるキーは、キーボードによって違います。

ここでは、実際に打って合っているかを確かめながら覚えます。見つからない記号は、近くのキーも試してみてください。

<Level0 title="記号のある場所">
<Keys highlight={['#', '_', '{', '*']} />

図は日本語配列の一例です。あなたのキーボードと違う場合があります。

`"` は `Shift` と数字の `2` です。`_` は `Shift` と、右下にある `\` のキーです（キーには `ろ` とも書いてあります）。`#` は `Shift` と数字の `3` です。

`*` は `Shift` と、`:` と同じキーです。`L` の2つ右にあります。

`{` は `Shift` と `[` のキーです。`[` は同じキーを `Shift` なしで押します。
</Level0>
