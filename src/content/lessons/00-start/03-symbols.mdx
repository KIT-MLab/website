{/* 困る例 */}

`~` や `|` のような記号は、ふだんの文章ではあまり使いません。いざ打とうとすると、キーボードのどこにあるか分からず、探すだけで時間がかかります。キーボードの配置は機種によって違うので、覚えても別のパソコンでは通じないことがあります。

  mistakes={[]}

次の文字列を、そのまま半角で打ってください。

```text
夏休み_写真
```
</Exercise>

{/* 説明 */}

記号の多くは、`Shift` を押しながら数字や文字のキーを打つと入力できます。組み合わせるキーは、キーボードによって違います。

ここでは、実際に打って合っているかを確かめながら覚えます。見つからない記号は、近くのキーも試してみてください。

<Level0 title="記号のある場所">
<Keys highlight={['~', '|', '{', '[']} />

図は日本語配列の一例です。あなたのキーボードと違う場合があります。

`"` は `Shift` と数字の `2` です。`_` は `Shift` と、右下にある `ろ` のキーです。`#` は `Shift` と数字の `3` です。

`*` は `Shift` と、`:` と同じキーです。`L` の右にあります。
</Level0>
