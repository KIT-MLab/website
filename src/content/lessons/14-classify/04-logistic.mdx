第14章3節では、予測した確率の外れを、交差エントロピーで測りました。この節は④の学習で、交差エントロピーが小さくなるように、勾配降下法で、直線の重み `w` と、定数の `b` を動かします。第13章4節の回帰と同じやり方で、合否を予測するモデルも学習できるでしょうか。

{/* 困る例 */}

勉強時間と睡眠時間の両方から、合格の確率を予測する良い `w` と `b` を見つけたいです。確率の出し方（第14章2節）と、外れの測り方（第14章3節）はそろったので、残るのは `w` と `b` を決めることです。

<Run
  code={`import numpy as np

hours = np.array([2.0, 3.0, 5.0, 6.0, 8.0])
sleep = np.array([6.5, 7.0, 6.0, 6.5, 7.0])
X = np.array([hours, sleep]).T
passed = np.array([0, 0, 1, 1, 1])

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def loss(w, b):
    p = sigmoid(X @ w + b)
    return np.mean(-(passed * np.log(p) + (1 - passed) * np.log(1 - p)))

def grad_w(w, b):
    p = sigmoid(X @ w + b)
    return X.T @ (p - passed) / len(passed)

def grad_b(w, b):
    p = sigmoid(X @ w + b)
    return np.mean(p - passed)

w = np.array([0.0, 0.0])
b = 0.0
h = 0.0001
dw0 = (loss(w + np.array([h, 0]), b) - loss(w, b)) / h
dw1 = (loss(w + np.array([0, h]), b) - loss(w, b)) / h
numeric = np.array([dw0, dw1])
print(np.round(numeric, 1))
print(np.round(grad_w(w, b), 1))

gw = grad_w(w, b)
gb = grad_b(w, b)
w = w - 0.1 * gw
b = b - 0.1 * gb
print(np.round(w, 2))
print(round(b, 2))`}

0.01`}

{/* 説明 */}

入力は、第13章4節と同じく勉強時間と睡眠時間の2つです。12行目などの `sigmoid(X @ w + b)` では、`X @ w + b` が第14章2節の `z` にあたります。これをシグモイド関数に通して、合格の確率にしています。

11〜13行目の `loss` は、第14章3節の2つ目のコードと同じ式で求めた交差エントロピーの、5人ぶんの平均です。

15〜17行目の `grad_w` が返す `w` の勾配は `X.T @ (確率 - 答え) / n` です（`n` は人数、答えは各人のラベルの配列です）。第13章4節の回帰の勾配 `X.T @ (予測 - 答え) * 2 / n` から、`* 2` を取っただけの形です。

`grad_b` が返す `b` の勾配は `np.mean(確率 - 答え)` です。`grad_w` と `grad_b` の式は、結果だけを示しました。導き方は、この教材のずっと後で扱います。

26〜30行目では、`w = [0, 0]` のときの勾配を、2通りの方法で求めて比べます。1つは、`w` の値を1つずつ `h` だけ動かして求める方法（`numeric`。第13章3節の `num_a`・`num_b` と同じ求め方）、もう1つは `grad_w` の式です。`w + np.array([h, 0])` は1つ目の重みだけに `h` を足した配列で、`h` は25行目で 0.0001 としています。`w` も `b` も0のときは、5人とも `z` が0なので、確率はどの人も0.5です。2つの方法の結果は、どちらも `[-1.4 -0.6]` で一致します。一致を確かめてから、この式を使います。

32〜35行目は、第13章3節と同じく、勾配に学習率を掛けて引く更新です。ここでは学習率が0.1です。`w` の勾配は `[-1.4 -0.6]` なので、`w` は 0 - 0.1 × (-1.4) = 0.14 と 0 - 0.1 × (-0.6) = 0.06、つまり `[0.14 0.06]` になります。`b` の勾配は、（確率 - 答え）の平均です。確率は5人とも0.5で、答えの平均は、合格3人を5人で割った0.6なので、0.5 - 0.6 = -0.1 になります。したがって `b` は 0 - 0.1 × (-0.1) = 0.01 になります。36・37行目が、この `w` と `b` の出力です。

確率はシグモイド関数で求め、損失は交差エントロピーで測ります。この損失を勾配降下法で小さくする分類の方法が、ロジスティック回帰(logistic regression)です。確率という数を求めるので回帰の名前が付いていますが、確率が0.5以上なら合格と決めるので、使い道は分類です。

この節の最初のコードは、5人で `w` と `b` を1回更新しただけです。勉強時間と睡眠時間を標準化したうえで、同じ更新を30人全員のデータで、学習率0.5、300回くり返すと、損失は0.079まで下がります。

確率が0.5以上なら合格と予測すると、30人中29人の合否が当たります（このコードを動かすのは第14章5節です）。
