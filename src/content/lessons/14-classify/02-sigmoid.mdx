{/* 困る例 */}

第14章1節で見たように、直線の予測 `z` は0未満にも1より大きくもなり、合格の確率としては読めません。この `z` を、確率として読める0から1の値に直したいです。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

z = np.array([-3.0, 0.5, 2.0])
exp_form = np.exp(z) / (np.exp(0) + np.exp(z))
sig_form = 1 / (1 + np.exp(-z))
print(np.round(exp_form, 3))
print(np.round(sig_form, 3))`}
  out={`[0.047 0.622 0.881]
[0.047 0.622 0.881]`}
/>

{/* 説明 */}

4行目は、第11章3節と同じ「`np.exp` で正の値にしてから合計で割る」方法です。合格に `z`、不合格に `0` という値を付けたものとして、2つを `np.exp` に通し、その和で割ります。不合格の側を0と決めておくと、合格の確率は `z` 1つで決まり、`z` が大きいほど大きくなります。

5行目は4行目を整理した式で、同じ値になります。4行目の分子と分母を `np.exp(z)` で割ると、`np.exp(0)` は1、`1 / np.exp(z)` は `np.exp(-z)` なので、5行目の式になります。この形をシグモイド関数(sigmoid function)と呼びます。

`z` がどんな値でも、`np.exp(-z)` は正の数(第11章3節)なので分母の `1 + np.exp(-z)` は1より大きく、シグモイド関数の出力は必ず0から1の間になります。`z` が0のときは分母が2になるので、確率はちょうど0.5です。
