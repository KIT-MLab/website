{/* 困る例 */}

第14章1節で見たように、直線の予測 `z` は0未満にも1より大きくもなり、合格の確率としては読めません。この `z` を、確率として読める0から1の値に直したいです。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

z = np.array([-0.08, 0.5, 1.26])
exp_form = np.exp(z) / (np.exp(0) + np.exp(z))
sig_form = 1 / (1 + np.exp(-z))
print(np.round(exp_form, 3))
print(np.round(sig_form, 3))`}
  out={`[0.48  0.622 0.779]
[0.48  0.622 0.779]`}
/>

{/* 説明 */}

4行目は、第11章3節と同じ「`np.exp` で正の値にしてから合計で割る」方法です。合格の点数を `z`、不合格の点数を `0` として、2つを `np.exp` に通し、その和で割ります。

5行目は4行目を整理した式で、同じ値になります。この形をシグモイド関数(sigmoid function)と呼びます。

6〜7行目の出力は、どちらも `[0.48 0.622 0.779]` で一致します。`z` がどんな値でも、シグモイド関数の出力は必ず0から1の間になります。

{/* よくある間違い */}

<Mistake
  id="sigmoid-list"
  code={`import numpy as np
z = [-2, 0, 3]
print(np.exp(-z))`}
  error={`TypeError: bad operand type for unary -: 'list'`}
>
`z` がリストのままだと、`-z` で符号を反転できません。`np.array(z)` で配列に変えてから `np.exp(-z)` を計算してください。
</Mistake>
