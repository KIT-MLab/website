第13章5節までは、勉強時間などから点数という数を予測しました（全体図1 の回帰）。この節では、全体図の5つの段階の①で決める「何を当てるか」を、点数から、合格か不合格かという種類に変えます（分類）。合格か不合格かを、第13章と同じ直線で予測できるでしょうか。

{/* 困る例 */}

勉強時間から、合格するかどうかを予測したいです。その予測は、「この人が合格する確率は0.8」のように言えると分かりやすいです。確率は0から1までの数で、1に近いほど起こりやすいことを表します（くわしくは第11章1節）。第13章のように、合格を1、不合格を0とした値に直線を合わせても、出てくる予測は0より小さい数や1より大きい数になることがあります。

{/* やってみる */}

hours = np.array([2.0, 3.0, 5.0, 6.0, 8.0, 9.0, 6.0, 6.5, 8.5, 5.5, 7.0, 8.0, 2.5, 0.5, 3.0, 3.0, 8.0, 8.5, 0.5, 4.5, 7.5, 1.5, 7.5, 1.5, 4.5, 7.5, 3.0, 3.5, 3.0, 6.5])
scores = np.array([45, 52, 65, 70, 82, 84, 63, 70, 85, 68, 70, 80, 44, 39, 62, 52, 85, 91, 33, 66, 80, 39, 77, 39, 72, 73, 52, 50, 49, 77])

a = 0.0
b = 0.0
for i in range(3000):
    z = a * hours + b
    a = a - 0.01 * np.mean(2 * (z - passed) * hours)
    b = b - 0.01 * np.mean(2 * (z - passed))

print(round(z.min(), 2), round(z.max(), 2))`}
  out={`-0.08 1.26`}

{/* 説明 */}

5行目の `(scores >= 60) * 1` は、`True` と `False` の配列(第7章3節)に1を掛けます。`True` は1、`False` は0になり、合格を1、不合格を0にした整数の配列ができます。この0と1の値をラベル(label)と呼びます。

全体図1 で「答え」（ラベル）と呼んだものを、分類では、このように0と1の数で表します。

ラベルを全員ぶん足すと合格した人数になるので、ラベルの平均は合格した人の割合です。この30人では合格が19人なので、19 ÷ 30 で約0.63です。この割合を「合格する確率」と見ます。

9〜12行目は、第13章3節と同じ形の勾配降下法で、`hours` からラベルを予測する直線を合わせています。

15行目の出力を見ると、この直線の予測 `z` は `-0.08` から `1.26` まで広がっています。`-0.08` は勉強時間がいちばん短い0.5時間の人の予測、`1.26` はいちばん長い9時間の人の予測です。ラベルは0か1しかないのに、予測はその範囲をはみ出し、確率としては読めません。
