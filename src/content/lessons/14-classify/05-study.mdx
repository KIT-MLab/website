第13章6節は、勉強時間・睡眠時間から点数を予測しました。同じ2つの入力から、今度は合否を予測したいです。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

hours = np.array([2.0, 3.0, 5.0, 6.0, 8.0, 9.0, 6.0, 6.5, 8.5, 5.5, 7.0, 8.0, 2.5, 0.5, 3.0, 3.0, 8.0, 8.5, 0.5, 4.5, 7.5, 1.5, 7.5, 1.5, 4.5, 7.5, 3.0, 3.5, 3.0, 6.5])
sleep = np.array([6.5, 7.0, 6.0, 6.5, 7.0, 5.5, 8.5, 6.5, 6.5, 6.5, 7.0, 6.5, 6.5, 8.5, 8.0, 8.0, 7.5, 7.0, 6.0, 8.5, 6.5, 5.0, 8.0, 5.0, 8.0, 7.0, 5.0, 4.5, 6.5, 4.5])
scores = np.array([45, 52, 65, 70, 82, 84, 63, 70, 85, 68, 70, 80, 44, 39, 62, 52, 85, 91, 33, 66, 80, 39, 77, 39, 72, 73, 52, 50, 49, 77])
passed = (scores >= 60) * 1

h_mean = hours.mean()
h_std = hours.std()
s_mean = sleep.mean()
s_std = sleep.std()
X = np.array([(hours - h_mean) / h_std, (sleep - s_mean) / s_std]).T

def sigmoid(z):
    return 1 / (1 + np.exp(-z))

def loss(w, b):
    p = sigmoid(X @ w + b)
    return np.mean(-(passed * np.log(p) + (1 - passed) * np.log(1 - p)))

def grad_w(w, b):
    p = sigmoid(X @ w + b)
    return X.T @ (p - passed) / len(passed)

def grad_b(w, b):
    p = sigmoid(X @ w + b)
    return np.mean(p - passed)

w = np.array([0.0, 0.0])
b = 0.0
loss_before = loss(w, b)

for i in range(300):
    gw = grad_w(w, b)
    gb = grad_b(w, b)
    w = w - 0.5 * gw
    b = b - 0.5 * gb

new_x = np.array([(5 - h_mean) / h_std, (7 - s_mean) / s_std])
print(round(loss_before, 3))
print(round(loss(w, b), 3))
print(np.round(w, 2))
print(round(b, 2))
print(round(sigmoid(new_x @ w + b), 2))`}
  out={`0.693
0.079
[5.07 1.32]
2.18
0.92`}
/>

{/* 説明 */}

8〜12行目で勉強時間と睡眠時間を標準化し(第13章5節)、1人ぶんが1行になる `X` を作ります。

14〜27行目の `sigmoid`・`loss`・`grad_w`・`grad_b` は、第14章4節と同じ式です。33〜37行目の勾配降下法は、第14章4節で1回だけ行った更新(`w = w - lr * gw`、`b = b - lr * gb`)を、300回くり返す形です。4節の最後で見た学習を、そのまま書いたものです。

39行目と44行目は、勉強時間5時間・睡眠時間7時間の人の合格の確率を求めます。出力は上から、学習前の損失 `0.693`、学習後の損失 `0.079`、`w`、`b`、そしてその人の合格の確率 `0.92` です。

この節の最初のコードの3〜6行目の30人のデータを、そのまま使ってください。勉強時間と睡眠時間を標準化した入力で、`w = [0, 0]`、`b = 0` から、学習率0.5で300回くり返して学習します。

そのあと、新しい人の勉強時間・睡眠時間を、学習に使った平均・標準偏差で標準化して、合格の確率を予測します。確率が0.5以上なら合格、そうでなければ不合格とします。

<Input>
- 1行目: 新しい人の人数（整数）
- 2行目から: 1人につき2行。勉強時間（小数）と睡眠時間（小数）を、この順に
</Input>

<Output>
- 1行目: 学習前の損失（小数第3位まで丸める）
- 2行目: 学習後の損失（小数第3位まで丸める）
- 3行目: 学習した `w`（小数第2位まで丸めて、配列のまま）
- 4行目: 学習した `b`（小数第2位まで丸める）
- 5行目から: 1人1行。`確率` という文字のすぐ後ろに、合格の確率の値（小数第2位まで丸める）を続けて書き、空白を1つ空けて `合格` か `不合格` を書く。形は出力例のとおりです
</Output>
</Exercise>
