{/* 困る例 */}

合格の確率を予測できるようになりましたが、ずれの大きさをどう測るかをまだ決めていません。第12章2節の平均二乗誤差で確率のずれを測ると、自信を持って外したときの損失が、1で頭打ちになってしまいます。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

p = np.array([0.5, 0.01, 0.0001])
cross_entropy = -np.log(p)
squared = (1 - p) ** 2
print(np.round(cross_entropy, 4))
print(np.round(squared, 4))`}
  out={`[0.6931 4.6052 9.2103]
[0.25   0.9801 0.9998]`}
/>

{/* 説明 */}

3行目の `p` は合格の確率で、3人とも正解は合格(1)とします。このとき、正解に付けた確率は `p` そのものです。`0.5` はどちらとも言えない場合、`0.01` と `0.0001` は自信を持って外した場合です。

4行目は `-np.log(p)` で、正解に付けた確率の対数(第11章4節)にマイナスを付けています。確率の対数は0以下なので、マイナスを付けると0以上の損失になります。この損失を交差エントロピー(cross-entropy)と呼びます。

5行目は、正解の1と `p` の差を2乗した二乗誤差(第12章2節)で、どれだけ自信を持って外しても1を超えません(`0.9801`、`0.9998`)。交差エントロピーは `4.6052`、`9.2103` と、自信を持って外すほど大きくなり、上限がありません。自信を持って外したほど強く直させたいので、上限が無いほうが向いています。

合格の確率を `p` とすると、正解が0(不合格)のとき、正解に付けた確率は `1 - p` です。損失は `-np.log(1 - p)` になります。

正解が1の人と0の人を、1つの式にまとめる形を見ます。次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

y = np.array([1, 0])
p = np.array([0.8, 0.3])
print(np.round(-(y * np.log(p) + (1 - y) * np.log(1 - p)), 3))`}
  out={`[0.223 0.357]`}
/>

5行目の式は、`y` が1のときは前半の `y * np.log(p)` だけが残ります。0のときは、後半の `(1 - y) * np.log(1 - p)` だけが残ります。1人目(`y` が1)は `-np.log(0.8)` の `0.223`、2人目(`y` が0)は `-np.log(1 - 0.3)` の `0.357` です。
