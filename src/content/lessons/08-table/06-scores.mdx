{/* 困る例 */}

第7.5節の点数表は、for文で1人ずつ読み取って配列にしていました。科目ごとの平均との差を出そうとすると、計算をもう1つ書き足すことになります。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

flat = [40, 55, 50, 65, 82, 70]
scores = np.array(flat).reshape(2, 3)
print(scores)
print(np.round(scores - scores.mean(axis=0), 1))`}
  out={`[[40 55 50]
 [65 82 70]]
[[-12.5 -13.5 -10. ]
 [ 12.5  13.5  10. ]]`}
/>

{/* 説明 */}

4行目の `reshape(2, 3)` は、前の節と同じく、1列の値を2人分・3科目の表に直します。

6行目は、8.3節のブロードキャストです。`scores.mean(axis=0)` で科目ごとの平均を出し、表から引くと、1人ずつの差が一度に出ます。`axis=0` は人をまたぐ方向なので、結果は科目ごとの平均になります。

reshapeで表を作り、ブロードキャストで差を出す。この2つを組み合わせると、for文なしで点数表の全体を作れます。人数が増えても、書き方は変わりません。

`[-12.5 -13.5 -10. ]` の末尾の `.` は、8.3節で見た小数の配列です。差は割り切れないことが多いので、小数で出ます。

第7章の点数表を、この章の道具で書き直してください。入力欄の1行目を人数として読み取り、続けて人数×3科目の点数を読み取ります。読み取った値はreshapeで人数行3列の表にし、for文で1人ずつ読み取らないでください。

1人ずつ `平均48.3点 不合格` の形で平均と合否を表示してください。そのあと、3科目それぞれが科目の平均より何点上か下かを、小数第1位まで丸めて、次の行に配列のまま表示してください。基準点は `60` とし、変数にします。

`total_score` や `average_score` のような関数は定義しないでください。`for value in scores` のような、値を1つずつ合計する書き方もしないでください。
