{/* 困る例 */}

第7章7節の点数表は、for文で1人ずつ読み取って配列にしていました。科目ごとの平均との差を出そうとすると、計算をもう1つ書き足すことになります。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

flat = [40, 55, 50, 65, 82, 70]
scores = np.array(flat).reshape(2, 3)
print(scores)
print(np.round(scores - scores.mean(axis=0), 1))`}
  out={`[[40 55 50]
 [65 82 70]]
[[-12.5 -13.5 -10. ]
 [ 12.5  13.5  10. ]]`}
/>

{/* 説明 */}

4行目の `reshape(2, 3)` は、前の節と同じく、1列の値を2人分・3科目の表に直します。

6行目は、第8章3節のブロードキャストです。`scores.mean(axis=0)` で科目ごとの平均を出し、表から引くと、1人ずつの差が一度に出ます。`axis=0` は行を上から下へたどる方向なので、結果は科目ごとの平均になります。

reshapeで表を作り、ブロードキャストで差を出す。この2つを組み合わせると、平均や差の計算はfor文なしで書けます。

第7章の点数表を、この章で習ったことで書き直してください。読み取った値はreshapeで、行の数が人数、列の数が3の表にし、1人分ずつリストにまとめて読み取らないでください。

1人ずつ、その人の3科目の平均を小数第1位まで丸めて表示してください。その平均が基準点 `60` 以上なら `合格`、そうでなければ `不合格` を添えます（基準点は変数にします）。続く行には、その人の3科目それぞれが、科目ごとの平均より何点上か下かを、小数第1位まで丸めた配列で表示してください。

`total_score` や `average_score` のような関数は定義しないでください。`for value in scores` のような、値を1つずつ合計する書き方もしないでください。

<Input>
- 1行目: 人数（整数）
- 2行目から: 人数×3科目の点数（整数、1行に1つ、1人ずつ3科目の順）
</Input>

<Output>
1人につき2行を、入力の順に表示します。1行目は、1人ぶんの平均を使った `平均○点 合格` または `平均○点 不合格` の形です。○ の形は出力例のとおりです。2行目は科目ごとの平均との差の配列です。
</Output>
</Exercise>
