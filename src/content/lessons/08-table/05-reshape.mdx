{/* 困る例 */}

第7章7節の点数表は、for文の中で1人分3科目のリストを作り、それを集めてから配列にしていました。1人分の区切りを、読み取るときに自分で作る必要があります。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

flat = np.array([80, 70, 90, 60, 50, 40])
print(flat.shape)
table = flat.reshape(2, 3)
print(table.shape)
print(table)`}
  out={`(6,)
(2, 3)
[[80 70 90]
 [60 50 40]]`}
/>

{/* 説明 */}

3行目の `flat` は、6個の値が1列に並んだ配列です。形は `(6,)` です。括弧の中の数が1つだけなので1次元です。2次元なら `(2, 3)` のように2つ並びます。

5行目の `flat.reshape(2, 3)` は、値の並び順を変えずに、2行3列の形に直します。この操作をreshapeと呼びます。先頭から3個ずつ、1行目・2行目に分けて詰め直されます。リストのままでは `.reshape` は使えないので、先に `np.array()` で配列にします。

reshapeが変えるのは形だけです。値の個数と並び順はそのまま残るので、`2 * 3` が元の個数6と一致していないと使えません。第7章7節のように1人分ずつリストを作らなくても、まず1列に読み取ってから、あとで人数×3科目の表に直せます。
