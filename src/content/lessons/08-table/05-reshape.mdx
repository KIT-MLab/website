{/* 困る例 */}

第7章5節の点数表は、for文で1人ずつ3科目ぶんを読み取り、リストに集めてから配列にしていました。人数が変わっても、組み立て方はそのままです。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

flat = np.array([80, 70, 90, 60, 50, 40])
print(flat.shape)
table = flat.reshape(2, 3)
print(table.shape)
print(table)`}
  out={`(6,)
(2, 3)
[[80 70 90]
 [60 50 40]]`}
/>

{/* 説明 */}

3行目の `flat` は、6個の値が1列に並んだ配列です。形は `(6,)` で、1次元であることを示します。

5行目の `flat.reshape(2, 3)` は、値の並び順を変えずに、2行3列の形に直します。reshapeと呼びます。先頭から3個ずつ、1行目・2行目に分けて詰め直されます。

reshapeが変えるのは形だけです。値の個数と並び順はそのまま残るので、`2 * 3` が元の個数6と一致していないと使えません。第7章5節のように人数ぶんfor文で読み取らなくても、まず1列に読み取ってから、あとで人数×3科目の表に直せます。

{/* よくある間違い */}

<Mistake
  id="reshape-size-mismatch"
  code={`import numpy as np
flat = np.array([80, 70, 90, 60, 50, 40])
print(flat.reshape(2, 4))`}
  error={`ValueError: cannot reshape array of size 6 into shape (2,4)`}
>
`2 * 4` は8で、元の個数6と合っていません。行数と列数の積が、元の個数と同じになるようにしてください。
</Mistake>
