{/* 困る例 */}

第7章2節では、行と列を入れ替えるのに、for文を二重に回して1つずつ移し替えました。行や列が増えるほど、書く行数が増えます。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

scores = np.array([[80, 70, 90], [60, 50, 40]])
print(scores.shape)
print(scores.T.shape)
print(scores.T)`}
  out={`(2, 3)
(3, 2)
[[80 60]
 [70 50]
 [90 40]]`}
/>

{/* 説明 */}

5行目の `scores.T` は、行と列を入れ替えた配列です。これを転置（transpose）と呼びます。2行3列の配列を転置すると、3行2列になります。

`.T` は関数と違い、かっこを付けずに書きます。転置する前に、新しい形を先に考えてから、shapeで確かめてください。

6行目のように転置した配列を表示すると、元の1列目だった `80` `60` が1行目に並びます。値そのものは変わらず、並ぶ向きだけが入れ替わります。

何行何列になるかを実行する前に言えるようにしておくと、形が合わずにエラーで止まったとき、どこで形が食い違ったかを探せます。

{/* よくある間違い */}

<Mistake
  id="transpose-not-callable"
  code={`import numpy as np
scores = np.array([[80, 70, 90], [60, 50, 40]])
print(scores.T())`}
  error={`TypeError: 'numpy.ndarray' object is not callable`}
>
`.T` はかっこを付けずに使います。`scores.T()` ではなく `scores.T` と書いてください。
</Mistake>
