{/* 困る例 */}

第7章5節の `scores[1][2]` は1つの値だけを取り出します。数学の点だけを全員分そろえたくても、列をまとめて指定する書き方がありません。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

scores = np.array([[80, 70, 90], [60, 50, 40]])
print(scores[0, 1])
print(scores[:, 1])
print(scores[1, :])`}
  out={`70
[70 50]
[60 50 40]`}
/>

{/* 説明 */}

4行目の `scores[0, 1]` は、`scores[0][1]` と同じ値を、コンマで区切った1つの `[ ]` で指定します。行と列のインデックスをまとめて書けます。

5行目の `scores[:, 1]` は、行の位置に `:` を書き、列をインデックス1のものだけに絞ります。`:` は「すべての行」という意味なので、全員分がそのまま残ります。列が国語・数学・英語の順に並んでいるとして、数学の点をこの形で全員分そろえられます。

6行目の `scores[1, :]` は逆に、行をインデックス1のものだけに絞り、列はすべて残します。1人分の3科目がそのまま出ます。
