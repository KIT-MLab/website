{/* 困る例 */}

第7章2節の `scores[1][2]` は1つの値だけを取り出します。数学の点だけを全員分そろえたくても、列をまとめて指定する書き方がありません。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

scores = np.array([[80, 70, 90], [60, 50, 40]])
print(scores[0, 1])
print(scores[:, 1])
print(scores[1, :])`}
  out={`70
[70 50]
[60 50 40]`}
/>

{/* 説明 */}

4行目の `scores[0, 1]` は、`scores[0][1]` と同じ値を、コンマで区切った1つの `[ ]` で指定します。行と列のインデックスをまとめて書けます。

5行目の `scores[:, 1]` は、行の位置に `:` を書き、列だけを1番目に絞ります。`:` は「すべての行」という意味なので、人の方向はそのまま残ります。数学の点をこの形で全員分そろえられます。

6行目の `scores[1, :]` は逆に、行を1番目に絞り、列はすべて残します。1人分の3科目がそのまま出ます。

まとめると、列を取り出すのは科目の方向を1つに絞る操作、行を取り出すのは人の方向を1つに絞る操作です。

{/* よくある間違い */}

<Mistake
  id="index-column-out-of-range"
  code={`import numpy as np
scores = np.array([[80, 70, 90], [60, 50, 40]])
print(scores[:, 3])`}
  error={`IndexError: index 3 is out of bounds for axis 1 with size 3`}
>
科目は3つなので、列のインデックスは `0` から `2` までです。`3` はどの列にも当たりません。
</Mistake>
