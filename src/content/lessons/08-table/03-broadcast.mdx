{/* 困る例 */}

科目ごとの平均を、全員の点数から引きたいとします。人と科目の両方をfor文で回すと、二重のループになります。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import numpy as np

scores = np.array([[80, 70, 90], [60, 50, 40]])
subject_mean = scores.mean(axis=0)
print(subject_mean)
print(scores - subject_mean)`}
  out={`[70. 60. 65.]
[[ 10.  10.  25.]
 [-10. -10. -25.]]`}
/>

{/* 説明 */}

4行目の `scores.mean(axis=0)` は、第7章3節で見た軸の指定です。`axis=0` は人をまたぐ方向なので、結果は科目ごとの平均になります。

6行目の `scores - subject_mean` は、2次元配列から1次元配列を引いています。形が違うのに、`subject_mean` が行の数だけ繰り返し使われ、どの行からも同じ並びが引かれます。この仕組みをブロードキャスト（broadcasting）と呼びます。

`[70. 60. 65.]` の末尾の `.` は、整数ではなく小数の配列であることを示します。平均は割り切れないことが多いので、小数で結果が出ます。

表から1次元の並びを引けるのは、並びの長さが表の列の数と同じときです。長さが行の数と同じでも、列の数と違えばエラーになります。

{/* よくある間違い */}

<Mistake
  id="broadcast-shape-mismatch"
  code={`import numpy as np
scores = np.array([[80, 70, 90], [60, 50, 40]])
weights = np.array([1, 2])
print(scores - weights)`}
  error={`ValueError: operands could not be broadcast together with shapes (2,3) (2,) `}
>
`scores` は3列、`weights` は2個の値です。列の数がそろっていないので、引き算できません。
</Mistake>

{/* 課題 */}

</Exercise>
