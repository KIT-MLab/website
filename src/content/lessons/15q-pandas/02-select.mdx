<Facilitate>

**よく詰まるところ**

- `[ ]` の中の条件で、`==` を `=` と書く。`SyntaxError` になり、`Maybe you meant '==' instead of '='?` と出る
- `&` でつなぐ条件の両側の `( )` を忘れる。`TypeError: unsupported operand type(s) for &` と出る。エラーの文に出ている行（条件を書いた行）の、`&` の両側を見る
- `&` を `and` と書く。`ValueError: The truth value of a Series is ambiguous` と出る

</Facilitate>

{/* 困る例 */}

タイタニック2 では、for文と if文で、乗客を1人ずつ見て数えました。891人の表では、条件を1つ書くだけで、条件に合う人をまとめて取り出せます。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run
  code={`import pandas as pd

df = pd.read_csv("train.csv")
women = df[df["Sex"] == "female"]
print(len(women))
print(women["Survived"].mean())`}
  out={`314
0.7420382165605095`}
/>

{/* 説明 */}

4行目の `df["Sex"] == "female"` は、`Sex` の列の各行が `"female"` と等しいかを比べ、`True` と `False` の列で返します。`"female"` は、列に入っている値が文字列なので、引用符で囲みます。pandas 1 で見た最初の5人なら、`False`、`True`、`True`、`True`、`False` の順に並びます。

この `True` と `False` の列を `df[ ]` の中に書くと、`True` の行だけが取り出されます。`df["Sex"]` のように列の名前を書くと列が取り出され、`True` と `False` の列を書くと行が選ばれます。第7章3節の `scores[scores >= 60]` と同じ形です。

```python
scores[scores >= 60]
df[df["Sex"] == "female"]
```

取り出した `women` も表なので、5行目の `len(women)` で女性の数、6行目の `women["Survived"].mean()` で、女性が生き残った割合が出ます。

次のコードの ▶ を押してください。

<Run
  code={`import pandas as pd

df = pd.read_csv("train.csv")
third_women = df[(df["Pclass"] == 3) & (df["Sex"] == "female")]
print(len(third_women))
print(third_women["Survived"].mean())`}
  out={`144
0.5`}
/>

条件を2つ重ねるときは、それぞれの条件を `( )` で囲み、`&` でつなぎます。4行目は、`Pclass` が 3 で、かつ `Sex` が `"female"` の行を取り出しています。

第3章4節の `and` は1つの値どうしをつなぐものなので、列まるごとには使えず、書くとエラーになります。
