タイタニック2〜4 では、年齢が整数で分かっている乗客だけを使いました。891人の表で、17歳未満の人と17歳以上の人を、それぞれ数えてみます。

{/* やってみる */}

次のコードの ▶ を押してください。

<Run

df = pd.read_csv("train.csv")
print(len(df[df["Age"] < 17]))
print(len(df[df["Age"] >= 17]))
print(df["Age"].isna().sum())`}

614
177`}

{/* 説明 */}

4行目の `print` は17歳未満の人数、5行目の `print` は17歳以上の人数を表示します。この2つの人数を足すと 714 で、乗客の数 891 に足りません。

足りない 177人は、表の中で年齢の値が入っていない人です。pandas 1 で見た `NaN` が入っている所のように、表の中で値が入っていない所を、欠損値と呼びます。`NaN` と何かを比べた結果は、`<` でも `>=` でも `False` になります。そのため、年齢が欠損値の人は、17歳未満にも17歳以上にも入りません。

6行目の `df["Age"].isna()` は、`Age` の列の各行が欠損値かどうかを、`True` と `False` の列で返します。これに `.sum()` を続けると、`True` が1として数えられ、欠損値の数が出ます。pandas 1 で `Survived` の合計が生き残った人数になったのと同じ形です。

次のコードの ▶ を押してください。

df = pd.read_csv("train.csv")
print(df.isna().sum())`}

`df.isna().sum()` のように、列を取り出さずに表へ `.isna()` を使うと、列ごとの欠損値の数が一度に出ます。`Age` は 177、`Cabin` は 687、`Embarked` は 2 で、ほかの列には欠損値がありません。`Embarked` は、乗客が船に乗った港の頭文字（`S`、`C`、`Q`）です。

出力の最後の `dtype: int64` は、数の種類を表す印で、気にしなくて構いません。

`Cabin`（客室の番号）は 687人も欠けているので、この列は埋めずに、使わないことにします。`Age` は、平均で埋めます。次のコードの ▶ を押してください。

<Run
  code={`import pandas as pd

df = pd.read_csv("train.csv")
age_mean = df["Age"].mean()
print(age_mean)
df["Age"] = df["Age"].fillna(age_mean)
print(df["Age"].isna().sum())
print(len(df[df["Age"] >= 17]))`}
  out={`29.69911764705882
0
791`}
/>

4行目の `df["Age"].mean()` は、`Age` の列の平均です。欠損値は飛ばして、年齢が分かっている 714人で計算します。

6行目の `.fillna(age_mean)` は、列の欠損値を `age_mean` の値で埋めた列を返します。`fillna` は新しい列を返すだけで、表そのものは変わりません。そのため、`df["Age"] = …` で、`df` の `Age` の列に入れ直しています。入れ直さないと、7行目で数えても欠損値が残ったままです。

埋めたあとは、欠損値が 0 になり、17歳以上の人数が 791 になりました。

次の練習問題では、`Embarked` の欠損値を `"S"` で埋めます。`"S"` がいちばん多い値（644人）だからです。値ごとの人数は、pandas 2 の「この節の書き方」の表にある `value_counts` で数えられます。
