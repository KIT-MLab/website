{/* 説明 */}

1行目の `import pandas as pd` は、表の形のデータを扱うモジュール pandas を、`pd` という名前で使う準備です。`import numpy as np` と同じ形です。

3行目の `pd.read_csv("train.csv")` は、`train.csv` を読み込みます。

CSV は、表の1行を文字の1行に書き、列の値をコンマで区切って並べたファイルの形式です。読み込んだ結果は、データフレームと呼ばれる表で、`df` に入れています。以後は、データフレームを単に表と呼びます。

4行目の `len(df)` は、表の行の数です。この表では1行が1人の乗客なので、乗客の数が表示されます。

5行目の `df.head()` は、表の最初の5行です。出力の2行目には、列の名前が並んでいます。その下の5行が5人の乗客で、表の1行が1人ぶん、1列が年齢や運賃などの1種類の値です。左端の 0〜4 は、pandas が付けた行の番号で、0 から数えます。

列が多くて横に入りきらないので、途中の列が `...` で省かれています。最後の行の `[5 rows x 12 columns]` は、いま見えているのが5行で、表には12列あることを表します。`NaN` は、その欄に値が入っていないことを表します。

使う列の意味は、次のとおりです。ほかの列は、あとの節で使うか、使いません。

| 列の名前 | 意味 |
|---|---|
| `Survived` | 生き残ったら `1`、亡くなったら `0` |
| `Pclass` | 客室の等級（`1`、`2`、`3`） |
| `Sex` | 性別（`male` が男性、`female` が女性） |
| `Age` | 年齢 |
| `Fare` | 運賃 |

次のコードの ▶ を押してください。

<Run
  code={`import pandas as pd

df = pd.read_csv("train.csv")
survived = df["Survived"]
print(survived.sum())
print(survived.mean())`}
  out={`342
0.3838383838383838`}
/>

4行目の `df["Survived"]` で、`Survived` の列だけを取り出します。列は、numpy の配列と同じように `.sum()`、`.mean()`、`.max()` で集計できます。

`Survived` は、生き残った人が `1`、亡くなった人が `0` なので、合計が生き残った人数、平均が生き残った割合になります。タイタニック1 で割り算を書いて求めた 342 / 891 が、割り算を書かずに出ています。
