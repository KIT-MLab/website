{/* 困る例 */}

学習したモデルがよいかを、学習に使ったデータで確かめるとします。例を全部覚えておき、見たことのあるメールにはその答えを言う規則なら、学習に使ったメールには全部当たります。けれども知りたいのは、答えのまだ分からない、新しく届くメールに当たるかどうかです。

{/* やってみる */}

答えの分かっている30通のメールのうち、20通を使って、迷惑メールを見分ける規則を2つ作りました。規則Aは、20通のうち外れたメールに合わせて、言葉の条件を何個も足したものです。規則Bは、「当選」「無料」「登録」のどれかを含めば迷惑メール、という短い規則です。

| 規則 | 作るのに使った20通 | 作るのに使っていない10通 |
|---|---|---|
| 規則A | 20通当たる（1.0） | 6通当たる（0.6） |
| 規則B | 17通当たる（0.85） | 8通当たる（0.8） |

新しく届くメールに使うなら、どちらの規則を選びますか。理由も考えてから、先へ進んでください。

{/* 説明 */}

選ぶのは規則Bです。新しく届くメールに近いのは、作るのに使っていない10通のほうで、そこでは規則Bのほうがよく当たっています。

このように、データを2つに分けて使います。学習に使うほうを訓練データ（学習用データ）、学習には使わずに良さを測るためだけに取っておくほうを、テストデータと呼びます。

| 30通のメール（答えが分かっている） | 使い方 |
|---|---|
| 訓練データ 20通 | 学習に使う（規則を作る） |
| テストデータ 10通 | 学習には使わず、良さを測る |

当たった数の割合を、正解率と呼びます。表のかっこの中の数がそれで、規則Bはテストデータ10通のうち8通当たったので、8 ÷ 10 ＝ 0.8 です。

規則Aは、訓練データでは全部当たるのに、テストデータでは0.6しか当たりません。このように、訓練データに合わせすぎて、訓練データではよく当たるのに、テストデータでは外れることを過学習と呼びます。

正解率の良し悪しは、何も考えない予測と比べて決めます。テストデータの10通のうち、迷惑メールは3通です。全部に「迷惑メールではない」と言えば、メールを読まなくても7通当たり、正解率は0.7です。

このように、いちばん多い答えを全部に言ったときの正解率を、ベースライン（baseline）と呼びます。規則Bの0.8はベースラインの0.7より上なので、言葉を見た意味があります。規則Aの0.6は、ベースラインより下です。

「テスト」という言葉には、別の使い方もあります。Kaggle（予測の正確さを競うサイト）などでは、答えを伏せたデータが配られ、それもテストデータと呼ばれます。この章のテストデータは、答えの分かっている手元のデータを分けたものです。

### 機械学習の5つの段

機械学習は、次の5つの段で進みます。コンピュータがするのは④の学習で、ほかの段は人間が決めます。

| 段 | すること | 決めるのは | この先で扱う節 |
|---|---|---|---|
| ① | 何を当てるかを決める（点数か、合格か不合格か） | 人間 | 第12章1節、第14章1節 |
| ② | 何を見て当てるか（入力）を決める | 人間 | 第12章1節、第13章4節 |
| ③ | モデル（式の形）と、良さを測る物差し（損失・正解率）を決める | 人間 | 第12章2節、第15章3節 |
| ④ | 学習する（式の中の数を、損失が小さくなるように選ぶ） | コンピュータ | 第12章3節、第13章3節 |
| ⑤ | 学習に使っていないデータで確かめ、答えの分からないものに使う | 人間（使うかどうかを決める） | 第15章1節、第15章2節 |

### この章で出した語

| 語 | 意味 |
|---|---|
| 機械学習 | 答えの分かっている例から、答えを当てる規則をコンピュータに作らせること |
| データ | 例を集めたもの |
| 入力（特徴量） | 当てるときに見る値 |
| 答え（ラベル） | 当てたいもの |
| 予測 | 作った規則やモデルが、入力から出した答え |
| 回帰 | 数を予測すること |
| 分類 | 種類を予測すること |
| モデル | 入力から予測を出す式 |
| パラメータ | モデルの中にあって、データに合わせて決める数 |
| 損失 | 予測の外れ具合を表す数。小さいほどよく当たる |
| 学習 | パラメータを、損失が小さくなるようにデータで選ぶこと |
| 訓練データ | 学習に使うデータ |
| テストデータ | 学習には使わず、良さを測るために取っておくデータ |
| 正解率 | 当たった数の割合 |
| ベースライン | いちばん多い答えを全部に言ったときの正解率 |
| 過学習 | 訓練データに合わせすぎて、テストデータで外れること |
