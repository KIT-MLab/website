**よく詰まるところ**

- `train_test_split` が返す4つの名前の順番を間違える。`X_train, y_train, X_test, y_test = …` のように並べて `fit(X_train, y_train)` まで進めると、`y_train` にテストデータの特徴量の表が入っているので、`ValueError: Unknown label type: continuous-multioutput.` になる。並べる順が `X_train, X_test, y_train, y_test` かを確かめる
- `test_size=20` と書く。エラーにならず、テストデータが20人になる。整数を書くと人数、小数を書くと割合になる
- ベースラインを891人の `y` で出す（0.616）。テストデータの `y_test` で出す（0.615）。どちらの人で測ったかを確かめる
- `random_state` を書かないと、▶ を押すたびに分け方が変わり、正解率も変わる
- `train_test_split` の `import` の行を忘れる。`NameError` になる

{/* 説明 */}

5〜8行目は、pandas 3・4 で書いた、読み込みと、欠けを埋めて文字を数に置き換える処理と同じです。

3行目の `from sklearn.model_selection import train_test_split` は、scikit-learn の `model_selection` から、`train_test_split` という名前だけを持ってきます。

12行目の `train_test_split(X, y, test_size=0.2, random_state=0)` は、表 `X` と答え `y` を、訓練データとテストデータに分けます。返すものは4つで、訓練データの特徴量、テストデータの特徴量、訓練データの答え、テストデータの答えの順です。`=` の左に名前を4つコンマで並べると、右の4つが左から順に、それぞれの名前に入ります。第1章2節の表にある書き方です。名前は、scikit-learn 1 で自分で付けた `X_train`・`y_train`・`X_test`・`y_test` と同じものを使いますが、並べる順は違います。`X_train`・`X_test`・`y_train`・`y_test` の順です。

`test_size=0.2` は、テストデータを全体のおよそ2割にするという指定です。891人のおよそ2割にあたる179人がテストデータ、残りの712人が訓練データになります。

`random_state=0` は、人を混ぜて分けるときの、混ぜ方を決める数です。同じ数を入れておくと、何度 ▶ を押しても同じ分け方になります。0 以外の数にすると、別の混ぜ方になります。混ぜ方の中身は、第15章1節で扱います。

14行目の `X_train.head()` では、左端の行の番号が 140、439、817 とばらばらです。タイタニック3・4 では前の30人・後ろの10人に分けましたが、ここでは、人を混ぜてから分けています。前から順に分けると、並びに偏りがあるとき（たとえば等級順に並んでいるとき）、訓練データとテストデータの中身が違ってしまうので、混ぜます。140番の人の年齢 `29.699118` は、年齢が欠けていて平均で埋めた人です。

次に、分けた訓練データで決定木を学習させ、訓練データとテストデータで正解率を出します。次のコードの ▶ を押してください。

<Run
  code={`import pandas as pd
from sklearn.tree import DecisionTreeClassifier
from sklearn.model_selection import train_test_split

df = pd.read_csv("train.csv")
age_mean = df["Age"].mean()
df["Age"] = df["Age"].fillna(age_mean)
df["Sex"] = df["Sex"].map({"male": 0, "female": 1})

X = df[["Pclass", "Sex", "Age"]]
y = df["Survived"]
X_train, X_test, y_train, y_test = train_test_split(X, y, test_size=0.2, random_state=0)

model = DecisionTreeClassifier(random_state=0)
model.fit(X_train, y_train)
print((model.predict(X_train) == y_train).mean())
print((model.predict(X_test) == y_test).mean())
print((y_test == 0).mean())`}
  out={`0.8792134831460674
0.8100558659217877
0.6145251396648045`}
/>

14行目の `DecisionTreeClassifier(random_state=0)` は、`max_depth` を書いていないので、深さの制限なしの木です。訓練データの人を分けられるところまで、境目で分け続けます。`DecisionTreeClassifier` の `random_state=0` も、何度 ▶ を押しても同じ結果になるようにする数です。同じくらい良い境目が2つ以上あるとき、どれを選ぶかを、この数で決めます。

15行目の `fit` には、訓練データだけを渡します。テストデータは、学習には使いません。

16行目は訓練データの正解率で 0.879、17行目はテストデータの正解率で 0.810 です。訓練データの正解率のほうが高めに出ている点は、タイタニック3 と同じです。

18行目は、テストデータの人に全員亡くなったと予測したときの正解率で、ベースラインです。`y_test == 0` が `True` の人の割合を出しています。テストデータの正解率 0.810 は、ベースライン 0.615 より約0.2 高くなっています。モデルが良いかどうかは、テストデータの正解率を、このベースラインと比べて判断します。
