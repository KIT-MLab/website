# 仕様 57: 節にファイル（CSV）を添える（2026-10-03）

`56-tools-curriculum.md` 第5節 C・第6節の「教材にファイルを添える仕組み」。pandas の最初の節（10/27）が `pd.read_csv("train.csv")` を使うので、その前に要る。

## 1. 決まっていること

- Titanic の train.csv（891人・12列）を、行も列も減らさずに置く。**リポジトリに入れてよい**（2026-10-03 代表。リポジトリは GitHub で公開）
- ファイルは `src/lesson/files/train.csv` に置いた（891行、Survived の合計 342、Age の欠け 177。`53-ml-intro.md` の数と合う）
- 使う章（pandas・scikit-learn・Titanic）はメンバーだけの「プロジェクトの教材」に置く。**サイトの画面では、節を見られる人にだけファイルを渡す**

## 2. 書き方

節の frontmatter に、その節のコードが読むファイルの名前を書く。

```yaml
files: [train.csv]
```

- 名前は `src/lesson/files/` の下のファイル名。使える字は英小文字・数字・`_`・`-`・`.` だけ。1節に3つまで、1つ 1MB まで
- 書いた節の `<Run>` と `<Exercise>`（採点も含む）は、実行のたびに、そのファイルが Python のいまのフォルダにある状態で始まる。`pd.read_csv("train.csv")` がそのまま動く
- 学習者のコードがファイルを書き換えたり消したりしても、次の実行では元に戻っている
- 今週の演習・練習問題集には、いまは付けない

## 3. 仕組み

### 3.1 ブラウザ

- 節の画面は、`files` のある節でだけ、最初の実行の前にファイルを取りに行く（`GET /api/lesson-file?lesson=<節の id>&name=<ファイル名>`）。取ったものは画面にいる間は持っておき、2度取りに行かない
- 実行係（`src/lesson/runtime/`）は、実行のたびにファイルを Pyodide の中のいまのフォルダに書いてから、コードを走らせる。書く時間は、時間切れの見張りに数えない
- ファイルを取れなかったとき（通信の失敗・403）は、実行を始めず、結果の欄に「データのファイルを読み込めませんでした。少し待ってから、もう一度 ▶ を押してください。」と出す

### 3.2 口（`/api/lesson-file`）

- `lesson` の節の `files` に `name` があるときだけ返す。それ以外は 404
- **その節のページを見られる人にだけ返す**（節のページを組むときと同じ判じ方。メンバーだけの章ならメンバー、準備中なら運営・管理者。だれでも見られる章の節なら誰にでも）。見られない人には 403 で、中身を1文字も送らない
- Cloudflare Workers にはファイルの読み出しが無いので、ビルドのときにサーバの束に入れる（`import.meta.glob` の `?raw` など）。**ブラウザに配る束（`public/`・画面の部品）には入れない**
- `cache-control: private, max-age=…` は付けてよい（メンバーだけのファイルなので `public` にしない）

### 3.3 ビルド（期待値づくりと検査）

- `npm run build:tests`（模範解答と `<Run>` を Node の Pyodide で走らせて期待値を作る）も、`files` のある節では、同じファイルを同じ場所に書いてから走らせる（`scripts/pyodide-node.mjs`）
- `check:lessons`: `files` に書いた名前のファイルが `src/lesson/files/` にあること、名前の字・数・大きさの決まりを検査する

## 4. あわせて確かめる・直すこと

pandas は初めての実行で読み込みに時間がかかる。**ブラウザ側の時間切れの見張り（`runner.ts`）が、パッケージを落として読み込む時間まで数えていると、初めての ▶ で時間切れになる。**

- 手元のブラウザで、`import pandas as pd` を含むコードの初めての実行が通るかを確かめる（キャッシュの無い状態で）
- 時間切れになるなら、見張りが数え始めるのを「パッケージを読み終えたあと」にする（Worker が読み終えたことを知らせてから数える）。読み込んでいる間は、いまの「準備しています」に当たる表示が出ていること（新しい見た目は足さない。いまある言葉と表示を使う）
- scikit-learn（約26MB）でも同じ確かめをして、結果を報告する（直しが同じ所で済むなら一緒に直す）
- `print(df.head())` の12列が、結果の欄でどう見えるか（折り返すか、横に流れるか）を見て、報告する（見た目は変えない）
