## 1. 第3部で分かってほしいこと

第3部を終えた学習者が、集まりで Titanic のノートを開いたときに言えてほしいこと:

1. **予測とは、入力から答えを返す関数を、データに合わせて選ぶこと。**選ぶ基準は損失（ずれの大きさ）で、損失が小さくなるようにパラメータを動かすことを「学習」と呼ぶ
2. **学習の中身は、第10章の「傾きの逆へ動かす」を繰り返すこと。**歩幅（学習率）を大きくしすぎると発散し、小さすぎると進まない
3. **数を当てる（回帰）と、種類を当てる（分類）は、同じ手順でできる。**違うのは、予測の出し方と損失の測り方だけ
4. **学習に使ったデータで測った良さは当てにならない。**分けておいたデータで測る。正解率は「多いほうを答えるだけ」と比べて初めて意味を持つ

**1周目の約束**（`00-overview.md` 第2.3節）: 何が起きているかを数値と図で見せ、式は結果だけ示す。結果だけ示した式は、第6部のどの章で導くかを本文に書く。

## 2. 章の表

### 2.1 第12章 予測とは何か（`12-predict`）

**この章を終えたときにできていてほしいこと**

- 予測を関数として書ける（入力の配列とパラメータを受け取り、予測の配列を返す）
- 2つの予測のどちらが良いかを、損失（平均二乗誤差）の数で決められる
- パラメータの候補を並べて全部試し、損失が最小のものを選べる。パラメータが増えると試す数が掛け算で増え、この方法が使えなくなることを数で言える

| 節 | 困る例 | 新しい概念 | 組む課題 |
|---|---|---|---|
| 12.1 | 勉強時間から点数を予想する直線を、2人が別々に引いた。どちらの直線で予想するかを決めようにも、そもそも「予想」をコードで書けていない | 予測を関数にする。入力（特徴）・答え（目的の値）・モデル・パラメータの名前 | 勉強時間の配列と `a`, `b` から予測の配列を返す関数を書く |
| 12.2 | 2本の直線のどちらが良いか、見た目では決められない。差の2乗の和で比べると、データの人数が違う2つのクラスでは比べられない | 損失。平均二乗誤差（差の2乗の平均）。人数で割る理由 | 予測と答えから平均二乗誤差を出す関数を書く |
| 12.3 | 良い `a` を探したい | 候補を `np.linspace` で並べて全部試し、損失が最小のものを残す。`a` と `b` の両方なら二重の for文 | `a` と `b` の候補から、損失が最小の組を出す |
| 12.4 | 入力を5つに増やすと、パラメータは6つ。候補を100ずつ試すと何回か | 試す数は掛け算で増える（100の6乗）。1回に1マイクロ秒でも約12日かかる。**全部試さずに、良くなる向きへ進みたい**（第13章への問い） | （組まない。`nobuild`: 数を見積もる節。確かめは確認問題と打つ問題） |
| 12.5 | **通し課題**: 勉強時間と点数 | （新概念なし） | データから、損失が最小の直線を候補の中から選び、その直線で新しい人（勉強時間5時間）の点数を予想する |

- 12.1 で「予測は、まだ答えの分からない新しいデータに使う」と書く。どれだけ当たるかの測り方は第15章（回収先を書く）
- 用語集に足す: モデル、パラメータ、特徴、損失、平均二乗誤差（初出 12-predict）。**「予測」は登録しない**（第7章・第10章が普通の日本語として使っていて、登録すると検査18が初出より前の使用として落とす。言葉の意味も普通の日本語のままでよい。2026-09-25）

### 2.2 第13章 回帰（`13-regression`）

**この章を終えたときにできていてほしいこと**

- 「傾きの逆へ少し動かす」を繰り返すコードを書け、損失が下がっていく様子を数で追える
- 学習率が大きすぎると発散し、小さすぎると進まないことを、数と図で見て言える。発散したら学習率を下げる、と判断できる
- 入力が複数でも `X @ w + b` で予測し、同じ手順で学習できる
- 入力の単位がそろっていないと学習が進みにくいこと、標準化で直ることを見て言える

| 節 | 困る例 | 新しい概念 | 組む課題 |
|---|---|---|---|
| 13.1 | 第10章3節で下る向きは分かったが、1歩動かしただけでは谷に着かない | 勾配降下。`x = x - 学習率 * 傾き` を繰り返す。1変数の関数で | 決まった回数だけ繰り返し、最後の `x` と値を出す |
| 13.2 | 早く着こうと歩幅を大きくしたら、値が行ったり来たりして大きくなった | 学習率。大きすぎると発散、小さすぎると進まない。**逆向きに問う**（第3.10節）:「値が発散した。何を変えればよいか」 | 3つの学習率で同じ回数だけ繰り返し、それぞれの最後の値から、発散したものを見分けて出す |
| 13.3 | 第10章5節で、ずれを減らす `a` と `b` の向きは出せた。そのまま繰り返して直線を合わせたい | 直線を勾配降下で合わせる（線形回帰）。パラメータを配列 `w = np.array([a, b])` で持ち、勾配も配列で返す。**勾配の式は結果だけ示し、数値の偏微分と一致することを確かめてから使う**（導くのは第6部） | 勉強時間と点数に直線を合わせ、100回ごとの損失と最後の `a`, `b` を出す |
| 13.4 | 点数を、勉強時間だけでなく睡眠時間からも予想したい。パラメータごとに勾配の式を書くと、入力が増えるたびに書き足すことになる | 入力が複数の予測 `X @ w + b`。勾配 `X.T @ (予測 - 答え) * 2 / n`（第9章の行列の積と転置。式は結果だけ） | 2つの入力から点数を予想する `w` と `b` を学習する |
| 13.5 | 勉強時間（時間）と通学時間（分）を並べると、どの学習率でも片方は発散し、片方は進まない | 入力の単位（大きさ）の違いと、入力の標準化（第11章6節）。予想するときも同じ平均と標準偏差で直す | 入力を標準化してから学習し、新しい人の入力も同じ値で直して予想する |
| 13.6 | **通し課題**: 勉強時間・睡眠時間と点数 | （新概念なし） | 標準化・勾配降下・予想をつなげる。学習の前と後の損失、学習した `w` と `b`、新しい人の予想を出す |

- **図が要る**（第5節）。13.1〜13.2 は「曲線の上を点が下っていく様子と、学習率を変えたときの違い」。13.3 は「散らばった点に直線が寄っていく様子と、損失が下がる線」
- 13.3 のパラメータを配列で持つのは、`a, b = …`（1行で複数の変数に入れる。まだ教えていない）を避けるためでもある。台帳の `python-99-unpack` は第3部でも使わない
- 「損失が十分小さくなるまで」を while文で書く問いを、13.1 か 13.2 に1つ置いてよい（while文は第4章5節の1問しか組んでいない。`35-learner-after-ch7.md`）。発散すると終わらないので、回数の上限も書かせる
- 用語集に足す: 勾配、勾配降下、学習率、発散、回帰、線形回帰（初出 13-regression）

### 2.3 第14章 分類（`14-classify`）

**この章を終えたときにできていてほしいこと**

- 分類は「決まった種類のどれかを当てる」ことで、答えを確率で出し、0.5 を境に種類を決められる
- 確率の出し方が、第11章3節の「`np.exp` で正にして合計で割る」の2種類の場合であることを言える
- 損失が「正解の種類に付けた確率の log のマイナス」であること、自信を持って外すほど損失が大きくなることを数で見て言える
- 第13章と同じ繰り返しで分類の重みを学習でき、境目（どこから合格と予想するか）を図で見て言える

**2種類（合格・不合格など）だけを扱う。**3種類以上（ソフトマックス）と `argmax` は第4部（第4節 B）。

| 節 | 困る例 | 新しい概念 | 組む課題 |
|---|---|---|---|
| 14.1 | 勉強時間から、合格するかどうかを予想したい。第13章の直線で点数を予想して60点で切ると、答えが「合格」「不合格」のどちらかでしかないデータには合わせられない | 分類。答えを 1（合格）と 0（不合格）で持つ。予測は「合格である確率」で出す | 合否の記録から、合格の割合を勉強時間の区間ごとに出す（確率とみなす。第11章1節） |
| 14.2 | 直線の値 `z` は負にも1より大きくもなり、確率にならない | 合格の点数 `z` と不合格の点数 `0` を、第11章3節の方法で分布に直す。合格の確率は `np.exp(z) / (np.exp(0) + np.exp(z))`。整理した形 `1 / (1 + np.exp(-z))` も示し、**シグモイド関数**と名付ける（第4節 A） | `z` の配列から合格の確率の配列を返す関数を書き、0.5 以上を合格として予想を出す |
| 14.3 | 平均二乗誤差で確率のずれを測ると、自信を持って外したときの罰が小さい | 損失は、正解の種類に付けた確率の log のマイナス（第11章4節）。名前は**交差エントロピー**。確率 0.01 で正解を当て損ねると損失は約4.6、0.5 なら約0.69 | 予想した確率と答えから、損失の平均を出す関数を書く |
| 14.4 | 良い `w` と `b` を探したい | 第13章と同じ勾配降下。ここまでの分類のやり方の名前は**ロジスティック回帰**（名前に回帰と付くが分類）。勾配は `X.T @ (確率 - 答え) / n` で、**回帰の勾配と同じ形になる**（式は結果だけ。導くのは第6部） | 合否のデータで `w` と `b` を学習し、学習の前と後の損失を出す |
| 14.5 | **通し課題**: 勉強時間・睡眠時間と合否 | （新概念なし） | 入力を標準化し、分類の重みを学習し、新しい人の合格の確率と予想（合格・不合格）を出す |

- **図が要る**（第5節）。14.4〜14.5 は「2つの入力の平面に合格・不合格の点を打ち、確率 0.5 の境目の線が学習につれて動く様子」
- 用語集に足す: 分類、ラベル（答えの種類）、シグモイド関数、交差エントロピー、ロジスティック回帰（初出 14-classify）
- 第11章3節の「ソフトマックスの名前は第4部で付けます」は変えない（3種類以上は第4部のため）

### 2.4 第15章 評価（`15-evaluate`）

**この章を終えたときにできていてほしいこと**

- 学習に使ったデータとは別のデータで測る理由を言え、データを学習用とテスト用に分けられる
- 入力を増やすほど学習用の損失は下がるのに、テスト用では上がることがある（過学習）と、数と図で見て言える
- 正解率を出し、「多いほうの種類を答えるだけ」の正解率と比べて良し悪しを言える
- 4つの場合（当たり・見逃し・空振り・正しく外す）を数えて、どちらの間違いが多いかを言える

| 節 | 困る例 | 新しい概念 | 組む課題 |
|---|---|---|---|
| 15.1 | 学習に使った人たちで測ると損失は小さいのに、新しく来た人の予想が外れる | 学習用とテスト用に分ける。`np.random` で並びを混ぜてから分ける（種を決めて毎回同じに混ぜる） | データを決まった種で混ぜ、8割と2割に分ける |
| 15.2 | 入力に `x**2`, `x**3`, … を足すほど、学習用の損失は下がり続ける。テスト用では途中から上がる | 過学習。モデルの複雑さと、学習用・テスト用の損失の開き | 次数を1から順に変え、学習用とテスト用の損失を並べて出す |
| 15.3 | 正解率90%のモデルができたと喜んだが、全員に「不合格」と答えるだけでも90%当たるデータだった | 正解率。**比べる基準**（多いほうの種類を答えるだけの正解率）。真偽の配列の平均が割合になること | テスト用データで、モデルの正解率と基準の正解率を出す |
| 15.4 | 同じ正解率でも、合格する人を見逃すモデルと、不合格の人を合格と言うモデルがある | 混同行列（4つの場合の数）。どちらの間違いが困るかは使う場面で決まる | 予想と答えから、4つの場合の数を出す |
| 15.5 | **通し課題**: 合否の予想を評価する | （新概念なし） | 分ける・標準化（学習用の平均と標準偏差で、テスト用も直す）・学習・テスト用での正解率と基準・4つの場合の数、をつなげる |

- **図が要る**（第5節）。15.2 は「次数を変えたときの、学習用とテスト用の損失の2本の線と、そのときの曲線」
- 15.5 の標準化は、**テスト用のデータの平均を使わない**ことを困る例か「よくある間違い」で扱う（テスト用の情報が学習に漏れる）
- 用語集に足す: 学習用データ、テスト用データ、過学習、正解率、混同行列（初出 15-evaluate）
