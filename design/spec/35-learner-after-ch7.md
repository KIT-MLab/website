# 教材仕様 35: 第7章を終えた学習者の像

第8章（numpy の続き）と第2部を組む前に、**この時点の学習者の頭の中**を書き出す。

利用者の言葉（2026-09-23）:

> 難しいのは何を与えたかを知っていることではなく、まだ何が分かっていない可能性があるかを推測することだろうと思う。

課程表は「何を与えたか」の表である。この文書はその裏側で、**与えたものが学習者の中でどうなっているか**を推測する。
推測には必ず根拠を書く。根拠のない「たぶん分かっていない」は書かない。

根拠に使うもの:

| 根拠 | 意味 |
|---|---|
| 組んだ | 「組む」課題で、白紙から自分で書いた。**いちばん強い** |
| 変えた | 「変える」課題で、見本の一部を書き換えた |
| 見た | `<Run>` で動かし、説明を読んだだけ |
| 名前だけ | 画面に出たが、説明していない |
| 高校 | 高校の課程で習っている（`00-overview.md` 第2.2節の前提） |

## 3. 数学（高校から持ってくるもの）

`00-overview.md` 第2.2節の前提: **数IIまではできる。ベクトルは2次元の内積まで知っている**（数C）。

| 知っている（高校） | 教材の中でまだ結び付いていないこと |
|---|---|
| 平均・分散・標準偏差・相関係数（数I データの分析） | コードで出したのは平均だけ。第7.5節は「ここまでに出ていない語」として標準偏差を外した。**高校では習っている**ので、第2部の確率の章では前提にしてよい |
| 確率、条件付き確率、期待値（数A） | コードで確率を扱ったことはない |
| 数列と Σ（数B） | Σ の式と `sum()` が同じものだと見たことはない |
| 多項式の微分（数II）。接線の傾き | コードで傾きを計算したことはない |
| 指数関数・対数関数（数II）。ただし底は 2 や 10 | **ネイピア数 e と自然対数は数III。**前提にできない。シグモイドとソフトマックスで要る |
| 2次元のベクトル、成分、内積（数C） | 3次元以上、配列としてのベクトル。内積を「掛けて足す」計算として見たことはない |

**高校に無いもの**: 行列（全く習っていない）、合成関数の微分（連鎖律、数III）、2変数の関数と偏微分、`e^x` の微分。

## 4. ここから読めること

第8章と第2部の中身を決めるための手がかり。**決定ではない。**

1. **学習者はすでに損失を計算している**（第7.1節の差の2乗の合計）。第2部と第3部はこれを「知っている計算」として出発点にできる。ただし学習者はそれが損失だとは知らない
2. **第8章の中心は「形」になる。**列の取り出し、転置、形の違う配列の計算、`reshape` はどれも「形」の話で、行列の積の前に要る。いまの学習者は形を予想した経験がない
3. **`axis` の向きの混乱**は第2部の行列の積で必ず再び出る。第8章か第2部の最初で、もう一度正面から扱う
4. **e と自然対数**は確率の章より前に要る。確率の章で扱うか、傾きの章（`e^x` の傾き）で扱うかを決める
5. **行列は全く新しい。**ベクトルは知っている前提でよいが、行列は「知らない前提」で書く
