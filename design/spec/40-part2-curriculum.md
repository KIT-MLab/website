## 2. 第9章 ベクトルと行列（`09-matrix`）

**この章を終えたときにできていてほしいこと**

- 内積を「掛けて足す」計算として出せ、何を計算しているかを言える
- 行列の積を、小さな例なら手で計算でき、numpy の `@` の結果と照らし合わせられる
- 積の前に、掛けられる形か、結果が何行何列になるかを言える（`(n, k) @ (k, m)` → `(n, m)`）

| 節 | 困る例 | 新しい概念 | 組む課題 |
|---|---|---|---|
| 9.1 | 2人の3科目の点数がどれくらい近いかを、1つの数で言えない | 数の並びとしてのベクトル。長さ（成分の2乗の和の平方根）と、2つのベクトルの距離。2次元の長さ（数C）から3次元以上へ広げる | 2人の点数のベクトルの距離を出す |
| 9.2 | 科目ごとの重み（0.3, 0.3, 0.4）で重み付きの合計を出すのに、掛けて足す式を毎回書く | 内積。`a @ b`。数Cの内積と同じ「成分ごとに掛けて足す」 | 重み付きの合計を内積で出す |
| 9.3 | 全員の重み付きの合計を出すのに、1人ずつ内積を繰り返す | 行列とベクトルの積。`(n, 3) @ (3,)` → `(n,)`。表の各行と重みの内積が並ぶ | 全員の重み付きの合計を一度に出す。結果の形も出す |
| 9.4 | 重みの組が2通り（理系の配点・文系の配点）あると、9.3 を2回書く | 行列と行列の積。`(n, 3) @ (3, 2)` → `(n, 2)`。結果の1マスは「左の行」と「右の列」の内積 | 2通りの配点で、全員の合計を一度に出す |
| 9.5 | 形が合わない積を書くと、エラーで止まる | 形の決まり `(n, k) @ (k, m)` → `(n, m)`。`.T` で形を合わせる。**掛ける前に形を言う** | 与えられた2つの表の形を読み、必要なら転置して積を出す |
| 9.6 | **通し課題**: 点数表 | （新概念なし） | 配点の重みを行列で持ち、全員の重み付きの平均と合否を `@` で出す。第8章の出力（平均・合否・科目平均との差）は残す |

- 9.4 では、**1マスを手で計算する問い**を1つ置く（確認問題）。行列の積の中身を、手で追えることがこの章の目標だから
- 「行列」「ベクトル」「内積」「行列の積」を用語集に足す（初出 09-matrix）

## 3. 第10章 変化率と傾き（`10-slope`）

**この章を終えたときにできていてほしいこと**

- 2点の差から傾きを出せ、幅を狭めると値が落ち着くことを Python で確かめられる。`x**a` の微分の結果と一致することを見る
- 傾きの符号を見て、値を小さくするには `x` をどちらへ動かせばよいかが分かる（勾配降下の手前。繰り返しは第3部）
- 動かすものが2つあるとき、それぞれの向きの傾き（偏微分）を数値で出せる

**題材**: 点数表の続きとして「勉強時間と点数」を使う。第3部の回帰（直線を合わせる）の題材がこれになる。

| 節 | 困る例 | 新しい概念 | 組む課題 |
|---|---|---|---|
| 10.1 | 勉強時間を1時間増やすと点数がどれだけ上がるかを、2人のデータから言いたい | 平均の変化率 `(f(b) - f(a)) / (b - a)`。直線なら傾き | 2点から傾きを出す関数を書く |
| 10.2 | `x**2` の `x = 3` での傾きは、2点の選び方で変わってしまう | 幅 `h` を小さくすると値が落ち着く。これが微分（数II）の値。`np.linspace` などで `h` を並べて確かめる | `x**3` の、ある `x` での傾きを数値で出し、`3 * x**2` と比べる |
| 10.3 | いちばん小さくなる所（谷）を探したいが、どちらへ進めばよいか分からない | 傾きの符号と下る向き。正なら左へ、負なら右へ | ある `x` で、値を小さくするにはどちらへ動かせばよいかを出す |
| 10.4 | 勉強時間から点数を予想する直線 `y = a x + b` のずれ（第7.1節の差の2乗の和）は、`a` と `b` の2つで決まる | 2変数の関数。片方を止めて、もう片方の向きの傾きを出す（偏微分）。名前は「偏微分」を出すが、記号 `∂` は第6部まで出さない | ずれの、`a` の向きの傾きと `b` の向きの傾きを数値で出す |
| 10.5 | **通し課題**: 勉強時間と点数 | （新概念なし） | データと直線（`a`, `b`）から、ずれ・`a` の向きの傾き・`b` の向きの傾きを出し、ずれを小さくするにはそれぞれをどちらへ動かすかを出す。**動かすのは1歩もしない**（第3部で繰り返す） |

- 関数を引数として渡すことは教えていない。10.2 の課題は、傾きを出したい関数を `def f(x):` として決めた形で書かせる
- 「変化率」「傾き」「微分」「偏微分」を用語集に足す（初出 10-slope）
- 図が要る。**曲線と、2点を結ぶ直線（幅を狭めると接線に近づく）**。言葉だけでは像が結ばない（`10-lesson-and-writing.md` 第2.0節の5）。図の部品はまだ無いので、第10章を書く前に作る（見た目は案を出して利用者が選ぶ）

## 4. 第11章 確率の初歩（`11-probability`）

**この章を終えたときにできていてほしいこと**

- データから、起こる割合（相対度数）を確率として出せる
- 合計が1になる数の並び（確率の分布）を作れる。どんな正の数の並びでも、合計で割ると分布になる
- `e` と `np.exp`、`np.log` の形と性質を、数値で見て言える（数III の内容を、使う分だけ）
- ばらつきを分散・標準偏差で表せる（数I のデータの分析）

第3部の分類（「このデータが A である確率」を出す）と、第4部のシグモイド・ソフトマックス・交差エントロピーの土台。

| 節 | 困る例 | 新しい概念 | 組む課題 |
|---|---|---|---|
| 11.1 | 過去の天気の記録から「明日雨になりそう」を数で言いたい | 相対度数を確率とみなす。確率は0以上1以下 | 記録から、それぞれの天気の割合を出す |
| 11.2 | 3つの候補の「点数」を、合計が1の割合に直したい | 分布（合計が1になる並び）。正の数の並びを合計で割る | 正の数の並びを分布に直す関数を書く |
| 11.3 | 点数が負の数だと、合計で割っても分布にならない | `e` と `np.exp`。どんな数も正の数に変わり、大きいものはより大きくなる。`np.exp` してから合計で割る（ソフトマックスの形。名前は第4部で付ける） | 負の数を含む並びを、`np.exp` を使って分布に直す |
| 11.4 | とても小さい確率どうしを掛けると、0になって比べられない | `np.log`。掛け算が足し算になる。確率の log は0以下 | 確率の並びの積と、log の和を比べる |
| 11.5 | 平均が同じ2つのクラスでも、点数の散らばり方が違う | 分散と標準偏差（数I）。`np.var` `np.std` と、自分で書いた式が一致することを見る | 点数表の科目ごとの標準偏差を出す |
| 11.6 | **通し課題**: 点数表 | （新概念なし） | 各人の点数を「平均からの差 ÷ 標準偏差」に直す（標準化）。第7章で外した偏差値の考え方を、ここで回収する |

- 11.6 は、第7.5節で「ここまでに出てこない統計の語」として外した偏差値の考え方を回収する。偏差値そのもの（50 + 10 × …）は出してよい
- 「確率」「分布」「ネイピア数（e）」「指数関数」「対数」「分散」「標準偏差」「標準化」を用語集に足す（初出 11-probability）
- 11.3 の「ソフトマックス」という名前は第4部で付ける。ここでは形だけ（`00-overview.md` 第2.3節の「あとで詳しくやる」には、回収先の章を明記する決まり）

## 5. 点数表の筋（第2部）

| 章 | 点数表 |
|---|---|
| 9 | 配点の重みを行列で持ち、全員の重み付きの平均と合否を `@` で出す |
| 10 | 題材を「勉強時間と点数」に広げる。直線のずれと、ずれを小さくする向きを出す（第3部の回帰の入口） |
| 11 | 点数を標準化する（偏差値の考え方の回収） |

**第1部より縮めない。**第9章の通し課題は、第8章の出力（平均・合否・科目平均との差）をすべて残したうえで足す。

**第10章だけは例外。**題材を「勉強時間と点数」（点数と、それを説明する量の組）に広げるので、第9章の出力は引き継がない。縮めたのではなく、第3部の回帰へ向けて題材を切り替える。第11章は点数表に戻り、第9章の出力を残したうえで標準化を足す。
