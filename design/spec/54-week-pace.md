## 1. なぜ変えるか

代表の指摘（2026-10-02）。

## 2. 決まったこと（代表が選んだ案）

1. **1回ぶんの列は「この回の前に（予習）」「この回でやること」「この回のあとに（復習）」の3つに分ける。** その回に関わるものだけを、時間の順に並べる
2. **Python の復習（集まりでは扱わず、各自で進める分）は列から外し、ページのいちばん上に1本の帯で出す。** 週ごとの目安（いつまでにどの章）と、自分の進み具合を並べる
3. **進み具合は、その章の練習問題集の★1・★2を通した割合で数える**（教材を読んだかではなく、書けるかで数える）

## 4. 画面

### 4.1 どの回を列にするか

「この回のあとに」は、集まりが終わってから要る。**列は「前回・今回・次回」の3つにする**（いまは「今回・次回・その次」）。

- 今回 = いまと同じ決め方（`nextMeeting`）。朱の枠は今回の列
- 前回 = 今回のすぐ前の集まりの行。前回が無い（最初の回より前）ときは、いまと同じ「今回・次回・その次」
- 列の頭の言葉は「前回 9/29」「今回 10/6」「次回 10/13」
- その次から先の回は、いまと同じく下に畳んだ行で並べる。前回より前の回は出さない（`/learn/plan/` にある）

### 4.2 1回ぶんの中身（`WeekMeeting.astro`）

見出しを3つにする。見た目（字の大きさ・色・リストの形・札・進み具合の棒）は、いまの `.wm` のものをそのまま使う。新しい色や形を足さない。

```
この回の前に（予習）
 ・第7章1節 配列でまとめて計算する

この回でやること
 前半（新しく学ぶ）  numpy① 配列・平均・条件で取り出す
   ・第7章1節 …
   ・第7章2節 …
 後半（みんなで取り組む）
   ・タイタニック2 規則で予測する

この回のあとに（復習）
 ・練習問題集 NumPy 配列と要素ごとの計算 ★1〜★3   ░░░░ 0%
 ・練習問題集 集計（合計・平均・最大）と軸 ★1・★2   ░░░░ 0%
 ・今週の演習 10/20（第7〜8章と練習編2）
```

- 見出しは `.wm__k`。「この回でやること」の中の「前半（新しく学ぶ）」「後半（みんなで取り組む）」は、見出しより一段小さい言葉（太字にしない。`.wm__k` の色のまま、字の太さだけ普通にしたもの）で出す
- 中身が無い見出しは「―」（いまの `.wm__none`）
- 練習問題集の行の言葉は「練習問題集 <話題の題> ★1・★2」。話題ごとに1行。★は、続いていれば「★1〜★3」、2つなら「★1・★2」、1つなら「★3」。行き先は話題のページ（`/learn/practice/<章>/<話題>/`）。進み具合の棒は、その行の★の段の問題だけで数える
- 見られない行き先の扱い（準備中の札、「まだ公開していません」、「まだ問題がありません」）は、いまと同じ
- 9/29 に入れた「練習問題（予習にも復習にも使えます）」の見出しはやめる

### 4.3 各自で進める復習の帯

3列の上、ページの説明の段落のすぐ下に置く。

```
各自で進める Python の復習
集まりでは扱いません。目安の日までに、練習問題集の★1・★2を解いておきます。

 第1〜2章   9/29 まで    ████████░░ 80%    教材 ／ 練習問題集 ／ 今週の演習 9/29
 第3〜4章   10/6 まで    ██░░░░░░░░ 20%    教材 ／ 練習問題集 ／ 今週の演習 10/6      今週はここ
 第5〜6章   10/13 まで   ░░░░░░░░░░  0%    教材 ／ 練習問題集 ／ 今週の演習 10/13
```

- 枠は、3列の列（今回でない列）と同じ枠・同じ地。見出しは列の頭の言葉と同じ字。新しい色や形を足さない
- 行: 名前・目安の日（「10/6 まで」）・進み具合の棒と百分率・行き先のリンク3つ・印
- **進み具合**: その行の章の、練習問題集の★1・★2の問題を通した割合。棒は `WeekMeeting` の `.wm-meter` と同じ部品・同じ塗り方（`data-ex-ids` を置き、`src/lesson/practice-progress.ts` が塗る。100% で緑）。その章の★1・★2の問題が1問も無いときは、棒の代わりに「まだ問題がありません」
- **行き先**: 「教材」は最初の章の最初の節、「練習問題集」は練習問題集の一覧のその章の所（`/learn/practice/#<章>` のように、その章の段へ飛べる形。飛び先の id が無ければ足す）、「今週の演習 10/6」はその回。見られないものは、いまの決まりのとおり札を添える。章が2つの行は、「教材」「練習問題集」を章ごとに出してよい（「教材 第3章・第4章」のように、章の番号がリンク）
- **印**: 目安の日が今回の集まりの日と同じ行に「今週はここ」（朱の字。今回の列の朱と同じ色）。今回が、どの行の目安の日よりも後ろなら、印は出さない
- **目安を過ぎた行**（目安の日が今回より前）で 100% でないもの: 百分率のあとに小さな札「残っています」（いまの `.wm__tag`）。責める言い方にしない
- 狭い画面では、行を縦に積む（名前と目安の日 → 棒 → 行き先）

### 4.4 変えないもの

- メンバーだけに見せる。`/learn/` の「次回」の行、`/learn/plan/`（`title` を読む）は変えない
- 休みの行の出し方、その先の回の畳んだ行
