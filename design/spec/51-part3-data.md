# 教材仕様 51: 第3部のデータ（勉強時間と点数の30人）

`50-part3-curriculum.md` 第3節「データは章をまたいで同じ人たちにする」の置き場所。**第12〜15章の本文・課題・図は、ここの値だけを使う。**章ごとに作り直さない。値を変えるときは、ここを直してから、使っている節と図（`src/components/lesson/` の第3部の図）をすべて直す。

作り方（一度きり。再現用）: 先頭5人は第10章の5人（`hours = [2, 3, 5, 6, 8]`、`scores = [45, 52, 65, 70, 82]`）。残り25人は `np.random.default_rng(7)` で、点数 ≈ 34 + 6 × 勉強時間 + 3 × (睡眠時間 − 6.5) + ばらつき（標準偏差5）として作り、整数に丸めた。通学時間は `np.random.default_rng(11)` で 10〜90分から選んだ（点数とはほぼ関係が無い）。

- 本文のコードに30人ぶんを毎回書くと長い。**節の中で使う人数を減らしてよいが、減らすときは先頭から順に取る**（「先頭の10人」）。人を入れ替えたり値を変えたりしない

## 2. このデータで確かめた数（Python で計算。本文と図はこれと合っていること）
