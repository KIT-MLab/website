# 用語集

`10-lesson-and-writing.md` 第5章の登録先。

- 新しい用語はこの表に足す。登録がない語を本文で使ってはいけない
- 節の frontmatter の `terms` は、この表にある語だけを書く（`scripts/check-lessons.mjs` 検査12）
- カタカナ語は「英語」の列に綴りを書く。本文の初出でも併記する
- 定義は1〜2文

| 語 | 英語 | 定義 | 初出の章 |
|---|---|---|---|
| print | | 値を画面に表示する関数。かっこの中に表示したいものを書く。 | 01-python |
| 文字列 | string | 文字を並べたもの。前後を `"` で囲んで書く。 | 01-python |
| 引数 | | 関数のかっこの中に渡す値。 | 01-python |
| 関数 | | 名前を付けた処理のまとまり。名前とかっこで呼び出す。 | 01-python |
| input | | 入力欄から1行読み取る関数。読み取った値は文字列になる。 | 01-python |
| int | | 文字列を整数に変える関数。整数を表す型の名前でもある。 | 01-python |
| 整数 | | 小数点を持たない数。Python では `3` や `-7` と書く。 | 01-python |
| 変数 | variable | 値に名前を付けて残しておく仕組み。`=` の左に名前、右に値を書く。 | 01-python |
| エラー | error | Python が実行を続けられないときに出す知らせ。種類の名前と場所が出る。 | 01-python |
| f文字列 | f-string | 文字列の前に `f` を付けた書き方。`{}` の中に変数を書くと値が展開される。 | 01-python |
| str | | 値を文字列に変える関数。 | 01-python |
| float | | 文字列や整数を小数に変える関数。小数を表す型の名前でもある。 | 02-numbers |
| round | | 数値を指定した桁数に丸める関数。第2引数に残す桁数を書く。 | 02-numbers |
| べき乗 | exponentiation | ある数を何回か掛け合わせる計算。Python では `**` を使う。 | 02-numbers |
| 剰余 | remainder | 割り算の余り。Python では `%` を使う。 | 02-numbers |
| 整数除算 | floor division | 割り算の商を整数で求める計算。Python では `//` を使う。 | 02-numbers |
| 優先順位 | precedence | 1つの式に複数の演算子があるとき、先に計算する順番。 | 02-numbers |
| import | | 他のモジュールの機能を使えるようにする文。 | 02-numbers |
| モジュール | module | 関連する関数や値をまとめたファイル。`import` で読み込む。 | 02-numbers |
| math | | 平方根や円周率など、数学の計算をまとめたモジュール。 | 02-numbers |
| if文 | if statement | 条件が成り立つときだけ、決まった処理を行う文。`if 条件:` の形で書く。 | 03-branch |
| else | | if文の条件が成り立たなかったときに行う処理を書く。`if` と対で使う。 | 03-branch |
| elif | | if文で3段階以上に分けるとき、前の条件が成り立たなかった場合の次の条件を書く。 | 03-branch |
| and | | 2つの条件が両方成り立つかどうかを判定する書き方。 | 03-branch |
| or | | 2つの条件のどちらかが成り立つかどうかを判定する書き方。 | 03-branch |
| not | | 条件の成り立つ・成り立たないを反転させる書き方。 | 03-branch |
