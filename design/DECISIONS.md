### 2026-09-02 サンドボックスの方向転換（ユーザー発、第2次設計）

> 「サンドボックスの目標と解禁」の6目標は**この決定で置き換わる**。序盤ステージとして形を変えて残す。

ユーザーが触ってみて出した方向: 概念を解禁していく形ではなく、**簡単な回帰・分類を解くという目標のもとで自由にいじる**。先に完成品（学習まで動く本体）を作り、操作のチュートリアルは後から少しずつ足す。詳しい理論は本に任せるのは変わらない。

言語化した骨格:

- **型は「工場建設ゲーム」**。お題（この関数に当てはめろ／この点を分けろ）に対し、モデルを自分で組み立てて、動かして、眺めて、直す。答えは一つではなく、組み方が遊び
- 進行の軸は2本。**ステージ＝お題の難しさ**（平均 → x² → sin → x·y → 分類 …）、**チュートリアル＝操作の種類**（層を置く → 活性化を割り当てる → 学習 → 学習率 → オプティマイザ …）。概念は解禁しない
- 手で重みを置けるのは序盤だけ。x² 以降は学習させないと解けないので、**損失・勾配降下・オプティマイザは後半の飾りではなく本体**
- 活性化を置かなければそのまま動くが線形にしかならない。「x² に直線しか当たらない」を体験させるのが非線形性の説明の代わり
- 真理値表・入力平面は「2入力のときだけ使える観察窓」に格下げ。廃止はしない

| 項目 | 決定 | 却下した案 |
|---|---|---|
| ステージの解き方 | **ステージで変わる**。序盤は手で重みを置いて解ける。以降は構造とハイパーパラメータを決めて学習させ、結果を見て組み直す。手動調整は最後まで残す | 基本は学習 / 基本は手組み |
| キャンバス | **層ブロックを横に並べる**。入力→[層][層]→出力。各ブロックにノード数と活性化。全結合のみ。分岐（concat 等）は将来ブロックとして足せる余地を残す | ノードと線を自由配置 / まずブロック後でノード単位 |
| 触れる設定（最終目標） | 層ごとの活性化・ノード数／学習率・オプティマイザ・エポック／損失関数・重みの初期化／データ側（ノイズ・点数・範囲）。将来: 層ごとの学習率、L1/L2、concat | — |
| 回帰中の主役の窓 | **当てはまりの図**（横軸 x、点がデータ、線がモデル、学習中に線が動く）。ネットワーク図は脇の小窓 | ネットワーク図のまま / 状況で切替 |
| クリア条件 | **損失のしきい値＋任意の縛り**（「パラメータ数〇以下」「層は1つ」など）。縛りが組み方の工夫を促す | しきい値だけ / スコア表示 |
| チュートリアル | **ステージ列の先頭に組み込む**。一本の列で、序盤ステージ（平均・AND・x²…）が操作のチュートリアルを兼ね、毎ステージ新しい操作が1つ増える。XOR は「2層目を置く」の回として残す | 別モード / ジャンル別の列 |
| 学習の操作 | **再生・停止・1ステップ＋履歴バー**。上のバーは学習履歴で、左右にドラッグするとその時点の重み・当てはまり・損失に全窓が戻る。途中からやり直せる | エポック数を指定して実行 |
| 作る順序 | **エンジン（逆伝播・オプティマイザ・履歴）→ ステージの枠組み → 層ブロックUIと当てはまり窓 → 序盤ステージ**。現在の版は同じ場所で上書きし、git に残す。上書き前に現在の2コミットを push | UIの見た目から |

引き継ぐもの: `forward()` が全記録を返すエンジン設計、ツールバー（道具／窓のオンオフ）、主役1枚＋脇の小窓、目標1行＋「?」、全画面レイアウト。捨てるもの: `objectives.ts` の解禁の中身。

### 2026-09-02 サンドボックス第2次実装（工場建設ゲーム型）

ユーザーの指示により、この回に限りサイトのデザイントークン（紙色・朱・明朝）から外れてよいことになった。
サンドボックスは「道具箱」として独立した見た目を持つ。以下は Claude が決めた内容の記録（次に触るときの前提）。

| 項目 | 決めたこと |
|---|---|
| 地 | 暗い作業台。背景 #171715 / パネル #201f1d / 段 #2a2926・#34322e / 罫 #403d38 |
| 文字 | #e8e4dc、補助 #9c968b。書体は OS の system-ui（サイト本体の明朝・BIZ UD は使わない）。数値はすべて等幅 |
| 符号の色 | **正 = 橙 #e08a3c / 負 = 青緑 #4aa39a**（朱・墨の2色から変更）。回帰の面も分類の領域もこの2色の発散配色で塗る |
| 強調 | 山吹 #f0c14b。選択中のチップ・再生ボタン・モデルの曲線・履歴の曲線に使う |
| 合否 | クリア = 若草 #8fbf6a、縛り違反 = 赤 #d2564a |
| 画面 | 4段の固定グリッド（ステージ／目標／学習操作／本体）。本体は 小窓132px + 主役1枚 + 右パネル254px。ページスクロールなし、右パネルだけ内部スクロール |
| ネットワーク図 | 案A（列の見出しがブロック）。見出しカードに「層1 · 4 · tanh」、クリックで選択、道具「設置」のとき列間に＋・見出しに×・ノード数の±。辺が16本を超えたら重みラベルを消す。図は等倍〜1.5倍までしか拡大しない（文字の大きさを揃えるため） |
| 履歴バー | 案A（損失の曲線そのものがバー）。対数目盛、しきい値を破線で重ねる。左右ドラッグでその時点に戻る。最大4000点、超えたら1つおきに間引く |

ステージ10本としきい値は `src/sandbox/stages.ts` に集約。しきい値は実測して決めてある
（線形だけでは届かず、狙った操作を使えば届く値）。

粗として残っているもの:
- 履歴を巻き戻すとオプティマイザの持ち越し量（Momentum/Adam のモーメント）はリセットされる
- 層の挿入・削除・ノード数の変更をすると重みは引き直しになる（ノード数だけは重なる部分を引き継ぐ）
- スマホ幅は未対応のまま
