### 2026-09-02 サンドボックスの技術構成

- **TensorFlow.js は使わない。** 中間層の勾配をすべて取り出して見せるのが目的なので、数値計算は自前実装する。扱うネットは数十パラメータ規模で自前で十分速い
- 計算部 `src/sandbox/engine/` は UI を一切持たない。`forward()` は出力だけでなく各層の z と a をすべて含む記録を返し、表示側はその記録を描くだけ。これで「内部が見える」を構造として保証する
- 表示部 `src/sandbox/views/`、ステージ定義 `src/sandbox/stages.ts`、島本体 `src/sandbox/Sandbox.tsx`
- Astro + React island（`@astrojs/react` を導入、`client:load`）。ページは `/learn/sandbox`
- 図はすべて SVG（ホバーやクリックで要素を選べるようにするため）

### 2026-09-02 サンドボックスの作り直し（ユーザーによる差し戻し）

差し戻しの理由:

- スクロールしないと下の情報に届かないのはユーザビリティとして良くない。1画面で済むようにする
- サンドボックスにサイトのナビは要らない。別ウィンドウで開けてもよい
- **説明が多い**。詳しい説明は本に任せる。ここは実際に手を動かせることが目的で、学習そのものより補助・楽しみに近い
- ステージ1〜5の順送りではなく、**要素が解禁されてできることが増える**形にする

決定:

| 項目 | 決定 | 却下した案 |
|---|---|---|
| 解禁の仕組み | **部品箱が増える方式**。目標を常に1つだけ提示し、達成すると部品・道具・窓が増える | 技術ツリー（見取り図） / 最初から全部使える＋実績 |
| ツールバー | **マウスの役割を切り替えるバー**（観察 / 調整 / 設置）。窓の表示オンオフも同じバーに置く（ユーザー提案） | — |
| レイアウト | **主役1枚＋左に小窓**。小窓をクリックすると主役と入れ替わる | 自動分割グリッド / ネットワーク中心固定 |
| 説明の出し方 | **目標1行＋「?」ボタン**。詳細はポップアップでのみ出す | 初回だけ自動表示 / 完全に無言 |
| サイトのナビ | サンドボックスは**全画面専用レイアウト**（`src/layouts/Full.astro`、ナビもフッターもなし）。学習ページからは別タブで開く | — |
| 入力 | 常に (0,0)(0,1)(1,0)(1,1) の**4通り固定**。自由入力モードは廃止 | 自由入力との併存（何を見ているかが二重になるため却下） |

| # | 目標 | 達成で解禁されるもの |
