## 別の書き方で解き直した結果

問題文と `<Input>` `<Output>` だけを見て、別の書き方（`zip`、`min` と `index`、`sum`、スライス `[::k]`、`int(p * 1.1)` `int(p * 0.9)` の小数版など、教えていない形も含む）で15問を Python の関数に直し、全テストケース（計64件）の出力を模範解答と比べた。全部一致した（`bad 0`）。

直した所が1つある。list-3 の解き直しを最初 `p - p // 10`（割引額を切り捨てる）で書いたところ、`2005` で模範解答と食い違った（`1805` と `1804`）。問題文は「割引のあとの値段は、1円未満を切り捨てます」で、模範解答の `p * 9 // 10` が正しく、私の別解が間違いだった。問題文のほうは「割引のあとの値段」と明記してあるので変えていない。テストの `2005` は、この読み違いを拾う値として残した。

`int(p * 1.1)`（list-1）と `int(p * 0.9)`（list-3）の浮動小数の別解も、全テストで一致することを確かめた。浮動小数で正しく書いた解答が落ちるケースは無い。

## 迷った所・本体に確かめること

- 空の出力: for-1・for-4・for-5 は、回数が0のケースで何も表示しない。`build:tests` `check:practice` は通った。画面の「期待する出力が空」の表示に問題が無いか、確かめてほしい。
- list-2 は「硬貨の種類は、リストにまとめて書いてください」と手段を問題文に書いた。リストを使わず6行の `print` でも通るため（入力が枚数1つだけなので避けられない）。問題文に手段を書くのが規約に反するなら、この1文を消す。
- 変数の名前の指定: for-4 などは変数名を決めていない（出力にしか影響しない）ので問題無し。
- for の話題の★2（for-3 割り勘、for-4 利息）に、合計を出す形に近い「変数の入れ直し」を for-4 で使った。「集計」の主題ではなく、毎年の残高を表示する問題にしたため、`total` の話題とは重ならないと判断した。重なると見るなら for-4 を差し替える。
- list-4 の「前の月との差」は、第3章の気温差（elif-4）と手順が近い。題材は貯金に変えた。
- ★の段差: for-4（変数の入れ直し）が for-3 より重い、と読み手が感じる可能性がある。両方とも「自分で考えること2個」にしたが、確かめてほしい。
- 点数表の題材は使っていない。「点数」を使う問題は list-5（体力テスト）と index-2（漢字テスト）で、それぞれ別の話題。
- 検査7（段落は3文以内）は、for-4・for-5・list-3 の問題文で落ちたので、2段落に分けて直した。
- `report:practice` の「寄りすぎ: for と range」（第4章全体で15問中8問）は、第4章の中心の書き方なので直していない。「試せていない: append / while」は、あとの話題の担当（まだ書かれていない）。
