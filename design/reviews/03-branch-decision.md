いまは `python-03-else-b1` の模範解答（`number % 2 == 0`）が、例の無いままこの形を使っている（`taught.mjs python-03-else` の「ここまでに教えた」にあるのは `print(7 % 2)` → 1 だけ）。

**足す場所**: 説明の最後の段落（「このコードでは `score` が `45` なので…」）のあと、`{/* 課題 */}` の前。

**足す文と例**（この3つだけ）:

> 2で割った余り（第2章）が `0` かどうかを条件にすると、偶数か奇数かで分けられます。

```
<Run
  code={`number = 7
```

> `number % 2` は `number` を2で割った余りで、`number % 2 == 0` は「2で割り切れる」という条件です。`7` を2で割った余りは `1` なので条件は成り立たず、elseの `奇数です` が表示されます。

（`py` で実行し、`奇数です` を確かめた。）

**これに合わせて `python-03-else-b1` の中身を替える（id は同じ）。** いまの b1 は偶数・奇数そのものなので、足した例を写せば通る（抜け道）。割る数を3にする。

  - `<Input>`: `- 1行目: 整数`
  - `<Output>`: 「3で割り切れるなら `3の倍数です`、割り切れなければ `3の倍数ではありません` と1行で表示します。」（ケース1は割り切れる側なので、`3の倍数ではありません` は問題文に書いておく必要がある）
- `stdin={`9`}`、テストケース（この順）: `9` `10` `0` `12` `20`（負の数の `%` は教えていないので入れない）

### X2 第3章4節（and・or・not）に、`and` と `or` を混ぜて `()` でまとめる例を足す

**足す場所**: `not` の説明の段落（「`not` の後ろのかっこの中は、先に確かめます。…」）のあと、3行の表の前。

**足す文と例**:

> 出席が10回以上で、そのうえテストが60点以上かレポートが80点以上なら合格、とするときは、次のように書きます。

```
<Run
  code={`attendance = 8
score = 75
report = 90
if attendance >= 10 and (score >= 60 or report >= 80):
    print("合格です")
else:
    print("不合格です")`}
  out={`不合格です`}
/>
```

> `and` と `or` を混ぜるときは、先にまとめたいほうを `()` で囲みます。かっこを外して `attendance >= 10 and score >= 60 or report >= 80` と書くと、`attendance >= 10 and score >= 60` が先にまとまり、`report >= 80` だけで全体が成り立つので、出席が足りなくても `合格です` と表示されます。

- 形は `A and (B or C)`。題材は出席・テスト・レポートで、今週の演習 10/6 の b5（身長・年齢・保護者）と別
- かっこあり → `不合格です`、かっこなし → `合格です`。結果が変わることを `py` で確かめた
- 説明は `_cross.md` のとおり「`()` で囲む」の一文と「かっこを外すとどう読まれるか」の一文だけ。最初の一文は、ほかの例と同じく Run の前置き
- 2つ目の文が65字前後になる（目安60字）。かっこを外した式を文の中に入れているため。切ると「どこが先にまとまるか」と「結果」が離れるので、このままにする
- 表には行を足さない。問題も置かない（`_cross.md`）
