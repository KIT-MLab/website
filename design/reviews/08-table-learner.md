## 止まる（ここで学習者が進めなくなる）

- L1【06-scores】場所: 課題 `python-08-scores-b1`。問題文「1人ずつ `平均48.3点 不合格` の形で平均と合否を表示してください。そのあと、3科目それぞれが科目の平均より何点上か下かを、…次の行に配列のまま表示してください」と、模範解答の出力の食い違い
  なぜ: 問題文どおりに読むと、「全員ぶんの平均と合否の行」を出し切ってから、差の2次元配列を1回だけ出す（「やってみる」の6行目と同じ形）。ところが模範解答は、人ごとのループの中で `print(diffs[i])` を出し、「平均の行・差の1次元配列」を人ごとに交互に出している。tests は stdout の完全一致なので、問題文どおりに書いた学習者は通らない。しかも「何が違うか」が画面に出るだけで、原因は問題文を読み直しても分からない
  案: 問題文に出力の順（人ごとに「平均の行」と「差の1行」を交互に出す）を例つきで書くか、模範解答を問題文の順（2次元配列を最後に1回）に合わせる

- L2【06-scores】場所: 同じ課題 `python-08-scores-b1`。「`平均48.3点 不合格`」「基準点は `60` とし」
  なぜ: (a) 平均が `48.3` と小数第1位に丸まっていることが、問題文のどこにも書いていない（40・55・50 の平均は 48.333…。丸めずに f文字列へ入れると `48.333333333333336` が出る）。(b) 合格は「60以上」か「60より大きい」かが書いていない。4つ目のテストが `59 60 61`（平均がちょうど 60.0）で、境界をちょうど突いているので、推測で書くと50%で落ちる。(c) `合格` のときの文面は例が `不合格` しか無く、`平均○点 合格` という形は推測するしかない
  案: 問題文に「小数第1位まで」「60以上で合格」を書き、合格の例も1行足す

## 引っかかる（進めるが、迷うか、分からないまま通る）

- L3【01-index / 02-transpose / 03-broadcast の build 課題】場所: 3つの課題 `python-08-index-b1` `python-08-transpose-b1` `python-08-broadcast-b1` の「入力欄から2人分、3科目の点数を読み取って」＋ `forbid` の `for `
  なぜ: 入力6個を for 文なしで2次元配列にする方法が、この章のどこにも出ていない。第7章5節の例は `append` を6回手で書く形、または for の中の `append`。模範解答の `np.array([[int(input()), int(input()), int(input())], [int(input()), …]])`（リストの中で `input()` を呼ぶ入れ子）は「初めての組み合わせ」。ヒントも「2次元配列にまとめます」までで、読み取り方には触れない。変数6個（`a = int(input())` ×6）を作って並べる遠回りなら書けるが、この節の主題（`[:, 1]` や `.T`）より、この読み取りの方がずっと重い。3つの節で同じ負担が繰り返される
  案: 01 の課題の前に「入力から2×3の配列を作る形」を例として1回見せる（または最初から `stdin` で読んだ値を使う形にして、読み取りを課題の主役にしない）

- L4【01-index】場所: 説明「`:` は『すべての行』という意味なので、人の方向はそのまま残ります」「列を取り出すのは科目の方向を1つに絞る操作、行を取り出すのは人の方向を1つに絞る操作です」
  なぜ: 「人の方向」「科目の方向」が何を指すかが定義されていない。しかも「列を取り出す＝科目の方向を絞る」は、列を指定する操作で「科目」を絞るので理解できるが、「人の方向はそのまま残る」と合わせて読むと、方向が行・列のどちらを指すのか前後で逆に見える。学習者は「行／列」の言葉でしか考えられない
  案: 「方向」をやめて、「行番号は全部、列番号は1」のように行・列で書く

- L5【03-broadcast】場所: 困る例「人と科目の両方をfor文で回すと、二重のループになります」
  なぜ: for の中に for を書く（入れ子の for）は第4章までに教えていない。「二重のループ」が何かは分からないまま通る（困る例なので読み流せはする）
  案: 「for文で行と列を1つずつ回すと、書く行が増えます」程度に言い換える

- L6【03-broadcast】場所: 課題 `python-08-broadcast-m1`（ヒント「1人目の点数から average を引いた形を、上の『やってみる』と見比べてください」）
  なぜ: 「やってみる」には、平均を引く例しかなく、`average` を自分で決める例が無い。`[5 5 5]` から逆算して `[75, 65, 85]` を出す（80-5, 70-5, 90-5 を3回計算する）のは、このヒントからは見えない
  案: ヒントを「`[5 5 5]` になるには、1人目の点数からそれぞれ何を引けばよいか、列ごとに考えます」に変える

- L7【02-transpose】場所: 説明「転置する前に、新しい形を先に考えてから、shapeで確かめてください」
  なぜ: 「転置する前に新しい形を考える」「shapeで確かめる」の2つを1文に詰めていて、何をすればよいか読み取りにくい（転置後の形は転置してから `.shape` を見て確かめられるのに、「転置する前に確かめる」とも読める）。直後の最終段落とも重なる
  案: 最終段落とまとめて「転置する前に新しい形を予想し、`.T.shape` で確かめましょう」の1文にする

- L8【04-range】場所: `np.linspace` と `np.zeros` の説明と、課題全体
  なぜ: 課題 m1・b1 はどちらも `arange` だけで通る。`linspace` と `zeros` は一度も使わせず、確かめもしない。また `zeros` の「あとから値を書き込む配列の枠として使えます」は、配列への値の書き込み（`x[0] = 5` など）をまだ教えていないので何のことか分からない。`[0.  0.5 1.  1.5 2. ]` の空白の幅が揃っていない理由も説明が無い（気にしなければ通れる）
  案: `linspace` を使う小問を足すか、`linspace`/`zeros` を落とす。「枠」の文は消す

- L9【05-reshape】場所: 困る例「第7章7節の点数表は、for文で…人数が変わっても、組み立て方はそのままです」
  なぜ: これは困っていない（「そのまま」で済むと書いてある）。reshapeが何を解決するのかが、困る例から読み取れない。説明の末尾「人数ぶんfor文で読み取らなくても」で初めて動機が分かる。なお、この章の01〜03の課題は for 禁止で6つの `int(input())` を並べていたので、「for文で読み取る方が楽」とも言えず、動機が逆に見える
  案: 困る例を「1人ずつの行を作って集める手間（リストを並べたリスト）が要る」という、困りごとの形に書き直す

- L10【05-reshape】場所: 説明「形は `(6,)` で、1次元であることを示します」「reshapeと呼びます」
  なぜ: `(6,)` の末尾の `,` の意味が分からないまま通る。`2 * 3` が個数と一致しないと使えない、と言うが、合わないとどんなエラーが出るかは示していない（エラー名が分からないと、学習者は第6章の読み方を使えない）
  案: `(6,)` は「要素が1つのタプル」とは言わなくてよいが、「1つの数が入っているだけ。2次元なら `(2, 3)` のように2つ並ぶ」と補う。形が合わないときの失敗例を `<Run>` に1つ足すと、ValueError に結びつく

- L11【06-scores】場所: 課題の文「for文で1人ずつ読み取らないでください」と、模範解答の `for i in range(count * 3): flat.append(int(input()))`
  なぜ: 模範解答は for 文で1個ずつ読み取っている（「1人ずつ」ではなく「1個ずつ」だが、学習者の目にはどちらも for 文での読み取りに見える）。何を禁じているのかが分かりにくい。`forbid` は `for value` などを見ているだけで、`for i in range(...)` は通る。問題文が禁じているものと、通る書き方が合っていない
  案: 「人ごとにリストに集めない」「`append([` を使わない」など、禁じる形を具体的に書く

- L12【全 m1 課題（01・02・03・04・05）】場所: kind="modify" の5問
  なぜ: tests が `stdout` だけなので、`print("[90 40]")` のように答えを直接 print しても通る。学習者が書き換えるべき行（01 は3行目の列番号、など）を理解したかは確かめられない
  案: 同じ書き換えを別のデータでもう1回通す tests を足すか、出力の直書きを禁じる `forbid` を付ける

## この節は何のためにあるか（学習者の言葉で一文）

- 01-index: 2次元の表から「ある1科目の全員ぶん」や「ある1人の全科目」を一度に取り出す書き方を知る節。
- 02-transpose: 行と列を入れ替えた表を `.T` で作る節。
- 03-broadcast: 表から「科目ごとの平均」のような1行ぶんの並びを、全員の行から一度に引ける仕組みを知る節。
- 04-range: 0.5刻みや等間隔の数の並びを、for文を書かずに作る節。（`linspace` と `zeros` は何に使うか、学習者にはまだ言えない）
- 05-reshape: 1列に並べた値を、あとから好きな行数・列数の表に並べ直す節。
- 06-scores: 前の節までの書き方で、第7章の点数表をfor文の少ない形に書き直す節。（新しく学ぶものは無く、復習の節だと学習者の目には映る）
