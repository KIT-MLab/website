# 第1章（01-python）日本語の読み 2回目

読んだ節: 01-print / 02-variable / 03-input-basic / 04-input / 05-fstring / 06-scores
意味が取れない文はほぼ無い。直すのは下の6か所。

## 意味が取れない・取り違える

- J1（03-input-basic）
  元: 「最初のコードの入力欄の1行目を `3 + 4` に書き換えて、▶ を押してください。1行目には何が表示されましたか。」（課題 python-01-input-basic-c1）
  種類: 指示があいまい。「1行目」が、入力欄の1行目か、表示の1行目かで取り違える。この節では「N行目」をコードの行にも入力欄の行にも使っている
  直し: 「最初のコードの入力欄の1行目を `3 + 4` に書き換えて、▶ を押してください。表示の1行目には何が出ましたか。」

## 不自然（意味は取れる）

- J2（03-input-basic）
  元: 「上のコードに1行書き足して、2行目に同じ名前を使ったあいさつも表示してください。」（課題 python-01-input-basic-m1）
  種類: 主語や目的語が分からない。「同じ名前」が何と同じなのか。2行目の「あいさつ」も、例を見るまで形が決まらない
  直し: 「上のコードに1行書き足して、読み取った名前を使ったあいさつを、2行目にも表示してください。」（例の `佐藤 さん、ようこそ` の文はそのまま残す）

- J3（04-input）
  元: 「計算の前に、文字列を整数に変える関数 `int()` を通します。」（説明）
  種類: 主語や目的語が分からない。何を `int()` に通すのかが書かれていない。「通す」も口で言わない言い方
  直し: 「読み取った文字列は、計算の前に `int()` に渡します。`int()` は、文字列を整数に変える関数です。」

- J4（06-scores）
  元: 「上のコードを書き換えて、平均も表示してください。`合計210点 平均70.0点` のように、合計のあとに平均を表示してください。」（課題 python-01-scores-m2）
  種類: 同じ語の繰り返し。「平均を表示してください」が2文に分かれて同じことを言っている
  直し: 「上のコードを書き換えて、合計のあとに平均も表示してください。`合計210点 平均70.0点` と表示されれば合っています。」

- J5（06-scores）
  元: 「点数を扱うプログラムができました。次の章では、平均の長い小数を短く丸め、合格の基準点も並べて表示します。」（つながり）
  種類: 中身が無い。1文目は読んでも何も増えない
  直し: 「次の章では、平均の長い小数を短く丸め、合格の基準点も並べて表示します。」

- J6（01-print）
  元: 「1行目の `print` は、かっこの中に書いた値を画面に表示する命令です。…」の次の段落「かっこの中に書いた値を引数（ひきすう）と呼びます。」（説明）
  種類: 同じ語の繰り返し。「かっこの中に書いた値」が2つの段落の頭に続けて出る
  直し: 「この値を引数（ひきすう）と呼びます。」

## 節全体について

- 06-scores の「困る例」は「点数から合計と平均を出したいとします。」の1文だけで、何が困るのかが書かれていない（説明が足りない。足さずに報告のみ）。
- 02-variable の「困る例」は、「値段と、送料50円を足した額と、20円引きの額を」と「と、」が3つ続く。意味は取れるので、直しは挙げない。
