### A. 真偽の配列を `&` でつなぐ書き方（L12）→ 4節で例を1回見せて教える

確かめたこと:
- `&` は第15章4節より前の本文・例・問題のどこにも無い。第15章4節の本文にも説明が無い。構文の一覧（`src/lesson/syntax-list.ts` 636行目付近）には第15章4節の行として `print(np.sum((pred == 1) & (y == 1)))` → `2`「& は両方に当てはまるか。当たりの数を数える」があり、節の下の「この節の書き方」の表には出ている。ただし表だけで、`and` では配列に使えないこと・かっこが要ることは、どこにも無い
- `(pred == 1) and (passed == 1)` は `ValueError: The truth value of an array with more than one element is ambiguous...` で止まる。かっこを外した `pred == 1 & passed == 1` も同じ `ValueError` で止まる（実行して確かめた）
- **真偽の配列を `np.sum` すると `True` の個数になることは、教えていない。** 第7章3節が教えるのは `scores >= 60` で真偽の配列ができること、`scores[scores >= 60]` で取り出すこと、個数は `len(scores[scores >= 60])` で数えること（構文の一覧 python-07-select）まで。第15章3節の説明に「真偽の配列の平均を取ると、`True`の個数を全体で割った値になります」があるが、合計については言っていない。第14章1節は `(scores >= 60) * 1` で0と1の整数にする形
- `&` は第15章4節・5節の例と模範解答（confusion-m1・confusion-b1・study-b1）にしか出ない。教材の他の章には無い

決めたこと: **`&` を使わない形に直すのではなく、4節で例を1回見せて教える。** 理由:
- 4節の4行（当たり・見逃し・空振り・正しく外す）は「予想が○で、答えが△」の形をそのまま4通り書いたもので、混同行列の2行2列の表と1対1に対応する。`&` を外して `np.sum(pred[passed == 1])` や `np.sum(pred * passed)` の形にすると、4行の形がそろわなくなり（見逃しは `len(...) - hit`、正しく外すは `(1 - pred) * (1 - passed)` など）、節で分かってほしいこと（4つの場合）より書き方の工夫のほうが目立つ
- 構文の一覧はすでに `&` を第15章4節で教える書き方として出しているので、本文が追いつけば表と本文がそろう
- 5節（通し）は4節の4行をそのまま使うので、4節で教えれば5節は直さなくてよい
- 練習編3（Titanic）で「女性かつ1等」のように配列の条件を2つ重ねるときにも同じ書き方が要る見込み（`spec/50` 2.5。まだ書いていないので見込み）

4節の直し（説明の、8行目の `hit` を説明する段落の直後に置く）:
1. 説明の文を足す（2文）:「8〜11行目の`&`は、2つの真偽の配列を同じ位置どうしで比べ、両方が`True`の位置だけを`True`にします。配列どうしには`and`は使えず、書くとエラーになります。`&`の両側の比べる式は、`(pred == 1)`のように`()`で囲みます。囲まないと、正しく計算されません。」
   （かっこの文は「囲みます」「囲まないと〜」の2文に分けてよい。中身はこの3点だけ。`&` が先に計算される理由は書かない）
2. 小さい `<Run>` を1つ足す:

   ```python
   import numpy as np

   pred = np.array([1, 0, 1, 1])
   passed = np.array([1, 1, 0, 1])
   print((pred == 1) & (passed == 1))
   print(np.sum((pred == 1) & (passed == 1)))
   ```
   `out`:
   ```
   [ True False False  True]
   2
   ```
   （実行して確かめた。numpy の表示で `True` の前と `False` の後ろに空白が入る形のまま `out` に書く）
3. その `<Run>` の下に一文:「真偽の配列を`np.sum()`に渡すと、`True`を1、`False`を0として足すので、`True`の個数になります。」

これで confusion-b1・study-b1 の模範解答の `&` の行は、教えた書き方になる。
