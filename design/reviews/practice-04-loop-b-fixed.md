# 練習問題集 第4章 後半3話題 直した記録

## 決定ごとの直し
- R1: while-3（旧 while-4、積み木）のヒントから「第4章5節のように」を消し、「繰り返しの中で1個ずつ読む。読んだ数を高さに足し、個数を1つ増やす。繰り返すかは、いまの高さと目標で決める」に書き直した。
- R2: while-4（予算）のヒントに「読み直す行は、買えたかどうかに関係なく、毎回実行される位置に書きます」を足した。while-5（各桁の和）に「1の位を取り除いた数は、元の数に入れ直します。入れ直さないと、繰り返しが終わりません」を足した。while-1 の指し先は、5節本文に `n = n - 1` が無く、節の冒頭の「この節の書き方」の表（`syntax-list.ts` の while の2つ目の例）にあるので、「第4章5節の冒頭の「この節の書き方」の表にある、`n = n - 1` の形」とした。
- R3: while の並びと id を入れ替えた。while-3 = 積み木（★2）、while-4 = 予算内の買い物（★2）、while-5 = 各桁の和（★3）。模範解答のファイル名も合わせた。各桁の和のヒントに「数が 0 より大きい間、繰り返します」を足した。
- R4: append-5 に `forbid={['max(']}` を足し、問題文に一文を足した。
- R5: while-2 の `forbid` を `['/']` にし、問題文を「割り算（`/` や `//`）は使わず、繰り返しで求めてください。」にした。
- R6: while-3 の問題文を「積み木の高さは同じとは限りません。積むたびに入力されます。」にした。
- R7: append-2 の問題文を「この5つの番号を、プログラムの中でリストにしてください。」にし、入力の説明に「整数」を足した。ケース1（`stdin` と `tests` の先頭）を `5` から `3` にした。
- R8: append-5 の「残りを集計します」を消した。
- R9: 採らない（触らない）。
- R10: total-3 のヒントに「出発値を 0 にすると、最小が正しく出ません。」を足した。
- R11・R12: total の並びと id を入れ替えた。total-4 = 平均を超えた人数（★2、ヒントは2つに分けた）、total-5 = 勤務時間の合計（★3、ヒントは「ある日の勤務時間が、リストのどのインデックスにあるか」）。模範解答のファイル名も合わせた。
- R13: total-1/4/5 を「`sum()` という関数を知っている人も、ここでは使わず、繰り返しで求めてください。」に、total-3 を「`max()` や `min()` という関数を〜」に、append-5 を「`max()` という関数を〜」にそろえた。`forbid` は残した。
- R14: while-4（予算）のヒントの「最初の1行を先に読み」を「予算の次の行を先に読み」にした。
- 日本語: while-2 を「水槽に入れた水の合計が必要な量以上になるまで」に、while-5（各桁の和）の「確認用の数として使います」を消して「各桁の数字をすべて足した値（各桁の和）を求めてください」にした。

## 迷った所・できなかった所
- while-5（各桁の和）の問題文は、前の文を消したあとの形を自分で書いた（「受付番号から、各桁の数字をすべて足した値（各桁の和）を求めてください。」）。
- R4 と R13 の一文は、append-5 では「繰り返しで求めてください」で統一した（「探して」にはしていない）。
- while-3（積み木）のヒントは、読み手の案の「足す前の高さと目標で決めます」を「いまの高さと目標で決めます」にした（元の言い方のほうが自然なので。コードは書いていない）。
