## 引っかかる（進めるが、迷うか、分からないまま通る）

- L1 場所: b7 ヒント2「伸びが0より大きいかどうかの配列を、そのままインデックスにすると、上がった教科だけを取り出せます。」
  なぜ: 7-3 の例は `scores[scores >= 60]` で、**条件を作った配列と、取り出す配列が同じ**。b7 では条件を作るのは `diff`（伸び）で、取り出すのは `after`（2回目の点数）と別の配列になる。ヒントは「そのままインデックスに」としか言わず、どの配列に付けるかを言っていない。7-3 の形を写すと `diff[diff > 0]` になり、`[5 5]` と出て落ちる（実際に動かして確かめた。期待は `[85 95]`）。問題文の「2回目の点数だけ」を読み返せば `after[diff > 0]` に気づけるが、「別の配列で作った条件で取り出す」書き方は7-3 のどこにも出てこない。
  案: ヒント2に「取り出したいのは2回目の点数なので、`after` に付けます」の一文を足す（または問題文の「2回目の点数」を強調する）。

- L2 場所: b3 の全体（`pass_count` の中身）
  なぜ: 例から模範解答までに自分で考えることが多く、数えて5つ。(1) 人数 `n` を先に読み、`range(3 * n)` で値を `append` する（どのヒントにも書かれていない。4-4 のコードは数が固定）、(2) `reshape(n, 3)` に変数を入れる（8-5 は `reshape(2, 3)` の数字だけ）、(3) 2次元の表に `table >= border` と比べる（7-3 は1次元で、比べる相手も数字だけ）、(4) その True と False を `sum` する。**「True を1、False を0として足す」はヒント1にしか書かれておらず、7-6 にも7-2 にも無い**。ヒントが言ってくれているので進めるが、本文では確かめられない。(5) `axis=0` と `axis=1` のどちらか。7-6 は「`axis=0` が科目ごと」と書いているので選べる。
  これ以外にも、`(table >= border).sum(axis=0)` のように、かっこで比べた結果を包んでから `.sum(...)` と書く形が初めて（`(1 + 2) * 3` の `()` と、`scores.sum()` の `.` は別々には出ている）。変数に入れてから `.sum(...)` と書けば避けられる。
  案: 問題を2つに分ける（比べて合格者を数える／デフォルト値付きの関数にして2回呼ぶ）か、ヒント1に「`passed = table >= border` のように変数に入れてから `passed.sum(axis=0)` と書いてもよい」を足す。

- L3 場所: b5 のケース4（`5` 段、1段の高さ `0`）と、入力の説明
  なぜ: `np.arange(h, n * h + 1, h)` と書いた答え（1段目の高さ `h` から `h` ずつ増やす、自然な考え方）は、ケース1〜3は通るが、ケース4で `step` が0になって止まる（実際に ValueError で止まる）。入力の説明に「1段の高さは0にもなる」とは書かれておらず、高さ0の階段は現実にも無いので、落ちた学習者は理由が分からない。ヒント1が「1からnまでの数の並びに1段の高さをかける」と別の作り方を示しているので、ヒントどおりに書けば通る。ヒントを使わず自分で考えた人だけが、意味の分からない落ち方をする。
  案: 「高さが0でもよい」ケースを意図しているなら、入力の説明に1行足す。意図していないなら、ケース4を消す。
  また、8-4 の本文の `np.arange` は引数3つの形だけで、`np.arange(1, n + 1)`（引数2つ）は出てこない。`range(1, 4)` と同じ考え方で書けるが、`np.arange(1, n + 1, 1)` と3つ書く方が本文に忠実。

- L4 場所: b7 と b1 と b2 と b6 の「入力を配列にする」ところ
  なぜ: 入力の読み方の説明がヒントに無い。b1 と b6 と b2 は `np.array([int(input()), ...])` と `int(input())` を5〜6回並べる形で、7-2 の課題（7-select-b1 など）では出てくるが、この回のヒントは指していない。b7 は `n` 個ずつ2回、リストに `append` してから `np.array` にする必要があり、ヒント1は「それぞれ配列にし」とだけ言う。4-4 の `for i in range(3): numbers.append(int(input()))` を思い出せば書けるが、これも「教材をまだ進めていなくても、ヒントを読めば解ける」には含まれない。
  案: 入力の読み方は、b7 のヒントに「リストに集めてから `np.array` に渡します。第4章4節」を足す。
