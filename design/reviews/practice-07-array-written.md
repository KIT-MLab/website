## 別の書き方で解き直した結果

全部の問題・全部のテストケース（15問・計49組）で、問題文の読み取りだけから書いた別解（純 Python のリストで、numpy を使わない）と模範解答の出力の数値が一致した（`bad: 0`）。空配列 `[]`、0、負の数、全部同じ値、平均と同じ値（select-5 の `>` の境目）も含む。

- 小数の揺れを避けた点: array-3 は入力を5の倍数に決めた（`c * 9 / 5` が割り切れる）。stats-1 は5個（平均が小数第1位までで割り切れる）、stats-4 は4個（平均が 0.25 刻みで二進数で正確）にした。別解を `c * 1.8 + 32` で書いても全ケースで一致する。
- 浮動小数点の表示: 平均は `21.0`、`-1.4` のように出る。合計・最大・最小は整数のままで `255` のように出る。

## 迷った所・本体に確かめること

- `forbid={['for ']}` を、答えが数になる問題（stats-1〜3、select-3）に付けた。第7章の演習問題と同じ扱い。練習問題集で `forbid` を使うのはこの4問だけなので、方針に合わなければ外してよい（外しても、`.mean()` などを使う書き方が最短であることは変わらない）。
- 「出したい出力をそのまま `print` に書けば通る」は、テストケースを3〜5組にして防いだ。
- array-3 の問題文は、華氏の式（9を掛けて5で割り32を足す）を書いている。式は理科の知識で、コードではないと判断した。
- select-5 の `前半の好調な日` は、取り出した k 日の平均ではなく6日全体の平均と比べる。ヒントで注意を促した。k=2 のケース（`9000 4000 ...`）が、全体から取り出す間違いを落とす。
- frontmatter は触っていない（array の `sections` に `python-07-shape`、select に `python-07-slice` が入っているまま。★1・★2はそれらを使わない）。
- stats-5 の解答は、教えた節の `.sum(axis=1)` `.min(axis=0)` だけ。`np.round` は使っていない。
