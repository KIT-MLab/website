# 第1章（01-python）日本語の読み　全6節

読んだ順: 01-print、02-variable、03-input-basic、04-input、05-fstring、06-scores。
番号 J は章を通したもの。直した文は意味を変えず、内容を足していない。

## 意味が取れない・取り違える

- J1【05-fstring／課題 python-01-fstring-b1の出力】
  元: 「名前・点数・100点まであと何点かを1行で表示します。形は出力例のとおりです。」
  種類: 指示があいまい（問題文だけでは、3つを並べる順と、区切りや「点」「あと」などの言葉が決まらない）
  直し: 「出力例のとおり」と書いてあるが、問題文の中には例が無い。画面に出力例が出ないなら、説明が足りない。出るなら問題無し（画面を見ていないので確認してほしい）。

- J2【05-fstring／課題 python-01-fstring-b2の出力とヒント2】
  元: 「読み取った1行の前後を `【` と `】` で囲んで、1行で表示します。」／ヒント2「`print("【", input(), "】")` とコンマで区切って渡すと、`【 りんご 】` のように間に空白が入ります。」
  種類: 指示があいまい（`【りんご】` と間に空白を入れないのか、入れるのかが問題文で決まらない。ヒント2は空白が入る形を見せていて、問題文と合わない読み方もできる）
  直し: 説明が足りない。問題文か出力の欄に、空白を入れるかどうかを1文で書く必要がある。

## 節全体について

- 01〜06のすべての節の終わりが「〜できるようになりました。次の節では〜」の同じ形。1文目はどこも中身が無いので、J4・J9・J11・J12・J17・J22のとおり消せばよい。
- 画面に出ない見出し「説明」を指すヒントが、02（2か所）・05（2か所）・06（2か所）にある。同じ形なので、まとめて直せる。
- 06の m2 は「平均、合計」の順、b1 は「合計、平均」の順で表示させる。意味は取れるが、続けて解くと取り違えやすい（日本語の誤りではないので、直しは挙げない）。
