対象: 01-rate / 02-derivative / 03-direction / 04-partial / 05-study

## 意味が取れない・取り違える

- J1（05-study）
  元: 「向きの判定は、上の「やってみる」の print("aを減らす" if ... ) と同じ形で書けます。」（ヒント2）
  種類: 指示があいまい／画面に出ない見出しを指す。最初のコードに `print("aを減らす" if ... )` という形は無く、`if` と `else` で `print` を分けて書いている。読んだ人は存在しない形を探す
  直し: 「向きの判定は、最初のコードの `if slope_a > 0:` から `else:` までと同じ形で書けます。」

- J2（01-rate）
  元: 「2点から変化率を求める関数を定義し、読み取った4つの数をそのまま渡すと、1か所にまとめられます。」（課題 python-10-rate-b1 ヒント1）
  種類: 主語・目的語が分からない。何が「1か所にまとめられる」のか取れない
  直し: 「2点から変化率を求める関数を定義し、読み取った4つの数をその関数に渡して呼び出します。式を書くのは関数の中の1か所だけで済みます。」

## 節全体について

- 5節すべての「つながり」が「〜できるようになりました。次の節では〜」の同じ形（J5, J8, J10, J12, J14）。1文目を消して、次の節で何をするかだけにすると中身が残る。
- 課題やヒントで「上の「やってみる」」が4か所（J3, J6, J7, J11, J1も同種）。画面に見出しは出ないので、「最初のコード」などに揃えると表記も統一できる。
- 04・05節の「ずれ」は第7章の語。節の中では「ずれ」で統一されていて、ゆれは無い。
