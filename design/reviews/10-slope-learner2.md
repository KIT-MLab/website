## 10.1 平均の変化率（python-10-rate）

### 止まる
無し

### 引っかかる
- L1 場所: 題「平均の変化率」と、本文の「この値を変化率と呼びます」
  なぜ: 題の「平均の」が本文に一度も出てこない。数IIで「平均変化率」を習った学習者はつながるが、本文だけ読むと「平均」が何の平均なのか（点数の平均？）と一瞬迷う
  案: 本文で「2点の間の平均の変化率」と一度言うか、題を本文の語に合わせる
- L2 場所: python-10-rate-b1 のテストケース3（`1\n-5\n4\n25\n`）
  なぜ: 入力は「1人目の点数（整数）」なのに、点数が -5 になっている。出力例（ケース1）しか見えないので害は小さいが、通らなかったときに失敗したケースとして表示されると「点数がマイナス？」と引っかかる
  案: 点数として自然な値に変える（変化率が負になる例にしたいなら、2人目の点数を下げる）

### 要らない
- 場所: python-10-rate-m1 のヒント2「5行目は書き換えず、4行目の `score_b` だけを変えて、目標の値になるようにします。」
  なぜ: 問題文「4行目の `score_b` を書き換えてください」の言い直しで、詰まった学習者が欲しい「(score_b − 50) ÷ 3 が 4 になる数」という手がかりになっていない

### 課題ごとの表
| 課題 | 何を確かめるか | 未習の行 | 自分で考える数 | 抜け道 | 消したら失うもの |
|---|---|---|---|---|---|
| python-10-rate-m1 | 変化率の式を逆にたどれるか（4.0 になる点数を求める） | 無し（starter のまま） | 1（(x − 50) ÷ 3 = 4 を解く） | 数を順に試して ▶ を押せば当たる（試行で通る） | 「分子が点数の差、分母が時間の差」を自分で使う場面 |
| python-10-rate-b1 | 変化率を関数にして、入力から求められるか | 無し。`def`/`return`（python-05-return）、`int(input())`（python-01-input）、`print(round(関数(...), 2))`（python-05-scores の `round(..., 1)` と同じ組み合わせ）。引数4つは初めてだが数が増えただけ | 2（式を `def` の中に移す、4つの入力を読む） | 無し | 変化率を「2点を渡せば出る関数」として書くこと |

### この節は何のためにあるか
2人の勉強時間と点数から、「1時間増えると何点変わるか」を（点数の差）÷（時間の差）で出せるようにするため。

## 10.2 微分（python-10-derivative）

### 止まる
無し

### 引っかかる
- L3 場所: 困る例「`x**2` の `x = 3` での傾きを…調べたいのですが」
  なぜ: 10.1 で定義した「傾き」は直線の傾きだけで、曲線の「x = 3 での傾き」はまだ定義されていない。説明の2段落目でようやく「その点で曲線に接する直線の傾き」と出る。数IIの接線を覚えていれば読めるが、困る例の時点では何を求めたいのかがぼやける
  案: 困る例に「曲線のある1点での傾き（その点で接する直線の傾き）」と一言足す

### 要らない
無し

### 課題ごとの表
| 課題 | 何を確かめるか | 未習の行 | 自分で考える数 | 抜け道 | 消したら失うもの |
|---|---|---|---|---|---|
| python-10-derivative-m1 | 数値の傾きと 2x の対応が分かるか | 無し（starter のまま） | 1（2x = 12 から x0 = 6） | 数を順に試せば当たる | 「数値で求めた傾き ≒ 公式の値」を自分で使う場面（c1 と重なるが、c1 は選ぶだけ） |
| python-10-derivative-c1 | h を0に近づけたときの行き先が分かるか | —（選ぶ問題） | 1（2×5 を考える、または動かして見る） | 11（h=1 の値）を選ばせる選択肢があり、当て推量は効きにくい | 「近づく先」という微分の考え方そのもの（m1 と b1 は数を出すだけ） |
| python-10-derivative-b1 | 数値微分を自分で組み、公式の値と並べられるか | 無し。`def f`/`return x ** 3`（Run の f）、`int(input())`、`(f(x0 + h) - f(x0)) / h`（Run 6行目）、`3 * x0 ** 2`（python-02-precedence の `2 * 3 ** 2`） | 3（f を x**3 にする、for を使わず h を1つ決める、公式 3x² を自分で出してコードにする） | 無し | x**3 の公式を自分で出してコードと突き合わせること |

実行で確かめた値: Run の 0.01 の行は丸めないと `6.009999999999849`（本文の記述どおり）。m1 模範解答 → `12.0`。b1 は x0=3 → `27.0009` / `27`、x0=0 → `0.0` / `0`、x0=-2 → `11.9994` / `12`。

### この節は何のためにあるか
2点の幅を0に近づけると傾きがある数に近づき、それが数IIで習った微分の値になる、と Python で確かめるため。

## 10.3 傾きの符号と動く向き（python-10-direction）

### 止まる
無し

### 引っかかる
- L4 場所: python-10-direction-b1
  なぜ: 最初のコードの4行目を `x0 = float(input())` に変えるだけで、あとは一字一句同じで通る。自分で考えることが1つしかなく、m1（x0 を書き換える）と合わせて、この節の課題はどちらも「最初のコードの1行を変える」になっている。符号から向きを決める `if` を自分で書く場面が無い
  案: b1 を、Run に無い形にする（例: 別の関数にする、出す文言や向きの言い方を変える、2つの x0 を比べる）か、b1 を消して c1 と m1 に任せる

### 要らない
無し

### 課題ごとの表
| 課題 | 何を確かめるか | 未習の行 | 自分で考える数 | 抜け道 | 消したら失うもの |
|---|---|---|---|---|---|
| python-10-direction-m1 | 傾きが正になる x0 を選べるか | 無し（starter のまま） | 1（2x − 4 = 2 から x0 = 3。微分の式はヒントに出る） | 数を順に試せば当たる | 傾きが正になる側の例を自分で作る場面 |
| python-10-direction-c1 | 「右へ動かして減った → 傾きは負」と逆向きに考えられるか | —（選ぶ問題） | 1 | 2択なので当て推量で半分通る | 符号と向きの関係を逆からたどること（ほかの問題は順向きだけ） |
| python-10-direction-b1 | 入力した x0 で傾きと向きを出せるか | 無し。`float(input())`（python-02-int-float）、ほかは Run と同じ | 1（float で読む） | 最初のコードを写して1行変えるだけで通る（L4） | 無い（m1 が同じことを確かめている） |

実行で確かめた値: Run → `-2.9999` / `右へ動かす`。m1 模範解答 → `2.0001` / `左へ動かす`。b1 は 0.5 → -2.9999 右、0 → -3.9999 右、-1 → -5.9999 右、3.5 → 3.0001 左。

### この節は何のためにあるか
傾きが正なら左、負なら右へ動かせば値が小さくなる、とプログラムで判定できるようにするため。

## 10.4 偏微分（python-10-partial）

### 止まる
無し

### 引っかかる
- L5 場所: 説明「外で作った名前は、関数の中から読むことができます。」と、Run 10〜14行目の `a = 7`・`b = 30`・`loss(a + h, b)`
  なぜ: この文の直後のコードでは、`a` と `b` が関数の外にもあり（10〜11行目）、`loss` の引数の名前にもなっている。「外の名前は中から読める」と習った直後なので、`loss` の中の `a` は外の `a = 7` なのか、渡した `a + h` なのかで迷う。第5章のスコープ（python-05-scope）では「中で作った同じ名前は別物」は習ったが、引数と外の変数が同じ名前のときにどちらが使われるかは出ていない
  案: 「引数と同じ名前が外にあっても、関数の中では渡した値が使われる」と一文足す
- L6 場所: 困る例「`a` と `b` のどちらを動かせばよいか分かりません。」と、説明全体
  なぜ: この節は傾き 78.0 と 8.0 を出して終わり、困る例の問いにも、この2つの数が何を意味するか（正だから減らす、など）にも答えない。答えは次の節で出るが、この節だけ読むと「で、どちらを動かすの？」が残る
  案: 困る例の問いを「それぞれの向きの傾きを知りたい」に寄せるか、説明の最後に「この2つの符号から向きを決めるのは次の節」と一言足す

### 要らない
無し

### 課題ごとの表
| 課題 | 何を確かめるか | 未習の行 | 自分で考える数 | 抜け道 | 消したら失うもの |
|---|---|---|---|---|---|
| python-10-partial-m1 | b の向きでは b だけを動かす、と分かるか | 無し（starter のまま） | 0〜1（Run の14行目と同じに直せばよい） | 最初のコードの14行目をそのまま写せば通る | 「a だけ動かす」と「b だけ動かす」の取り違えに気づくこと（b1 も同じ形を書くので、重なりは大きい） |
| python-10-partial-b1 | 2変数の式の偏微分を両方の向きで求められるか | 無し。`def f(a, b)`（Run の loss と同じ形）、`a ** 2 + a * b + 2 * b ** 2`（問題文の式をそのまま）、ほかは Run 13〜16行目と同じ形 | 1（numpy を使わない f に置きかえて、2つの入力を読む） | 無し | numpy の配列を使わない、ふつうの2変数の式でも同じやり方で傾きが出る、と確かめること |

実行で確かめた値: Run → `78.0` / `8.0`（丸める前は 78.01379999961）。m1 模範解答 → `-954.0` / `-188.0`。b1 は (1,2) → 4.0 / 9.0、(3,-1) → 5.0 / -1.0、(-2,1) → -3.0 / 2.0、(0,0) → 0.0 / 0.0。

### この節は何のためにあるか
直線の a と b のように動かせる数が2つあるとき、1つだけ動かして、それぞれの向きの傾きを求めるため。
