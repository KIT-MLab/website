### 引っかかる（進めるが、迷うか、分からないまま通る）

**L1（01 / 課題 `fit-b1`・`fit-m1`）`reshape` が要る理由が、規則として書いてあるだけ。忘れたときの英語のエラーに、教えていない `-1` が出る。**
- 場所: 「特徴量が年齢1つだけでも、モデルには2次元の配列で渡します」
- なぜ: 理由は「そう決まっている」としか読めない。`reshape` を忘れる失敗が `tree_test` で一番起きる（`ages[:n]` をそのまま `fit` に渡す）。出る英語のエラーは `reshape(-1, 1)` を勧め、`-1` は未習。`fit-b1` のヒントは `reshape` の形そのものを言っていない（ヒント1は `np.array()` とスライスだけ、ヒント2は人数だけ）。`reshape(n, 1)` と `reshape(len(ages) - n, 1)`（変数と式を引数に書く）は初めての組み合わせで、ここが `fit-b1` のいちばん重い1歩になる。
- 案: `fit-b1` のヒントを1つ足し、「`fit` に渡す年齢は、人数ぶんの行と1列の形。本文の6行目と同じ形です」と言う。または、1次元のまま渡すとこのエラーが出る例を節の中で一度見せる（Facilitate の詰まり対策が学習者には見えない）。

**L2（02）モデルが性別を選んだ、が1行の等式から読み取りにくい。**
- 場所: 「`(pred == df["Sex"]).mean()` は、予測が `Sex` の列と一致した割合で、`1.0` と出ています。モデルは、…性別を選び、『女性なら生存』と予測したことが分かります」
- なぜ: `pred`（生存=1）と `Sex`（女性=1）が全員一致なら「女性なら生存」になる、という2段の読み替えが要る。文は結論を言うだけで、「`Sex` は女性が1、`pred` は生き残るが1」の確認が無い。pandas 4 で `Sex` を0・1にしたことを覚えていれば読めるが、30分の最後で疲れていると通り過ぎる。もう1つ、`pred` が全部 `Sex` と一致するのに、なぜ「等級や年齢は使われなかった」と言えるのかも、数行で終わっている。
- 案: 1文足す。「`Sex` は女性が1、`pred` は生き残る予測が1なので、全員一致は『女性なら1、男性なら0』と同じです」。

**L3（02）`max_depth=1` が「1つの列の1つの境目」だと、この節で言い直していない。**
- 場所: `DecisionTreeClassifier(max_depth=1)` の行の説明（無い）と、「3つの列のうち性別を選び」
- なぜ: scikit-learn 1 では特徴量が1列だけで、「境目を1つだけ選ぶ」で足りた。3列を渡すと、境目がどの列に付くのか書いていない。学習者は「3列まとめて1つの境目を作る」と読むこともできる。`Sex`（0と1だけ）に「境目」があることも、書いていない。
- 案: 14行目の説明に「3つの列のうち、1つの列の1つの境目だけを選びます」を足す。

**L4（01）「タイタニック3 と同じ答えになる」の根拠が、読んで確かめにくい。**
- 場所: 「境目は16歳と18歳の間です。タイタニック3 で選んだ17歳と同じ場所です」「自分で書いた学習と、`fit` が、同じ答えを出しました」
- なぜ: 数 0.733 と 0.6 が同じなのは、そのとおりに読める。しかし境目の話は、`predict` に17歳を入れていないので「16と18の間」までしか言えず、タイタニック3 の `< 17` と「同じ場所」かは17歳を試さないと確かめられない（学習者はこの40人に17歳がいないことを見ていない）。また、`fit` が選ぶ基準は「いちばんよく分けられる」で、タイタニック3 の「正解率がいちばん高い」とは同じ言葉ではない。同じ数が出たから同じと受け取れるが、「同じ探し方」と言い切る根拠は読み手には無い（ここは節が言い過ぎている程度で、進めはする）。
- 案: `new` に17を足して `[1 1 0 0 0]` を見せるか、「同じ場所」を「17歳あたり」に弱める。

**L5（02）エラーの例の筋。**
- 場所: 「止まったのは、8行目の `model.fit(X, y)` です。…`'male'` を小数に変えられない…pandas 4 で性別を数に置き換えたのは、このためです」
- なぜ: エラーの読み方（最後の行に値が出る）は第6章の `ValueError` で読める。ただし、「モデルは数しか受け取れない」とは書いていない。「このためです」の先は、pandas 4 の本文が書いた理由（タイタニック4 の `sex` と同じ形にするため）と違う。`float` を「小数」と読む所も、`int("10歳")` のエラー（第6章）とは違うメッセージで、迷う人は出る。通れる程度。
- 案: 「モデルに入れられるのは数だけです」を1文足す。

**L6（01 / `fit-m1`）`new` が starter に無く、2次元に直す手順を、書き足すのは学習者。**
- 場所: 問題文「10歳・16歳・18歳・30歳の4人の予測を、この順に並べた配列のまま、もう1行に表示」
- なぜ: 「配列のまま」は、`print(model.predict(new))` の出力をそのまま、の意味だが、`new` の用意（`np.array([...]).reshape(4, 1)`）に触れていない。本文の1つ目のコードの11行目を探して写せばよいと気づけば通る。気づかないと L1 のエラーに当たる。また `ages[10:]` だけ替えて `survived[10:]` を替え忘れても、30人と30人で長さが合ってしまい、エラーが出ずに別の数が出る（学習者は理由が分からない）。
- 案: 問題文に「4人の年齢は、本文の1つ目のコードの `new` と同じ形にします」を足す。

**L7（01 / `fit-b1`）「深さ1の決定木」。**
- 場所: 問題文「深さ1の決定木を訓練データで学習させ」
- なぜ: 本文は `max_depth=1` を「境目を1つだけ」としか言っておらず、「深さ」の語が本文に無い。`max_depth` の語から推測できる人は多いが、はっきりはしない。
- 案: 問題文に `max_depth=1` と書く。

**L8（量）2節を続けて30分は多い。**
- なぜ: 本文は短めでも、動かす ▶ が01で2回、02で3回（1回目は止まる例）。▶ の初回は20秒待つ。課題は4問で、`tree_test` と `train_accuracy` は関数を一から組む。さらに最後の7分が答え合わせなので、作業に使えるのは約23分。01の `tree_test`（約10分）、02の本文＋ `m1`（約8分）で埋まり、`train_accuracy` に入る時間が無い。Facilitate は「`train_accuracy` はこの回のあとに」と逃がしてあるので、それで合っている。ただ、学習者の画面にそれは出ない。
- 案: `train_accuracy` に「あとでもよい」と画面に出すか、`tree_test` を後回しにできる形にする。
