## 引っかかる（進めるが、迷うか、分からないまま通る）

- **L1（pandas 2）**
  場所: 「`df["Sex"] == "female"` は、…`True` と `False` の列で返します」から「その列を `df[ ]` の中に書くと、`True` の行だけが取り出されます」へ
  なぜ: その `True` と `False` の列が、画面のどこにも出てこない。
  - 第7章3節の `scores[scores >= 60]` は、条件の結果を1回も `print` していない。
  - 学習者は「列で返す」を想像で補うしかない。補えない学習者は、`df[ ]` が「条件に合う行を選ぶ」魔法に見える。
  - 同じ `df[ ]` が、pandas 1 では `df["Survived"]`（名前で列を取る）、ここでは `df[True/Falseの列]`（行を選ぶ）と、2通りの意味で出る。この違いを言う文が無い。
  - `df` が2回出る形は、下の2行を並べた対比で、書き方は分かる。「なぜ2回か」は、`scores` と同じ形だから、で通る。
  案: 1つ目のコードの前に `print(df["Sex"] == "female")` の例を足すか、2行並べた箇所に「`df["Sex"] == "female"` の列が、そのまま `df[ ]` の中に入っている」と一言足す。

- **L2（pandas 2 b1 `survival_rate`）**
  場所: 「`train.csv` を読み込む行も、自分で書いてください」（ヒントは空）
  なぜ: 読み込みの行を関数の外に書くか中に書くかが決まらない。
  - どちらでも通る（中に書くと3回読むが遅くない）。
  - 外に書いたとき、関数の中から外の `df` を読めることは、どこにも教えていない。第5章3節のスコープの例（taught.mjs の `x = 10` の例）は「関数の中で付けた名前は外に出ない」ことだけで、逆（外の名前を中で使う）は無い。
  - 学習者は「外の `df` は関数から見えるのか」で迷う。見えないと思って中に書くのは自然で、それでも通る。
  - `pclass`（引数）と `Pclass`（列の名前）が大文字・小文字だけの違いで並ぶ。`df["Pclass"] == pclass` の左右でどちらが何かを取り違えやすい。
  案: ヒントを1つ足す（「`df` は関数の外で1回読み込んでおけば、関数の中でも使えます」と、「列の名前 `"Pclass"` と引数 `pclass` は別物」）。

- **L3（pandas 1）**
  場所: `print(df.head())` の出力の左端の `0 1 2 3 4`
  なぜ: 説明に出てこない。
  - 「そのあとの5行が5人の乗客」とあるだけで、左端の 0〜4 は何かの説明が無い。
  - すぐ右の `PassengerId` が 1〜5 なので、「0〜4 と 1〜5、2種類の番号がある」と戸惑う。
  - `...` `NaN` `[5 rows x 12 columns]` は、説明で読み解ける。
  - 列が12ある中、見えている6列（`PassengerId`、`Survived`、`Pclass`、`Fare`、`Cabin`、`Embarked`）のうち `Sex` と `Age` は見えない。表で「使う列」に挙げ、「省かれた列も、表には入っています」とあるので、そこは補える。
  案: 「左端の 0〜4 は、行の番号で、0 から数えます」を1文足す。

- **L4（pandas 2 困る例）**
  場所: 「タイタニック2 では、for文と if文で、女性で生き残った人を1人ずつ数えました」
  なぜ: 08q-mlintro/02 の実際の内容と食い違う。
  - 02 のコードは、予測が当たった人を数えて正解率を出すもの。女性で生き残った人を数えていない。
  - 学習者は「そんなのやったっけ」と思う。for と if で1人ずつ数えた形は同じなので、進めはする。
  案: 「for文と if文で、予測が当たった人を1人ずつ数えました」に直し、「女性だけを取り出して数える」へつなぐ。

- **L5（pandas 1 b1 の出力）**
  場所: 「運賃の平均は、小数第2位まで丸めます」と、3行目の「年齢のいちばん高い値」
  なぜ: 出力の見た目が予想とずれる。
  - `round(…, 2)` の結果は `32.2` で、`32.20` ではない。
  - `Age` の最大は `80.0` で、`80` ではない。
  - 学習者は自分の出力を見て、合っているのか不安になる。
  - `Age` に欠けた欄（`NaN`）があるのに最大が出ることは、説明されない。ただし、うまくいくので進める。
  案: 問題文に「`round(…, 2)` を使う（`32.2` のように末尾の 0 は出ません）」を一言足すか、例の出力に小数が出る行を見せる。

- **L6（2節を続けて30分）**
  場所: 全体の量
  なぜ: 概念が盛りだくさんで、時間が足りなくなる。
  - 新しい概念: `pd`、`read_csv`、データフレーム、`head()` の読み方、列の取り出し `df["…"]`、`.sum()` `.mean()`、条件で行を取り出す `df[ ]`、`&` と `( )`。
  - 実行する例が5つ、問題が4問。
  - Facilitate の前後（3分と7分）を引くと、学習者が使えるのは20分ほど。
  - 5人が、初めての pandas を打ち込みながら読む量としては、タイトに思える。
  - とくに 02 b1（関数と pandas の初めての組み合わせ）は、3つ考えることがあり、詰まる人は次に進めない。
  案: 02 b1 を「余裕があれば」にするか、30分に収まらなかったら 02 b1 は宿題にする。
