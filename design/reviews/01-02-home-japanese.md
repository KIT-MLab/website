- J2【02-numbers/04-precedence 説明】
  元: 「計算する順の表の2番目や3番目のように、同じ順位の演算子が並ぶときは、左から順に計算します（`8 / 4 / 2` は `(8 / 4) / 2` と同じです）。」

- J3【01-python/02-variable 説明】
  元: 「名前と値をコンマで並べて `a, b = 3, 5` と書くと、`a` に `3`、`b` に `5` を一度に入れられます。」

  直し: 「`=` の左に名前を、右に値を、それぞれコンマで並べて `a, b = 3, 5` と書くと、`a` に `3`、`b` に `5` を一度に入れられます。」
  あわせて: この文は、`price = price + 10` の例と、「名前は自分で決められますが、次の決まりがあります」の間に入っていて、前後とのつながりが無い。「`=` の使い方にはもう1つ、…」のような橋があるとよい（直し方は書き手に任せる）。
