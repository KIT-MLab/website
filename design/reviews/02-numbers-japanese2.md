# 第2章 日本語の読み（reader-japanese、章をまとめて読む）

対象: `src/content/lessons/02-numbers/` の 01〜06 の6節。重い順に並べ、章を通した番号を振った。

## 意味が取れない・取り違える

- **J1**（01-int-float / 課題 b1）
  元: 「1つ目を2つ目で割った値を、小数のままの形と、整数に変えた形の両方で表示してください。」
  種類: 指示があいまい。「整数に変える」が、`int()` で小数点以下を切り捨てることなのか、`//` で割ることなのか、`round()` で丸めることなのかが問題文から決まらない。テストに `-9 2` があり、この3つで答えが変わる。ヒントを読めば `int()` と分かるが、問題文だけでは決まらない。
  直し: 「1つ目を2つ目で割った値を、小数のままの形と、`int()` で整数に変えた形の両方で表示してください。」

- **J2**（03-operators / 課題 m1 の2つ目のヒント）
  元: 「余りが2で商が3になるのは「割る数 × 3 + 2」の数です。」
  種類: 主語や目的語が分からない。「割る数」がどの数か決まっておらず、「〜の数です」が何の数（割られる数）を指すのかも読み取れない。
  直し: 「割る数を決めたとき、余りが2で商が3になる割られる数は、「割る数 × 3 + 2」です。」

- **J3**（02-round / 説明、最後の段落）
  元: 「丸めた結果の末尾の0は表示されません。たとえば `round(2.504, 2)` は `2.5` と出ます。」
  種類: 取り違える。すぐ上の表と本文に `82.0`（末尾が0の表示）があるため、「末尾の0は表示されません」と食い違って読める。
  直し: 「丸めた結果が `2.50` のように小数の末尾が0になるときは、その0は表示されず、`round(2.504, 2)` は `2.5` と出ます。」

## 不自然（意味は取れる）

- **J4**（03-operators / 説明、最後の段落）
  元: 「`//` は、答えより小さい側の整数に切り捨てます。」
  種類: 言葉の選び・係り受け。「答えより小さい側の整数」は、口で言わない言い方で、何と比べて小さい側なのかが一度で取れない。続く負の数の例（`-9 // 2` が `-5`）とのつながりも唐突。
  直し: 「`//` は、割り算の答えを、それ以下でいちばん大きい整数に切り捨てます。」

- **J5**（03-operators / 説明、最初の段落と表）
  元: 「3行目の `10 // 3` は切り捨て除算（整数除算）です。」と、表の「切り捨て除算」「`3`（10を3で割った商）」
  種類: 表記のゆれ。同じ `//` を「切り捨て除算」「整数除算」「商」と、節の中で3通りに呼んでいる。`%` も「余り（剰余）」と二重に書く。
  直し: 「3行目の `10 // 3` は切り捨て除算です。」（「整数除算」を消す）、「2行目の `10 % 3` は余りです。」（「剰余」を消す）。表の「商」は「`3`（10を3で割って切り捨てた値）」。

- **J6**（06-scores / 説明、最後の段落）
  元: 「この節では、基準点を変数にして、表示にも含めるところまでを書きます。」
  種類: 硬い・翻訳調。「〜までを書きます」は、読み手に向けた説明というより作り手の範囲の宣言に聞こえる。前の文と合わせて、合否の判定を扱わないことを言うだけの段落になっている。
  直し: 「基準点を使って合否をどう決めるかは、次の章で学ぶif文で扱います。この節では、基準点を変数にして、表示に出すところまでです。」

- **J7**（06-scores / 説明、最初の段落）
  元: 「1〜3行目は、変数（第1章2節）に点数を入れています。4行目で平均を計算しています。5行目の `round(average, 1)` で小数第1位に丸めています。」
  種類: ぶつ切り。「〜行目で〜しています」が同じ調子で3つ続き、つながりが読み手任せになっている。
  直し: 「1〜3行目は、変数（第1章2節）に点数を入れています。4行目でその平均を計算し、5行目の `round(average, 1)` で小数第1位に丸めて表示しています。」

- **J8**（01-int-float / 説明、`float()` の段落）
  元: 「`int()` が文字列を整数に変えるのと対になる関数で、小数を含む入力を読み取るときに使います。」
  種類: 硬い。「〜と対になる関数で」が長く、主語（`float()`）から述語までが遠い。
  直し: 「`int()` が文字列を整数に変えるように、`float()` は文字列を小数に変えます。小数を含む入力を読み取るときに使います。」

## 節全体について

- 02-precedence: 優先順位の表で `*` `/` `//` `%` が同じ段にあるが、同じ段の演算子が並んだときにどちらから計算するかの説明が足りない（日本語の指摘ではなく、読んで疑問が残る点として）。
- 全6節とも「つながり」の文は具体的で、中身の無い締めの文は無かった。画面に出ない見出し（「説明」「やってみる」）を指す文も無かった。作り手の言葉（学習者、通し課題など）も無かった。
- 課題の問題文は、modify は出したい結果を言う形、build は問題文・入力・出力に分ける形で、全体にそろっている。
