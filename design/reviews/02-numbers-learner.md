  場所: 模範解答の `average = (a + b + c) / 3`
  なぜ: 「かっこでまとめて先に計算する」は第2章4節（04-precedence）で初めて教える。ここまでの一覧にも、この節の説明にも無い。`a + b + c / 3` と書くと、7・7・8 でも 7 + 7 + 2.666... = 16.7 が出て不正解になる。ヒント2は「平均を求めてから `round()` に渡します」で、足し算を先にするとは言っていない。数IIの知識で「かっこで足し算を先に」と気づく人は通るが、この教材が教えたことだけでは通れない。誤答のとき「なぜ違うか」は、先の節の内容になっている。
  案: かっこを4節より前に（この節かその前の節に）1行で教えるか、b1 のヒントに「足し算を先にするには、かっこを使います」と書く。または、節の順を入れ替える。

（これ以外に、教えていないことが無いと通れない課題は無かった。下の L2 は、画面に出力例が出ているかどうかで「止まる」になる。）

### 引っかかる（進めるが、迷うか、分からないまま通る）

- L2（01-int-float / python-02-int-float-b1、05-math / python-02-math-b1）
  場所: b1 の `<Output>`。01 は「間に半角空白を1つ入れます。形は出力例のとおりです」。05 は「円周の長さと面積を1行で表示します。形は出力例のとおりです」
  なぜ: 模範解答は `小数:5.0 整数:5`、`円周:15.71 面積:19.63` のように、`小数:` `整数:` `円周:` `面積:` というラベルを付けている。問題文のどこにもラベルの文字は書いていない（01 は「間に半角空白を1つ」とまで書いてあり、読んだ通りに `print(q, int(q))` と書くと `5.0 5` で不正解になる）。出力例が画面に出るなら足りるが、出力例が無ければ、ラベルの文字を当てる手段が無い。02-operators の b1（`分` `秒` を文面で指定）と書き方が揃っていない。

- L3（04-precedence / python-02-precedence-m1）
  場所: 「`10` と `14` が表示されるようにしてください」（数だけ書き換える）
  なぜ: `a + b * c = 10` と `(a + b) * c = 14` を同時に満たす3つの数を探す、数あてパズルになっている。優先順位が分かっていることより、数を探す根気を試す問題になる。ヒント1（14 = 7 × 2）とヒント2（足して7になる組）をたどれば通れるが、ヒント1が「かっこの中が7、掛ける数が2」と、答えのほとんどを言っている。ヒントを見ないと、整数の組を片っ端から試すことになる。また「数だけ書き換える」は `tests` では確かめられず、`print(10)` `print(14)` の書き写しでも通る。
  案: 数あてをやめて「`print(2 + 3 * 4)` を `(2+3)*4` の結果にする」など、優先順位そのものを使う問題にする。またはヒント1を弱める。

- L4（03-operators / python-02-operators-m1）
  場所: 「`1024` と `2` と `3` が表示されるようにしてください」

  案: 1行目も `2 ** 10` 以外の手がかりを出す（例「2を10回掛けた数」）か、ヒント2の20と6を言わない。

- L5（01-int-float / python-02-int-float-m2 のヒント）
