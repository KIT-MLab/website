- 問題文: 「この節の最初のコードの3〜6行目のデータと `predict` を、そのまま使います。`w = [0.0, 0.0]`、`b = 0.0` から、学習率0.01で、勾配降下法を入力の回数だけくり返してください。損失は平均二乗誤差です。」

- 模範解答（いまのものを、`<Run>` の1回動かす2行をくり返す形に寄せる）:
  ```python
  import numpy as np

  hours = np.array([...30人...])
  sleep = np.array([...30人...])
  scores = np.array([...30人...])
  X = np.array([hours, sleep]).T

  def predict(X, w, b):
      return X @ w + b

  def loss(w, b):
      pred = predict(X, w, b)
      return np.mean((pred - scores) ** 2)

  steps = int(input())
  w = np.array([0.0, 0.0])
  b = 0.0
  n = len(scores)
  for i in range(steps):
      pred = predict(X, w, b)
      w = w - 0.01 * (X.T @ (pred - scores) * 2 / n)
      b = b - 0.01 * np.mean(2 * (pred - scores))

  print(np.round(w, 2))
  print(round(b, 2))
  print(round(loss(w, b), 1))
  ```
- ヒント: 1「データと `predict`、1回動かす2行は、上のコードと同じです。」 2「損失は第13章3節の `loss` と同じ、`np.mean((pred - scores) ** 2)` です。」 いまのヒント2・3（勾配の式）は `<Run>` に入ったので消す。
