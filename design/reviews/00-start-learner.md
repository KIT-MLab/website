# 00-start 章 学習者の目での読み（全6節）

読み方: `node scripts/taught.mjs start-01-how-to-use` の出力は「ここまでに教えた」が空（章の最初なので）。以降は、この章で読んだことだけを知っている学習者として読んだ。この章は Python のコードも模範解答のファイルも無いので、手順2の「模範解答の行を挙げる」は、課題の答えの文字列・選択肢に置き換えた。`<Keys>` の図の中身だけは `src/components/lesson/Keys.astro` を開いて確かめた。

指摘の番号 L1〜 は章を通した番号。

---

## 止まる（ここで学習者が進めなくなる）

- **L1（02-hankaku、課題 start-02-hankaku-1 と本文）** 日本語入力をオフにする方法が、課題より前にも本文にも無い
  場所: 「打つ前に、日本語入力をオフにしておくと安全です」／Level0「クリックすると切り替わります」
  なぜ: 課題 -1 は説明より前に出る。解く前に「どうすれば半角になるか」が分からない。本文は「オフにしておく」としか言わず、方法は Level0 の最後の1文（右下の `A` / `あ` をクリック）にしか無い。キーボードの `半角/全角` キーは図（03 の Keys）には描かれているが、02 では一度も教えない。Level0 は開いた状態で出るので気づく人は多いが、「確かめる」という題の中に切り替え方が埋まっていて、題から探せない。
  案: 本文に「日本語入力のオンとオフは、右下の `A` / `あ` をクリックするか、`半角/全角` キーで切り替えます」と1文書く。

- **L2（02-hankaku、課題 start-02-hankaku-4）`(締め切り)` を、かっこだけ半角で打つ手順が教えられていない**
  なぜ: 漢字を打つには日本語入力がオン、かっこを半角にするにはオフ、という切り替えを1語の途中で2回する必要がある。オンのまま `(` を打つと `（` になり、それをその場で半角に直す方法（切り替えてから打ち直す）は書いていない。「どこが全角かを教えてくれる」とあるので、直す所は分かるが、直し方は学習者が自分で考える。（このあと 04 のコピーを使えば別の道もあるが、まだ教わっていない。）かつ、日本語の変換（スペースで漢字にする、Enter で確定）は教材のどこにも出ない。
  案: 02-4 の前の説明に「打ち分けるときは、`(` を打つ前に入力をオフにし、日本語を打つ前にオンにします」と1つ書く。あるいは、この問題を「全角のかっこを半角に打ち直す」形にして、日本語入力のオン・オフの練習だけに絞る。

（Windows ではないパソコンを使う人は、L3 で止まる。）

## 引っかかる（進めるが、迷うか、分からないまま通る）

- **L3（全節、とくに 04・05）この章が Windows 専用だと、どこにも書かれていない**
  場所: 04 `Ctrl+C` の表、05「`Win` を押しながら `E`」、06「ファイル名拡張子」
  なぜ: Mac を使う学習者は、`Ctrl+C`（Mac では `Command+C`）、`Win`、右クリック、エクスプローラーのどれも当てはまらない。01 の使い方にも、章の頭にも「Windows のパソコンを使う前提」とは無い。Mac の人は 04 の課題 3 つ（`requirePaste`）で止まるはず。
  案: 01 に「この章は Windows の操作です。Mac の人は運営に聞いてください」のような1文を足す（または Mac 用の補足を作る）。

- **L4（01〜05）「押す」と「クリック」が混ざり、「押す」がマウスで画面を押すことだと、どこにも書かれていない**
  場所: 01「『採点する』を押してください」「左の列にある『デスクトップ』を押す」(05)／02 のクリックの定義は Level0 の中だけ
  なぜ: 02 の Level0 に「クリックは、マウスの左のボタンを1回押す操作です」とあるが、01 でも05 でも「画面の項目を押す」と書いている。キーボードで押すのか、マウスで押すのかは文脈で推測するしかない。`terms` に「クリック」は 02 で出るのに、01 の本文はクリックを使わず「押す」を使っている。
  案: 01 の課題の前に「画面の項目を押すとは、マウスの左のボタンで1回クリックすることです」と1文。

- **L5（03-symbols）本文は `_` を「`ろ` のキー」と呼ぶが、図には `ろ` が描かれていない**
  場所: Level0「`_` は `Shift` と、右下にある `ろ` のキーです」／図の下の説明「`_` は `Shift` ＋ `\` のキー」
  なぜ: 実際のキートップには `ろ` と書いてあるが、図のキーは `\`（と `_`）しか描いていない。本文は `ろ`、図は `\`、で二通りに呼ばれ、学習者は同じキーだと気づけない（図の `_` が点いているキーを見れば分かるが、文と図を自分で突き合わせる必要がある）。
  案: 本文を「図で色が付いているキー」に寄せるか、図に `ろ` を足す。

- **L6（03-symbols、課題 start-03-symbols-4）`[` の位置を教える文が無い**
  場所: Level0「`"` は…、`_` は…、`#` は…、`*` は…」
  なぜ: 本文の4つの説明は `"` `_` `#` `*` だけ。`{` は図の説明（`Shift` ＋ `[` のキー）で、同じキーに `[` があると分かる。気づけば進めるが、課題の記号は `_ * [ {` の4つで、`[` と `{` が同じキーだという事実は、図を見ない人には出てこない。
  案: 本文に「`[` と `{` は同じキーです。`Shift` を押しながらなら `{`」と1文。

- **L7（03-symbols）英語配列のキーボードは扱われていない**
  なぜ: 「図は日本語配列の一例です。あなたのキーボードと違う場合があります」とあるが、違う場合の探し方は「近くのキーも試して」だけ。英語配列の人は `"` が `Shift+'`、`_` が `Shift+-` で、図とは位置がずれる。入力欄で合っているかは確かめられるので進めるが、時間はかかる。
  案: 無理に対応しないなら現状のままでよい。気にするなら「配列の見分け方（Enter が大きい／細い）」を足す。

- **L8（04-copy、課題 start-04-copy-3）画面のコード枠の文字を選ぶ方法が、課題の通りには教えられていない**
  場所: 表の `Ctrl+A`「いま見えている範囲をすべて選ぶ」／「ドラッグは…好きな範囲を選べます」
  なぜ: 学習者がコード枠の文字をコピーしようとして `Ctrl+A` を押すと、ページ全体が選ばれ、貼り付けると余計な文字が入る。「いま見えている範囲」が入力欄の中の話か、ページの話かは書かれていない。ドラッグで選ぶ道があるので進めるが、`Ctrl+A` で試して失敗する人は多い。
  案: 表の説明を「入力欄の中にいるとき、欄の中の文字をすべて選ぶ」に直す、または「コードの文字を選ぶときはドラッグを使います」と書き添える。

- **L9（04-copy、課題 start-04-copy-4）「真ん中の1語だけを消す」の消し方（Backspace / Delete、範囲を選んで消す）が教えられていない**
  なぜ: 「消す」にあたるキー（`Backspace`、`Delete`）が、この章のどこにも出ない。さらに答えは `月 金`（空白1つ）なので、`水` を消したあと空白が2つ残る。「残りは半角の空白1つで区切ります」で気づけるが、ヒントは「コピーと貼り付けを使わないと通りません」だけで、消し方については何も言わない。
  案: 表に `Backspace`（文字を1つ消す）を足すか、ヒントに「消したい言葉をドラッグで選んで `Backspace`」を書く。

- **L10（04-copy、課題 start-04-copy-1）貼り付けを2回する入れ替えのやり方が、問題文から分からない**
  場所: 「入れ替えて入力欄に入れてください」
  なぜ: 「右 左」を「左 右」にするには、`右` と `左` を別々にコピーして順に貼る必要がある。問題は「コピーと貼り付けを使って」としか言わず、全部コピーして貼ってから直す道（手順が増える）と、1語ずつ貼る道の両方が可能。進めるが、段差は大きい（自分で考えること: 1語だけ選ぶ、貼る、もう1語を選ぶ、貼る、空白を打つの5つ。「3を超えたら段差が大きい」に当たる）。
  案: 入れ替えを答えにするなら、ヒントに「`左` だけを選んでコピー、入力欄に貼り付け、…」の手順を載せる。または問題を「2語をコピーして貼り、間の空白を打つ」程度に下げる。

- **L11（04-copy）`Ctrl+C` の「+」が「同時に押す」ことだと、書かれていない**
  場所: 表「`Ctrl+C` | コピーする」
  なぜ: 「`Ctrl` と組み合わせて使う」とは書いてあるが、`Ctrl` を押したまま `C` を押す、という動きは書かれていない。05 の「`Win` を押しながら `E`」は書いてある。04 より先の節でなく、04 が最初の出会い。
  案: 表の前に「`Ctrl` を押したまま、もう1つのキーを押します」。

- **L12（05-files）課題は実際の操作の結果を聞くが、操作したかを確かめられず、本文だけで答えが分かる**
  場所: 課題 start-05-files-3（`naka` を開いたとき上の帯に何と出るか）
  なぜ: 写真の説明に「デスクトップ ＞ sample」とあるので、`sample` の中の `naka` は「デスクトップ ＞ sample ＞ naka」と、写真を読むだけで答えられる。フォルダを作らなくても通る。他の選択肢（順序が逆や、`sample` が抜けたもの）は、読めば外せる。
  案: 問題を「いま自分が作ったフォルダの帯に、何と出ていたか」に近づけるか、作ったかどうかを確かめる別の方法（たとえば `naka` を開いた画面の帯を見て、デスクトップの次に出る名前を打つ）にする。確かめられないなら、「作る操作そのもの」が目的の節だと、本文で言ってしまってもよい。

- **L13（05-files）フォルダの作り方が、課題の中ではなく「操作の補足」の中にしか無い**
  場所: 課題 start-05-files-3 の問題文
  なぜ: 問題文は「フォルダを作ってください」としか言わない。作り方は Level0 の中（開いた状態で出るので見つかるが、「やってみる」の欄に出る課題の文には指し示しが無い）。ヒントに「上の『フォルダの作り方』にあります」と書いてあるのでたどれる。ヒントが無い状態で課題を読むと、右クリックをまだ教わっていない人は止まる。右クリックの説明は Level0 にあるので、見ていれば進める。
  案: 問題文に「作り方は『操作の補足』にあります」と1文入れる。

- **L14（05-files）エクスプローラーで「デスクトップ」を押すところが、手順として書かれているのに、Windows 11 以外では画面が違う**
  なぜ: 「画面のいちばん下にある検索欄」「左上の『新規作成』」は Windows 11 の画面。Windows 10 だと「新規作成」の位置が違う。06 の「表示」→「表示」→「ファイル名拡張子」も Windows 11 のメニューの階層で、Windows 10 では「表示」を押すと、「ファイル名拡張子」にチェックを付ける欄が1つ目の階層に出る。写真の1から3の順を探しても、同じものが画面に無い人が出る。
  案: 「Windows 11 の画面で説明します」と1行。Windows 10 の人の道は別に用意するか、運営に聞く案内にする。

- **L15（06-extension）説明より先に課題を出し、課題の答えに出る `txt` の意味を、あとからしか教えない**
  場所: 課題 start-06-extension-2 と、その下の「説明」
  なぜ: 課題 -2（`メモ` の末尾に何が見えるか）は、拡張子という言葉の説明より前にある。「やってみる」で操作した結果を見て答えるので進めるが、「ピリオドのあとの `txt`」が何なのか（拡張子という名前、種類を表す文字）は、答えたあとに初めて分かる。順序としては、操作→観察→名前が付く、という流れで筋は通る。引っかかるのは、`doc` `pdf` という選択肢が、知らない人には区別できないこと。「テキスト ドキュメント」を作ったことから `txt` が選べる、という関係は書かれていない。
  案: そのままでよい。気になるなら、選択肢の `doc` と `pdf` を、画面のどこにも出ない形（たとえば `exe`）に変える。

- **L16（06-extension）前の節で `sample` を作っていない人は、そこから動けない**
  場所: 「前の節で作った `sample` を開き」
  なぜ: 05 の課題は選択式で、フォルダを作ったかどうかは確かめられない。作らずに答えた人は、06 の最初の指示で「sample が無い」状態になる。デスクトップで新しくテキストを作れば進めるが、そのことは書かれていない。
  案: 「`sample` が無いときは、デスクトップで作ってください」と1文。

- **L17（01-how-to-use）「4問中 2問目」の例が、この節の課題の数と合わない**
  場所: 「上には『4問中 2問目』のように、いま何問目かが出ます」
  なぜ: この節の課題は2問。「4問中」が例だと分かるので止まりはしないが、画面には「2問中 1問目」と出るので、書いてあることと目の前の表示が違い、一瞬迷う。
  案: 例を「2問中 1問目」にするか、「たとえば」を付ける。

## 要らない（消しても何も失わない文・問題）

- **L18（01）「次の節では、半角と全角の違いを練習します。」ほか、各節の最後の「次の節では…」**
  なぜ: 画面の左に節の一覧があり、次の節の題が分かる。節の題の繰り返しで、学習者は何も失わない。（06 の「Python を書くときも、ここまでの操作をそのまま使います」は、章が Python の準備だったことが分かる点で意味があるが、「ここまでの操作をそのまま使います」だけは、挙げた操作の数が節ごとに違うので中身が無い。）
- **L19（03 の「やってみる」と課題 start-03-symbols-4 の「`_ * [ {`」の中の `_ *`）**
  なぜ: `_` と `*` は 03-1（`#`）と 03-2（`"`）では扱わず、03-4 で初めて出る。ここでは、課題 -1（`#` 1つ）、-2（`"合言葉"`）、-4（`_ * [ {`）が同じ「記号を打つ」を3回繰り返すので、確かめることは「その記号のキーが見つかるか」の1つだけ。-1 を消すと「記号を1つ打つ」の最初の練習が消えるが、-2 と -4 が確かめている。
- **L20（02 の課題 -1 と -4）**
  なぜ: -1（`( ) : = 100 ,`）は全角と半角を打ち分ける練習。-4（`(締め切り)`）は同じことを日本語に混ぜた形。-4 は L2 のように、混ぜる手順が増える分、確かめることが別（切り替えを途中ですること）。-1 を消すと最初の1問が消えるが、それは「やってみる」としての役割。

## この節は何のためにあるか（学習者の言葉で一文）

- 01 この教材の使い方: 打つ問題は「採点する」で、選ぶ問題は選ぶと自動で採点されることが分かる。（言える）
- 02 半角と全角: 記号が全角になっていると通らないので、日本語入力をオフにして打つ、ということが分かる。ただし、オンとオフの切り替え方は節の中の1か所にしか無い（L1）。
- 03 記号の打ち方: キーボードで `#` `_` `{` などを探して打てるようになる。（言える）
- 04 コピー・貼り付け・取り消し: コピーと貼り付けで長い文を打ち直さずに入れ、間違えたら `Ctrl+Z` で戻せる、ということが分かる。（言える。ただし消し方が抜けている: L9）
- 05 ファイルとフォルダ: ファイルとフォルダは別のものだと分かり、フォルダを作って、上の帯の読み方が分かる。（言える。ただし、作ったかは確かめられない: L12）
- 06 拡張子: ファイル名の末尾の `.txt` などが種類を表すもので、最初は隠れているので表示させる、ということが分かる。（言える）
