# 練習問題集 第2章 日本語の読み（int-float / round / divmod / power / math）

対象: `src/content/practice/02-numbers/` の int-float.mdx・round.mdx・divmod.mdx・power.mdx・math.mdx（各5問、計25問）。
frontmatter の `title`、`<Exercise>` の `name`、問題文、入力、出力、ヒントを読んだ。

## 意味が取れない・取り違える

- J1 話題 math / 問題 `practice-02-math-5`（丸いテーブル）／ 問題文
  元: 「テーブルの直径と、1人が座るのに要る幅から、円周の長さと、座れる人数を求めてください。座れる人数は、円周の長さを1人の幅で割り、端数を切り捨てた数です。」
  種類: 指示があいまい。出力の円周は小数第1位に丸めるが、人数を出すときの円周は「丸めたあとの値」か「丸める前の値」か、問題文からは決まらない（ヒントにだけ「丸める前の値を変数に入れます」とある）。丸め方で人数が変わる入力がありうる
  直し: 説明が足りない（人数を求める円周が、丸める前か後かを、問題文に1文で書く必要がある）。直す人は、ヒント1の内容に合わせて「人数は、丸める前の円周の長さから求めます」の形で書くとよい

- J2 話題 power / 問題 `practice-02-power-5`（複利の貯金）／ 問題文
  元: 「1年ごとに、そのときの金額に年利を掛けた分だけ増えます。」
  種類: 指示があいまい。入力の年利は「5」（%、整数）なので、「年利を掛けた分」と読むと5倍を足すと取り違える。5% の意味だとはヒント1まで読まないと分からない
  直し: 「1年ごとに、そのときの金額の年利（%）ぶんだけ増えます。」

## 不自然（意味は取れる）

- J3 話題 divmod / 問題 `practice-02-divmod-5`（箱の数と空き）／ 問題文
  元: 「1箱に入る数から、全部を詰めるのに要る箱の数と、詰め終わったあとに空いている場所の数を求めてください。」
  種類: 語順・係り受け。「1箱に入る数から」だけが材料に見え、品物の数が材料に入っていない
  直し: 「品物の数と1箱に入る数から、全部を詰めるのに要る箱の数と、詰め終わったあとに空いている場所の数を求めてください。」

- J4 話題 divmod / 問題 `practice-02-divmod-4`（偶数と奇数の個数）／ ヒント
  元: 「1から7までを書き出して、偶数と奇数を数えてみます。10までや、1だけのときも数えて、きまりを探します。」
  種類: 語順。「10までや、1だけのときも」は、「10までのとき」と「1だけのとき」が並ぶ形になっていない。「みます」と「〜ます」も同じ調子で続く
  直し: 「1から7までを書き出して、偶数と奇数を数えます。1から10までのときや、1だけのときも数えて、きまりを探します。」

- J5 話題 divmod / 問題 `practice-02-divmod-1`（ダースに分ける）／ ヒント
  元: 「割った商は `//`、余りは `%` で求めます。」
  種類: 言葉の選び。「割った商」は、入門書では「割ったときの商」と言う
  直し: 「割ったときの商は `//`、余りは `%` で求めます。」

- J6 話題 math / 問題 `practice-02-math-3`（正方形の1辺）／ ヒント2
  元: 「1辺の長さを丸める前の値で変数に入れておき、周りの長さもその変数から求めます。」
  種類: 語順・係り受け。「丸める前の値で」が「入れておき」にかかり、「値で入れる」が不自然。「丸める前の」が長さにかかるのか読み取りにくい
  直し: 「1辺の長さは、丸める前の値のまま変数に入れておき、周りの長さもその変数から求めます。」

- J7 話題 int-float / 問題 `practice-02-int-float-5`（大袋と小袋）／ 問題文・出力の説明
  元: 「それぞれの値段と重さから、100gあたりの値段を求めてください。」「1行目に大袋、2行目に小袋の100gあたりの値段を表示します。形は出力例のとおりです。」
  種類: 指示があいまい（軽い）。100gあたりの値段を丸めるのか小数のまま出すのか、問題文には書かれていない。「形は出力例のとおり」で済むなら、出力例に小数点以下が出ているはずなので、その場合は直さなくてよい
  直し: 出力例で小数点以下の扱いが読み取れるなら無し。読み取れないなら、説明が足りない（丸め方を問題文に書く必要がある）

## 話題全体について

- 25問とも、「数だけを表示します」「この順に2行で表示します」の言い方は揃っている。ヒントの「第2章○節を見てください」も同じ調子で、読みにくくはない。
- 「平方根」「摂氏」「華氏」「複利」は専門の語として説明なしに出る。直す対象ではないが、1年生が初めて見る語である。
