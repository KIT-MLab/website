# 06-error 日本語の読み（2）

対象: `src/content/lessons/06-error/` の01〜05節。

## 意味が取れない・取り違える

- J1 【04-logic】
  元: 「よくある間違いは3つあります。条件の `>` と `>=` や向きの取り違え、`scores[0]` のように同じ位置を取り出し続けること、`return` の書き忘れです。」（説明）
  種類: 語順・係り受け。「`>` と `>=` や向きの取り違え」が、「`>` と `>=` の取り違え」と「向きの取り違え」の2つなのか、ひとまとまりなのか分からない。
  直し: 「よくある間違いは3つあります。条件の `>` と `>=` を取り違えること、`<` と `>` の向きを取り違えること、`scores[0]` のように同じ位置を取り出し続けること、そして `return` の書き忘れです。」（4つに数えが変わるので、数を揃えるなら「よくある間違いは4つあります」とする。3つのまま直すなら「条件の `>` と `>=` の取り違えや、向きの取り違え」と区切る。）

## 不自然（意味は取れる）

- J2 【01-read】
  元: 「そのあとに続く英語は、`avarage` のことではないかと聞いています。」（説明）
  種類: 指示があいまい／説明が足りない。画面の ▶ の結果（`error`）にはその1行しか出ておらず、「そのあとに続く英語」が読み手には見えない。また「聞いています」は、Pythonが人のように尋ねているように読め、取り違えやすい。
  直し: 直しは挙げない（説明が足りない。実行結果にその英語を出すか、この文を削る）。

- J3 【04-logic】
  元: 「期待は `27` と `25` の2日ですが、`25` の行で `count` が増えていません。」（説明）
  種類: 硬い・翻訳調。「期待は〜ですが」は人が口で言わない。
  直し: 「数えたいのは `27` と `25` の2日ですが、`25` の行で `count` が増えていません。」

- J4 【02-syntax】
  元: 「1つ直すと、そのあとの行の別のSyntaxErrorが出ることもあります。」（説明）
  種類: 語順・係り受け。「そのあとの行の別の」と「の」が続き、何が別なのか一度では取れない。
  直し: 「1つ直すと、そのあとの行にある別のSyntaxErrorが出ることもあります。」
