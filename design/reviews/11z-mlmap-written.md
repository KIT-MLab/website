## 2. 中身（3節）

3節とも `<Run>` 無し、確認問題（選ぶ）2問ずつ、`nobuild` は「コードを書かない章で、例は表と文で見せる。理解は確認問題（選ぶ）で確かめる」。数は全部 Python（`fractions`）で計算して確かめた。運営メモ（`<Facilitate>`）は、全体図1 の頭に30分の全体の台本と全体図1 の10分、全体図2・3 にそれぞれの10分。タイタニックは運営メモにだけ書き、本文には書いていない。

### 全体図1 機械学習とは何か（`01-what.mdx`、`python-mlmap-what`）

- 分かってほしいこと: 人が規則を書く代わりに、答えの分かっている例から、答えを当てる規則をコンピュータに作らせるのが機械学習
- 見せたもの: 4通のメールに「当選を含むなら迷惑メール」を当てはめて数える（合うのは2通）。条件を足しても例外が出る。人が書く規則と機械学習の表。入力と答えの表（勉強時間 → 点数。第12章と同じ数）。予測は答えのまだ分からないものに使う。回帰と分類の例3つずつ（家賃・気温・点数／合否・迷惑メール・事故で生き残ったか）
- 語: 機械学習、データ、入力（特徴量）、答え（ラベル）、予測、回帰、分類
- 問題1: 明日の天気の4つ（最高気温・雨の量・雨が降るか・風の速さ）から分類を選ぶ（答え3）。同じ題材で「数か種類か」だけを見分けさせる
- 問題2: 中古の自転車の記録（年数・タイヤの大きさ・売れた値段）の入力と答えの組み合わせ（答え2）。問題文に「値段を予測する」とは書かず、「新しく来た自転車にいくらの値を付けるか」から、分からない列＝答えを考えさせる。ヒントは1つ（「新しく店に来た自転車で、まだ分からないのはどの列か」）

### 全体図2 学習とは何をすることか（`02-learn.mdx`、`python-mlmap-learn`）

- 分かってほしいこと: 学習とは、モデルの中の数（パラメータ）を、外れ具合（損失）が小さくなるように選ぶこと。式の形と入力は人間が決める
- 見せたもの: 3人（1時間40点・3時間54点・5時間64点）。a = 5、b = 40 で自分で予測と差を出させ（45・55・65、差 5・1・1）、外れ具合 (25＋1＋1)÷3 ＝ 9。3組の表（4・40 → 12、5・40 → 9、6・35 → 1）から 6・35 を選ぶのが学習。全部試す方法（第12章3節）と少しずつ動かす方法（勾配降下法。第13章）を1文ずつ。2乗の理由は第12章2節へ送り、こだわらせない
- 語: モデル、パラメータ、損失、学習
- 問題1: 別の3人（2・4・6時間、52・60・74点）で4組の損失（4・45 → 9、7・30 → 24、7・34 → 8、10・22 → 56）から学習で選ばれる組（答え3）。9 と 8 を近くして、表を読ませる
- 問題2: 学習でコンピュータが決めるのは（式の形／a と b の値／入力の列／何を予測するか）（答え2）
- 補足: 3人の最小の損失は a = 6、b ≈ 34.67 で約0.89。本文は「この3組なら」と書いており、6・35 が全体でいちばん小さいとは言っていない

### 全体図3 確かめ方と、機械学習の全体の流れ（`03-flow.mdx`、`python-mlmap-flow`）

- 分かってほしいこと: 良さは学習に使っていないデータで測る。ベースラインと比べる。過学習に気をつける。全体は5つの段で、コンピュータがするのは④の学習だけ
- 見せたもの: 30通のメールを20通（訓練）と10通（テスト）に分ける。規則A（外れたメールに合わせて条件を足した。20通全部 1.0／10通で 0.6）と規則B（「当選」「無料」「登録」のどれか。0.85／0.8）を先に選ばせる。分け方の表。正解率。過学習。ベースライン（テスト10通のうち迷惑メール3通 → 全部「迷惑メールではない」で 0.7。B の 0.8 は上、A の 0.6 は下）。「テスト」の2つの意味（Kaggle の答えを伏せたデータ）を1段落。5つの段の表（決めるのは人間／コンピュータ、第12〜15章の節へのリンク10本）。この章で出した語16個の一覧
- 語: 訓練データ、テストデータ、正解率、ベースライン、過学習
- 問題1: モデルC（訓練 0.95・テスト 0.70）とモデルD（0.80・0.78）のどちらを使うかと理由（答え2「D。テストデータで高い」）。誤りの選択肢に「D。訓練データが低いほうが合わせすぎていない」を入れた（理由を取り違えている人を拾う）
- 問題2: 家賃の予測で、4つのことのうちコンピュータがしたこと（答え3「a、b、c の値を、損失が小さくなるように選んだ」）。5つの段の表を写すのではなく、新しい場面に当てはめさせる
- 運営メモの最後の問い: タイタニック1〜4 で人間が決めたこと（①〜③⑤、タイタニック4 で条件を足したのも人間）とコンピュータが決めたこと（④ タイタニック3 の境目17歳だけ）。タイタニック3 の 0.733 → 0.6 を「選んだから下がった」とは言わない、と書いた
