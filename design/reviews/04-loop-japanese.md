# 第4章（04-loop）日本語の読み　全6節

節の番号: 1=for文 / 2=リスト / 3=インデックス / 4=append・remove / 5=while / 6=点数表。指摘には J1 からの通し番号を振った。

## 意味が取れない・取り違える

- J1【6節・課題 python-04-scores-b1】
  元: 「入力欄の1行目を人数として読み取ってください。続けて、人数ぶん3教科の点数を読み取り、1人ずつ平均と合否を表示するプログラムを書いてください。基準点は `60` とし、変数にしてください。」
  種類: 指示があいまい。問題文だけでは、何をどんな形で出せば正解かが決まらない。「やってみる」の例は `平均48.3点 不合格` の形で、平均は小数第1位に丸めて出しているが、課題の文には出力の形も丸めも書いていない。
  直し: 内容を足さずには直せない。「出力の形と平均の丸め方が書かれていない」とだけ報告する。直す人は、出力の欄に出力の形（例: `平均48.3点 不合格`）と丸めを書き足す必要がある。

- J2【4節・説明】
  元: 「`append()` も `remove()` も、`リスト名.append(値)` の形で書きます。」
  種類: 取り違える。`remove()` も `リスト名.append(値)` の形で書くと読める。
  直し: 「`append()` は `リスト名.append(値)`、`remove()` は `リスト名.remove(値)` の形で書きます。」

- J3【5節・課題 python-04-while-m1】
  元: 「読み取った行をそのまま1行ずつ表示するようにしてください。」
  種類: 指示があいまい。入力の最後の `終わり` も「読み取った行」なので、これも表示するのかどうかが決まらない。
  直し: 「`終わり` より前に読み取った行を、そのまま1行ずつ表示するようにしてください。」

- J4【3節・ヒント python-04-index-b1 の1つ目】
  元: 「インデックスを `0` から `len(numbers) - 1` まで動かすには、前の節の `range(len(numbers))` を使います。」
  種類: 指す先が違う。`range(len(numbers))` が出てきたのは前の節（リスト）ではなく、この節の説明の最後。
  直し: 「インデックスを `0` から `len(numbers) - 1` まで動かすには、この節の説明にある `range(len(numbers))` を使います。」

- J5【4節・課題 python-04-append-m1 と、そのヒント】
  元: 「`[2, 9]` と表示されるように、4行目に1行足してください。」／ヒント「`remove()` の行をもう1つ、4行目に足します。」
  種類: 指示があいまい。4行目はもともと `print(numbers)` の行なので、「4行目に足す」が、その行の前に入れるのか、置き換えるのか、読み手には決まらない。
  直し: 「`[2, 9]` と表示されるように、`print(numbers)` の前に1行足してください。」／ヒント「`remove()` の行をもう1つ、`print(numbers)` の前に足します。」

- J6【6節・説明】
  元: 「リストにまとめたことで、人数が増えても同じ3行のままで対応できます。」
  種類: 指す先が分からない。「同じ3行」がコードのどの3行か分からない。また、人数が増えても対応できるのは `range()` のためで、リストにまとめたからだとは読み取れない。
  直し: 内容に関わるので、直した文は出さない。「説明が足りない」とだけ報告する。

## 不自然（意味は取れる）

- J7【4節・説明】
  元: 「4行目の `print(numbers)` のように、リストをそのまま表示すると `[3, 2, 9]` の形で出ます。値をそのまま並べて確かめられます。」
  種類: 中身が無い。同じ語の繰り返し（「そのまま」が2回）。2文目は何も増えない。
  直し: 「4行目の `print(numbers)` のように、リストをそのまま表示すると `[3, 2, 9]` の形で出ます。」（2文目を消す）

- J8【6節・説明】
  元: 「3行目は `scores = [int(input()), int(input()), int(input())]` です。1人ぶんの3教科を、リストにまとめて読み取ります。」
  種類: ぶつ切り。「3行目は〜です。」のあとで、改めて説明する形になっている。
  直し: 「3行目の `scores = [int(input()), int(input()), int(input())]` で、1人ぶんの3教科をリストにまとめて読み取ります。」

- J9【6節・説明】
  元: 「繰り返しの中の変数は、1人判定するたびに読み取り直されます。同じ変数名を、人数ぶん使い回しています。」
  種類: 何の値か分からない。読み取り直すのは `scores` だけで、`average` は計算し直しているのに、「繰り返しの中の変数」とひとまとめにしている。また、2文が同じことを言っている。
  直し: 「`scores` と `average` は、1人判定するたびに新しい値に入れ替わります。同じ変数名を人数ぶん使い回しています。」

- J10【5節・困る例】
  元: 「for文は繰り返す回数を先に決める書き方で、回数が決まっていない繰り返しをまだ書けません。」
  種類: 語順・係り受け。（「まだ書けません」の「まだ」が離れている）
  直し: 「for文は繰り返す回数を先に決める書き方で、回数が決まっていない繰り返しは、まだ書けません。」

- J11【3節・困る例】
  元: 「リストの中で、1番先頭の値と3番目の値だけを比べたいとします。」
  種類: 言葉の選び。「1番先頭」とは言わない。
  直し: 「リストの中で、先頭の値と3番目の値だけを比べたいとします。」

- J12【1節・説明】
  元: 「`range(1, 6)` は `1` から `5` までの整数を順に生成する関数です。終わりの数そのものはふくみません。」
  種類: 何を指すか分からない（「終わりの数」が `5` にも `6` にも読める）。「ふくみません」は、同じ章の別の節の「わたす」「渡します」と表記がそろっていない（下の節全体の指摘も見る）。
  直し: 「`range(1, 6)` は `1` から `5` までの整数を順に作る関数です。渡した `6` は含みません。」

- J13【5節・説明】
  元: 「4行目の `count = count + 1` で、繰り返すたびに数を1つ増やします。」
  種類: 主語が分からない。何の数かが書いていない（コードを見れば分かるが、文だけでは分からない）。
  直し: 「4行目の `count = count + 1` で、繰り返すたびに `count` を1つ増やします。」

- J14【4節・説明】
  元: 「3行目の `numbers.remove(7)` は、リストから値が `7` の要素を1つ取り除くメソッドです。」
  種類: 言葉の選び。この章では「値」で通しているのに、ここだけ「要素」が出てくる。習っていない語。
  直し: 「3行目の `numbers.remove(7)` は、リストから `7` という値を1つ取り除くメソッドです。」

## 節全体について

- 表記: 同じ章の中で、「ふくみません」（1節）と「含む」系の語、「わたす」（2節のヒント）と「渡す」（1節の説明、1・6節のヒント）のように、ひらがなと漢字が混ざっている。章の中でそろえるとよい。
- 画面に出ない見出しを指す文、作り手の言葉（学習者・通し課題など）は、この章には見つからなかった。
- 「〜できるようになりました」で終わる形は、全6節に同じ形で出ている（J15〜J20）。
