# 日本語の読み：第0章（00-start）全6節

読んだもの: `reader-japanese.md`、`examples.md`、`00-start/01〜06` の地の文・課題の問題文・ヒント・選択肢。
指摘は全部で9件（J1〜J9）。

## 意味が取れない・取り違える

- **J1**（05-files／ヒント）
  元: 「上の帯の読み方は、画像のすぐ下の文章にあります。」
  種類: 言葉の選び・語順（同じ文の中の「上の「フォルダの作り方」」の「上の」は「ページの上のほう」の意味で、「上の帯」の「上」は「画面の上部にある帯」の意味。同じ「上の」が2つの意味で並び、取り違えやすい）。あわせて、「帯」は Windows や入門書では「アドレスバー」と呼ぶことが多い
  直し: 「アドレスバーの読み方は、画像のすぐ下の文章にあります。」
  （「上の帯」は 05-files の説明・問題文にも出る。J2 参照。直すなら全部同じ語にそろえる）

- **J2**（05-files／説明と課題）
  元: 説明「上の帯には、いま開いている場所が外側から順に出ます。」／ 課題「`naka` を開いたとき、上の帯には何と出ていますか。」
  種類: 言葉の選び（「帯」は一般的な呼び名ではない。J1 と同じ語にそろえる）
  直し: 説明「画面の上のアドレスバーには、いま開いている場所が外側から順に出ます。」／ 課題「`naka` を開いたとき、アドレスバーには何と出ていますか。」

## 不自然（意味は取れる）

- **J3**（02-hankaku／説明）
  元: 「全角の数字や記号は、日本語入力がオンのときに打たれます。」
  種類: 硬い・翻訳調（「打たれます」と受け身にしているので、誰が何をしたときに全角になるのかが遠回しになる）
  直し: 「日本語入力がオンのときに数字や記号を打つと、全角で入力されます。」

- **J4**（02-hankaku／やってみる後の Level0「いまの入力方式を確かめる」）
  元: 「下の打つ欄をクリックしたあとなら、…」
  種類: 表記のゆれ（同じ章で、同じものを 01 では「下に出る欄」、04 では「入力欄」と呼んでいる。「打つ欄」はこの1か所だけ）
  直し: 「下の入力欄をクリックしたあとなら、…」

- **J5**（03-symbols／困る例）
  元: 「キーボードの配置は機種によって違うので、覚えても別のパソコンでは通じないことがあります。」
  種類: 言葉の選び（キーの場所は「通じる」ものではない）
  直し: 「キーボードの配置は機種によって違うので、覚えた場所が別のパソコンでは違っていることがあります。」

- **J6**（04-copy／やってみる）
  元: 「次の2つの言葉を、コピーと貼り付けを使って、入れ替えて入力欄に入れてください。」
  種類: 同じ語の繰り返し（「入れ替えて」と「入れて」が近く、「入れ替えて入れる」と読みにくい）
  直し: 「次の2つの言葉を、コピーと貼り付けを使って、順番を逆にして入力欄に打ち込んでください。」

- **J7**（04-copy／説明）
  元: 「ドラッグは、マウスのボタンを押したまま動かして離す操作です。この動きでも、好きな範囲を選べます。」
  種類: 主語や目的語が分からない（「この動きでも」の「でも」が何と並べているのか、何の範囲かが書かれていない。直前の表では Ctrl+A だけが「選ぶ」操作なので、ここで初めて「範囲を選ぶ」が出てくる）
  直し: 「ドラッグは、マウスのボタンを押したまま動かして離す操作です。ドラッグすると、コピーしたい文字の範囲を好きなように選べます。」
  （補足: 表の `Ctrl+C` は「コピーする」だけで、何をコピーするのか（先に選んだ文字）が書かれていない。説明が足りない）

- **J8**（06-extension／やってみる）
  元: 「次に、画面の上の「表示」を押し、出てきた一覧から、もう一度「表示」を押し、続けて「ファイル名拡張子」を押します。」
  種類: ぶつ切り・係り受け（「〜を押し、〜から、〜を押し、〜を押します」と、押す操作が1文に3つつながり、「出てきた一覧から、もう一度「表示」を押し」の「から」が何に係るか取りにくい）
  直し: 「次に、画面の上にある「表示」を押します。出てきた一覧の中で、もう一度「表示」を押し、続けて「ファイル名拡張子」を押してください。」

- **J9**（06-extension／やってみる）
  元: 「`sample` が無いときは、先にデスクトップに作ってください。前の節で作った `sample` を開き、何もない場所で右クリックします。」
  種類: 語順（「無いとき」の話のあとすぐ「前の節で作った sample を開き」と続き、無かった人がどうするのかが読み手任せになる）
  直し: 「前の節で作った `sample` を開き、何もない場所で右クリックします。`sample` が無いときは、先にデスクトップに作ってください。」

## 節全体について

- 05-files の説明に「〜が並びます。〜が並びます。〜が出ます。」と、左の列・右の一覧・上の帯の説明が同じ調子で3つ続く。意味は取れるので直し文は挙げない。
- 05-files は、やってみるで「デスクトップ」を押させたあとに、説明で「デスクトップは、パソコンを開いたときに最初に見える画面です」と初めて説明する。順番は内容の話なので、日本語の指摘には入れない（別の人が見る）。
- 画面に出ない見出しを指す文（「上の説明」「やってみるの例」など）、「学習者」「通し課題」などの作り手の言葉は、この章には見つからなかった。05 のヒントの「上の「フォルダの作り方」」は、画面に出る Level0 の見出しを指しているので問題ない。
- 節の終わりの中身の無いまとめ文は、見つからなかった（06 の「つながり」は何をするかを書いている）。
