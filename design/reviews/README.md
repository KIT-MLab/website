## 2. 先に知っておいてほしいこと

- **タイタニック1 の演習は、模範解答が問題文の入力の順と食い違っていた。** 問題文どおりに正しく書いても、4つのテスト全部で落ちる状態だった（9/29 に使った節）。模範解答を直した
- **問題の中身を替えたものがある（課題の id は同じ）。** 替える前に解いた人の記録は「通った」のまま残る。下の表のうち「前」と「後」が違う問題
- **組む問題を、問題文・入力・出力の形にそろえた。** 古い形（全部を地の文に書く形）では、画面に入力例・出力例が出ていなかった
- **書き換える問題の「上のコード」を「下のコード」に直した（25か所）。** 画面では、問題文の下にコード欄が出る
- **文の長さ・段落の文の数・字数は、機械が止めずに知らせるだけになった。** いま目安から外れている所は `npm run check:lessons` の先頭に並ぶ。切ると読みにくくなる文を残したもの
- **画面で確かめたのは第1章だけ。** 手元の開発用の環境では、ほかの章が「準備中」で開けなかった。機械の検査（模範解答が全部のテストで通る、例の実行結果が本文と合う、何もせずには通らない）は全部通っている

## 5. 直していないもの

- **出したい出力をそのまま `print` に書けば通る／その節の書き方を使わなくても通る。** 判定は出力しか見ないので、機械では止められない。例の値を写せば通る問題・何もしなくても通る問題は直した
- 「関数を定義してください」という問題は、関数を作らずに書いても通る（関数を呼んで確かめる判定は、入力欄を読む問題と一緒に使えない）
- 第7章の演習は、numpy を使わずに書いても通るものがある
- 読み手が「消しても失うものが無い」とした問題のうち、消したものは無い。中身を替えるか、残した
