# 練習問題集 第1章 学習者の目での読み（practice-01-learner）

対象: `src/content/practice/01-python/` の print / variable / input / format（各5問、計20問）。
学習者が持っているもの: `node scripts/taught.mjs python-02-int-float` の「ここまでに教えた」（第1章1〜6節ぶん）。
模範解答20本は `py` で実際に実行し、すべてエラー無く動き、出力が問題文と合うことを確かめた。

## 止まる（ここで学習者が進めなくなる）

- 無し。20問とも、問題文と画面の例から何を書けばよいかは分かり、模範解答に使う語・関数は第1章で一度は出ている。
  （ただし下の L1・L2 は、進めるが模範解答と同じ形には自力でたどり着きにくい。）

## 引っかかる（進めるが、迷うか、分からないまま通る）

- L1 場所: input-2, input-3, input-4, input-5 の模範解答 `print(int(input()) + int(input()))` など
  なぜ: 「1つの式の中で `int(input())` を2回書く」形は初めての組み合わせ。教えたのは `x = int(input())`（04節）と `print("こんにちは", input())`（03節、input を1つだけ）まで。04節の例・課題の解答（`x = int(input())` / `y = int(input())` / `print(x + y)`）は変数に分けている。式の中で2回呼ぶと「左から先に読まれる」ことは教えていない。input-3 は引き算なので、順番が逆だと答えが変わる。変数に分ければ自力で通るので止まりはしないが、模範解答は教えた書き方より一段進んでいる。
  案: 模範解答を変数に分ける形（教えた書き方）に直す。式の中で2回呼ぶ形を見せたいなら、先に節で教える。

- L2 場所: input-1 の模範解答 `print(int(input()) * 2)`
  なぜ: `print( int( input() ) * 2 )` と3つが入れ子になる。教えた入れ子は `int(input())` と `print(int("5") + 1)`、`print("こんにちは", input())` で、「print の中の int(input()) に掛け算」は初めての組み合わせ。★1 なのに、考えることが多い。
  案: 変数に入れる形（`x = int(input())`）を模範解答にし、04節の例（x を読んで x+1）の値を変える程度にとどめる。

- L3 場所: print-1（`120 * 3 + 80 * 2`）、print-5、input-4（`+` と `*` が混ざる式）
  なぜ: 足し算と掛け算が混ざる式。01節に「計算の順番は第2章で扱います」とあり、順番の決まりは未習。かっこで先にまとめる書き方も未習（第2章）。数学の知識で補えば通るが、教材は「この章では順番を教えない」と言っている。学習者は、書いた式が掛け算を先にするのか確信が持てない。
  案: 第1章の問題では、掛け算の結果を別々の変数か別々の項に分けて足す形にする（または 順番を第1章で一言教える）。

- L4 場所: variable-1「長方形の周り」（★1）
  なぜ: 変数を使わなくても通る。`print(int(input()) * 2 + int(input()) * 2)` で、縦も横も1回ずつ読むだけで済む（かっこも不要）。ヒントは「同じ値を何度でも使える」と書いているが、この問題の通り方は変数を要求していない。変数の話題の ★1 が、変数を使わずに通る。
  案: 縦と横の値を2回以上使う問題（周りと面積を両方出す、など）に変える。

- L5 場所: variable-3「値上げの前と後」（★2）と variable-5「動物園の入場料」（★3）
  なぜ: ★の段差が逆。variable-3 は入力3つ、計算した値4つ（値上げ後の値段・前の代金・後の代金・差）、出力3行で、新しく考えることが多い。variable-5 は入力2つ、計算2つ、出力3行（ラベル付き）で、考える量は variable-3 より少ない。variable-5 が ★3 なのは print の話題（ラベルと数を並べる）をまたぐからだが、variable-3 のほうが重い。
  案: variable-3 を ★3 にし、variable-5 を ★2 にする（または variable-3 を軽くする）。

- L6 場所: format-3 の出力指定「`×` は『かける』と打って変換すると入ります」、format-4「かっこは全角の『（』と『）』です」
  なぜ: start-02-hankaku で「全角は Python のコードとして読み取れない」と教えた。`"` の中の全角文字が使えることは、第1章では教えていない（`f"…"` の中に日本語は出るが、`×` `（` `）` などの記号は初めて）。問題文は入力の仕方まで書いていて親切だが、「コードに全角を入れてよいのは文字列の中だけ」だとは書いていない。
  案: 問題文に「文字列の `" "` の中なら全角でもよい」と一言足す（または半角の記号で済む出力例にする）。

- L7 場所: print-2 の「カンマ（`,`）」
  なぜ: 01節は `,` とだけ書き、05節は「コンマ」と呼んでいる。練習は「カンマ」。学習者が同じものと分かれば進めるが、呼び名が3通りになっている。
  案: 教材の呼び名（コンマ）に合わせる。

- L8 場所: format-2 のヒント「1mは100cmです」
  なぜ: 問題を解くのに必要な換算が、問題文ではなくヒントにしか書かれていない。1m=100cm を知っている学習者は困らないが、問題文だけでは足りない。
  案: 問題文に書く（ヒントは `{}` の話にとどめる）。

## 要らない（消しても何も失わない文・問題）

- L9 場所: input-1「2倍にする」とinput-2「2つの数の和」
  なぜ: 教えた節の課題（python-01-input-m1 は `x * 2` に書き換える、python-01-input-m2 は2つの数の和）と、問うことが同じ。練習問題集の段差の最初としては価値があるが、新しく確かめることは無い。
  （input-3 は、読む順を変えると答えが変わる引き算なので、python-01-input-b1 と似ていても「順番」を確かめている。残す。）

- L10 場所: format-2「メートルとセンチ」
  なぜ: format-1（`{age + 1}` を文の中に入れる）と確かめることが同じ（読んだ整数を `{ }` の中で計算して文に入れる）。違うのは文字列を読まないことだけ。同じ ★1 が2つ並んでいる。

- L11 場所: format-4「予定の時刻」
  なぜ: format-3 と確かめることが同じ（整数を読んで、計算した値を f文字列に入れる）。違うのは全角のかっこだけで、これは L6 の引っかかりを増やしている。消しても失うものは無い。

- L12 場所: print-4「授業の時間」
  なぜ: print-2（文字列と数の並び）と print-3（式をコンマで並べる）を足しただけで、新しく確かめることは無い。print-5 が「3行＋考える手順」で同じことを確かめている。残すなら ★1〜★2 の間の橋として残してよいが、確かめることとしては print-5 が引き受けている。

- L13 場所: variable-4「アルバイトの給料」
  なぜ: 「先に求めた値を変数に入れて、そこから次を求める」は variable-3（`before` を求めて `after - before`）と variable-5（`adult_fee` を使って合計）が確かめている。

## この節は何のためにあるか

第1章で習った書き方を、自分で式を組んで1つずつ確かめる場所。print は「出す形」、variable は「値を残して使い回す」、input は「読んで数に直して使う」、format は「文の中に値や式を入れる」を練習する。
ただし今の形だと、input-1・2 は教材の課題の繰り返し（L9）、format-2・4 と print-4・variable-4 は別の問題が確かめていることの繰り返し（L10〜13）で、20問のうち5問は消しても学習者が何も失わない。
