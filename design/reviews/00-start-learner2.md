# 00-start 学習者の目で読んだ報告（learner2）

対象: `src/content/lessons/00-start/` の01〜06（6節）。
`node scripts/taught.mjs start-01-how-to-use` は1回実行した。出力は「ここまでに教えた」が空で、この章が教材の最初であることが分かる。以後の節は、この章で読んだことだけを持っているものとして読んだ。
この章は Python を使わないので、模範解答の `.py` は無い（`solutions/` も無い）。「模範解答の行」の手順は、type・choose の正解の文字列・選択肢に当てはめた。

指摘の番号は章を通した L1〜。重い順ではなく節の順に付け、重さは見出しで分けた。

## 止まる（ここで学習者が進めなくなる）

- **L1（02-hankaku, 課題 `start-02-hankaku-4`。同じ問題が 03-symbols `start-03-symbols-2` にもある）**
  場所: 説明の「打つ前に、`半角/全角` キーを押して、日本語入力をオフにしておくと安全です。」と、課題「次の言葉を、かっこだけ半角にして打ってください `(締め切り)`」
  なぜ: 日本語入力をオフにしたままでは「締め切り」が打てない。オンのままでは `(` が `（` になる。つまり1つの文字列の途中で、オン→オフ→オンのように切り替えながら打つ必要がある。ところが節が教えているのは「打つ前にオフにする」だけで、課題はそれと反対のことを求めている。切り替えのキーも、途中で何度も切り替えてよいことも、課題の前には書いていない。「何文字目が全角か」を教えてくれる表示があるので、試行錯誤すれば抜けられる人もいるが、説明どおりにした人は止まる。
  案: 説明に「日本語を打つときだけオンにし、記号を打つ前にもう一度 `半角/全角` を押す。切り替えは何度してもよい」という1文と、`(` を打つ順の例を足す。

- **L2（05-files, 課題 `start-05-files-3`）**
  場所: 「作った `sample` を開き、その中にもう1つフォルダを作ってください」
  なぜ: フォルダを「開く」操作（ダブルクリック）が章のどこにも書かれていない。この節で出る操作は「押す」（左の列の「デスクトップ」）と「右クリック」だけで、「押す」を1回押しただけではフォルダは開かない。クリックは02のLevel0で「左のボタンを1回押す操作」と定義されており、そこから学習者は、フォルダも1回押せば開くと読む。06でも「`sample` を開き」と同じ書き方で出てくる。
  案: 05の説明に「フォルダやファイルは、左のボタンを2回続けて押す（ダブルクリック）と開く」を1文足す。

## 引っかかる（進めるが、迷うか、分からないまま通る）

- **L3（01-how-to-use, 課題 `start-01-how-to-use-1`）**
  場所: 「下に出る欄に文字を打って…」で `れんしゅう` を打つ
  なぜ: ひらがなを打つには日本語入力がオンでなければならないが、その確かめ方・切り替え方は次の02まで出てこない。入力がオフのまま `rensyuu` と出て、どうしてよいか分からなくなる人がいる。この節の最初の問題で止まると、02にたどり着く前に手が止まる。
  案: 最初の問題の下に「ひらがなにならないときは、`半角/全角` キーを押す（くわしくは次の節）」と1行足す。

- **L4（02-hankaku, 課題 `start-02-hankaku-1`）**
  場所: `( ) : = 100 ,` を打つ
  なぜ: `(` `)` `:` `=` `,` がキーボードのどこにあるかは、この節にも前の節にも書いていない。記号の位置の説明は次の03にあり、しかも `_ * [ { #` だけである。また、記号の間の空白は「半角の空白」と書いてあるのが03の課題だけで、02のこの課題は「すべて半角で打つ」としか言っていない。空白を打つのか、全角の空白でもよいのかが分からない。
  案: 問題文に「間の空白も半角で打つ」を足す。記号の場所は、見つからない人向けに `Shift+8` などの1行を Level0 に足すか、問題を03の後ろに回す。

- **L5（02-hankaku, 説明）**
  場所: 「`半角/全角` キーを押して」
  なぜ: `半角/全角` キーがキーボードのどこにあるかを書いていない。05の `Win` は Level0 で位置まで書いてあるのに、この節の `半角/全角` には無い。Level0 の「右下の `A` / `あ` をクリックしても切り替わります」が代わりにはなるが、その Level0 は、読みに行かない人もいる開閉の部分である。
  案: 「キーボードの左上にある」と位置を足す。

- **L6（02-hankaku, 説明）**
  場所: 「全角のままでは、検索でもファイル名でも、半角として扱われません。」
  なぜ: 「困る例」では「検索で見つからない」と言っていた。「ファイル名でも」は、何がどう困るのか分からない。全角のファイル名は作れるので、「扱われません」の意味が読み取れない。そもそも、この先で半角が要る理由（プログラムは半角で書く、など）が章のどこにも出てこない。
  案: 「ファイル名でも」を削るか、困る内容を一言足す。

- **L7（03-symbols, 説明）**
  場所: 「見つからない記号は、近くのキーも試してみてください。」「組み合わせるキーは、キーボードによって違います。」
  なぜ: 見つからないときに何をすればよいかが「近くを試す」だけである。`[` は Level0 の1文にしか出ないが、図（`<Keys highlight={['#', '_', '{', '*']} />`）には光らない。配列が違うキーボード（英語配列など）の人は図が使えず、「困る例」の最後の問題（別のパソコンでは通じない）が解消されないまま終わる。
  案: 図の `highlight` に `[` を足す。英語配列の人向けに「見つからないときは、ほかの人に聞く／画面のキーボード（スクリーンキーボード）を使う」など、逃げ道を1つ書く。

- **L8（04-copy, 課題 `start-04-copy-1`）**
  場所: 「コピーと貼り付けを使って、入れ替えて入力欄に入れてください」
  なぜ: この問題を解くには、`右 左` の「左」だけをコード欄から選ぶ必要がある。範囲を選ぶ方法（ドラッグ）は、この問題のあとの説明で出る。ヒントには `Ctrl+C` と `Ctrl+V` しかなく、範囲の選び方は無い。また、入れ替えた結果の間に半角の空白を自分で打つのか、コピーするのかも書いていない（「区切りは半角の空白1つです」はあるので、打てばよいと読めるが、貼り付けと打つ作業が混ざる）。
  案: 問題の前に「ドラッグ」の説明を移すか、ヒントに「選びたい文字の上でドラッグ」を足す。

- **L9（04-copy, 説明）**
  場所: 「下の入力欄に試しに1文字打ってから `Ctrl+Z` を押すと」
  なぜ: この説明の「下」にあるのは、次の課題の欄である。課題は1問ずつ出る（01で教えた）ので、この時点で、解いていない課題の欄が見えるかどうか分からない。見えなければ試せない。
  案: 「次の問題の欄で」と言う。または欄の場所を指さず「入力欄で」とだけ書く。

- **L10（04-copy, 課題 `start-04-copy-4`）**
  場所: 「真ん中の1語だけを消してください。残りは半角の空白1つで区切ります。」
  なぜ: 「水」を消しただけでは空白が2つ残る（`月  金`）。「空白1つで区切ります」で気づく人もいるが、`Backspace` のヒントは「選んだ文字は消せる」としか言わず、空白も1つ消すことは書かない。入力欄の中で、1語だけをどう選ぶか（ドラッグ、ダブルクリック、矢印キー）も、ドラッグ以外は出てこない。
  案: 問題文に「消したあと、空白が2つ並ばないようにする」を足す。

- **L11（05-files, 説明）**
  場所: 「キーボードの `Win` を押しながら `E` を押してください。」（やってみる）
  なぜ: `Win` がどのキーかは、閉じている Level0（「エクスプローラーが開かないとき」）にしか書いていない。「開かないとき」の Level0 を開くのは、一度失敗してからになる。
  案: 本文に「（窓の形のキー）」と一言足す。

- **L12（05-files, 説明）**
  場所: 「右クリック」「メニュー」（`terms` にあり、説明は Level0 だけ）
  なぜ: `右クリック` は05の Level0 で初めて定義される。06の本文は「何もない場所で右クリックします」と、定義済みの語として使う。Level0 を開かずに課題へ進んだ人は、06でこの語が分からない（05の課題のヒントは Level0 を指しているので、05では開くはずである）。
  案: 06の本文に「右のボタンを1回押す」を括弧で足す。

- **L13（05-files, 課題 `start-05-files-3`）**
  場所: 「デスクトップに `sample` という名前のフォルダを作ってください。…」
  なぜ: 選択式なので、フォルダを作らなくても、画像の読み方だけで正解を選べる。作業をしたかどうかは確かめられない。作ったフォルダは次の06で使うが、06に「`sample` が無いときは、先に作ってください」とあるので、作らなくても進める。名前を `sample` にするときに日本語入力をオフにする、という02の内容を使う場面でもあるが、確かめられない。
  案: 問題としては現状のままでよい。ただし、作ったかどうかは確かめられないことを前提に、06の誘導（「無ければ作る」）を残す。

- **L14（06-extension, 課題 `start-06-extension-2`）**
  場所: 「設定を変えたあと、`メモ` の名前の末尾には何が見えますか。」
  なぜ: 設定を変えなくても、「テキスト ドキュメント」から `txt` を連想して、選択肢3つ（`doc`、`pdf`）から選べる。拡張子の説明は、この問題のあとの「説明」にあるので、問題の時点では「拡張子」という語だけが「ファイル名拡張子」の操作に出てくる。
  案: 現状でも通れる。ただ、実際に設定を変えた人にしか分からない選択肢（例: 「ピリオドのあとに何が見えるか」ではなく見えた文字そのものを打つ type 問題）にすると抜け道が減る。

- **L15（06-extension, 課題 `start-06-extension-6`）と説明**
  場所: 「拡張子は、ファイル名の末尾にある、ピリオドから後ろの部分です。」（ヒント）と、06-2 の選択肢「ピリオドのあとに `txt`」
  なぜ: 拡張子はピリオドを含むのか含まないのかが、節の中でぶれている。06-2の選択肢は「ピリオドのあとの `txt`」が見えるものと言い、説明は `.jpg` `.py` とピリオド付きで書き、課題6の正解は `.csv`（ピリオド付き）である。ヒントの「ピリオドから後ろ」は、含むのかどうか判断できない。この課題では、選択肢に `csv`（ピリオド無し）が無いので問題は起きない。
  案: 説明に「ピリオドも含めて拡張子と呼ぶ」と書くか、含めないなら課題6の正解の書き方を揃える。

- **L16（06-extension, 説明）**
  場所: 「写真のファイルには `.jpg`、Python のプログラムを書いたファイルには `.py` がよく付きます。」
  なぜ: 「困る例」は「何で開けばよいかが分からない」と言っているが、説明は種類の例を挙げるだけで、拡張子を見ると何が分かるか（どのソフトで開くか）には答えていない。学習者は「で、なぜ表示させたのか」が分からないまま課題へ進む。`.py` は Python を知らない人には何のことか分からないが、次の章で出るので、ここでは見ておく程度でよい。
  案: 「拡張子を見ると、ファイルの種類が分かる」と1文で結ぶ。

- **L17（01-how-to-use, 説明）**
  場所: 「右上には、アカウントを作ったりログインしたりする場所があります。」
  なぜ: アカウントが何のためか、いまは作るべきなのか、書いていない。作らなくても進めるのか分からない。
  案: 「作ると、進み具合が残ります（作らなくても読み進められます）」のような一言を足すか、消す。
