## 別の書き方で解き直した結果

問題文と `<Input>` `<Output>` だけを見て、教えていない形（`sum()` `max()` `min()`、内包表記、スライス、`-(-a // b)`、`break`、文字列の各桁を `int` に直す、`x * n > sum(v)` の整数比較）で15問を書き直し、全テストケース（61件）の出力を模範解答と比べた。**全部一致した**（`bad 0`）。解き直しの途中で食い違った問題は無い。

あらかじめ潰したこと:
- append-3・append-5 は、同じ値が複数あるとき `remove` がどれを外すかで出力が変わる（例 `[8, 9, 7, 6]` と `[8, 7, 9, 6]`）ので、「先に受けた（出た）ほうの1つを外す」を問題文に書き、テストにも同じ値が複数ある場合を入れた。
- while-4 は、テストの入力行が、塔の高さが届くのに過不足なく並ぶように作った（足りないと `input()` が行を読めずに落ちる。余る行は無い）。無限ループになるテストは無い（while-1 は数が減る、while-2 はバケツ1杯が1以上、while-3 は `//` で必ず0になる、while-5 は最後に `終わり`）。
- total-5 の平均の比較は、`total / n`（小数）と整数どうしの比較で食い違わないことを確かめた（割り切れるときは同じ値、割り切れないときは整数と等しくならない）。

## 迷った所・本体に確かめること

- **教えた例に数でしか出ていない形を、変数に替えた所**:
  - total-5 の `average = total / n`（割り算の例は `7 / 2` のように数どうし。変数どうしの割り算）。
  - while-3 の `number % 10` `number // 10`（割る数は数、割られるほうが変数。`pencils // 12` と同じ形で、1つ前の話題の for-3 は `amount // k` と割る数も変数にした）。
  - while-5 の `price <= budget`（比較の例は `5 >= 5` のように数どうし。変数どうしの比較）。
  - total-4 の `range(first - 1, last)`（`range(1, 6)` は数。式を渡す形は第4章1節の `range(1, n + 1)` と同じ）。
  いずれも台帳の検査は通っている。
- **`forbid` の使い方**: while-1 は `for ` を、while-2 は `//` を禁止した（`for` で逆順に回す、割り算の切り上げで、`while` を使わずに解けるため）。total の4問は `sum()`・`max(`・`min(` を禁止し、問題文にも1文で書いた（`_cross.md` の「繰り返しで求める」の決定）。while-2 の `//` 禁止は強すぎると見るなら、問題文の「割り算は使わず」の1文と `forbid` を消してよい（その場合 `-(-a // b)` の3行でも解ける）。
- **append-2 の「0番のロッカー」**: 入力が1つの問題では、境界の検査（0・負・同値・空）を満たすために、リストに `0` を入れた。ロッカー番号が0から始まるのは少し不自然かもしれない。差し替えるなら、同値を作れるよう入力を2つ以上にする必要がある。
- **while-2 の必要な量が0**: 「あと0リットル必要」は、すでに足りている状態として問題文の `<Output>` に書いた。
- **append の `print(リスト)`**: 出力は `[420, 455, 438]` のようなリストの表示そのもの。`<Output>` に「`print()` でそのまま」と書いた（第4章4節の例が同じ形で出している）。
- **while-3 の例（`205` → `7`）**: 問題文に答えの形の例を書いた。ケース1（`4821` → `15`）とは別の値。「問題文に答えを書かない」の趣旨に反するなら、この1文を消す。各桁の意味は「各桁の数字をすべて足した値」だけでも通じる。
- **★の段差**: while-3（各桁の和、考えることは2つ）と while-4（積み木、2つ）は、考えることの数は同じ。読み手が while-4 のほうを重く感じる可能性がある（入力を繰り返しの中で読む形が、第4章5節の例にない）。
- **total の話題と前半の重なり**: total-1 の合計は for-b1（節の課題）と別（入力を読んで足す）。total-3 の最大は list-b1（節の課題の最小）と近いが、最大と最小の両方を、リストから探す形にした。for-4（利息）と同様、total-5 も「変数の入れ直し」を使うが、主題は平均と数える処理。
- **`report:practice`**: 「試せていない」は第4章全体で無し。「寄りすぎ: for と range」は前半の報告にある指摘と同じで、第4章の中心の書き方なので直していない。
