対象: 01-accuracy / 02-rule / 03-learn / 04-overfit（`<Facilitate>` と frontmatter は読んでいない。`Guess` の question と answerNote は読んだ）
読み手の立場: 大学1年・情報系でない・プログラミング初めて。

## 意味が取れない・取り違える

- J1【03-learn・説明】
  元: 「このように、データを使って規則の数を決めることを学習と呼びます。」
  種類: 言葉の選び（取り違える）。「規則の数」は「規則がいくつあるか」と読める。実際に決めているのは、規則の中に入れる数（境目の年齢）
  直し: 「このように、データを使って、規則の中に入れる数（ここでは境目の年齢）を決めることを学習と呼びます。」

- J2【04-overfit・説明】
  元: 「`fine` は学習用では 1.0 当たりますが、テスト用では 0.9 から 0.7 に下がりました。」
  種類: 主語や目的語が分からない。「0.9」が何の正解率か書かれていない。`fine` のテスト用の正解率が 0.9 だったと読める（0.9 は「女性なら生存」のテスト用の値）
  直し: 「`fine` は学習用では 1.0 当たりますが、テスト用では 0.7 でした。「女性なら生存」のテスト用の 0.9 より下がっています。」

- J3【03-learn・Guess の question（本文の最初の問い）】
  元: 「「年齢が境目より下なら生き残る」の境目を、学習用の30人でいちばん当たるように選ぶと、学習用では73.3%当たりました。学習に使わなかった残りの10人では、何%当たると思う？」
  種類: 言葉の選び（まだ教えていない語）。「境目」「学習用」はこの問いが画面でいちばん先に出るため、説明より前に出てくる。初めて読む人には「学習用の30人」が何か分からない。「学習に使わなかった残りの10人」という言い方で、かろうじて推測できる程度
  直し: 「年齢が境目より下なら生き残る、という規則で予想します。境目は、40人のうち最初の30人でいちばん当たるように選ぶと、その30人では73.3%当たりました。残りの10人では、何%当たると思う？」

## 節全体について

- 03-learn: 「訓練データ（学習用データ）」と定義したあとは「学習用」「テスト用」「テストデータ」と呼び方が混ざる。定義の1か所だけ「訓練データ」で、あとは「学習用」に揃えると読みやすい（04-overfit は「学習用／テスト用」で揃っている）
- 04-overfit・説明: 「ブールインデックス」という語が説明なしで出る（足さずに、説明が足りないとだけ記す）
- 説明の中の「N〜M行目」の行番号は、01〜04 とも実際のコードと合っていた（02 の「13〜14行目は…割って正解率を出します」は、13行目が人数を表示するだけなので、厳密には14行目のこと。直すなら「14行目は」）
