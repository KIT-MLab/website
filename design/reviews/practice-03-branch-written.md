## 迷った所・本体に確かめること

1. **`not` の問題を置かなかった。** 第3章4節が教えている `not` は `not (条件)` の1つの例だけで、`score >= 60` を逆にする使い方しか見せていない。問題文から `not` を使う必要が出る問題は、`<` や `>=` で書き換えれば通るので、`not` を確かめられない。logic の5問は、`and` `or` と `()` の混ぜ方だけで組んだ。もし `not` を問題で確かめさせたいなら、「`not` を使って」と問題文に書く形になるが、判定は出力しか見ないので強制できない。
2. **logic-5（授業の成績判定）は、第3章3節の `elif` と4節の `and` `or` を合わせる。** 問題文に「上から順に確かめ、最初に当てはまったものを表示」と手順を書いたので、考えるのは3つ（条件の書き方、並べる順、境界）。難しすぎないか見てほしい。
3. **elif-5 と if-1 の題材（送料）が近い。** 話題が違い、elif-5 は個数と値段から合計を出す手順が加わるので、同じ手順の問題ではないと判断した。
4. **if-3 は、偶数のとき `n // 2`、奇数のとき `n * 3 + 1`（掛け算と足し算が混ざる式）を使う。** 第2章4節（計算の順番）の後なので変数に分けていない。ケースに `0`（偶数なので `0`）を入れた。
5. **コロン付きの比較で `True`/`False` は出していない。** 全問、文言を出力する形。
6. **logic-2 の曜日番号は 0=日曜〜6=土曜にした。** `0` を入力に入れて検査5（境界）を通すため。1〜7 のほうが日本の学習者に自然かもしれない。変えるなら、テストの `0` を別の境界（同じ値の繰り返し）に替える必要がある。
7. **問題文の箇条書き・番号つきリスト**（elif-3、elif-5、logic-4、logic-5）は、1つの段落が3文を超える検査7と、1文60字の検査6を避けるために使った。画面でリストが崩れないか、本体で見てほしい（ほかの練習問題集の問題文には、リストを使った例が見つからなかった）。
