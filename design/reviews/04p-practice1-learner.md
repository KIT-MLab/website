## 全体の指摘（章を通した番号）

### 止まる（ここで学習者が進めなくなる）

無し。全問、「ここまでに教えたこと」と第4章の課題・ヒントの範囲で、模範解答まで届く。ただし次の L1〜L3 は、通れるが、見たことのない書き方が混ざる。

### 引っかかる（進めるが、迷うか、分からないまま通る）

- L1（02-choose / python-04p-choose-b3）: 模範解答の `same = True` と `same = False`
  なぜ: `True` `False` は、教えた一覧では「比較の答えとして画面に出るもの」（`7 > 5` → True）としてしか出ない。変数に入れて、あとで `if same:` と条件に直接使う書き方は、どこにも出ていない。`if` の条件には `score >= 60` のような比較しか書いたことがない。
  案: 「目印の変数を作る」という手を、第3章か第4章のどこかで1回見せておく。または、この問題の `hints` に「違いを見つけたら、数える変数を1つ増やす」のような、`True/False` を使わずに通れる道を書く（`count` で数える道は、既習だけで通れる）。

- L2（02-choose / python-04p-choose-b2）: 「いちばん長い値を探す」手順（`longest = times[0]` のあと、`if value > longest: longest = value`）
  なぜ: 最初の値で初期化する、リストを1周しながら大小を比べて入れ直す、という手は初めて。部品（if、for、変数の入れ直し）は個別には既習だが、`hints[0]` が言葉で手順をほぼ全部書いているので、ヒントを読めば通る。読まずに通るには、考えることが多い。さらに「合計を時間と分に直す」（`// 60` と `% 60`）も別に考える。1問に考えることが4つ（合計を出す、最大を探す、時間と分に直す、書式を合わせる）あり、最大を探すは段差が大きい。
  案: 問題を変えない。ただし最大を探す手は、1問に押し込まず、01節の問題の1つに回すか、「合計」と「最長」の片方だけの問題に分ける。

- L3（01-combine / python-04p-combine-b3）: `temps[i - 1]` と `range(1, d)`
  なぜ: `numbers[len(numbers) - 1 - i]` は第4章3節の課題の模範解答に出る。`[i - 1]` の形そのものは、教えた節の説明文には無く、`1つ前` を `i - 1` と書くのは初めての組み合わせ。ヒント「1つ前のインデックスの値を使います」は、ここまでは導いてくれるが、`i - 1` を書くかどうかは学習者が考える。`range(1, d)` で1番目を飛ばすのも、`range(1, n+1)` の形は見ているので通る。
  案: そのままでよい。もし段差を減らしたいなら、ヒントに `temps[i]` と `temps[i - 1]` の2つを並べて見せる。

- L4（01-combine / python-04p-combine-b4）: 受け付けた値が1つも無いとき
  なぜ: 問題文は「受け付けた値の平均」としか言わず、0件のときどうするかを書いていない。模範解答は `total / len(accepted)` で、0件だと割り算のエラーで止まる。テストにも0件のケースは無いので、通りはするが、学習者が自分のプログラムが 0 件でエラーになることに気づかないまま終わる。
  案: 0件を問題に入れない（今のまま）なら、問題文に「受け付けた値は1つ以上あるものとします」と1文足す。

- L5（01-combine / はじめに）: 「どれを使うかは自分で決めてください」
  なぜ: 初めて「どの節の話を使うか」を自分で選ぶ章。ヒントが毎回「第4章5節（while文）と第3章4節（and・or・not）を参考に」と節を名指しするので、実際には選ばずに済む。選ぶ練習になっていない。
  案: ヒントの2つ目（節の名指し）を、片方の問題だけ外す。または、名指しをそのままにして、はじめにの「どれを使うかは自分で決めてください」を消す。

- L6（01-combine / つながり）: 「次の練習1-2では」
  なぜ: 「練習1-2」が、画面のどこで何と書かれているかが分からない。章の題が「練習編」で、節の題が「手を選ぶ」。学習者には「練習1-2」という名前は節の題として出てこないので、次が何なのか分からない。
  案: 「次の節では」に変える。

### 要らない（消しても何も失わない文・問題）

- 場所: 01-combine「ここまでに習ったことだけで解けます。」と、02-choose「ここまでに習ったことだけで解けます。」
  なぜ: 同じ文が2節に並ぶ。ひとことで言うと、練習編の頭にいちどだけあればよい。2節目の「解き方は1つではないので」の部分だけは残す価値がある。
- 場所: python-04p-combine-b2（3の倍数または7の倍数を数える）
  なぜ: 消すと失うものは、`or` を条件の中で使うこと。ただし b1 の `and` と b4 の `and` が条件を組み立てる練習をすでにしていて、`or` だけが新しい。b2 を消すと、第4章までで `or` を問題の中で使うのが 0 回になる。**消さない方がよい**（下の表の「消したら失うもの」を参照）。

## 補足

- `forbid={['reversed', '[::']}`（b3）は、この学習者には必要ない。教えていない書き方を、止めるために書いているが、学習者はその書き方を知らない。教えていないことを禁止する文が、かえって「何か知らないものがある」と感じさせる。これは引っかかる程度。案: 問題文の「`reversed` のような書き方は使わないでください。」を消す。
- 02節の4問は、01節より1問あたりの考えることが増えている（01は2〜3、02は3〜4）。章末に向かって段差が上がるのは自然だが、b2 だけが4つで、他と比べて重い。
