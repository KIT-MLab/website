- L2（節1・python-08p-combine-b1 / b2 / b4）

  案: 変更不要。

# 節2: 手を選ぶ（python-08p-choose）

## 止まる（ここで学習者が進めなくなる）

- L5（節2・python-08p-choose-b3）
  場所: 問題文「このとき `[ 50.  50.  50.]` と `[100. 100. 100.]` の2行を表示します。」
  なぜ: 実際に `print(to_percent(table))` で出るのは `[[ 50.  50.  50.]` と ` [100. 100. 100.]]`（2行だが、外側のかっこが付き、2行目の頭に空白がある）。問題文の例は外側のかっこが無い。テストは出力を完全一致で比べるはずなので、問題文どおりに1行ずつ自分で `print(...)` すると全部不一致になる。「割合の表のまま表示」の「のまま」も、学習者には「行ごとに分けずに配列をそのまま print する」と読み取れず、例の2行を作ろうとして止まる。
  案: 例を `[[ 50.  50.  50.]` と ` [100. 100. 100.]]` の2行にそろえ、「配列をそのまま1回 print する」と言い切る。

## 引っかかる（進めるが、迷うか、分からないまま通る）

- L6（節2・python-08p-choose-b3）
  場所: 模範解答 `np.round(table / table.max(axis=0) * 100, 1)`、ヒント「表をその最大値で割って100を掛けると、割合の表がブロードキャストで一度に作れます」
  なぜ: 教えたのは配列 `* 2`（第7章1節）、配列どうしの `-`（第7章1節）、`表 - 平均の並び`（第8章3節）まで。「配列を配列で割る」「そのあとに `* 100`」は、`-` と同じ形と思えば通るが、割り算は一度も出ていない。ヒントが言ってしまっているので進める。
  案: 変更不要。気になるなら第8章3節の参照をヒントに足す。

- L7（節2・python-08p-choose-b3）
  場所: 問題文「種目ごとの最高記録を100としたときの割合を、小数第1位まで丸めて求める関数を書いてください。」
  なぜ: 「割合」が「各記録 ÷ その種目の最高記録 × 100」のことは、例の数（50 20 10 / 100 40 20 → 50, 50, 50 / 100, 100, 100）を見て自分で逆算するしかない。計算式は問題文に無い（ヒントには書いてある）。
  案: 問題文に「記録 ÷ 種目の最高記録 × 100」を一行足す。

- L8（節2・python-08p-choose-b2）
  場所: 模範解答 `cheapest = 0` / `if row[1] < row[cheapest]: cheapest = 1` / `if row[2] < row[cheapest]: cheapest = 2`
  なぜ: 位置を覚える最大探し（最小探し）が b3（節1）に続いて出るが、`range` を使わず `if` を2つ並べる形になる。for で書き直そうとすると節1の b3 の形、2つ並べるなら今の形。どちらも通る（解き方を選ぶ、という節の趣旨に合う）。「覚える変数に位置を入れる」が分かっていないと、ここで L1 のつまずきが再び起きる。
  案: 節1 の b3 で位置を覚える形をヒントに補えば、ここは自然に通る。

- L9（節2・python-08p-choose-b2）
  場所: 問題文 `1: 店2 40.0円安い`、および「小数第1位まで丸めて」
  なぜ: `round(row.mean() - row[cheapest], 1)` を f文字列に入れると `40.0` と出るが、`np.round` や `round` を付けずに `{row.mean() - row[cheapest]}` を直接入れると `40.0` ちょうどでも `33.33333333333333` のような桁になる。丸め忘れを自分で気づく手がかりは、問題文の「小数第1位まで丸めて」のみ。迷うがテストで分かる。
  案: 変更不要。

- L10（節2・python-08p-choose-b1）
  場所: 問題文「連続する3つずつの平均を、前から順に小数第1位まで1行ずつ表示してください。」
  なぜ: 個数 `n` から繰り返す回数が `n - 2` になる点を、自分で数えて出す必要がある（`range(n - 2)`）。ヒントは「開始位置を1つずつずらした範囲」としか言わず、何回ずらすかの数え方（個数 − 2）は無い。`range(n)` のままだと、最後の2回が範囲外のスライスで短い配列の平均になり、余分な行が出てテストに落ちる。気づけるが、学習者によっては時間がかかる。
  案: 例（5つなら3行）の「5 → 3」から数が出ることを、ヒントに一言足す。
