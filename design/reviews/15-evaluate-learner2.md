## 04-confusion（混同行列）

### 止まる
無し

### 引っかかる
- L7（04-confusion）場所: 「`&`の両側の比べる式は、`(pred == 1)`のように`()`で囲みます。囲まないと、正しく計算されません。」
  なぜ: 実際に `pred == 1 & passed == 1` と書くと、計算が違うのではなく `ValueError`（The truth value of an array with more than one element is ambiguous）で止まる（`py` で確認）。「正しく計算されません」と読んだ学習者は、間違った数が出ると思っているので、英語のエラーが出たとき、かっこ忘れと結び付けられない。直前の「`and`は使えず、書くとエラーになります」と同じエラーである点も分からない
  案: 「囲まないと、`and` のときと同じエラーになります」と書く。
- L8（04-confusion）場所: 「この4つの数を、予想（合格・不合格）と答え（合格・不合格）の2行2列の表に並べたものを、混同行列と呼びます。」
  なぜ: 表がどこにも出てこない。コードの出力は4つの数を1行に並べるだけなので、どれが行でどれが列か、どこに何が入るかが分からないまま「混同行列」という語だけ覚える
  案: 4つの語を2行2列に並べた小さな表を本文に1つ置く。

### 要らない
無し

### 実行結果
- `<Run>`（1つ目）: `0.75` / `1 2 0 5` / `0.75` / `3 0 2 3`（本文どおり）
- `<Run>`（2つ目）: `[ True False False  True]` / `2`（本文どおり）
- m1（8人目を1に）: `0.625` / `1 2 1 4`。空振りを1人足す位置は5か所どれでも通る
- b1: ケース1 `2 0 2 4`、ケース2 `0 0 1 0`、ケース3 `0 2 2 0`

### 課題ごとの表
| 課題 | 何を確かめるか | 未習の行 | 自分で考える数 | 抜け道 | 消したら失うもの |
|---|---|---|---|---|---|
| python-15-confusion-m1 | 「空振り」がどの位置の組み合わせかを読み取る | 無し | 1（実際は0の位置の1つを1にする） | 無し（問題文が4つの数を全部言うので、目標ははっきりしている） | 4つの場合の名前と位置の対応を、自分で動かして確かめる場面 |
| python-15-confusion-b1 | 4つの場合を、読み取ったデータで数える | 無し（入力の読み方は 03 の b1 と同じ、式は例の8〜11行目） | 1（入力を2つのリストに読む） | 無し | 薄い（03 の b1 と入力が同じで、式は例の写し。05 の b1 でも同じ4行を書く） |
