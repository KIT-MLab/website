# 第3章 条件分岐（03-branch）日本語の読み

対象: 01-if / 02-else / 03-elif / 04-andor / 05-scores の5節。地の文・課題の問題文・入力・出力・ヒントを読んだ。

## 意味が取れない・取り違える

無し

## 不自然（意味は取れる）

- J1（01-if・課題 python-03-if-m2 のヒント）
  元: 「`if number > 0:` とその下のインデントした行のように、ifの行と中身の行の組を、もう1組下に足します。」（ヒント）
  種類: 語順・係り受け（「〜のように」が何に係るのか分かりにくい。「組」がどれを指すのかも一度では取れない）
  直し: 「今ある `if number > 0:` の行と、その下のインデントした行が1組です。同じ形の組を、もう1組下に足します。」

- J2（01-if・説明）
  元: 「条件が成り立たなければ、インデントされた行は実行されません。」（説明。比べる記号の表と `==` の注意書きのあとに、1文だけ離れて置かれている）
  種類: ぶつ切り（直前の「条件が成り立つとき、下の行が実行されます。」と対の文なのに、表をはさんで離れており、何の続きか読み取りにくい）
  直し: 文は変えず、「条件が成り立つとき、下の行が実行されます。」の段落の中、その直後に移す。

- J3（02-else・説明）
  元: 「4行目の `else:` はelseです。」（説明）
  種類: 中身が無い（「elseはelseです」で何も増えない。直後の文が同じことを言っている）
  直し: 「4行目の `else:` の次の行から、ifの条件が成り立たなかったときの処理を、インデントして書きます。」（2文目の「ifの条件が成り立たなかったときの処理を、`else:` の次の行から、インデントして書きます。」とまとめ、1文にする）

- J4（05-scores・説明）
  元: 「基準点を変数にしているので、`threshold` の値を変えれば合格ラインを変えられます。」（説明）
  種類: 表記のゆれ（同じ節の中で、困る例・課題・出力では「基準点」なのに、ここだけ「合格ライン」）
  直し: 「基準点を変数にしているので、`threshold` の値を変えれば基準点を変えられます。」

## 節全体について

- 要確認（J5候補・01-if の課題 m1・m2）: 問題文が「上のコードの `number` の値を…」「上のコードに…足してください」と始まる。問題のコードが問題文の上に出ているなら問題ない。問題文の下にコード欄が出る作りなら「上の」は取り違えのもとになる（他の節の課題は「上の」を付けず「`score` の値を決めてください」と書いている）。画面の並びで確かめてほしい。
- 04-andor の説明は、`and`・`or`・`not`・混ぜる場合の各段落とも、「コード → 何が成り立ち、なぜその表示になるか」の順で一度読んで取れる。直す所は無い。
- 画面に出ない見出しを指す文、作り手の言葉、節末の中身の無いまとめは、5節とも見つからなかった。「つながり」の文はどれも次の節で何をするかを具体的に言っている。
