数の関わる所は `py` で、模範解答と「問題文どおりに書いた別の答え」を全部のテストケースで動かして確かめた。

## 章全体で確かめたこと（数）

- 全節の `<Run>` の `out`、本文中の数（第2節の8回ぶんの `6.30 → -0.63 → 6.99`、`11.89`〜`42.35`、第3節の `a ≈ 6.06`・`b ≈ 33.29`・`19.0`、第5節の「学習率0.0005で発散」）は、実際に動かした値と一致した

- 問題に要るデータ（30人の `hours`・`sleep`・`commute`・`scores`）は、どの節でもその節の最初の `<Run>` のコードに全部出ている
- 始めの値を `0` と書くか `0.0` と書くかで結果が変わるのは、「くり返す回数 0」のケースを持つ第3節・第4節・第5節の組む問題だけ（L4・L7・L10）。第6節は200回動かすので、`0` で書いても全ケース通った

  なぜ: 発散しないだけでは足りない。20回で `3.0 1.0` になる3つ目の値は 0.14〜0.86 だけで（0.01刻みで `py` で調べた）、1.05 から少しずつ下げて試す学習者が選びがちな `1.0`（`6.0 10.0`、行ったり来たりで止まる）、`0.95`・`0.9`（発散しないが3に届かない）はどれも落ちる。「発散しないのに違う」で迷う

# 第3節 直線を学習する（線形回帰）（python-13-linear）

## 引っかかる
- L4 場所: python-13-linear-b1 の回数 `0` のケースと、説明の「16〜19行目で、`w = [0, 0]` の勾配を、…」
  なぜ: 回数0では `w` が始めの値のまま表示される。`w = np.array([0, 0])` と書くと `[0 0]` と出て、模範解答の `[0. 0.]` と合わずにケース4だけ落ちる（`py` で確認。Python のリスト `w = [0.0, 0.0]` と書いた場合は通る）。問題文は `[0.0, 0.0]` と書いているが、説明の本文は `[0, 0]` と書いている

- L5 場所: 「第10章5節では、`a = 7`、`b = 30` のとき、`a` と `b` をそれぞれ増やすか減らすかの向きまでは分かりました。ですが、`a` と `b` はまだ1回も動かしていません。」
  なぜ: この続きとして `a = 7`、`b = 30` から動かすと思って読むと、例は `w = [0, 0]` から、30人で、平均二乗誤差（第10章は5人で2乗の和）で始まる。どこで切り替わったかの説明が無く、「さっきの a=7, b=30 は？」で一度戻る
  案: 「今度は30人のデータで、`a = 0`、`b = 0` から動かします」と一文足す
- L6 場所: 「式は結果だけ示します（導くのは第6部）。」

  案: 「この教材のずっと後で導きます」程度に言い換える
- L6b 場所: 「比べた結果は、どちらも `[-723.0, -127.6]` で一致します。」
  なぜ: 画面に出るのは `[-723.  -127.6]`（コンマ無し、`.0` 無し）。軽いが、出力と本文の書き方が違う
  案: 本文を出力のとおり `[-723.  -127.6]` にする
