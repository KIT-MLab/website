# 第10章（10-slope）日本語の読み 報告

読んだ節: 01-rate / 02-derivative / 03-direction / 04-partial / 05-study（番号順）。`design/authoring/examples.md` も先に読んだ。
全体として、文は短く素直で、一度読んで意味が取れないものは見つからなかった。指摘は不自然な文が中心で、全部で6件。

## 意味が取れない・取り違える

無し

## 不自然（意味は取れる）

- J1（02-derivative）
  元: 「`h` を0に近づけたときに近づいていく値を、`x = 3` での微分と呼びます。」（説明）
  種類: 同じ語の繰り返し／主語が分からない（「近づける」「近づいていく」が続き、何が近づくのかが書かれていない）
  直し: 「`h` を0にどんどん近づけたとき、傾きが近づいていく値を、`x = 3` での微分と呼びます。」

- J2（04-partial）
  元: 「7〜8行目では、関数の外で作った `hours` と `scores` を、関数の中から読んでいます。外で作った名前は、関数の中から読むことができます。」（説明）
  種類: 同じ語の繰り返し／中身が無い（2文目は1文目の言い直しで、「〜ことができます」の硬さもある）
  直し: 「7〜8行目では、関数の外で作った `hours` と `scores` を、そのまま関数の中で使っています。」

- J3（04-partial）
  元: 「`b` を固定したまま `a` だけを `h` だけ増やし、ずれの変化を `h` で割っています。」（説明）
  種類: 同じ語の繰り返し（「だけ」が1文に2回、しかも別の意味で出る）
  直し: 「`b` は変えないまま `a` を `h` だけ増やし、ずれの変化を `h` で割っています。」

- J4（05-study）
  元: 「17〜20行目は、傾きが正なら減らす、負なら増やすと判定しています。」（説明）
  種類: 目的語が分からない（何を減らす・増やすのか。直後の「`a` に当てはめた」まで読まないと分からない）
  直し: 「17〜20行目は、傾きが正なら `a` を減らし、負なら `a` を増やすと判定しています。」

- J5（03-direction）
  元: 「傾きが正なら、`x` を増やすと値も増えるので、値を減らすには左(小さい方)へ動かします。」（説明）
  種類: 何の値か分からない（「値」が `f(x)` を指す。直前の段落では `f(x)` と書いているのに、ここだけ「値」になる）
  直し: 「傾きが正なら、`x` を増やすと `f(x)` も増えるので、`f(x)` を減らすには `x` を左（小さい方）へ動かします。」
  （負のときの文「右(大きい方)へ動かすと値が減ります」も同様に「右（大きい方）へ動かすと `f(x)` が減ります」）

- J6（05-study）
  元: 「次の章では、確率の考え方を扱います。」（つながり）
  種類: 中身が無い（examples.md 4 の「次の章では、…を扱います」と同じ形。何をするのかが分からない）
  直し: 説明が足りない（次の章で実際に何をするかを、章の中身に合わせて具体的に書く必要がある。ここでは足さない）

## 節全体について

- 03-direction の `左(小さい方)`、`右(大きい方)`、説明の図のキャプション `x = 0.5 での傾き(負の場合)`、04-partial の困る例 `ずれ(差の2乗の和)` は半角の括弧で、02-derivative や 04-partial 説明・05-study 課題の `（…）` は全角の括弧。章の中で括弧の書き方がゆれている（J5 の直しは全角にそろえた）。
- 画面に出ない見出しを指す文（「上の「説明」」など）、作り手の言葉（「学習者」「通し課題」など）は、この章には見つからなかった。
