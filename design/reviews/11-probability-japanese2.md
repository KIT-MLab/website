## 不自然（意味は取れる）

- J1（04-log）
  元: 「とても小さい確率どうしを掛け合わせると0.0になってしまいます。別の組の積も0.0になると、どちらが大きいのかを比べられません。」（困る例）
  種類: 主語や目的語が分からない（「別の組」は何の組か、「どちらが」は何と何か）
  直し: 「とても小さい確率どうしを掛け合わせると0.0になってしまいます。2組の確率をそれぞれ掛け合わせた積がどちらも0.0になると、どちらの組の積が大きいのかを比べられません。」

- J2（02-distribution）
  元: 「7行目で合計を丸めているのは、小数の計算の誤差で `0.9999999999999999` と表示されるからです。」（説明）
  種類: 主語や目的語が分からない（実際の出力は `1.0` なので、「丸めなければそう表示されることがある」のか、いつもそうなのかが取り違えやすい）
  直し: 「7行目で合計を丸めているのは、丸めないと、小数の計算の誤差で `0.9999999999999999` のように表示されることがあるからです。」

- J3（05-spread）
  元: 「`reshape` は第8章5節です。」（課題 python-11-spread-b1 のヒント1）
  種類: 硬い・翻訳調（文として言い切れていない。何が第8章5節なのかが分からない）
  直し: 「`reshape` の使い方は、第8章5節にあります。」

- J4（06-scores）
  元: 「9行目は、標準化した値を50を中心とした10点刻みの目盛りに直しています。偏差値と呼ばれる表し方と同じ式です。」（説明）
  種類: 言葉の選び（偏差値という語をここで初めて出すのに、「呼ばれる表し方と同じ式」と回りくどい。「同じ式」と「呼ぶ」の関係が読み取りにくい）
  直し: 「9行目は、標準化した値を、50を中心にして10点が標準偏差1つ分になる目盛りに直しています。この値を偏差値と呼びます。」

- J5（06-scores）
  元: 「標準偏差を使えるようになったので、科目が違っても同じ基準で比べられます。」（説明の最後）
  種類: 中身が無い（「〜できるようになったので」の形で、何が増えたのかが分からない。「同じ基準」が何かも書かれていない）
  直し: 「標準化した値は、平均からの差を標準偏差で割ってあるので、散らばり方が違う科目どうしでも、同じ目盛りで比べられます。」

- J6（06-scores）
  元: 「配点は0.3・0.3・0.4、基準点は平均・配点平均のどちらも60とし、変数にします。」（課題 python-11-scores-b1）
  種類: 語順・係り受け（「どちらも」が何と何を指すのかが取りにくく、「変数にします」の目的語が配点だけか基準点もかも分からない）
  直し: 「配点は0.3・0.3・0.4とし、合否の基準点は、平均でも配点による平均でも60とします。配点と基準点は変数に入れてください。」

- J7（06-scores）
  元: 「`total = total` で足していく書き方や、`for value in scores` で1つずつ足す書き方もしないでください。」（課題 python-11-scores-b1）
  種類: 指示があいまい（`total = total` だけを見ると、何もしない文に見える）
  直し: 「`total = total + …` の形で足していく書き方や、`for value in scores` で1つずつ足す書き方もしないでください。」

- J8（06-scores）
  元: 「入力はすべて1列に読み取ってから、reshapeで人数行3列の表にします（第8章5節）。」（課題 python-11-scores-b1 のヒント1）
  種類: 言葉の選び（「1列」は、すぐ後の「3列」と紛らわしい。「1つのリスト」「1次元の配列」のほうが取り違えない）
  直し: 「入力はすべて1つのリストに読み取ってから、reshapeで人数行3列の表にします（第8章5節）。」

## 節全体について

- 01〜05 は、困る例 → コード → 説明 → 課題の運びがそろっていて、同じ形の引っかかりが何度も出る所は無かった。節の終わりの「つながり」の文も、次に何をするかが具体的に書かれている（中身が無い文は無し）。
