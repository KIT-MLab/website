### 第3章4節 and・or・notで条件を組み合わせる（python-03-andor）

**1. 分かってほしいこと**

2つの条件を `and` か `or` でつないで、1つの if に書ける。`not` を付けると、条件が成り立つかどうかが逆になると分かる。

**2. なぜ今これが要るのか**

点数が60以上80未満のときだけ「合格ラインです」と表示したい。条件は「60以上」と「80未満」の2つあるが、ここまで if に書いた条件はいつも1つだった。

**3. 使うもの と 新しく出すもの**

| | 中身 | 根拠 |
|---|---|---|
| 使う | `if` / `elif` / `else`、比べる記号（`>=` `<` `<=` `>`）、`int(input())` | 第3章1〜3節、第1章4節 |
| 新しく出す（書き方） | `条件 and 条件`、`条件 or 条件`、`not (条件)` | 下の例1・例2・例3 |
| 新しく出す（語） | and、or、not（用語集にある） | |

**出さないもの**: `True` `False` を変数に入れる書き方。

**2026-10-02 の読み直しで変えたこと**: `and` と `or` を1つの条件に混ぜて `()` でまとめる形は、今週の演習 10/6 の b5 が使うので、**例4として1つ見せることにした**（問題は置かない）。割り切れるかを `% n == 0` で調べる形は第3章2節で、比べた結果が `True` `False` になることは第3章1節で、それぞれ一文と例で教える（`design/reviews/_cross.md`）。

**4. 例で見せること**

3つとも、if 文の中で動くところを見せる。変数は `score`。

| 例 | 置く場所 | コード | 結果 |
|---|---|---|---|
| 例1（and） | 冒頭の一文のすぐあと | `score = 72` で `if score >= 60 and score < 80:` → `合格ラインです`、`else:` → `合格ラインではありません` | `合格ラインです` |
| 例2（or） | 説明の中 | `score = 120` で `if score < 0 or score > 100:` → `範囲外です`、`else:` → `範囲内です` | `範囲外です` |
| 例3（not） | 説明の中 | `score = 45` で `if not (score >= 60):` → `不合格です`、`else:` → `合格です` | `不合格です` |

説明で言うこと（これだけ）:

- `and` は、左右の条件がどちらも成り立つときだけ成り立つ。例1で `score` が `55` だったらどうなるかを一文で言う（`score < 80` は成り立つが `score >= 60` が成り立たないので、`else` のほうになる）
- `or` は、左右のどちらか一方でも成り立てば成り立つ
- `not` は、かっこの中の条件を先に確かめて、成り立つかどうかを逆にする
- 3つをまとめた表（書き方｜成り立つとき）は置いてよい。**表に書いたことを、地の文でくり返さない**

**5. 確かめること → 問題**

| 確かめたいこと | 問題の形 | 解くのに要るもの | 自分で考えること |
|---|---|---|---|
| `and` は両方が成り立たないと成り立たない | 練習（書き換える）`python-03-andor-m1`。starter は `temperature = 30` と `if temperature >= 15 and temperature < 25:`（過ごしやすい／過ごしにくい）。`過ごしやすい` と表示されるように、1行目の値を決める | 例1 | 1個（2つの条件を両方満たす数を選ぶ） |
| `or` はどちらか一方で成り立つ | 練習（書き換える）`python-03-andor-m2`。starter は `hour = 12` と `if hour < 9 or hour >= 18:`（営業時間外です／営業中です）。`営業時間外です` と表示されるように、1行目の値を決める | 例2 | 1個（どちらかの条件を満たす数を選ぶ） |
| 日本語の「または」「〜以上〜以下」を、自分で `or` と `and` に直して if / elif / else に組める | 演習（白紙から）`python-03-andor-b1`。下の仕様 | 例1・例2、第3章3節の `elif`、`int(input())` | 3個（3つに分ける順番を決める／「または」を `or` で書く／「13歳以上18歳以下」を `and` で書く） |

`not` を確かめる問題は置かない（7 に理由）。

練習の2問は、最初は例1・例2と同じ変数と数で書いた。読み手が「例の `72` と `120` を写せば通る」と指摘したので、変数と数を例と別のものに変えた（2026-10-02）。

**演習 `python-03-andor-b1` の仕様**（このとおりに書く）

- 問題文: 年齢から、入場料の区分を求めるプログラムを書いてください。
- 入力: 1行目: 年齢（0以上の整数）
- 出力: 区分を1行で表示します。6歳未満または65歳以上は `無料です`、13歳以上18歳以下は `学生料金です`、それ以外は `通常料金です` です。
- テストケース（この順。ケース1が出力例になる）: `15` `5` `6` `12` `13` `18` `19` `64` `65` `0`
- 模範解答の方針: `if age < 6 or age >= 65:` → `elif age >= 13 and age <= 18:` → `else:`
- ヒント: 1つだけ。「「6歳未満または65歳以上」と「13歳以上18歳以下」は、それぞれ1つの条件にまとめられます。この節の1つ目と2つ目のコードを見てください。」（最初は elif の順番を見るように書いたが、読み手が「`and` と `or` を使わずに elif だけで刻む道へ誘導している」と指摘したので変えた）
- `forbid` は付けない

**6. つまずきそうな所**

- `score >= 60 and < 80` と、2つ目の `score` を省いて書く。日本語の「60以上80未満」をそのまま写すとこうなる。説明で、`and` の左右にはそれぞれ条件を丸ごと書くことを一文で言う（例1の2行目を指して）

**7. 置かないと決めたもの**

| もの | 理由 |
|---|---|
| 閏年の判定（いまの演習） | 「割り切れる」を `% 4 == 0` と書く形も、`and` と `or` を `()` でまとめる形も、ここまでに例が無い。自分で考えることが4〜5個になる。課程表（`spec/30` 第4章 3.4）からは変わるので、利用者に確かめる |
| 「`and` は `or` より先に評価されます。`()` で区切ると…」 | 例の無い一文だった。例4（混ぜる形）を足し、その説明の中で「かっこを外すと `and` が先にまとまる」と言う形にした |
| 「`not` はそれ自体で新しい条件を作るわけではありません」 | 何を言いたいのか分からない文。読み手2人とも止まった |
| `not` の問題 | 例3で動くところを見れば足りる。問題にすると、例3の値を変えるだけになる |
| 節の終わりの「条件を組み合わせられるようになりました。」 | 中身が無い |

**8. 次の節へ**
