## 章について

- **この章を終えたとき、できるようになっていてほしいこと**
  1. CSV のファイルを `pd.read_csv` で表として読み込み、列の名前で列を取り出して `.mean()` `.sum()` `.max()` で集計できる

## 節ごと

### pandas 1 表を読み込む（`python-15q-read`）

**1. 分かってほしいこと**: CSV のファイルを1行で表として読み込み、列の名前で取り出した列を、numpy の配列と同じように `.mean()` `.sum()` `.max()` で集計できる。

**2. なぜ今これが要るのか**: タイタニック4 では、乗客40人ぶんの値を、列ごとに配列へ手で書き写していた。891人ぶんは書き写せない。

**3. 使うもの・新しく出すもの**

| | 中身 | 根拠 |
|---|---|---|
| 使う | `import numpy as np` の形（`import … as …`）、配列の `.mean()` `.sum()` `.max()`、`len()`、`round()`、f文字列、`print` | 第7章1・2節、第4章3節、第2章、第1章 |
| 新しく出す（書き方） | `import pandas as pd` と `pd.read_csv("train.csv")`、`print(df.head())`、`df["列の名前"]` | 例1（読む・頭の5行）、例2（列を取り出して集計） |
| 新しく出す（語） | CSV、データフレーム | 用語集に足す。「データフレーム（DataFrame）」は初出で一度だけ言い、あとは「表」と呼ぶ |

**4. 例で見せること**

- 例1: `df = pd.read_csv("train.csv")`、`print(len(df))`（891）、`print(df.head())`。**出力は実際に実行したものを見てから説明を書く。** 12列は横に入りきらず、pandas が途中の列を `...` で省く見込み（実装の担当が見え方を確かめている。報告を本体から受け取る）。省かれることと、1行が1人・1列が1つの項目であることを、出力の行を指して言う。列の意味は、この節で使うもの（`Survived`・`Pclass`・`Sex`・`Age`・`Fare`）だけを表にする。ほかの列は「あとの節で使うか、使わない」と一言
- 例2: `survived = df["Survived"]`、`print(survived.sum())`（342）、`print(survived.mean())`（0.3838…）。タイタニック1 の「342 / 891 = 38.4%」が、割り算を書かずに出ることを言う。`Survived` は生き残った人が1、亡くなった人が0 なので、合計が人数、平均が割合になる（タイタニック4 の `.mean()` と同じ）

**5. 確かめること → 問題**

| 確かめたいこと | 問題の形 | 解くのに要るもの | 自分で考えること |
|---|---|---|---|
| 列の名前を替えて、別の集計ができる | 練習（書き換える）。例2 の形のコードを渡し、「運賃（`Fare`）のいちばん高い値」を表示するように変える（512.3292） | `df["列"]`、`.max()` | 列の名前を替える、メソッドを替える（1〜2個） |
| 読み込みから集計までを、白紙から書ける | 演習（白紙から）。乗客の数、運賃の平均（`round` で小数第2位まで。32.2）、年齢（`Age`）のいちばん高い値（80.0）を、この順に3行で表示 | `pd.read_csv`、`len`、`df["列"]`、`.mean()`、`.max()`、`round` | 読み込む行を自分で書く、3つの集計を選ぶ、丸める（3個） |

- 演習は入力を使わないので判定は1組。出力の形（数だけ、3行、順番、丸め）を `<Output>` に全部書く
- 年齢の `.max()` は、欠けた値があっても数になる（80.0）。欠けた値の話は pandas 3 でするので、ここでは触れない。**年齢の平均は問題にしない**（欠けた値を飛ばして計算されることの説明が要るため）

**6. つまずきそうな所**

- 列の名前の大文字・小文字（`df["survived"]` は `KeyError`）。エラーの読み方（第6章）で読める。「集まりの進め方」の「よく詰まるところ」に書く
- `print(df.head())` の `print` を忘れると何も出ない（Colab と違う）

**7. 置かないと決めたもの**

- `df.shape`・`df.columns`・`df.info()`・`df.describe()`: 書き方が3つを超える。人数は `len(df)` で足りる
- 列を2つ以上選ぶ `df[["A", "B"]]`: scikit-learn 2 で、モデルに入れるときに出す

### pandas 2 条件で行を取り出す（`python-15q-select`）

**1. 分かってほしいこと**: 第7章3節の「条件で取り出す」が表にもそのまま使え、条件を `&` で2つ重ねられる。

**2. なぜ今これが要るのか**: タイタニック2 では、for と if で「女性で生き残った人」を1人ずつ数えた。891人の表でも、同じことを条件1つで取り出したい。

**3. 使うもの・新しく出すもの**

| | 中身 | 根拠 |
|---|---|---|
| 使う | 配列の `配列[条件]`（第7章3節）、比べる記号、`len()`、`.mean()`、関数（`def`・`return`。第5章1・2節） | 第7章3節、第3章1節、第5章 |
| 新しく出す（書き方） | `df[df["列"] == 値]`（表から行を取り出す）、文字列と `==` で比べる（`df["Sex"] == "female"`）、`(条件) & (条件)` | 例1（条件1つ）、例2（条件2つ） |
| 新しく出す（語） | 無い | |

- 文字列を `==` で比べる形は、ここが初めて。例1 の説明で一文使って言う（`"female"` は引用符で囲む。列の値が文字だから）

**4. 例で見せること**

- 例1: `women = df[df["Sex"] == "female"]`、`print(len(women))`（314）、`print(women["Survived"].mean())`（0.742…）。`[ ]` の中の条件が、第7章3節の `scores[scores >= 60]` と同じ形であることを、2つを並べて言う。取り出した `women` も表で、列の名前で列を取り出せる
- 例2: `third_women = df[(df["Pclass"] == 3) & (df["Sex"] == "female")]`、人数（144）と割合（0.5）。条件はそれぞれ `( )` で囲み、`&` でつなぐ。第3章4節の `and` は、1つの値どうしをつなぐもので、列まるごとには使えない（使うとエラーになる、と一文。エラーの例は見せない）

**5. 確かめること → 問題**

| 確かめたいこと | 問題の形 | 解くのに要るもの | 自分で考えること |
|---|---|---|---|
| 条件を自分で書き替えられる（数の列・別の記号） | 練習（書き換える）。例1 の形のコードを渡し、「運賃（`Fare`）が100より高い人」の人数と生き残った割合に変える（53人、0.7358…） | `df[条件]`、`>` | 列を替える、記号と値を替える（2個） |
| 条件2つを、引数から組み立てられる | 演習（白紙から）。等級と性別を受け取り、その人たちの生き残った割合を返す関数 `survival_rate(pclass, sex)`。判定は関数を呼んで返り値を比べる形（`kind: 'call'`）: `(1, "female")` → 0.968…、`(3, "male")` → 0.135…、`(2, "female")` → 0.921… | `&`、`df[条件]`、`.mean()`、`def`・`return` | 条件を引数で書く、2つを `&` でつなぐ、割合を返す（3個） |

- 演習の関数の中で `df` を使う。`df = pd.read_csv("train.csv")` を関数の外（上）に書く形でよい。**問題文に、読み込みの行を自分で書くことと、関数の名前・引数の順・返すもの（割合。丸めない）を書く**
- 返り値が判定で一致するか（`.mean()` の返す数の表示のされ方）は、`build:tests` の期待値を見て確かめる。人数（`.sum()`・`len`）を返す形にはしない（`56-tools-curriculum.md` 第3.1節 P2 の注）
- 例2 の「3等の女性」と同じ組は、演習の判定に入れない（写して通る）

**6. つまずきそうな所**

- `&` の両側の `( )` を忘れる（エラーになる。エラーの文を実行して確かめ、「よく詰まるところ」に、何行目のどこを見るかを書く）
- `and` と書く（上の例2 の一文）
- `=` と `==` の取り違え（第3章1節で扱った）

**7. 置かないと決めたもの**

- `|`（または）と `~`（ではない）: 書き方が3つを超える。要る場面が出た節で出す
- 取り出した行を並べ替える・数える（`.sort_values()`・`.value_counts()`）: この章の「分かってほしいこと」に要らない
- for文で1行ずつ回す形: 使わせない（遅く、pandas の書き方ではない）。「タイタニック2 では for で数えた」と言うだけ
