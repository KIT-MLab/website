### 2.1 int と float（python-02-int-float）→ 型と型変換のホーム

- 本文に足す基本:
  - int・float・str の3つの型と、互いに変える関数の小さな表（行: `int()`・`float()`・`str()`。列: 何に変えるか・例・結果）。`int()` は第1章4節、`str()` は第1章5節で出たことを1文で言う
  - 小数は近似の値なので、`0.1 + 0.2` が `0.30000000000000004` のようにわずかにずれること。表示するときは次の節の `round()` で丸めること（1〜2文）
- 表に足す行（since `python-02-int-float`）:
  - `print(type(2.5))` → `<class 'float'>` 「値の型を調べる」
  - `print(float(3))` → `3.0` 「整数を小数に」
  - `print(int("2.5"))` → 実行した最後の行（`ValueError: invalid literal for int() with base 10: '2.5'`） 「小数の文字列は int() で直せない。float() を使う」
  - `print(0.1 + 0.2)` → `0.30000000000000004` 「小数は近似なので、わずかにずれる」
  - `print(2.5e3)` → `2500.0` 「2.5×10の3乗の書き方」
- いまある `print(1e-3)` の行（分類「確率と散らばり」、since `python-11-log`）を、分類「input と型変換」へ移し、since を `python-02-int-float`、`also: ['python-11-log']` にする。第11章4節の本文が `1e-3` を一から説明しているなら、「第2章1節の表にある書き方です」の1文に縮めてよい（縮めるのは説明の文だけ。例と課題は変えない）
- 第10章2節・第11章2節・scikit-learn 4 の「小数の誤差」の説明は、そのままでよい。各所に「第2章1節」と1文で指すだけにする（文を足す場所が不自然なら、足さずに報告）

### 2.5 math（python-02-math）

- 本文に足す基本（1〜2文）: math には sqrt と pi のほかにもよく使う関数があり、一覧は節の冒頭の表にあること。`floor` と `ceil` は整数（int）を、ほかの関数は小数（float）を返すこと
- 表に足す行（since `python-02-math`）:
  - `print(math.floor(2.7))` → `2` 「切り捨て（小さいほうの整数）」
  - `print(math.ceil(7 / 3))` → `3` 「切り上げ（何箱いるか、など）」
  - `print(math.e)` → 実行結果 「ネイピア数 e（かっこは付けない）」
  - `print(math.exp(1))` → 実行結果 「e の x 乗（意味は第11章3節）」
  - `print(math.log(math.e))` → `1.0` 「自然対数（底は e。第11章4節）」
  - `print(math.log10(1000))` → `3.0` 「底が10の対数」
  - `print(math.sin(math.pi / 2))` → `1.0` 「三角関数。角度はラジアン」
  - `print(abs(-3))` → `3` 「絶対値。import は要らない（math ではない）」
  - `from math import sqrt\nprint(sqrt(16))` → `4.0` 「名前だけ持ってくると math. を付けずに使える」
