**4. 例で見せること**

例1（答えの無い表に予測を出して、2列の表にする）:

```python
import pandas as pd
from sklearn.tree import DecisionTreeClassifier

df = pd.read_csv("train.csv")
train_df = df[df["PassengerId"] <= 712]
test_df = df[df["PassengerId"] > 712]

age_mean = train_df["Age"].mean()
train_df["Age"] = train_df["Age"].fillna(age_mean)
train_df["Sex"] = train_df["Sex"].map({"male": 0, "female": 1})
test_df["Age"] = test_df["Age"].fillna(age_mean)
test_df["Sex"] = test_df["Sex"].map({"male": 0, "female": 1})

features = ["Pclass", "Sex", "Age", "Fare", "SibSp", "Parch"]
model = DecisionTreeClassifier(max_depth=3, random_state=0)
model.fit(train_df[features], train_df["Survived"])
pred = model.predict(test_df[features])

submission = pd.DataFrame({"PassengerId": test_df["PassengerId"], "Survived": pred})
print(len(train_df), len(test_df))
print(submission.head())
```

例1（答えの無い人を半分に分けて、Public と Private に見立てる）:

```python
import pandas as pd
from sklearn.tree import DecisionTreeClassifier

df = pd.read_csv("train.csv")
train_df = df[df["PassengerId"] <= 712]
test_df = df[df["PassengerId"] > 712]
age_mean = train_df["Age"].mean()
train_df["Age"] = train_df["Age"].fillna(age_mean)
train_df["Sex"] = train_df["Sex"].map({"male": 0, "female": 1})
test_df["Age"] = test_df["Age"].fillna(age_mean)
test_df["Sex"] = test_df["Sex"].map({"male": 0, "female": 1})
public = test_df[test_df["PassengerId"] <= 801]
private = test_df[test_df["PassengerId"] > 801]

features = ["Pclass", "Sex", "Age", "Fare", "SibSp", "Parch"]
for depth in [1, 3, 5, 8, 20]:
    model = DecisionTreeClassifier(max_depth=depth, random_state=0)
    model.fit(train_df[features], train_df["Survived"])
    a = (model.predict(public[features]) == public["Survived"]).mean()
    b = (model.predict(private[features]) == private["Survived"]).mean()
    print(depth, round(a, 3), round(b, 3))
print(len(public), len(private))
```

import pandas as pd
from sklearn.tree import DecisionTreeClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.model_selection import train_test_split

age_mean = df["Age"].mean()
