### 7.1 numpy の配列と要素ごとの計算（python-07-array）

- 本文に足す（1〜2文）: `np.sqrt(配列)` のように、`np.` の数学の関数も、配列の値ひとつずつに使える。一覧は「この節の書き方」の表
- 表に足す: `print(np.array([1, 2, 3]) ** 2)` → `[1 4 9]` 「2乗も値ごと」、`print(np.array([3, 4]) / 2)` → `[1.5 2. ]`、`print(np.sqrt(np.array([4, 9, 16])))`、`print(np.abs(np.array([3, -2, 0])))`、`print(np.round(np.exp(np.array([0, 1])), 3))` 「e の累乗（意味は第11章3節）」、`print(np.round(np.log(np.array([1, 10])), 3))` 「対数（意味は第11章4節）」、`print(np.maximum(np.array([-2, 0, 3]), 0))` 「値ごとに大きいほう」、`print(np.array([1.5, 2.7]).astype(int))` → `[1 2]` 「小数を切り捨てて整数の配列に」

### 7.3 条件で取り出す（python-07-select）→ True と False の配列のホーム

- 本文に足す基本（1段落、`<Run>` を1つ置いてよい）: 配列どうしを `==` で比べると、同じ位置どうしの `True` と `False` の配列になる。`True` を1、`False` を0として数えるので、`.sum()` で個数、`.mean()` で割合になる（正解率もこの形）。2つの条件の両方は `&`、どちらかは `|` で、それぞれの条件を `( )` で囲む（`and` `or` は配列には使えない）
- 表に足す（前提 `s = np.array([40, 90, 55, 70, 30])` などを各行のコードに含める）: `print(pred == y)`、`print(pred != y)`、`print((s >= 60).sum())` → `2`、`print(len(s[s >= 60]))` → `2`、`print((s >= 60).mean())` → `0.4` 「True の割合（正解率もこの形）」、`print(s[(s >= 50) & (s < 80)])` → `[55 70]`、`print(s[(s < 40) | (s >= 90)])` → `[90 30]`、`print((s >= 60) * 1)` → `[0 1 0 1 0]` 「True と False を1と0の整数にする」
- いまある行のうち、第15章3節の `(pred == y).mean()`、第15章4節の `&` を使う行、第14章1節の `(scores >= 60) * 1` は、上の行と重なる。重なる書き方の行は `since` を `python-07-select` に移して `also` に元の節（概念の説明を兼ねている行なら、元の節に残して、7.3 には上の一般の行だけ置く。どちらにしたかを報告）
- 台帳に `&` や `|` の行があれば `in` を `python-07-select` に
- 指しを足す所: タイタニック4（`08q-mlintro/04-overfit.mdx`）、第14章1節、第15章3節・4節、pandas 2（`&`）
