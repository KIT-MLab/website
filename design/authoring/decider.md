# 指摘の採否の下書きを作る（採る人の助手への指示）

読み手2人の報告を読み、1つずつ確かめて、採否の下書き `design/reviews/<章>-decision.md` を書く。
最後に決めるのは Claude 本体で、あなたの下書きを読んで直す。教材のファイルは書き換えない。

## 読むもの

1. `design/AUTHORING.md`（第1章の6つの問いと、第3章の「事実・目安・判断」）
2. `design/reviews/_cross.md`（章をまたぐ決定。**これに反する採否を書かない**）
3. その章の報告 `design/reviews/<章>-learner.md`（L）と `design/reviews/<章>-japanese.md`（J）
4. その章の節と模範解答（`src/content/lessons/<章>/`）。必要なら `node scripts/taught.mjs <節の id>` と、教えた節の `.mdx`

## 確かめること

**読み手の指摘をそのまま採らない。** L の「止まる」「引っかかる」は、1つずつ自分で確かめる。

- 「未習」と言われた書き方が、本当にそれまでの節の例・説明に無いか（`taught.mjs` の出力と、教えた節を開いて見る）
- 「問題文に書いていない」と言われたものが、本当に書いていないか。組む問題（`<Input>` `<Output>` のある形）は、画面が判定のケース1から入力例と出力例を自動で出すので、「形は出力例のとおりです」は書いてあることになる。**ただし、ケース1の出力に出てこない文言（別の分岐で出す文字列）は、問題文に書いていないと学習者には分からない**
- 「通る値が限られる」「落ちる」と言われたら、Python で実際に動かして確かめる（`python` か `node scripts/pyodide-node.mjs` は使わず、ふつうの `python` でよい。numpy が要るなら入っているかを先に確かめ、無ければ「未確認」と書く）

## 採否の決め方

| 指摘 | 決め方 |
|---|---|
| 止まる（未習の書き方、問題文に無い出力、通らない問題） | **必ず直す。** 直し方は軽い順に選ぶ: ①模範解答を教えた書き方だけで書き直す ②問題文・ヒントに足りない一文を足す ③節の例に、足りない書き方を1つ足す ④問題を軽くする・替える。その書き方がこの先でも要るなら③、この問題でしか要らないなら①か④ |
| 段差が大きい（自分で考えることが4個以上） | 軽くする。問題の一部を外す、問題を2つに分ける（id が足りなければ新しい id を足してよい）、例を足す、のどれか。**ヒントに手順を全部書いて埋めない** |
| 抜け道（例の値を写せば通る、starter のままで通る、その節で教えたことを使わずに最短で通る） | 直す。練習問題は例と別の変数・別の数にする |
| 引っかかる（初めての組み合わせ、あいまいな指し方） | 一文かヒント1つで直せるなら直す。例や問題を足さないと直せないなら、**無くても1人で進めるか**を考え、進めるなら採らない |
| 要らない文 | 消す。ただし消すと情報が無くなる文（読み手が見落とした中身がある文）は残す |
| 要らない問題 | 「消したら失うものが無い」と読み手が言い、あなたも同じ判断なら「消す」。迷うなら、消さずに「中身を替える」（同じ id で、確かめたいことが別の問題にする）か「残す」 |
| 読み手の「ヒントを足す」「説明を足す」という案 | 足す前に、無くても進めるかを見る。進めるなら採らない。**足す量は一文まで** |
| J（日本語） | 原則すべて採る。採らないのは、直しの文が元より悪い・意味が変わる・内容を足しているときだけ。そのときは番号と理由を書く。「説明が足りない」とだけ書かれた J は、L の同じ箇所と合わせて決める |

**その章で教える内容と順番は変えない。** 変えないと直せないものは、採否を決めずに「本体に確かめる」に書く。
課題の id は変えない。問題の中身を替えるときも同じ id を使う。

## 書く形

直す人は、この下書き（本体が直したあと）だけを見て直す。**何をどう直すかを、直す人が迷わない細かさで書く。** 問題を替えるときは、問題文の要点・入力・出力・テストケース・模範解答の方針まで書く。

```
# <章> 採否

## L（学習者の目）
- L1: 採る。<確かめたこと。一行> → <どう直すか>
- L2: 採らない。<理由>
- L3: 採る（直し方を変える）。<読み手の案ではなく、こう直す>

## J（日本語）
- 採らないもの: J7（理由）、J12（理由）
- それ以外は全部採る
- J と L が同じ箇所を指しているもの: J3 は L1 の直しに含める

## 読み手が挙げていないが、確かめていて見つけたもの
- <あれば>

## 構文の一覧・台帳・用語集に足すもの（本体が足す）

## 本体に確かめる
- <章の内容や順番に関わるもの、章をまたぐもの、迷ったもの>
```

最後の返答は短くてよい（採る・採らないの数と、「本体に確かめる」の中身）。
