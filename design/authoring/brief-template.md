# 設計メモの型

章を書く前に、Claude 本体が `design/briefs/<章>.md` に書く。書き手はこれだけを見て書く（`AUTHORING.md` 第4章 ②）。

**欄を埋めるための型ではない。** 下の問いに答えていくと、節に置くものが決まる。答えが「無い」なら、その欄は「無い」と書く。問題が0問の節、冒頭の一文だけで例に入る節があってよい。

書く前に `node scripts/taught.mjs <節の id>` を出す（新しい節は、1つ前の節の id で出して、その節のぶんを足して読む）。

---

## 章について

- **この章を終えたとき、何ができるようになっていてほしいか**（2〜4個。「〜を書ける」「〜を見て〜と言える」の形）
- **この章に入る時点で、あやふやかもしれないこと**（根拠つき。学習者の像 `spec/35-…` から、この章に関わるものだけ）
- **点数表の筋**: 前の章の完成形から何が増えるか（`HANDOFF.md` 第6章。前の章より縮まないこと）

## 節ごと

### <節の番号と題>（id）

**1. 分かってほしいこと**（一文。主語は学習者）

> 例: 2つの条件を `and` か `or` でつないで、1つの if に書ける。

**2. なぜ今これが要るのか**（学習者が、説明を読む前に納得できる理由。一文）

> 例: 「60点以上80点未満」は、ここまでの書き方だと if の中に if を入れるしかない。

これが節の冒頭になる。**「〜できません」の形でなくてよい。** 前の節の続きとして自然に入れるなら、それでよい。

**3. 使うもの（もう持っている）** と **新しく出すもの**

| | 中身 | 根拠 |
|---|---|---|
| 使う | | `taught.mjs` の行、または教えた節 |
| 新しく出す（書き方） | | この節の例のどれで見せるか |
| 新しく出す（語） | | 用語集に足す語 |

- 「使う」に書いたものが `taught.mjs` に出てこないなら、**まだ教えていない。** この節で教えるか、前の節に戻って足すか、使わない形に変える
- **書き方の組み合わせも数える。** `%` と `==` をそれぞれ教えていても、`x % 4 == 0` で「割り切れる」を調べる形は別に1つ見せないと出てこない

**4. 例で見せること**（`<Run>` で実際に動くところを見せるもの）

新しく出す書き方のうち、**問題を解くのに要る基本は、どれも1回は動くところを見せる。**
表にだけ載せた書き方（`spec/10` 第2.4節）も問題に使ってよいが、例で見せた書き方と同じ形の応用（`math.sqrt` を見せて `math.sin`）にとどめ、節の最初の問題には使わない。

**5. 確かめること → 問題**

| 確かめたいこと | 問題の形 | 解くのに要るもの（全部が 3 の表にあること） | 例から答えまでに自分で考えること |
|---|---|---|---|
| | 練習（書き換える）／演習（白紙から）／確認（選ぶ）／打つ | | 1〜3個を、言葉で並べる |

- **「確かめたいこと」が先にあり、問題はそのあとに決まる。** 確かめたいことが1つなら1問。同じことを2問で確かめない
- 自分で考えることが0個なら、写せば通る。その問題は要らない。**例に出した値をそのまま入れて通る問題も0個である。** 練習問題は、例と別の変数・別の数で作る
- ヒントが、その節で教えたことを使わない解き方へ誘導していないか4個以上なら段差が大きい。例を足すか、問題を分けるか、軽くする
- 演習（白紙から）を置けない節は、理由を書く（frontmatter の `nobuild` になる）
- 模範解答の方針を一行で書く。**問題文に書いていないことを、答えが出していないか**（出力の形、出す順番、行の頭に付けるもの）

**5.5 ホーム**（`spec/10` 第2.4節）

- この節は、どの話題のホームか（無ければ「無い」）。ホームなら、その話題の基本を本文で一通り教え、ほかのよく使う書き方を表に載せたか。調べに戻った人が「〜はどう書くんだっけ」で困るものが抜けていないか
- この節で使う書き方・語のうち、ホームが別の節にあるものは、軽く触れてそこを指しているか。ホームがまだ無いなら、本来の章のホームに先に足す

**6. つまずきそうな所**（根拠があるものだけ。無ければ「無い」）

**7. 置かないと決めたもの**（理由つき）

> 例: 閏年の判定。`and` と `or` を1つの式に混ぜる形と、割り切れるかの判定を同時に初めて使うことになり、自分で考えることが4個を超える。練習問題集の★3に回す。

**8. 次の節へ**（次の節でこれを使う場面が決まっているなら一文。無ければ書かない。節の終わりの「〜できるようになりました」は書かせない）

## 見てほしい所（利用者へ）

採る段（`AUTHORING.md` 第4章 ⑥）のあとに書く。

- 課程を変えた所（課程表と違う問題にした、節を分けた、など）
- 採るかどうか迷った所
- 目安を外したままにした所と理由
