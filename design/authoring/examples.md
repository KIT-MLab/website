# 文の実例集（直す前 → 直した後）

書き手と、日本語の読み手が最初に読む。決まりではなく実例である。**同じ形の文を書きそうになったら、右の形にする。**

増やし方は `AUTHORING.md` 第6章。利用者に直された文、読み手が挙げて採った文を、ここに足す。1つの種類につき5つくらいまで。増えたら古いものと入れ替える。

出どころの印: 【利】利用者の指摘・判断　【直】公開ずみの教材で実際に直したもの　【読】読み手が挙げたもの（2026-10-02 の試し。教材はまだ直していない）

---

## 1. 作り手の言葉が、学習者に見える所に出ている

原稿の印（困る例・やってみる・説明・課題・つながり）と、設計で使う言葉（学習者、通し課題、組む・変える）は、画面には出ない。

| 直す前 | 直した後 | |
|---|---|---|
| 上の「説明」で見た、変数に値を代入する書き方を思い出してください。 | `=` で名前に値を結び付ける書き方を使います。右には `a + b` を書けます。 | 【直】 |
| 「やってみる」の例では `score` が `55` です。 | 最初のコードでは `score` が `55` です。 | 【読】 |
| 次の節では、…合否を予想する通し課題に取り組みます。 | 次の節では、勉強時間と睡眠時間の両方から合否を予想するプログラムを書きます。 | 【読】 |
| 表示名は他の学習者には見えず、運営にだけ見えます。 | 表示名はほかの人には見えず、運営にだけ見えます。 | 【読】 |
| メンバーの画面 ／ 入る・出る ／ 運営の画面へ | マイページ ／ ログイン・ログアウト ／ 管理画面へ | 【利】 |
| 集まりの問題 ／ みんなの工夫の表 | 今週の演習 ／ 試したことの記録 | 【利】 |
| 道具（「ここまでの道具を使って」） | 書き方、習ったこと | 【利】 |

画面に出す名前は、世の中のウェブサイトや入門書でふつうに使われている呼び名に合わせる【利】。

## 2. 何の値か、何を指すかが書いていない

| 直す前 | 直した後 | |
|---|---|---|
| 値は `11.89` から `42.35` まで増えてしまいました。 | `f(x)` の値は `11.89` から `42.35` まで増えます。 | 【読】 |
| 学習率0.05は20回動かしても3に届かず、0.3はほぼ届きます。 | 学習率が0.05のときは、20回動かしても `x` が3に届かず、0.3のときはほぼ届きます。 | 【読】 |
| 複数を組み合わせるときは、`()` で区切ると… | `and` と `or` を組み合わせるときは、`()` でくくると… | 【読】 |
| 発散しない学習率にすると、3行目も 3.0 1.0 に近づきます。 | …表示の3行目も 3.0 1.0 に近づきます。（コードの3行目と取り違える） | 【読】 |
| 1行目の `{name}` には… | 3行目の `{name}` には…（行番号は実際のコードで数える） | 【直】 |

## 3. 語順・係り受け

| 直す前 | 直した後 | |
|---|---|---|
| 2つの条件を同時に満たすかどうかを、1つのifでまだ書けません。 | 2つの条件を同時に満たすかどうかは、まだ1つのifでは書けません。 | 【読】 |
| 入力欄から学習率を3つ、続けてくり返す回数を読み取ってください。 | 入力欄から学習率を3つ読み取り、そのあとに、くり返す回数を読み取ってください。 | 【読】 |

| 入力欄の行が尽きた状態で `input()` を呼ぶと… | 入力欄に読む行が残っていないのに `input()` を呼ぶと… | 【直】 |

## 4. 中身が無い文

読んでも何も増えない文は、直さずに消す。

| 直す前 | 直した後 | |
|---|---|---|
| 条件を組み合わせられるようになりました。次の節では、… | 次の節では、ここまでに習ったことを使って、点数表に合否を付けます。 | 【読】 |
| 学習率が大きすぎると発散することを見ました。次の節では、… | 次の節では、この繰り返しを使って、直線を実際のデータに合わせます。 | 【読】 |
| `not` は条件の結果を反転させます。それ自体で新しい条件を作るわけではありません。 | `not` は、後ろの条件が成り立つかどうかを逆にします。（2文目は何を言いたいのか分からないので消す） | 【読】 |
| 次の章では、平均をきれいな桁で表示し、基準点を変えやすくする書き方を扱います。 | 次の章では、平均の長い小数を短く丸め、合格の基準点も並べて表示します。（何をするのかを具体的に） | 【直】 |

## 5. 言葉の選び

| 直す前 | 直した後 | |
|---|---|---|
| 添字 ／ 既定値 ／ 字下げ ／ 剰余 | インデックス ／ デフォルト値 ／ インデント ／ 余り（調べたときに出てくる言い方。`spec/10` 第5.1節） | 【利】 |
| 第2引数 | 2つ目の引数 | 【直】 |
| `and` は `or` より先に評価されます。 | `and` は `or` より先に計算されます。（「評価」は教えていない語） | 【読】 |
| 両側が両方成り立つとき | 両側の条件がどちらも成り立つとき | 【読】 |
| 話題の見出し「商 // と余り %」 | 「切り捨て除算と余り」（教材の目次らしい言葉に） | 【利】 |
| 節の参照「7.1節」 | 「第7章1節」 | 【利】 |

## 6. 問題文

問題文だけを読んで、何を出せば正解かが決まること。

| 直す前 | 直した後 | |
|---|---|---|
| 上のコードの `age` を `30` に変えて実行してください。 | `33` と `23` が表示されるように、`age` の値を決めてください。（答えを書かない。出したい結果を言う） | 【直】 |
| 閏年は4で割り切れる年です。ただし100で割り切れる年は除きます。ただし400で割り切れる年は含みます。 | 4で割り切れる年はうるう年です。ただし、100で割り切れる年はうるう年ではありません。それでも、400で割り切れる年はうるう年です。 | 【読】 |
| 問題文は「閏年」、表示する文字列は「うるう年」 | どちらも「うるう年」（1つの問題の中で表記を変えない） | 【読】 |
| 動かしたあとの値が `f(0)` より大きい学習率は「発散」と表示してください。（模範解答は行の頭に学習率も出している） | 出力の欄に「各行の最初に学習率を表示します」と書く。**模範解答が出しているものは、全部問題文に書く** | 【読】 |
| 入力欄の2行から数を2つ読み取り、…`小数:5.0 整数:5` のように、間に半角空白を…（全部を1文に） | 問題文・入力・出力に分ける（`spec/10` 第3.11節） | 【直】 |

## 7. ヒント

| 直す前 | 直した後 | |
|---|---|---|
| 1行目の `print` の式から先に `age` を求めてください。 | 最初の `print(age + 5)` が `33` になるには、`age` がいくつならよいかを考えます。 | 【直】 |
| `%` を使って割り切れるかどうかを確かめます。第2章の内容を思い出してください。（第2章に、割り切れるかを調べる例は無い） | 教えていないことを「思い出して」と書かない。その形を節の例で見せてから、「この節の2つ目のコードを見てください」と指す | 【読】 |
| 発散したかどうかは、動かす前の値 f(0) と、動かしたあとの値を比べれば分かります。（問題文の言い直し） | 消す。思いつかなければヒントは0個でよい | 【読】 |
